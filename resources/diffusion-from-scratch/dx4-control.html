Fine-tuning and control: LoRA, DreamBooth, ControlNet, inpainting and editing

Training a foundation model costs millions of dollars, but you can adapt one for a few dollars. This part covers the standard adaptation and control techniques, what each changes, what it costs and when to choose it.

LoRA in detail

The idea

A weight matrix W of shape d_out x d_in is frozen. Add a trainable low-rank update: W' = W + (alpha / r) B A, where A is r x d_in, B is d_out x r and r (the rank) is small (4 to 128). B starts at zero, so the model begins exactly unchanged. Only A and B receive gradients, which cuts optimiser memory and storage dramatically.

mats, r = 160, 8

Where it is applied and what rank means

For diffusion, LoRA is usually attached to the attention projections (query, key, value, output) in the U-Net or DiT, and sometimes to the text encoder and convolutions. A larger rank gives more capacity (more detail, more risk of overfitting and larger files). Typical practice: rank 8 to 32 for styles, 4 to 16 for characters, learning rate about 1e-4, a few thousand steps.

Using and combining LoRAs

Weights can be merged into the base model (W + scale B A) for zero inference overhead, or loaded at runtime with a scale between 0 and 1 (0.7 means 70 percent of the effect). Several LoRAs can be added together; too many conflicting ones cause artefacts. QLoRA-style training keeps the base weights in 4 or 8 bits to save memory.

# A rank-1 update changes the output only along one direction: W' = W + b a^T
W = [[1.0, 0.0], [0.0, 1.0]]
b = [0.5, -0.5]        # d_out x 1
a = [1.0, 2.0]         # 1 x d_in
Wp = [[W[i][j] + b[i] * a[j] for j in range(2)] for i in range(2)]
x = [3.0, 1.0]
print("base output   :", [sum(W[i][j] * x[j] for j in range(2)) for i in range(2)])
print("with LoRA     :", [sum(Wp[i][j] * x[j] for j in range(2)) for i in range(2)])
print("delta  = b (a.x):", [bi * sum(aj * xj for aj, xj in zip(a, x)) for bi in b])

Output

base output   : [3.0, 1.0]
with LoRA     : [5.5, -1.5]
delta  = b (a.x): [2.5, -2.5]

Why is B initialised to zero in LoRA?

  • To save memory Not the reason.
  • So the adapted model starts identical to the base model Correct.
  • To make A zero too No.
  • To speed up merging No.

W + B A = W when B = 0, so training begins from the pretrained behaviour.

Self-check

What does LoRA change and what does it cost?

It adds trainable low-rank matrices B A to frozen weights, with r (d_in + d_out) parameters per matrix, a tiny fraction of the full count.

DreamBooth and textual inversion

Textual inversion

Freeze the whole model and learn one new word embedding (a pseudo-token such as <my-cat>) so that prompts using it recreate your concept. It trains in minutes, produces a tiny file, but cannot teach new details the model cannot already express.

DreamBooth

Fine-tune the model to bind a rare identifier (sks dog) to a specific subject from 3 to 30 images, while a prior preservation loss keeps the general class meaning (dog) intact: you also train on class images generated by the original model so that "dog" does not collapse into your dog. Without it, language drift and overfitting appear: every dog looks like yours.

SettingGuidance
Images5 to 20, varied angles, lighting and backgrounds, same subject
CaptionsA rare token plus the class, a photo of sks dog, optionally richer captions
Steps400 to 1,500 at a small learning rate (about 1e-6 full fine-tune)
Prior preservation100 to 200 class images, weight 1.0
LoRA-DreamBoothMuch cheaper, usually good enough

Common failures: overfitting (the subject appears in every image regardless of the prompt, background copied), underfitting (the subject is not recognisable), and loss of style flexibility. Fix with fewer steps, lower learning rate, more variety, prior preservation or a lower LoRA scale.

How this gets asked

What does the prior preservation loss in DreamBooth prevent?

  • Overheating No.
  • Language drift: the class word losing its general meaning and every image looking like your subject Correct.
  • Slow training No.
  • Large files No.

It trains on class images generated by the original model.

Self-check

DreamBooth versus textual inversion?

DreamBooth fine-tunes weights to bind a rare token to a subject; textual inversion only learns one embedding, so it is lighter and less expressive.

ControlNet and adapters

Structural control

A text prompt cannot say "this exact pose" or "these exact edges". ControlNet adds spatial control without damaging the base model:

  1. Make a trainable copy of the U-Net encoder blocks, fed with the control image (Canny edges, depth, pose skeleton, segmentation, scribble).
  2. The original weights stay locked.
  3. Connect the copy to the decoder through zero convolutions (1 by 1 convolutions initialised to zero), so at the start the copy contributes nothing and training cannot break the pretrained behaviour.

Lighter alternatives

Control strength is a scale applied to the added features; lowering it (0.5 to 0.8) lets the prompt contribute.

How this gets asked

Why does ControlNet connect through zero convolutions?

  • To make it faster Not the reason.
  • So training starts with no effect and cannot damage the pretrained model Correct.
  • To avoid GPUs No.
  • To remove noise No.

The added branch contributes nothing until its zero weights are learned.

Editing: img2img, SDEdit, inpainting

img2img (SDEdit)

Do not start from pure noise. Encode the input image, add noise only up to an intermediate timestep, then denoise from there. The strength parameter in [0, 1] chooses how much noise: low strength keeps the layout, high strength lets the prompt override it.

steps = 30
for strength in (0.2, 0.5, 0.8, 1.0):
    run = int(steps * strength)
    print("strength %.1f -> start at step %2d, run %2d denoising steps (%.0f%% of full cost)" % (strength, steps - run, run, 100 * run / steps))

Output

strength 0.2 -> start at step 24, run  6 denoising steps (20% of full cost)
strength 0.5 -> start at step 15, run 15 denoising steps (50% of full cost)
strength 0.8 -> start at step  6, run 24 denoising steps (80% of full cost)
strength 1.0 -> start at step  0, run 30 denoising steps (100% of full cost)

Inpainting and outpainting

Fill a masked region consistently with the rest.

  • Inpainting-trained models take extra input channels: the mask and the masked image, concatenated to the latent. They are trained on random masks.
  • Without a special model, a trick (RePaint) denoises the whole image but, at each step, replaces the known region with a correctly noised copy of the original, so only the hole is generated.
  • Outpainting extends the canvas with the same mechanism.

Blend mask edges softly, and match the lighting and the denoising strength to the context.

Prompt-level editing

Prompt-to-prompt keeps the cross-attention maps of the original generation while changing words, editing objects without moving the layout. InstructPix2Pix conditions on an input image and an instruction ("make it winter") and is trained on synthetic edit triples. DDIM inversion recovers a noise that regenerates a real image, then you regenerate with an edited prompt (DX2).

Choosing a method

Need a style or a character: LoRA. A specific person or object with fidelity: DreamBooth LoRA. Exact pose or layout: ControlNet. Match a reference image's look: IP-Adapter. Change part of an image: inpainting. Change the whole image gently: img2img.

Interview questions: Diffusion control

12 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What is LoRA and why is it popular?

Low-rank adaptation freezes the base weights and trains small matrices B A added to attention layers, using about 0.1 to 1 percent of the parameters, producing tiny files that can be merged or swapped at inference.

Basic How many parameters does a rank-r LoRA add to a d_out by d_in matrix?

r times (d_in + d_out).

Medium DreamBooth versus textual inversion?

DreamBooth fine-tunes model weights to bind a rare token to a subject with prior preservation. Textual inversion trains only a new token embedding, so it is lighter but less expressive.

Medium What is prior preservation loss?

A regularisation that trains on class images generated by the original model so the class word keeps its general meaning and the model does not drift or overfit.

Medium How does ControlNet add spatial control without harming the base model?

It clones the encoder as a trainable branch fed with the control map and connects it to the frozen U-Net through zero-initialised convolutions, so training starts as an exact no-op.

Medium Explain img2img and the strength parameter.

Encode the input, add noise only to an intermediate timestep, then denoise. Strength sets how much noise: low keeps the layout, high lets the prompt override.

Medium How does inpainting work?

Inpainting-trained models receive the mask and masked image as extra channels. Alternatively, at each step replace the known region with a noised copy of the original so only the hole is generated.

Advanced What failure modes appear when fine-tuning on a few images?

Overfitting (the subject appears everywhere, backgrounds copied), language drift, catastrophic forgetting of general abilities; mitigate with fewer steps, lower learning rate, regularisation images and LoRA scale.

Advanced IP-Adapter versus ControlNet?

IP-Adapter injects a reference image's CLIP features through extra cross-attention to transfer appearance or style; ControlNet injects spatial structure maps such as edges, depth or pose.

Advanced How can you edit a real photo with a text prompt while preserving layout?

DDIM-invert the photo to a noise code, reuse or blend cross-attention maps (prompt-to-prompt), regenerate with the edited prompt, or use an instruction-tuned editor such as InstructPix2Pix.

Advanced How do you choose a LoRA rank?

Start at 8 to 32 for styles and 4 to 16 for characters; raise rank for more capacity if underfitting, lower it if overfitting, watching file size and generalisation.

Advanced Why does generating far from the training resolution cause duplicated subjects?

The model learned composition at specific sizes; larger canvases are treated as several images. Use hires fix, tiled approaches, or models trained on multiple aspect ratios.
