What does the U-Net predict during standard DDPM training?

  • The clean image x_0 It can be derived from the noise, but it is not the training target here.
  • The noise that was added to the image Correct.
  • The timestep t t is an input, not an output.
  • The next, slightly cleaner image That is what the sampling formula computes from the prediction.

The target is the noise tensor, and the loss is the MSE between it and the prediction.

Which statement about the noise schedule is correct?

  • It is learned by the U-Net No learnable parameters are involved.
  • It is fixed in advance, before training starts Correct.
  • It is updated by Adam each epoch The optimizer only touches network weights.
  • It is only used when sampling It is used in training (shortcut formula) and in sampling.

Betas are a plan written down in advance. The network never changes them.

Why can training jump straight to timestep t without adding noise t times?

  • The sum of independent Gaussians is Gaussian, so t steps collapse into one closed-form step Correct.
  • PyTorch caches the noise from earlier epochs Caching is not involved.
  • The network undoes the loop internally The forward process has no network.
  • Beta is the same at every step Not required; the product of alphas handles varying betas.

x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * noise follows from composing the steps.

Why is a U-Net a natural denoiser?

  • Input and output have the same shape, and skip connections carry fine detail across Correct.
  • It has no learnable parameters It has millions.
  • It only works on 1D signals It is a convolutional image architecture.
  • It avoids needing a loss function It is trained with the usual MSE.

Downsampling gives context, upsampling restores resolution, and skips keep sharp detail.

Why is the timestep fed to the network?

  • The image has no pixels without it Pixels are always present.
  • To tell it how noisy its input is, since denoising t = 10 differs from denoising t = 900 Correct.
  • To choose the learning rate The learning rate is set in the optimizer.
  • To pick the batch size Unrelated.

The embedding of t is added into every ResBlock.

Why does the DDPM sampler add fresh noise at every step except the last?

  • Each reverse step is a draw from a Gaussian, and the noise keeps outputs varied Correct.
  • To make training faster Sampling does not train anything.
  • To avoid needing the U-Net The U-Net is called at every step.
  • Because the last step has no U-Net call It does have a call; it just adds zero noise.

Without it samples drift toward bland, repetitive output. The final step adds none so the image is clean.

What is the main weakness of the linear schedule at T = 1000?

  • It never reaches pure noise alpha_bar ends near 4e-5.
  • It destroys the signal too early, so many steps see near-static Correct: alpha_bar is about 0.08 at t = 500.
  • It needs a second network No.
  • It cannot be used with mixed precision Unrelated.

The cosine schedule spreads the destruction out; alpha_bar is about 0.49 at t = 500.

With EMA enabled, which weights do you use to generate final images?

  • The raw weights from the last step These jitter from batch to batch.
  • The shadow EMA copy Correct.
  • A random mixture of checkpoints Not a technique.
  • The initial random weights These have learned nothing.

Train with the real weights and sample with the smoothed EMA copy.

What is GradScaler for?

  • Scaling images to 0-1 That is a data transform.
  • Preventing fp16 gradients from underflowing, by scaling the loss up and gradients back down Correct.
  • Increasing the batch size It does not change batch size.
  • Clipping gradients to a maximum norm That is clip_grad_norm_, a separate step.

Small gradients vanish in 16-bit floats, so the loss is multiplied up before backward and unscaled before the step.

In classifier-free guidance training, how often is the real label replaced with the null label?

  • Never Then the model could not run unconditionally.
  • About 10% of the time Correct.
  • About 50% of the time Too much; conditioning would be learned poorly.
  • Always Then the model would ignore labels.

One model learns both modes, so sampling can compare conditional and unconditional predictions.

Loss becomes nan after some training. What is the best first response?

  • Increase the learning rate That makes divergence more likely.
  • Lower the learning rate and add gradient clipping Correct.
  • Remove the timestep embedding That would break the model.
  • Switch to a larger image size That raises memory use and does not address instability.

A huge gradient creates a feedback loop. Clipping caps the step size and a lower learning rate calms it.

Why is attention used only at the bottleneck?

  • Attention cost grows with the square of the number of positions, and the bottleneck has the fewest Correct.
  • Attention cannot run on a GPU It runs fine.
  • Convolutions already contain attention They do not.
  • The bottleneck has the most pixels It has the fewest.

Cheap there, and global context matters most at the coarsest scale.

What changes when you switch from DDPM sampling to DDIM?

  • The model must be retrained The same trained weights are used.
  • Only the sampling loop changes, and it can skip timesteps Correct.
  • The noise schedule is relearned It is fixed.
  • The loss becomes cross-entropy Training is unchanged.

DDIM visits, say, every 20th timestep, using the same model.

Why does each image in a batch get its own random timestep?

  • So the network sees all noise levels over many batches Correct.
  • To save GPU memory It does not.
  • Because t must be unique per image Duplicates are fine.
  • To avoid computing the loss The loss is still computed.

At generation time the network must handle every timestep from T down to 0.

Loss is falling but generated images are still pure noise. Which is the most useful first check?

  • Train longer, then verify the sampling formula line by line Correct.
  • Delete the checkpoints That removes your progress.
  • Raise the batch size to 256 Unlikely to fix a sampling bug and impossible on 4GB.
  • Turn off the noise schedule Nothing works without it.

A falling loss shows the model is learning, so a sampling bug or too little training is the likely cause.

  • It can jump to any timestep in closed form
  • By the last timestep the image is close to pure Gaussian noise

The forward process is a plain formula. The network is only needed for the reverse direction.

Select all true statements about classifier-free guidance.

  • One model learns both conditional and unconditional generation
  • It needs a separate classifier network
  • Sampling needs two network evaluations per step
  • A guidance scale of 1.0 adds no extra push beyond the conditional prediction

The name says it: no classifier is needed.

A pixel has x_0 = 1.0, the noise is 0.5, and alpha_bar_t = 0.25. What is x_t? (3 decimals)

sqrt(0.25) * 1.0 + sqrt(0.75) * 0.5 = 0.5 + 0.8660 * 0.5 = 0.933.

Two steps have beta = 0.1 and beta = 0.2. What is alpha_bar after both?

alpha = 0.9 and 0.8, and alpha_bar is their product: 0.9 x 0.8 = 0.72.

How many numbers are in a batch tensor of shape (16, 3, 32, 32)?

16 x 3 x 32 x 32 = 49,152.

How much memory does a (16, 3, 64, 64) tensor take in fp32, in KiB?

16 x 3 x 64 x 64 = 196,608 numbers x 4 bytes = 786,432 bytes = 768 KiB.

cond = 0.4, uncond = 0.1, guidance scale 3. What is the combined prediction?

uncond + scale x (cond - uncond) = 0.1 + 3 x 0.3 = 1.0.

Micro-batch size 4 with 8 accumulation steps. What is the effective batch size?

4 x 8 = 32.

How many parameters does nn.Embedding(11, 128) have (10 classes plus a null class)?

11 rows x 128 values = 1,408.

DDIM with 50 steps and classifier-free guidance: how many U-Net evaluations to generate one batch?

50 steps x 2 evaluations (conditional and unconditional) = 100.

Base channels 64 and multipliers (1, 2, 4, 8). How many channels at the deepest stage?

64 x 8 = 512.

In the DDPM step, what is the factor 1 / sqrt(alpha_t) when alpha_t = 0.98? (4 decimals)

sqrt(0.98) = 0.98995, and 1 / 0.98995 = 1.0102.

By what factor does DDIM with 50 steps cut the network evaluations compared with 1000 DDPM steps?

1000 / 50 = 20.
