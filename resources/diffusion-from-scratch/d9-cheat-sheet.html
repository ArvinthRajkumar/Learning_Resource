Formulas and numbers

Forward process (fixed, no learning)

alpha_t = 1 - beta_t alpha_bar_t = alpha_1 * alpha_2 * ... * alpha_t
x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * noise

noise ~ N(0, I), the same shape as the image. One formula jumps to any t.

Training step

  • batch of clean images x_0
  • t = random integer in [0, T) per image
  • noise = randn_like(x_0)
  • x_t = shortcut formula
  • pred = U-Net(x_t, t)
  • loss = mse(pred, noise)
  • backward, (clip), optimizer step, (EMA update)
loss = mean((real_noise - predicted_noise) ** 2)

DDPM sampling step (t from T-1 down to 0)

x = 1/sqrt(alpha_t) * (x - (1 - alpha_t)/sqrt(1 - alpha_bar_t) * pred_noise) + sqrt(beta_t) * z

z = fresh randn for every step except t = 0, where z = 0. Finish with clamp(-1, 1), then (x + 1) / 2.

DDIM step (same model, fewer steps)

x0_hat = (x_t - sqrt(1 - ab_now) * pred_noise) / sqrt(ab_now) x_prev = sqrt(ab_prev) * x0_hat + sqrt(1 - ab_prev) * pred_noise

Visit about 50 of the 1000 timesteps: roughly 20x fewer U-Net calls. No retraining.

Noise schedules

Linear: linspace(1e-4, 0.02, 1000). Cosine: define alpha_bar as a squared cosine, recover beta, clip at 0.999.

Classifier-free guidance

  • train: replace label with the null class ~10% of the time
  • embedding table has NUM_CLASSES + 1 rows
  • sample: run twice per step (label, null label)
pred = uncond + scale * (cond - uncond)

scale 1.0 = no extra push, about 3.0 to start. Costs 2x per step.

4GB VRAM levers

  • resolution 32, then 64 (activations grow with its square)
  • batch 4 to 16, plus gradient accumulation
  • mixed precision (fp16 or bf16)
  • small U-Net: 32 to 64 base channels, 2 to 3 stages
  • attention only at the bottleneck

Gradient accumulation and clipping

effective batch = micro_batch * accumulation_steps loss = loss / accumulation_steps
scaler.scale(loss).backward() scaler.unscale_(optimizer) clip_grad_norm_(model.parameters(), 1.0) scaler.step(optimizer); scaler.update()
