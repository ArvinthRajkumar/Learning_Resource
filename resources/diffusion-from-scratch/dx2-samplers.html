Samplers and speed: DDIM, ODE solvers, distillation and flow matching

A trained diffusion model is only half the system: the sampler decides how many network calls you pay for each image. This part shows what samplers do, why fewer steps work, and how to prove a sampler right by testing it on data whose answer is known exactly.

Advanced~5 hours

Why sampling is slow

The cost

Generation runs the network once per step. At 1,000 steps and about 0.05 seconds per step on a laptop GPU, one image takes about 50 seconds; classifier-free guidance doubles it. Training sees one noise level per example, but sampling must walk the whole chain, so speed is a sampler problem, not a training problem.

Ancestral DDPMFollow the learned reverse chain1,000

Distillation (progressive, guidance, LCM)Train a student that takes fewer steps1 to 8

Exactly solvable data: a tool for testing

To judge a sampler fairly we need a case where the network is perfect. For data that is a mixture of Gaussians the optimal noise prediction has a closed form, so we can run any sampler with the exact eps and check whether the result matches the target distribution. Everything below uses this toy.

For data x_0 drawn from a mixture of Gaussians with means m_k, standard deviation s and weights w_k, the noisy marginal at alpha_bar is a mixture with means sqrt(alpha_bar) m_k and variance v = alpha_bar s^2 + 1 - alpha_bar. Its score is a weighted average of the component scores, with weights from the component responsibilities at x_t. The optimal noise predictor is eps*(x, t) = - sqrt(1 - alpha_bar) score(x).

Ancestral DDPM sampling

The algorithm

Start at x_T ~ Normal(0, 1) and for t = T ... 1 set x_(t-1) = mu_theta(x_t, t) + sigma_t z (DX1). Each step adds fresh noise, so the process is stochastic and every run gives a different image from the same start.

import math, random
random.seed(0)

def schedule(T):
    betas = [1e-4 + (0.02 - 1e-4) * i / (T - 1) for i in range(T)]
    alphas = [1 - b for b in betas]
    ab, p = [], 1.0
    for a in alphas:
        p *= a
        ab.append(p)
    return betas, alphas, ab

MEANS, S_STD, W = [-2.0, 2.0], 0.3, [0.3, 0.7]      # target: 30 percent near -2, 70 percent near +2

def eps_star(x, ab):
    """Exact optimal noise prediction for the mixture data at noise level ab."""
    v = ab * S_STD ** 2 + 1 - ab
    resp, tot = [], 0.0
    for m, w in zip(MEANS, W):
        r = w * math.exp(-((x - math.sqrt(ab) * m) ** 2) / (2 * v))
        resp.append(r); tot += r
    score = sum((r / tot) * (-(x - math.sqrt(ab) * m) / v) for r, m in zip(resp, MEANS))
    return -math.sqrt(1 - ab) * score

def ddpm_sample(n, T=1000):
    betas, alphas, ab = schedule(T)
    out = []
    for _ in range(n):
        x = random.gauss(0, 1)
        for t in reversed(range(T)):
            mean = (x - betas[t] / math.sqrt(1 - ab[t]) * eps_star(x, ab[t])) / math.sqrt(alphas[t])
            x = mean + (math.sqrt(betas[t]) * random.gauss(0, 1) if t > 0 else 0.0)
        out.append(x)
    return out

xs = ddpm_sample(600)
right = sum(1 for x in xs if x > 0) / len(xs)
m1 = sum(x for x in xs if x > 0) / max(1, sum(1 for x in xs if x > 0))
print("fraction near +2: %.2f (target 0.70), mean of that mode: %.2f (target 2.00)" % (right, m1))

Output

fraction near +2: 0.72 (target 0.70), mean of that mode: 2.03 (target 2.00)

The sampler has never seen the data: it only used the exact noise predictor and the schedule, yet it reproduces the mixture proportions. If your trained model is good, the same thing happens in high dimensions.

Self-check

Why does DDPM sampling add noise at each step?

Each reverse step is a draw from a Gaussian; skipping the noise would collapse variety and miss the target distribution.

DDIM: deterministic sampling and fewer steps

Derivation in three lines

DDIM observes that the training objective only depends on the marginals q(x_t | x_0), not on the chain. So there is a family of processes with the same marginals; one member is deterministic. Given a noise prediction at step t:

  1. Estimate the clean image: x0_hat = (x_t - sqrt(1 - ab_t) eps_theta) / sqrt(ab_t).
  2. Pick a target step s < t (it need not be t - 1).
  3. Move there: x_s = sqrt(ab_s) x0_hat + sqrt(1 - ab_s - sigma^2) eps_theta + sigma z.

With sigma = 0 (eta = 0) the update is deterministic: the same starting noise always gives the same image. With sigma set to the DDPM value, DDIM equals DDPM. Because s can skip many steps, you visit, say, 20 of the 1,000 timesteps.

Deterministic means invertible

Because the map from noise to image is a deterministic ODE solution, you can also run it backwards (DDIM inversion) to find the noise that reproduces a given image. That enables editing: invert a photo, change the prompt, regenerate.

import math, random
random.seed(1)
T = 1000
betas = [1e-4 + (0.02 - 1e-4) * i / (T - 1) for i in range(T)]
ab, p = [], 1.0
for b in betas:
    p *= 1 - b
    ab.append(p)
MEANS, S_STD, W = [-2.0, 2.0], 0.3, [0.3, 0.7]

def eps_star(x, a):
    v = a * S_STD ** 2 + 1 - a
    r = [w * math.exp(-((x - math.sqrt(a) * m) ** 2) / (2 * v)) for m, w in zip(MEANS, W)]
    tot = sum(r)
    score = sum((ri / tot) * (-(x - math.sqrt(a) * m) / v) for ri, m in zip(r, MEANS))
    return -math.sqrt(1 - a) * score

def ddim(x, steps):
    ts = [round(i * (T - 1) / (steps - 1)) for i in range(steps)][::-1]
    for i, t in enumerate(ts):
        a_now = ab[t]
        a_next = ab[ts[i + 1]] if i + 1 < len(ts) else 1.0
        e = eps_star(x, a_now)
        x0 = (x - math.sqrt(1 - a_now) * e) / math.sqrt(a_now)
        x = math.sqrt(a_next) * x0 + math.sqrt(1 - a_next) * e
    return x

noise = [random.gauss(0, 1) for _ in range(1500)]
for steps in (5, 10, 20, 50):
    xs = [ddim(z, steps) for z in noise]
    pos = [x for x in xs if x > 0]
    print("%2d steps: fraction near +2 = %.2f, mode mean %.2f, mode std %.2f" % (
        steps, len(pos) / len(xs), sum(pos) / len(pos), math.sqrt(sum((x - sum(pos) / len(pos)) ** 2 for x in pos) / len(pos))))
print("target:    fraction 0.70, mode mean 2.00, mode std 0.30")
print("deterministic:", ddim(0.5, 20) == ddim(0.5, 20))

10 steps: fraction near +2 = 0.71, mode mean 1.95, mode std 0.24

ODE solvers and DPM-Solver

Sampling as numerical integration

The probability flow ODE (DX1) is dx/d(sigma) = eps_theta(x, sigma) in a convenient parameterisation (the Karras formulation, where sigma is the noise std). DDIM is Euler's method applied to it: one network call per step, first-order accurate. Better solvers use more information per step.

SolverOrderNetwork calls per stepNotes
Euler (= DDIM)11Simple baseline
Heun22Averages slopes at both ends; good quality, EDM default
DPM-Solver / DPM-Solver++2 to 31 (reuses past outputs)Multistep, 10 to 20 steps, widely used
UniPC, DEISmultistep1Predictor-corrector variants
Ancestral samplers (Euler a)11Add noise each step, never fully converge, creative variety

Multistep methods reuse previous network outputs, so higher accuracy costs no extra calls. This is why 20 to 25 steps of DPM-Solver++ is a common default in image tools.

Error from step size

# Solve dx/dt = -x from t=0 to 1 (exact answer exp(-1)) with Euler and Heun.
import math
def euler(n):
    x, h = 1.0, 1.0 / n
    for _ in range(n): x += h * (-x)
    return x
def heun(n):
    x, h = 1.0, 1.0 / n
    for _ in range(n):
        k1 = -x
        k2 = -(x + h * k1)
        x += h * (k1 + k2) / 2
    return x
exact = math.exp(-1)
for n in (4, 8, 16):
    print("steps %2d  euler error %.5f  heun error %.6f" % (n, abs(euler(n) - exact), abs(heun(n) - exact)))

Output

steps  4  euler error 0.05147  heun error 0.004650
steps  8  euler error 0.02427  heun error 0.001054
steps 16  euler error 0.01181  heun error 0.000251

Halving the step size halves Euler's error (order 1) but quarters Heun's (order 2), at twice the calls per step. High-order solvers win when the trajectory is smooth.

Guidance and its cost

Classifier-free guidance (D5) runs the network twice per step: eps = eps_uncond + w (eps_cond - eps_uncond). High w sharpens prompt adherence but reduces diversity, and large w combined with high-order solvers can push x0_hat out of range; dynamic thresholding (clip and rescale the predicted x0 per step) and guidance rescaling fix saturation.

# Guidance on the toy: condition on "mode +2"; the unconditional prediction is approximated by the prior-weighted mix.
import math
def gauss(x, m, v): return math.exp(-((x - m) ** 2) / (2 * v)) / math.sqrt(2 * math.pi * v)
ab = 0.5
v = ab * 0.3 ** 2 + 1 - ab
def eps_mode(x, m):                      # exact eps for a single Gaussian component
    return math.sqrt(1 - ab) * (x - math.sqrt(ab) * m) / v
x = 1.0
cond, uncond = eps_mode(x, 2.0), 0.3 * eps_mode(x, -2.0) + 0.7 * eps_mode(x, 2.0)
for w in (0.0, 1.0, 3.0, 7.0):
    print("w=%.1f guided eps=%.3f" % (w, uncond + w * (cond - uncond)))

Output

w=0.0 guided eps=0.563
w=1.0 guided eps=-0.537
w=3.0 guided eps=-2.739
w=7.0 guided eps=-7.143

At w = 1 guidance equals the conditional prediction; larger w extrapolates beyond it, which is why very high guidance produces oversaturated, low-diversity images.

Distillation and consistency models

Idea

A trained model is a slow teacher. Train a student to reach the same output in fewer steps.

MethodHowResult
Progressive distillationStudent learns to do two teacher steps in one; repeat, halving the steps each round1,000 to 4 or 8 steps
Guidance distillationStudent reproduces the guided output in one passRemoves the double cost of CFG
Latent consistency models (LCM)Student predicts the ODE solution endpoint from any point2 to 4 steps
Consistency modelsA function f(x_t, t) with f(x_t, t) = f(x_s, s) along one trajectory, mapping any point to the clean sampleOne to a few steps
Adversarial distillation (SDXL Turbo, ADD)Add a GAN loss to a distilled studentSingle step, higher sharpness

Consistency in one picture

All points on one ODE trajectory should map to the same clean image. A consistency model enforces f(x_t, t) = f(x_(t'), t') for neighbouring points on the trajectory, with the boundary condition f(x_0, 0) = x_0. Sampling then needs one call: x_0 = f(x_T, T), optionally refined by a few more steps.

Trade-off

Distilled models are fast but usually less diverse and a little less detailed than their teachers, and they are often tied to a particular guidance scale. Keep the full model for quality work.

How this gets asked

  • Trains a student to match two teacher steps in one, halving the steps Correct.
  • Adds layers No.
  • Removes the text encoder No.

Repeating it takes 1,000 steps down to a handful.

Flow matching and rectified flow

The idea

Instead of noising and denoising with a schedule, learn a velocity field that moves noise to data along (nearly) straight lines. Pick a data point x_0 and noise x_1, interpolate x_t = (1 - t) x_0 + t x_1, and train v_theta(x_t, t) to predict x_1 - x_0, the constant velocity of that straight path. Sampling integrates dx/dt = v_theta from t = 1 to t = 0 with any ODE solver. Straighter paths need fewer steps; rectified flow repeats training on the model's own pairs to straighten further. Stable Diffusion 3 and Flux use this objective with a transformer backbone.

A check on exact data

For data Normal(m, s^2) and noise Normal(0, 1), the optimal velocity (the conditional expectation of x_1 - x_0 given x_t) is available in closed form, so we can integrate it and test the sampler.

import math, random
random.seed(3)
m, s = 3.0, 0.5

def v(x, t):
    """E[x1 - x0 | x_t = x] for x0 ~ N(m, s^2), x1 ~ N(0, 1), x_t = (1 - t) x0 + t x1."""
    var_t = (1 - t) ** 2 * s * s + t * t
    return -m + (t - (1 - t) * s * s) / var_t * (x - (1 - t) * m)

def sample(steps):
    x = random.gauss(0, 1)           # start from noise at t = 1
    dt = 1.0 / steps
    for i in range(steps):
        t = 1 - i * dt
        x -= v(x, t) * dt            # integrate backwards in t with Euler
    return x

for steps in (2, 4, 8, 32):
    xs = [sample(steps) for _ in range(4000)]
    mean = sum(xs) / len(xs)
    std = math.sqrt(sum((x - mean) ** 2 for x in xs) / len(xs))
    print("%2d Euler steps: mean %.2f (target %.2f), std %.2f (target %.2f)" % (steps, mean, m, std, s))

Self-check

Why do flow models need fewer steps?

Their paths are close to straight lines, which numerical solvers integrate accurately with big steps.

Choosing steps in practice

  1. Start with 25 steps of DPM-Solver++ 2M and the model's recommended guidance.
  2. If images look noisy or under-detailed, raise steps or switch to Heun; if too slow, try a distilled model.
  3. For deterministic edits and inversion use a deterministic sampler and keep the seed fixed.
  4. Always compare samplers at equal number of network evaluations, not equal steps (Heun uses two per step, CFG doubles everything).
  5. Measure with a fixed prompt set and metrics (DX5), not one lucky image.

How this gets asked

A sampler uses Heun (2 evaluations per step) with CFG (2 passes) for 20 steps. How many network evaluations per image?

20 steps x 2 (Heun) x 2 (CFG) = 80.

Interview questions: Diffusion samplers

12 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic Why is diffusion sampling slow?

It runs the network once per step for tens to thousands of sequential steps, and guidance doubles the cost.

Basic What is the difference between DDPM and DDIM sampling?

DDPM adds fresh noise each step (stochastic, 1,000 steps). DDIM with eta = 0 is deterministic and can skip timesteps, giving good images in 20 to 50 steps from the same trained model.

Medium Write the DDIM update.

x0_hat = (x_t - sqrt(1 - ab_t) eps) / sqrt(ab_t); x_s = sqrt(ab_s) x0_hat + sqrt(1 - ab_s - sigma^2) eps + sigma z, with sigma = 0 for the deterministic version.

Medium What is DDIM inversion used for?

Because the map from noise to image is deterministic and invertible, running it backwards from a real image finds a noise code that regenerates it, enabling editing by changing the prompt.

Medium Why do higher-order solvers need fewer steps?

The sampling trajectory is a smooth ODE; second or third order methods such as Heun and DPM-Solver have much lower error per step than Euler.

Medium What are ancestral samplers?

Samplers that inject fresh noise each step. They never converge to a single image as steps increase, which gives variety but makes results less repeatable.

Medium What does classifier-free guidance cost and what are its failure modes?

Two network evaluations per step. Large scales oversaturate and reduce diversity; thresholding and guidance rescaling mitigate it.

Advanced Explain progressive distillation.

A student is trained to match two teacher steps with one; the student becomes the next teacher and the number of steps halves each round, down to 4 or 8 steps.

Advanced What is a consistency model?

A function that maps any point on a probability flow ODE trajectory to the same clean sample. It enables one-step generation, trained by distillation or directly with consistency losses.

Advanced What is flow matching and why does it sample efficiently?

Learn a velocity field that transports noise to data along straight interpolation paths. Straight paths are integrated accurately with few ODE steps; rectified flow straightens paths further.

Advanced How do you compare samplers fairly?

At equal number of network evaluations, not steps, with a fixed prompt set and seeds, using distribution metrics and human preference with confidence intervals.

Advanced How does timestep spacing affect results?

Spacing in log-SNR (or the Karras schedule) places more steps where the image changes most; uniform spacing wastes steps at very high noise.
