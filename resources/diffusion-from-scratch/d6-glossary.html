Full glossary, A-Z

Every term from this page, in one place, for quick lookup while you code.

TermMeaning
Activation functionA small non-linear function (e.g. SiLU) applied after each convolution, letting the network learn curved, complex patterns instead of only straight-line relationships.
Adam / AdamWA standard, ready-made PyTorch optimizer that adapts how much to change each weight during training, based on that weight's recent history.
Alpha (α)Defined as 1 − β at a given timestep; represents how much of the original signal survives one noising step.
Alpha-bar (ᾱ)The running product of every alpha up to timestep t; used in the one-step shortcut formula to jump directly to any noise level.
ArchitectureThe overall structure of a neural network, how many layers, what kind, and how they connect. "U-Net" names one specific architecture.
Attention (self-attention)A layer letting every position in a feature grid weigh how relevant every other position is, regardless of distance, used sparingly (often just at the bottleneck) due to memory cost.
BatchA group of images processed together as one tensor, since GPUs are efficient at doing the same operation on many pieces of data at once.
Beta (β) / noise scheduleA fixed list of numbers, calculated in advance, controlling how much noise is added at each timestep of the forward process.
BottleneckThe middle of a U-Net, at the smallest spatial size and largest channel count, the most compressed, abstract representation of the image.
BroadcastingPyTorch's rule for automatically combining tensors of different shapes in element-wise operations, by stretching the smaller one to match without copying data.
ChannelsSeparate grids stacked within a tensor, 3 for RGB color images, or many more inside a network's internal "feature" representations.
Class (Python)A blueprint for creating objects that bundle data and functions together; nn.Module subclasses (like your ResBlock or UNet) are classes.
Classifier-free guidanceA technique where the model is trained both with and without labels, then at generation time runs twice per step so the result can be pushed harder toward the requested label.
Computation graphThe record PyTorch silently builds of every operation performed on tensors, connecting input to output, which backward() walks in reverse to compute gradients.
Context manager / withA Python pattern (the with keyword) that sets something up before a block of code and automatically cleans it up afterward, used for torch.no_grad() and torch.autocast().
Cosine scheduleAn alternative noise schedule that destroys the image more gradually than the linear one, leaving more useful timesteps for the network to learn from.
CUDANVIDIA's platform letting programs like PyTorch send computation to run on the GPU.
Data augmentationRandomly altering training images as they load (such as a horizontal flip) so the model sees fresh variations each epoch, effectively enlarging a small dataset.
DDIMA faster sampling method that reuses a DDPM-trained network but generates images in far fewer steps than 1000.
DDPM"Denoising Diffusion Probabilistic Models", the original, foundational diffusion model formulation this guide is based on, where the network predicts noise.
DecoderThe growing (right) half of a U-Net, rebuilding spatial resolution back up from the bottleneck to the original image size.
Decorator (@)A line starting with @ placed above a function definition that wraps it with extra behavior, such as @torch.no_grad().
DownsamplingShrinking an image or feature grid's height and width, typically halving them at each stage of the encoder.
DriverSoftware letting your operating system communicate with a hardware device, here, the NVIDIA driver for your GPU.
Element-wise operationAn operation applied independently to every matching position across tensors of the same shape, such as addition or multiplication.
EMA (exponential moving average)A slowly-updated shadow copy of the model weights, used for generation instead of the live weights. Smooths out batch-to-batch jitter and noticeably improves sample quality.
EncoderThe shrinking (left) half of a U-Net, reducing spatial size while increasing channel count at each stage.
enumerate()A Python function that loops over a list while also providing each item's position (index), without a manually tracked counter.
EpochOne full pass through the entire training dataset.
f-stringA Python string prefixed with f that lets you embed variable values directly inside curly braces, e.g. f"Epoch {epoch}".
Forward processThe fixed, formula-based process of gradually adding noise to a clean image across timesteps, requiring no neural network.
Gaussian noiseRandom values drawn from a bell-curve distribution centered at zero, the specific kind of randomness used throughout diffusion models.
GradientA measure of how much a small change in one weight would change the loss, the "slope" that backward() computes and step() uses to update weights.
Gradient accumulationAdding up gradients across several small batches before updating weights once, simulating a larger batch size without the extra VRAM cost.
Gradient clippingCapping the overall size of gradients before the optimizer uses them, which prevents one bad batch from blowing the weights up and sending the loss to nan.
Indexing / gatherLooking up specific values from a tensor by position, used to batch-lookup schedule values (alpha, beta) for a whole batch of different timesteps at once.
InferenceUsing an already-trained model to produce output, with no further learning happening.
Kernel / filterThe small grid of learnable numbers that slides across an image during a convolution.
Learning rateA number controlling how large each weight-update step is during training.
List comprehensionA compact Python one-liner for building a new list by transforming every item of an existing one, e.g. [base * m for m in mults].
LossA single number measuring how wrong a model's output currently is; training works by reducing this number over time.
Mean Squared Error (MSE)A loss that squares and averages the differences between two tensors, element-by-element, used here to compare predicted noise to real noise.
Mixed precisionStoring most training numbers in a smaller 16-bit format instead of 32-bit, roughly halving VRAM use for a negligible accuracy cost.
ModelA function with adjustable internal numbers (parameters/weights) that gets better at a task through training.
Neural networkA model built from stacked layers, each combining weighted sums with non-linear activation functions.
nn.EmbeddingA learnable lookup table of vectors, indexed by an integer. Used to turn a class label into a vector the network can combine with the timestep embedding.
nn.ModulePyTorch's base class for any custom layer or network; provides automatic weight tracking and requires an __init__ (declare sub-layers) and forward (define data flow) method.
Noise predictionThe specific quantity the U-Net is trained to output: its best guess at exactly which noise tensor was added to produce the noisy input.
None (Python)Python's representation of "no value at all," distinct from zero or an empty string, commonly used as a default function argument.
Normalization (GroupNorm)A layer that rescales numbers to a stable range between other layers, keeping training numerically stable.
OptimizerThe algorithm (e.g. Adam/AdamW) deciding exactly how to adjust each weight, given the direction computed by automatic differentiation.
os.makedirs() / os.path.join()Python's built-in functions for creating folders and building file paths safely across operating systems.
Parameters / weightsThe adjustable internal numbers of a model, tuned automatically during training.
Query, Key, Value (Q, K, V)The three learned vectors an attention layer computes for every position, what it's looking for, what it advertises, and what it contributes if chosen as relevant.
Receptive fieldThe region of the input image that can influence a given output value; grows larger as more convolution layers are stacked.
Residual block (ResBlock)A small stack of convolutions plus a shortcut path adding the block's input directly to its output, so the block only learns a correction rather than a full reconstruction.
Reverse processThe learned direction of diffusion: given a noisy image, produce a slightly less noisy one, this is the part the U-Net is trained for.
Sampling loopThe generation procedure: starting from pure noise, repeatedly applying the trained network's denoising step from t=T down to t=0.
selfInside a Python class, refers to the specific instance a method is running on, used to store and access that instance's own data (e.g. self.conv1).
Sinusoidal timestep embeddingA fixed formula converting a single timestep integer into a rich vector using sine/cosine waves at many frequencies, so the network can make sense of "how noisy is this."
Skip connectionA direct link copying an encoder stage's output across to the matching decoder stage, preserving fine detail that would otherwise be lost through the bottleneck.
SoftmaxA function that rescales a list of numbers so they're all positive and sum to 1, turning raw attention scores into interpretable weighting percentages.
state_dict()A method returning a model's learnable weights as a dictionary, used with torch.save() and load_state_dict() to save and restore a trained model.
super().__init__()Calls the parent class's own setup code; required as the first line of any nn.Module subclass's __init__ so PyTorch's weight tracking is set up correctly.
TensorA grid of numbers with a specific shape; the basic data structure PyTorch stores and computes with.
TimestepA step number in the noising/denoising process, from 0 (clean) to T (pure noise).
TrainingRepeatedly showing a model examples, measuring loss, and nudging its weights to reduce that loss.
U-NetThe standard architecture for diffusion models' noise-prediction network: a shrinking encoder, a bottleneck, and a growing decoder, connected by skip connections.
UpsamplingGrowing an image or feature grid's height and width back up, typically doubling them at each stage of the decoder.
Virtual environment (venv)An isolated folder containing its own Python and libraries, kept separate per project to avoid version conflicts.
VRAMMemory physically on the GPU, used to store a model's weights and working data during training and inference, your 4GB constraint.
zip()A Python function that pairs up elements from two or more lists by position, so you can loop over all of them together in one loop.
