Sum of Digits

Easy Loops and arithmetic

Given a non-negative integer n, return the sum of its decimal digits.

FieldDetail
DSA conceptLoops and arithmetic (Programming & Problem-Solving Foundations)
Input formatOne integer n.
Output formatOne integer: the digit sum.
Constraints0 <= n <= 10^18

Sample input

493

Sample output

16

Explanation: 4 + 9 + 3 = 16.

Stuck? Reveal hints one at a time

Hint 1

What does n % 10 give you for 493?

Hint 2

What does n // 10 give you for 493?

Recommended approach (spoiler)

Peel off the last digit with n % 10, add it to a running total, then remove it with n // 10. Repeat until n becomes 0.

Python solution (try first)

def digit_sum(n):
    total = 0
    while n > 0:
        total += n % 10   # last digit
        n //= 10          # drop the last digit
    return total

Complexity: Time O(d) where d is the number of digits (= O(log n)); Space O(1).

Edge cases to test

  • n = 0 -> loop never runs, answer 0
  • Numbers ending in zeros such as 1000

Prime Check

Easy Loops, math, sqrt optimisation

Return True if n is a prime number, otherwise False.

FieldDetail
DSA conceptLoops, math, sqrt optimisation (Programming & Problem-Solving Foundations)
Input formatOne integer n.
Output formatTrue or False.
Constraints0 <= n <= 10^12

Sample input

29

Sample output

True

Explanation: 29 has no divisor between 2 and 5, so it is prime.

Stuck? Reveal hints one at a time

Hint 1

Numbers below 2 are not prime.

Hint 2

If n = a * b then one of a, b is at most sqrt(n).

Recommended approach (spoiler)

A composite number always has a divisor <= sqrt(n). So test i = 2, 3, ... while i*i <= n. Brute force to n-1 would be O(n) and too slow for 10^12.

Python solution (try first)

def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:        # only check up to sqrt(n)
        if n % i == 0:
            return False
        i += 1
    return True

Complexity: Time O(sqrt n); Space O(1).

Edge cases to test

  • 0 and 1 are not prime
  • 2 is the only even prime
  • Perfect squares such as 49 (i*i <= n must use <=)

Palindrome Number

Easy Digit manipulation LC 9

Return True if the integer n reads the same forwards and backwards. Negative numbers are not palindromes.

This is a well-known public interview classic (LeetCode-style problem #9). The guide does not claim any company asked it.

Python solution (try first)

def palindrome_number(n):
    if n < 0:
        return False
    original, rev = n, 0
    while n > 0:
        rev = rev * 10 + n % 10
        n //= 10
    return rev == original

Complexity: Time O(log n); Space O(1).

Edge cases to test

  • Negative numbers
  • 0 is a palindrome
  • Numbers ending in 0 (10) are not

Number Pyramid Pattern

Easy Nested loops, patterns

Given n, return n lines. Line i (1-indexed) contains the numbers 1..i separated by single spaces.

FieldDetail
DSA conceptNested loops, patterns (Programming & Problem-Solving Foundations)
Input formatOne integer n.
Output formatA list of n strings (print them one per line on a judge).
Constraints1 <= n <= 50

Sample input

3

Sample output

['1', '1 2', '1 2 3']

Explanation: Line 1 has one number, line 2 has two, line 3 has three.

Stuck? Reveal hints one at a time

Hint 1

Remember range(1, i + 1) includes i.

Hint 2

join needs strings, so convert numbers with str.

Recommended approach (spoiler)

Outer loop chooses the row; inner idea builds the numbers 1..row. In Python, " ".join(map(str, range(1, i+1))) does the inner loop for you.

Python solution (try first)

def pyramid(n):
    lines = []
    for i in range(1, n + 1):
        row = [str(j) for j in range(1, i + 1)]
        lines.append(" ".join(row))
    return lines

Complexity: Time O(n^2) (the output itself has n(n+1)/2 numbers); Space O(n^2).

Edge cases to test

  • n = 1
  • Do not leave a trailing space on a line

Python solution (try first)

def fizzbuzz(n):
    out = []
    for i in range(1, n + 1):
        if i % 15 == 0:
            out.append("FizzBuzz")
        elif i % 3 == 0:
            out.append("Fizz")
        elif i % 5 == 0:
            out.append("Buzz")
        else:
            out.append(str(i))
    return out

Complexity: Time O(n); Space O(n) for the output.

Edge cases to test

  • n = 1
  • Checking 15 last (a classic bug)

Armstrong Number

Easy Digits and powers

A number is an Armstrong number if the sum of each digit raised to the power of the number of digits equals the number. Return True or False.

FieldDetail
DSA conceptDigits and powers (Programming & Problem-Solving Foundations)
Input formatInteger n.
Output formatTrue or False.
Constraints0 <= n <= 10^9

Sample input

153

Sample output

True

Explanation: 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153.

Stuck? Reveal hints one at a time

Hint 1

Converting to a string makes the digits easy to loop over.

Recommended approach (spoiler)

Count the digits (len(str(n))), then add digit ** count for each digit and compare with n.

Step-by-step dry run

Call: is_armstrong(153), returns True. Bold means the value just changed.

Python solution (try first)

def is_armstrong(n):
    digits = str(n)
    power = len(digits)
    return sum(int(d) ** power for d in digits) == n

Complexity: Time O(d); Space O(d).

Edge cases to test

  • Single digits are all Armstrong numbers
  • 0

Python solution (try first)

def fib_list(n):
    out, a, b = [], 0, 1
    for _ in range(n):
        out.append(a)
        a, b = b, a + b
    return out

Complexity: Time O(n); Space O(n).

  • n = 1 -> [0]

Reverse Integer

Medium Digit manipulation + bounds LC 7

Reverse the digits of a signed 32-bit integer. Return 0 if the result does not fit in 32 bits.

This is a well-known public interview classic (LeetCode-style problem #7). The guide does not claim any company asked it.

Why interviewers ask this: Looks trivial but tests overflow and negative number handling.

FieldDetail
DSA conceptDigit manipulation + bounds (Programming & Problem-Solving Foundations)
Input formatInteger x.
Output formatInteger.
Constraints-2^31 <= x <= 2^31 - 1

Explanation: The sign stays.

Hint 1

Python has no overflow; you must check the range yourself.

Recommended approach (spoiler)

Work with the absolute value, peel digits, and check the result against the 32-bit range before returning.

Python solution (try first)

def reverse_integer(x):
    sign = -1 if x < 0 else 1
    x, rev = abs(x), 0
    while x:
        rev = rev * 10 + x % 10
        x //= 10
    rev *= sign
    return rev if -2 ** 31 <= rev <= 2 ** 31 - 1 else 0

Complexity: Time O(digits); Space O(1).

  • Overflow
  • Zero
