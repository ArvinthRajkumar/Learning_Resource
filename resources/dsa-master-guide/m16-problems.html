Climbing Stairs

Easy DP (Fibonacci pattern) LC 70 must-do

You can climb 1 or 2 steps at a time. In how many distinct ways can you reach step n?

This is a well-known public interview classic (LeetCode-style problem #70, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptDP (Fibonacci pattern) (Dynamic Programming)
Input formatInteger n.
Output formatInteger.
Constraints1 <= n <= 45

Sample input

5

Sample output

8

Explanation: Ways(n) = Ways(n-1) + Ways(n-2).

Stuck? Reveal hints one at a time

Hint 1

State: ways to reach step i.

Hint 2

Base: ways(1) = 1, ways(2) = 2.

Recommended approach (spoiler)

To stand on step n you came from n-1 (1 step) or n-2 (2 steps). So dp[n] = dp[n-1] + dp[n-2]. Only the last two values are needed.

Python solution (try first)

def climb_stairs(n):
    if n <= 2:
        return n
    prev, cur = 1, 2             # ways(1), ways(2)
    for _ in range(3, n + 1):
        prev, cur = cur, prev + cur
    return cur

Complexity: Time O(n); Space O(1).

  • Large n (45 fits easily)

Python solution (try first)

def fib_memo(n, memo={}):
    if n < 2:
        return n
    if n not in memo:
        memo[n] = fib_memo(n - 1) + fib_memo(n - 2)
    return memo[n]

Complexity: Time O(n); Space O(n).

def house_robber(nums):
    skip, take = 0, 0              # best up to i-2, best up to i-1
    for x in nums:
        skip, take = take, max(take, skip + x)
    return take

Python solution (try first)

def coin_change(coins, amount):
    INF = float("inf")
    dp = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return -1 if dp[amount] == INF else dp[amount]

Complexity: Time O(amount * len(coins)); Space O(amount).

def unique_paths(m, n):
    row = [1] * n                 # first row: only one way to each cell
    for _ in range(1, m):
        for c in range(1, n):
            row[c] += row[c - 1]  # from above (old row[c]) + from left
    return row[-1]

Minimum Path Sum

Medium 2D DP LC 64

Find the path from top-left to bottom-right (moving only right or down) with the smallest sum of cell values.

This is a well-known public interview classic (LeetCode-style problem #64). The guide does not claim any company asked it.

FieldDetail
DSA concept2D DP (Dynamic Programming)
Input formatGrid of non-negative integers.
Output formatInteger.
Constraintsrows, cols <= 200

Sample input

[[1,3,1],[1,5,1],[4,2,1]]

Sample output

7

Explanation: Path 1 -> 3 -> 1 -> 1 -> 1.

Stuck? Reveal hints one at a time

Hint 1

Edges have only one possible predecessor.

Recommended approach (spoiler)

cost[r][c] = grid[r][c] + min(cost from above, cost from left). Fill the first row/column separately.

Python solution (try first)

def min_path_sum(grid):
    rows, cols = len(grid), len(grid[0])
    dp = [[0] * cols for _ in range(rows)]
    for r in range(rows):
        for c in range(cols):
            if r == 0 and c == 0:
                dp[r][c] = grid[r][c]
            elif r == 0:
                dp[r][c] = dp[r][c - 1] + grid[r][c]
            elif c == 0:
                dp[r][c] = dp[r - 1][c] + grid[r][c]
            else:
                dp[r][c] = grid[r][c] + min(dp[r - 1][c], dp[r][c - 1])
    return dp[-1][-1]

Complexity: Time O(rows * cols); Space O(rows * cols).

Edge cases to test

  • Single cell
  • Single row or column

    return best * best

def knapsack_01(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for wt, val in zip(weights, values):

            dp[w] = max(dp[w], dp[w - wt] + val)
    return dp[capacity]

from bisect import bisect_left

def lis(nums):
    tails = []                       # tails[k] = smallest tail of an increasing subsequence of length k+1
    for x in nums:
        i = bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)

def edit_distance(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i][j - 1], dp[i - 1][j], dp[i - 1][j - 1])
    return dp[n][m]

from functools import lru_cache

def longest_inc_path_matrix(matrix):
    R, C = len(matrix), len(matrix[0])
    @lru_cache(maxsize=None)
    def go(r, c):
        best = 1
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1 + go(nr, nc))
        return best
    return max(go(r, c) for r in range(R) for c in range(C))

def burst_balloons(nums):

def regex_match(s, p):
    n, m = len(s), len(p)
    dp = [[False] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = True
    for j in range(2, m + 1):
        if p[j - 1] == "*":
            dp[0][j] = dp[0][j - 2]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if p[j - 1] == "*":
                dp[i][j] = dp[i][j - 2] or (p[j - 2] in (s[i - 1], ".") and dp[i - 1][j])
            else:
                dp[i][j] = p[j - 1] in (s[i - 1], ".") and dp[i - 1][j - 1]
    return dp[n][m]
