Start here

  1. Read the coding round strategy to learn how a round is approached, then pick a study plan that fits your time.
  2. Learn a module. Each topic runs: definition, analogy, interactive animation, step-by-step walkthrough, tested code, dry-run table, complexity, mistakes, then quiz questions.
  3. Play with the animations. Change the input, step forward and back, and predict the next step before you click.
  4. Write each solution yourself first. On every problem, use hints one at a time and open the solution last.
  5. Test yourself with the final assessment, the interview classics and the question bank.

Disclaimer: this is an independent study resource. It is not affiliated with Infosys and does not contain real Infosys questions. All practice problems are original or well-known classic problems.

Advanced topics (parts X1 to X7)

Beyond the core modules: Fenwick and segment trees, advanced graph algorithms, advanced dynamic programming, string algorithms, number theory, complexity theory and more interview problems.

X1 Advanced data structures: Fenwick tree, segment tree, sparse table, AVL, LFU and more

Range queries with prefix sums, Fenwick trees, segment trees with lazy propagation and sparse tables; balanced trees with an AVL implementation; O(1) LRU and LFU caches; skip lists, Bloom filters and monotonic structures, each tested against a brute-force version.

Advanced

X2 Advanced graph algorithms: shortest paths, MST, SCC, bridges and flow

Dijkstra, Bellman-Ford, Floyd-Warshall and 0-1 BFS, A*, minimum spanning trees with Kruskal and Prim, strongly connected components, bridges and articulation points, topological orders, bipartite checks and maximum flow, all verified.

Advanced

X3 Advanced dynamic programming: knapsacks, bitmasks, intervals, trees and optimisation

A method for designing DP, knapsack variants, longest increasing subsequence in n log n, edit distance, interval DP, bitmask DP, DP on trees and digit DP, state compression and when greedy or other methods beat DP, all checked against brute force.

Advanced

X4 String algorithms: KMP, Z, Rabin-Karp, Manacher, tries and suffix structures

Efficient pattern matching with the prefix function, the Z algorithm and rolling hashes, palindromes with Manacher, tries and Aho-Corasick for many patterns, suffix arrays and longest common prefixes, each tested against naive search.

Advanced

X5 Number theory, combinatorics and probability for interviews

Primes and sieves, gcd and modular arithmetic, fast exponentiation, modular inverses, the Chinese remainder theorem, counting with nCr modulo a prime, matrix exponentiation and expected value, all checked by brute force.

Advanced

X6 Complexity theory: amortised analysis, recurrences, NP-completeness and lower bounds

Amortised analysis with aggregate and potential arguments, solving recurrences with the Master theorem, the classes P, NP, NP-hard and NP-complete, reductions, approximation, and the n log n sorting lower bound.

Advanced

X7 More interview problems with verified solutions

Twenty more classic interview problems across arrays, strings, hashing, heaps, intervals, trees, graphs, backtracking and design, each with the idea, a solution and a randomised check against brute force.

How to use this guide

  • Click Mark as done at the end of each section. The bars above and the parts menu update.
  • Quiz answers feed the weak-areas box. Retry with shuffle on later passes.
  • All code on these pages is read from files in solutions/. Run python3 resources/dsa-master-guide/solutions/test_dsa.py to check every example yourself.
  • Animations run in your browser with no network access. Use the controls under each one: reset, back, play, step, and speed.

Progress, quiz scores and theme are stored only in this browser. Press ? for keyboard shortcuts.
