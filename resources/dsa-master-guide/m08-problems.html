Pair Sum in a Sorted Array

Easy Two pointers (opposite ends) LC 167

The list is sorted ascending. Return the indices [i, j] (i < j) of two numbers adding up to target, or [-1, -1].

This is a well-known public interview classic (LeetCode-style problem #167). The guide does not claim any company asked it.

FieldDetail
DSA conceptTwo pointers (opposite ends) (Two Pointers & Sliding Window)
Input formatSorted list, target.
Output formatTwo indices.
Constraintslen <= 10^5

Sample input

[2,7,11,15], 9

Sample output

[0, 1]

Explanation: 2 + 7 = 9.

Stuck? Reveal hints one at a time

Hint 1

Why can you safely discard nums[lo] when the sum is too small?

Recommended approach (spoiler)

Put one pointer at each end. If the sum is too small move the left pointer right (bigger value); if too big move the right pointer left. Each step discards one element for good.

Python solution (try first)

def two_sum_sorted(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return [lo, hi]
        if s < target:
            lo += 1
        else:
            hi -= 1
    return [-1, -1]

Complexity: Time O(n); Space O(1).

Edge cases to test

  • Fewer than two elements
  • Duplicate values

Maximum Sum of K Consecutive Elements

Easy Fixed-size sliding window

Return the maximum sum of any k consecutive elements, or -1 if k > len(nums).

FieldDetail
DSA conceptFixed-size sliding window (Two Pointers & Sliding Window)
Input formatList nums and integer k.
Output formatInteger.

Recommended approach (spoiler)

Python solution (try first)

def max_sum_window(nums, k):
    if k > len(nums):
        return -1
    window = sum(nums[:k])            # first window
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]   # slide by one
        best = max(best, window)
    return best

Complexity: Time O(n); Space O(1).

Edge cases to test

  • k greater than n
  • Negative numbers

Container With Most Water

Medium Two pointers (greedy shrink) LC 11 must-do

Each value is the height of a vertical line at its index. Choose two lines that, with the x-axis, hold the most water.

This is a well-known public interview classic (LeetCode-style problem #11, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptTwo pointers (greedy shrink) (Two Pointers & Sliding Window)

Output formatMaximum area.
Constraints2 <= len <= 10^5

Sample input

def max_area(h):
    lo, hi, best = 0, len(h) - 1, 0
    while lo < hi:
        best = max(best, (hi - lo) * min(h[lo], h[hi]))
        if h[lo] < h[hi]:
            lo += 1
        else:
            hi -= 1
    return best

Python solution (try first)

def min_subarray_len(target, nums):
    left = total = 0
    best = float("inf")
    for right, x in enumerate(nums):
        total += x                       # expand
        while total >= target:           # shrink while still valid
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float("inf") else best

Complexity: Time O(n) - each index enters and leaves the window once; Space O(1).

Edge cases to test

  • No valid subarray -> 0
  • A single element is enough

def longest_unique_substring(s):
    last = {}                    # char -> last index
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1  # skip past the previous copy
        last[ch] = right
        best = max(best, right - left + 1)
    return best

Complexity: Time O(n); Space O(min(n, alphabet)).

  • All same character
  • Repeat outside the current window ("abba")

def longest_ones(nums, k):
    left = zeros = best = 0
    for right, x in enumerate(nums):
        if x == 0:
            zeros += 1
        while zeros > k:              # too many zeros: shrink
            if nums[left] == 0:
                zeros -= 1
            left += 1
        best = max(best, right - left + 1)
    return best

Permutation in String

Medium Fixed window + frequency LC 567

Return True if some substring of s2 is a permutation (rearrangement) of s1.

This is a well-known public interview classic (LeetCode-style problem #567). The guide does not claim any company asked it.

FieldDetail
DSA conceptFixed window + frequency (Two Pointers & Sliding Window)
Input formatStrings s1 and s2.
Output formatTrue or False.
Constraintslen <= 10^4

Sample input

s1="ab", s2="eidbaooo"

Sample output

True

Explanation: "ba" is a rearrangement of "ab".

Stuck? Reveal hints one at a time

Hint 1

Window size is fixed.

Hint 2

Counter equality compares all letters.

Recommended approach (spoiler)

Slide a window of length len(s1) over s2 and compare letter counts with those of s1. Update counts by adding the new letter and removing the old one.

Python solution (try first)

from collections import Counter

def check_inclusion(s1, s2):
    k = len(s1)
    if k > len(s2):
        return False
    need = Counter(s1)
    window = Counter(s2[:k])
    if window == need:
        return True
    for i in range(k, len(s2)):
        window[s2[i]] += 1                 # letter enters
        out = s2[i - k]
        window[out] -= 1                   # letter leaves
        if window[out] == 0:
            del window[out]
        if window == need:
            return True
    return False

Complexity: Time O(n * alphabet); Space O(alphabet).

Edge cases to test

  • s1 longer than s2
  • Repeated letters

3Sum Closest

Medium Sort + two pointers LC 16

Return the sum of three numbers that is closest to the target.

This is a well-known public interview classic (LeetCode-style problem #16). The guide does not claim any company asked it.

Why interviewers ask this: A natural follow-up to 3Sum that tests whether you can adapt the two-pointer idea to "closest" instead of "equal".

FieldDetail
DSA conceptSort + two pointers (Two Pointers & Sliding Window)
Input formatList nums and target.
Output formatInteger sum.
Constraints3 <= len <= 500

Sample input

[-1,2,1,-4], target 1

Sample output

2

Explanation: -1 + 2 + 1 = 2.

Stuck? Reveal hints one at a time

Hint 1

Track abs(sum - target).

Recommended approach (spoiler)

Sort. For each i run two pointers on the rest; move lo if the sum is too small and hi if too big, remembering the closest sum seen.

Python solution (try first)

def three_sum_closest(nums, target):
    nums.sort()
    best = nums[0] + nums[1] + nums[2]
    for i in range(len(nums) - 2):
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if abs(s - target) < abs(best - target):
                best = s
            if s < target:
                lo += 1
            elif s > target:
                hi -= 1
            else:
                return s
    return best

Complexity: Time O(n^2); Space O(1).

Edge cases to test

  • Exact match
  • Exactly three numbers

Delete a key when its count reaches 0.

Recommended approach (spoiler)

Longest subarray with at most two distinct values. Keep counts in a window; when more than two types appear, shrink from the left.

Python solution (try first)

from collections import defaultdict

def fruit_baskets(fruits):
    count = defaultdict(int)
    left = best = 0
    for right, f in enumerate(fruits):
        count[f] += 1
        while len(count) > 2:
            count[fruits[left]] -= 1
            if count[fruits[left]] == 0:
                del count[fruits[left]]
            left += 1
        best = max(best, right - left + 1)
    return best

Complexity: Time O(n); Space O(1).

Edge cases to test

  • One type only
  • Empty list

Three Sum

Hard Sort + two pointers LC 15 must-do

Return all unique triplets that sum to zero. Each triplet in non-decreasing order, and the list of triplets sorted.

This is a well-known public interview classic (LeetCode-style problem #15, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Stuck? Reveal hints one at a time

Hint 1

Sorting makes duplicate skipping easy.

Hint 2

After finding a triplet, move both pointers and skip equal values.

Recommended approach (spoiler)

Sort. Fix the first number a (skipping duplicates). For the rest, run the sorted pair-sum two-pointer search for -a. Skip duplicates after finding a triplet. O(n^2) instead of O(n^3).

Python solution (try first)

def three_sum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue                      # skip duplicate first numbers
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                res.append([nums[i], nums[lo], nums[hi]])
                lo += 1
                hi -= 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1
    return res

Complexity: Time O(n^2); Space O(1) extra (ignoring output and sort).

Edge cases to test

  • All zeros [0,0,0,0]
  • No triplet
  • Fewer than 3 numbers
