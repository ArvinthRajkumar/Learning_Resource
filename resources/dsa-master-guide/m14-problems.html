Python solution (try first)

from collections import deque

def bfs_order(graph, start):
    visited = {start}
    order, q = [], deque([start])
    while q:
        node = q.popleft()
        order.append(node)
        for nb in graph[node]:
            if nb not in visited:
                visited.add(nb)
                q.append(nb)
    return order

Complexity: Time O(V + E); Space O(V).

Flood Fill

Easy Grid DFS LC 733

Starting at cell (sr, sc), change its colour and every connected cell (up/down/left/right) with the same original colour to new_color.

This is a well-known public interview classic (LeetCode-style problem #733). The guide does not claim any company asked it.

FieldDetail
DSA conceptGrid DFS (Graphs)
Input formatImage grid, sr, sc, new_color.
Output formatUpdated grid.
Constraintsrows, cols <= 50

Sample input

[[1,1,0],[1,0,0]], 0, 0, 2

Sample output

[[2,2,0],[2,0,0]]

Explanation: The connected 1s become 2.

Stuck? Reveal hints one at a time

Hint 1

Check old == new first.

Recommended approach (spoiler)

Remember the old colour, then DFS: paint the cell and visit neighbours that still have the old colour. If old == new return immediately (otherwise infinite loop).

Python solution (try first)

def flood_fill(image, sr, sc, new_color):
    old = image[sr][sc]
    if old == new_color:
        return image
    def dfs(r, c):
        if 0 <= r < len(image) and 0 <= c < len(image[0]) and image[r][c] == old:
            image[r][c] = new_color
            dfs(r + 1, c); dfs(r - 1, c); dfs(r, c + 1); dfs(r, c - 1)
    dfs(sr, sc)
    return image

Complexity: Time O(rows * cols); Space O(rows * cols) recursion.

Edge cases to test

  • Same colour
  • Single cell

Is There a Path?

Easy Graph DFS LC 1971

Given an undirected graph with n nodes and edges, return True if there is a path from source to destination.

This is a well-known public interview classic (LeetCode-style problem #1971). The guide does not claim any company asked it.

FieldDetail
DSA conceptGraph DFS (Graphs)
Input formatn, edges, source, destination.
Output formatTrue or False.
Constraintsn <= 2*10^5

Sample input

n=3, [[0,1],[1,2],[2,0]], 0, 2

Sample output

True

Explanation: 0 -> 2 directly.

Stuck? Reveal hints one at a time

Hint 1

Use a stack and a visited set.

Recommended approach (spoiler)

Build an adjacency list and run an iterative DFS from the source, stopping if you reach the destination.

Python solution (try first)

def path_exists(n, edges, source, destination):
    graph = [[] for _ in range(n)]
    for a, b in edges:
        graph[a].append(b)
        graph[b].append(a)
    seen, stack = {source}, [source]
    while stack:
        node = stack.pop()
        if node == destination:
            return True
        for nb in graph[node]:
            if nb not in seen:
                seen.add(nb)
                stack.append(nb)
    return False

Complexity: Time O(V + E); Space O(V + E).

  • Disconnected graph

Number of Islands

Medium Grid DFS / BFS, connected components LC 200 must-do

In a grid of "1" (land) and "0" (water), count islands. Land connects horizontally and vertically.

This is a well-known public interview classic (LeetCode-style problem #200, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptGrid DFS / BFS, connected components (Graphs)
Input formatList of strings.
Output formatInteger.
Constraintsrows, cols <= 300

Sample input

["11000","11000","00100","00011"]

Sample output

3

Explanation: Top-left block, the single middle cell, and the bottom-right pair.

Stuck? Reveal hints one at a time

Hint 1

Mark visited cells (modify a copy or use a set).

Hint 2

Four directions: up, down, left, right.

Recommended approach (spoiler)

Scan every cell. When you find unvisited land, count one island and flood-fill (DFS) all connected land so it is not counted again.

Python solution (try first)

def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    seen = set()
    def dfs(r, c):
        if not (0 <= r < rows and 0 <= c < cols):
            return
        if grid[r][c] != "1" or (r, c) in seen:
            return
        seen.add((r, c))
        dfs(r + 1, c); dfs(r - 1, c); dfs(r, c + 1); dfs(r, c - 1)
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == "1" and (r, c) not in seen:
                count += 1
                dfs(r, c)
    return count

Complexity: Time O(rows * cols); Space O(rows * cols).

Edge cases to test

  • Empty grid
  • All water
  • All land

Shortest Path in a Grid

Medium BFS shortest path

Grid cells are "." (open) or "#" (wall). Find the minimum number of moves (up/down/left/right) from the top-left to the bottom-right, or -1.

FieldDetail
DSA conceptBFS shortest path (Graphs)
Input formatList of strings.
Output formatInteger.
Constraintsrows, cols <= 100

Sample input

["..#","...","#.."]

Sample output

4

Explanation: Move down, right, right, down (4 moves).

Stuck? Reveal hints one at a time

Hint 1

Check start and end cells for walls.

Hint 2

Mark visited on enqueue.

Recommended approach (spoiler)

BFS explores cells in increasing distance, so the first time it reaches the target the distance is minimal. Store (row, col, dist) in the queue.

Python solution (try first)

from collections import deque

def shortest_path_grid(grid):
    rows, cols = len(grid), len(grid[0])
    if grid[0][0] == "#" or grid[-1][-1] == "#":
        return -1
    q = deque([(0, 0, 0)])
    seen = {(0, 0)}
    while q:
        r, c, d = q.popleft()
        if (r, c) == (rows - 1, cols - 1):
            return d
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == "." and (nr, nc) not in seen:
                seen.add((nr, nc))
                q.append((nr, nc, d + 1))
    return -1

Complexity: Time O(rows * cols); Space O(rows * cols).

Edge cases to test

  • Start or end blocked
  • 1x1 grid -> 0
  • No path

Python solution (try first)

from collections import deque

def can_finish(n, prereqs):
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in prereqs:
        graph[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    done = 0
    while q:
        node = q.popleft()
        done += 1
        for nb in graph[node]:
            indeg[nb] -= 1
            if indeg[nb] == 0:
                q.append(nb)
    return done == n

Complexity: Time O(V + E); Space O(V + E).

Connected Components

Medium DFS / Union-Find LC 323 must-do

Given n nodes (0..n-1) and undirected edges, return the number of connected components.

This is a well-known public interview classic (LeetCode-style problem #323, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptDFS / Union-Find (Graphs)
Input formatn and edges.
Output formatInteger.
Constraintsn <= 2000

Sample input

n=5, [[0,1],[1,2],[3,4]]

Sample output

2

Explanation: {0,1,2} and {3,4}.

Stuck? Reveal hints one at a time

Hint 1

Isolated nodes are components of their own.

Recommended approach (spoiler)

Build an adjacency list. For each unvisited node, start a DFS and count one component.

Python solution (try first)

def count_components(n, edges):
    graph = [[] for _ in range(n)]
    for a, b in edges:
        graph[a].append(b)
        graph[b].append(a)
    seen = set()
    def dfs(u):
        seen.add(u)
        for v in graph[u]:
            if v not in seen:
                dfs(v)
    comps = 0
    for i in range(n):
        if i not in seen:
            comps += 1
            dfs(i)
    return comps

Cycle in an Undirected Graph

Medium Union-Find / DFS

Return True if an undirected graph contains a cycle.

FieldDetail
DSA conceptUnion-Find / DFS (Graphs)
Input formatn and edges.
Output formatTrue or False.
Constraintsn <= 10^4

Sample input

n=3, [[0,1],[1,2],[2,0]]

Sample output

True

Explanation: The triangle is a cycle.

Stuck? Reveal hints one at a time

Hint 1

Use path compression in find().

Recommended approach (spoiler)

Union-Find: for each edge, if both endpoints already share a root, the edge closes a cycle; otherwise union them.

Python solution (try first)

def has_cycle_undirected(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]    # path compression
            x = parent[x]
        return x
    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra == rb:
            return True
        parent[ra] = rb
    return False

Complexity: Time O(E * alpha(V)) ~ O(E); Space O(V).

Edge cases to test

  • Tree (no cycle)
  • Parallel edges

Rotting Oranges

Medium Multi-source BFS LC 994

Grid cells: 0 empty, 1 fresh orange, 2 rotten orange. Every minute rotten oranges rot their 4 neighbours. Return minutes until no fresh orange remains, or -1 if impossible.

This is a well-known public interview classic (LeetCode-style problem #994). The guide does not claim any company asked it.

FieldDetail
DSA conceptMulti-source BFS (Graphs)
Input formatGrid.
Output formatInteger.
Constraintsrows, cols <= 10

Sample input

[[2,1,1],[1,1,0],[0,1,1]]

Sample output

4

Explanation: The rot spreads outward for 4 minutes.

Stuck? Reveal hints one at a time

Hint 1

Put all rotten cells in the queue first.

Recommended approach (spoiler)

Start BFS from ALL rotten oranges at once. Each BFS level is one minute. At the end if any fresh orange is left, return -1.

Python solution (try first)

from collections import deque

def rotting_oranges(grid):
    rows, cols = len(grid), len(grid[0])
    q, fresh = deque(), 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                q.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    while q and fresh:
        for _ in range(len(q)):                     # one minute = one BFS level
            r, c = q.popleft()
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    q.append((nr, nc))
        minutes += 1
    return minutes if fresh == 0 else -1

Complexity: Time O(rows * cols); Space O(rows * cols).

Edge cases to test

  • No fresh oranges -> 0
  • Unreachable fresh orange -> -1

Is the Graph Bipartite?

Medium BFS colouring LC 785

A graph is bipartite if you can colour nodes with two colours so every edge joins different colours. Input is an adjacency list; return True or False.

This is a well-known public interview classic (LeetCode-style problem #785). The guide does not claim any company asked it.

FieldDetail
DSA conceptBFS colouring (Graphs)
Input formatgraph (list of neighbour lists).
Output formatTrue or False.
Constraintsn <= 100

Sample input

[[1,3],[0,2],[1,3],[0,2]]

Sample output

True

Explanation: Colour 0 and 2 red, 1 and 3 blue.

Stuck? Reveal hints one at a time

Hint 1

Odd cycles break bipartiteness.

Recommended approach (spoiler)

BFS each unvisited node. Give the start colour 0; give each neighbour the opposite colour; if a neighbour already has the same colour as the current node, return False.

Python solution (try first)

from collections import deque

def is_bipartite(graph):
    color = {}
    for start in range(len(graph)):
        if start in color:
            continue
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in graph[u]:
                if v not in color:
                    color[v] = 1 - color[u]      # opposite colour
                    q.append(v)
                elif color[v] == color[u]:
                    return False
    return True

Complexity: Time O(V + E); Space O(V).

  • Triangle (odd cycle)

Course Schedule II

Medium Topological sort (Kahn) LC 210

Return an order in which all courses can be taken (prerequisite pairs [a, b] mean b before a), or an empty list if impossible.

This is a well-known public interview classic (LeetCode-style problem #210). The guide does not claim any company asked it.

Why interviewers ask this: The follow-up to Course Schedule: return an actual order.

FieldDetail
DSA conceptTopological sort (Kahn) (Graphs)
Input formatn and prerequisites.
Output formatList.
Constraintsn <= 2000

Sample input

4, [[1,0],[2,0],[3,1],[3,2]]

Sample output

[0,1,2,3]

Explanation: 0 first, then 1 and 2, then 3.

Stuck? Reveal hints one at a time

Hint 1

The output order is the answer.

Recommended approach (spoiler)

Kahn's algorithm: queue nodes with in-degree 0, output them and decrement neighbours. If fewer than n nodes are output, there is a cycle.

Python solution (try first)

from collections import deque

def course_order(n, prereqs):
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in prereqs:
        graph[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []

Complexity: Time O(V + E); Space O(V + E).

Edge cases to test

Pacific Atlantic Water Flow

Medium Multi-source DFS/BFS LC 417 must-do

Water flows to neighbouring cells with height <= current. Return the cells from which water can reach both the top/left edge (Pacific) and the bottom/right edge (Atlantic).

This is a well-known public interview classic (LeetCode-style problem #417, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Why interviewers ask this: Reverse thinking: flood from the oceans uphill instead of from every cell.

DSA conceptMulti-source DFS/BFS (Graphs)

Constraintsrows, cols <= 200

Sample input

5 x 5 sample

[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]

Explanation: Seven cells reach both oceans.

Stuck? Reveal hints one at a time

Hint 1

Recommended approach (spoiler)

Do BFS/DFS from each ocean's border moving UPHILL (to cells with height >= current). The answer is the intersection of the two reachable sets.

Python solution (try first)

from collections import deque

def pacific_atlantic(heights):
    R, C = len(heights), len(heights[0])
    def reach(starts):
        seen, q = set(starts), deque(starts)
        while q:
            r, c = q.popleft()
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < R and 0 <= nc < C and (nr, nc) not in seen and heights[nr][nc] >= heights[r][c]:
                    seen.add((nr, nc))
                    q.append((nr, nc))
        return seen
    pac = reach([(0, c) for c in range(C)] + [(r, 0) for r in range(1, R)])
    atl = reach([(R - 1, c) for c in range(C)] + [(r, C - 1) for r in range(R - 1)])
    return sorted([r, c] for r, c in pac & atl)

Complexity: Time O(R * C); Space O(R * C).

Hint 1

Recommended approach (spoiler)

Python solution (try first)

def number_of_provinces(is_connected):
    n = len(is_connected)
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    count = n
    for i in range(n):
        for j in range(i + 1, n):
            if is_connected[i][j]:
                ri, rj = find(i), find(j)
                if ri != rj:
                    parent[ri] = rj
                    count -= 1
    return count

def redundant_connection(edges):
    parent = list(range(len(edges) + 1))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra == rb:
            return [a, b]
        parent[ra] = rb

def surrounded_regions(board):
    grid = [list(r) for r in board]
    R, C = len(grid), len(grid[0])
    def mark(r, c):
        if 0 <= r < R and 0 <= c < C and grid[r][c] == "O":
            grid[r][c] = "S"                     # safe
            mark(r + 1, c); mark(r - 1, c); mark(r, c + 1); mark(r, c - 1)
    for r in range(R):
        mark(r, 0); mark(r, C - 1)
    for c in range(C):
        mark(0, c); mark(R - 1, c)
    return ["".join("O" if ch == "S" else "X" for ch in row) for row in grid]

Python solution (try first)

def cheapest_flights(n, flights, src, dst, k):
    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):
        nxt = dist[:]
        for u, v, w in flights:
            if dist[u] + w < nxt[v]:
                nxt[v] = dist[u] + w
        dist = nxt
    return -1 if dist[dst] == INF else dist[dst]

Python solution (try first)

import heapq

def network_delay(times, n, k):
    graph = {i: [] for i in range(1, n + 1)}
    for u, v, w in times:
        graph[u].append((v, w))
    dist = {}
    heap = [(0, k)]
    while heap:
        d, u = heapq.heappop(heap)
        if u in dist:
            continue                  # already finalised with a shorter distance
        dist[u] = d
        for v, w in graph[u]:
            if v not in dist:
                heapq.heappush(heap, (d + w, v))
    return max(dist.values()) if len(dist) == n else -1

Complexity: Time O(E log V); Space O(V + E).

Minimum Spanning Tree (Kruskal)

Sort by the weight field.

Recommended approach (spoiler)

Kruskal's: sort edges by weight; take an edge if it connects two different components (Union-Find); stop after n-1 edges.

Python solution (try first)

def mst_weight(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    total = used = 0
    for u, v, w in sorted(edges, key=lambda e: e[2]):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            total += w
            used += 1
            if used == n - 1:
                break
    return total

Complexity: Time O(E log E); Space O(V).

Python solution (try first)

from collections import deque

def word_ladder(begin, end, words):
    words = set(words)
    if end not in words:
        return 0
    q = deque([(begin, 1)])
    while q:
        word, steps = q.popleft()
        if word == end:
            return steps
        for i in range(len(word)):
            for ch in "abcdefghijklmnopqrstuvwxyz":
                nxt = word[:i] + ch + word[i + 1:]
                if nxt in words:
                    words.remove(nxt)               # visited
                    q.append((nxt, steps + 1))
    return 0
