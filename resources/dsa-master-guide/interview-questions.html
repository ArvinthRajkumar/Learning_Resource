Programming & Problem-Solving Foundations (54)

Basic Conceptual What is the difference between a list and a tuple in Python?

A list is mutable (you can add, remove or change items). A tuple is immutable (fixed once created). Tuples are slightly faster, use less memory, and can be used as dictionary keys because they are hashable. Lists cannot be dictionary keys.

Basic Conceptual What does 'is' do and how is it different from '=='?

'==' checks whether two values are EQUAL. 'is' checks whether two names point to the very SAME object in memory. [1,2] == [1,2] is True, but [1,2] is [1,2] is False because they are two separate lists. Use 'is' mostly for None: if x is None.

Basic Conceptual Why is b = a dangerous for lists?

It does not copy the list. Both a and b point to the same list, so changing one changes the other. Make a copy with b = a[:] or b = a.copy(). For lists inside lists use copy.deepcopy(a).

Basic Conceptual What is the output of print(7 // 2, -7 // 2, 7 % 3, -7 % 3)?

3 -4 1 2. Floor division rounds DOWN toward minus infinity, so -7 // 2 is -4. The remainder always has the same sign as the divisor, so -7 % 3 is 2. This differs from C and Java, so be careful.

Basic Conceptual How do you read n integers from one line in Python?
nums = list(map(int, input().split()))

input() reads the line as text, split() cuts it into pieces, map(int, ...) converts every piece to an integer, and list() collects them.

Basic Conceptual What is a mutable default argument bug?
def add(x, items=[]):
    items.append(x)
    return items

The default list is created ONCE when the function is defined, so every call that uses the default shares the same list. The fix is items=None and then 'if items is None: items = []' inside the function.

Basic Conceptual Why does Python have no integer overflow?

Python ints are arbitrary precision. When a value exceeds the machine word size, Python stores it as multiple digits. The cost is speed on enormous numbers, but correctness is automatic. This is why problems asking for answers modulo 10^9+7 are still required: the judge wants a small number.

Basic Behavioral Tell me about a bug you found because of an input/format mistake and how you prevented it later.

A good answer is a specific story: I misread that the first line was the count, so my list was off by one and the hidden tests failed. I now (1) rewrite the input format in a comment, (2) test the sample in the exact judge format, and (3) always test one empty or minimal case before submitting.

Basic Conceptual How do you approach a coding problem you have never seen?

I go in steps: (1) restate the problem in my own words, (2) note input, output and constraints, (3) work the sample by hand, (4) list edge cases, (5) think of a simple brute-force way and its time cost, (6) improve it with a suitable tool (hash map, sorting, two pointers...), (7) code it, and (8) dry-run it on the sample and an edge case.

Basic Conceptual What do you do if you are stuck?

I try a smaller input by hand and look for a pattern, ask what work is being repeated, and think about which data structure fits. If I still have no idea, I write the brute force first - a correct slow solution is better than nothing and often shows where to optimise.

Basic Conceptual Why do constraints matter?

They tell you the speed your solution needs. About 10^7 to 10^8 simple operations fit in one second. If n = 10^5 then O(n^2) (10^10 steps) is too slow but O(n log n) is fine.

Basic Conceptual What are edge cases? Give examples.

Edge cases are unusual inputs that often break code: an empty list, one element, all elements equal, negative numbers, zero, duplicate values, the largest allowed input, and a target that is missing.

Basic Conceptual Why should you ask clarifying questions in an interview?

Problems are deliberately underspecified. Asking about input size, duplicates, sorted or not, negative numbers and expected output on invalid input shows maturity, and the answers often reveal the intended algorithm.

Basic Behavioral Describe how you handle a task when requirements are unclear.

I restate the requirement in my own words, list assumptions and open questions, confirm them with the owner, and start with the smallest useful version while keeping the unclear parts easy to change.

Basic Conceptual What is recursion and what must every recursive function have?

Recursion is a function calling itself on a smaller problem. It must have a base case (stops the calls) and a recursive step that gets closer to the base case. Without them it never ends and Python raises RecursionError.

Basic Conceptual What is the time and space complexity of recursive factorial?

Time O(n) because there are n calls. Space O(n) because n frames sit on the call stack at the deepest point. An iterative loop uses O(1) space.

Basic Conceptual How do you avoid RecursionError for deep recursion?

Convert the recursion to a loop with your own stack, or raise the limit with sys.setrecursionlimit (use with care), or restructure the algorithm (for example iterative DFS).

Basic Conceptual What is the difference between a parameter and an argument?

A parameter is the variable name in the function definition. An argument is the real value you pass when calling. In def f(x): x is a parameter; in f(5) the 5 is an argument.

Basic Conceptual What is the difference between direct and indirect recursion?

Direct: f calls f. Indirect: f calls g and g calls f. Both need base cases to stop.

Medium Tricky output What does print(0.1 + 0.2 == 0.3) show and why?

False. Floats are stored in binary, and 0.1 and 0.2 cannot be represented exactly, so the sum is 0.30000000000000004. Compare floats with a tolerance: abs(a - b) < 1e-9, or use math.isclose(a, b).

Medium Coding Write a function that returns the sum of the digits of a number without converting to a string.
def digit_sum(n):
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

n % 10 takes the last digit and n // 10 removes it.

Medium Real-world Why do online judges give wrong answer for an extra space at the end of a line?

Many judges compare output text exactly (some trim trailing whitespace, but you cannot rely on it). The safe habit: print exactly what the format says, use print(*items) for space-separated lines and avoid prompts like 'Enter n:'.

Medium Why / Why not Why does Python not make you declare variable types?

Python decides the type from the value at run time (dynamic typing). It makes short programs easy to write. The price is that mistakes (like adding a number to text) appear only when that line runs.

Medium Why / Why not Why not use input() for very large input?

Each input() call has overhead. For 10^5 lines the calls add up. sys.stdin.read().split() reads everything at once and is much faster.

Medium Why / Why not Why convert with int() instead of just using the text?

Text '5' + '3' joins to '53'. Only numbers can be added. The conversion tells Python what kind of data you mean.

Medium Why / Why not Why use a for loop instead of a while loop when counting?

A for loop updates the counter for you, so you cannot forget it and create an endless loop. while is for 'repeat until something changes'.

Medium Why / Why not Why not name variables a, b, c?

Short names hide meaning. total_marks tells the reader (and you, an hour later) what the value is. Good names are a cheap form of documentation.

Medium Why / Why not Why should you not print prompts like 'Enter a number' in a coding round?

The judge compares your output exactly with the expected output. Extra text makes every test fail even if your logic is correct.

Medium Tricky output What does print(type(5 / 2), type(5 // 2)) print?

<class 'float'> <class 'int'>. / always returns a float, // returns an int when both operands are ints.

Medium Coding Read a number n and print the sum of the first n natural numbers in one line.
n = int(input())
print(n * (n + 1) // 2)

Using the formula avoids a loop; // keeps the result an integer.

Medium Real-world How do constraints guide your choice of algorithm?

n up to about 20 permits exponential search; up to about 500 allows O(n^3); up to a few thousand O(n^2); 10^5 requires O(n log n) or O(n); 10^7 or more needs near O(n) or O(log n) per query.

Medium Tricky output What is wrong with testing only the sample input?

Samples are usually the easy case. Hidden tests cover boundaries, large inputs, and special values. A solution can pass the sample and fail most tests, so always add your own edge cases.

Medium Why / Why not Why write down edge cases before coding?

Because after coding you will unconsciously test only inputs your code already handles. Listing them first makes you design for them.

Medium Why / Why not Why not start coding as soon as you see a familiar problem?

Similar-looking problems often differ in one detail (distinct vs duplicates, sorted vs unsorted, indices vs values). Coding the wrong variant wastes the whole attempt.

Medium Why / Why not Why do constraints decide the algorithm?

They tell you how many steps you can afford. n = 10^5 allows about n log n steps, so an O(n^2) idea is rejected before you write it.

Medium Why / Why not Why dry-run instead of just running the code?

Running tells you the result is wrong; dry running shows exactly which line first goes wrong. It also works when no judge or tests are available.

Medium Why / Why not Why break a problem into steps?

People hold only a few things in mind at once. Small steps fit in memory, are easy to test separately and map to functions.

Medium Why / Why not Why not trust the sample test alone?

Samples are usually the easy case. Hidden tests include empty input, single values, duplicates, negatives and maximum size.

Medium Real-world Give an example where a misread requirement caused a bug.

A statement said 'positive integers' but the data contained 0, so a division failed. Re-reading constraints and testing zero would have caught it.

Medium Tricky output What does this print?
def f(n):
    if n == 0:
        return
    print(n)
    f(n - 1)
    print(n)
f(3)

3 2 1 1 2 3 (each on its own line). Going down it prints 3, 2, 1; after the base case returns, each pending call prints its own n on the way back up: 1, 2, 3.

Medium Coding Write a recursive function to reverse a string.
def rev(s):
    if len(s) <= 1:
        return s
    return rev(s[1:]) + s[0]

Base case: 0 or 1 characters. Recursive step: reverse the rest and put the first character at the end. O(n^2) because slicing copies; an index-based version is O(n).

Medium Real-world Where does recursion appear in everyday software?

Directory traversal, parsing JSON/HTML, rendering nested UI components, evaluating expressions, game tree search and divide-and-conquer sorting.

Medium Why / Why not Why does recursion need a base case?

Without a stopping point the function keeps calling itself until Python raises RecursionError. The base case is the smallest problem you can answer directly.

Medium Why / Why not Why not always use recursion since it looks shorter?

Each call uses a stack frame and Python limits depth to about 1000. Loops are faster and use constant memory for simple repetition.

Medium Why / Why not Why use functions at all?

To name a piece of logic, reuse it, test it alone and keep each part small enough to understand.

Medium Why / Why not Why does a function return None if you forget return?

Python functions always return something; with no return statement the result is None. This is why print(f()) sometimes shows None.

Medium Why / Why not Why use default arguments carefully?

Defaults are created once. A mutable default like [] is shared between calls, so values from earlier calls leak into later ones.

Medium Why / Why not Why is recursion natural for trees but not for summing a list?

A tree node is made of smaller trees, so the code mirrors the data. A list can be summed with a simple loop without any stack cost.

Medium Coding Write a recursive function that counts down from n to 1.
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)
Medium Tricky output What does factorial(0) return and why?

1. By definition 0! = 1, and it serves as the base case for the recursion.

Advanced Follow-up Now do the same for negative numbers and for a number given as a string with up to 10^6 digits.

For negatives use abs(n) first. For a huge digit string, do not convert to int; loop over the characters: sum(int(ch) for ch in s if ch.isdigit()). O(length) time.

Advanced Follow-up You wrote a solution. What do you do before saying 'done'?

Dry-run it on the sample, run an empty and single-element input, state the time and space complexity, and mention what I would improve with more time.

Advanced Follow-up You finished early. How do you use the remaining time?

Re-read the statement against my output format, test boundary inputs, reconsider complexity on the largest input, and clean up variable names.

Advanced Follow-up Your recursive solution hits RecursionError for n = 100000. What do you do?

Convert it to a loop or use an explicit stack. Raising the limit is risky. If subproblems repeat, convert to bottom-up dynamic programming.

Time & Space Complexity (38)

Basic Conceptual What is the time complexity of binary search and why?

O(log n). Each step throws away half of the remaining items, so the number of steps is how many times you can halve n before reaching 1, which is log2(n).

Basic Conceptual What is the difference between O(n) and O(2n)?

No difference in Big-O. Constants are dropped, so O(2n) is O(n). Both grow in a straight line.

Basic Conceptual What is the complexity of two loops, one after the other, each running n times? What if one loop is inside the other?

One after the other: O(n) + O(n) = O(n). One inside the other: O(n * n) = O(n^2).

Basic Conceptual What is the worst case of searching a list with 'x in nums'?

O(n). In the worst case x is last or missing and Python has to check every element.

Basic Conceptual Is O(n log n) faster than O(n^2)?

Yes for large n. For n = 1000: n log n is about 10,000 steps while n^2 is 1,000,000. The gap grows as n grows.

Basic Conceptual What is amortised O(1)?

An operation that is occasionally expensive but cheap on average over many calls. list.append is amortised O(1): usually one step, sometimes it copies the list to a bigger memory block, but spread over all appends the average is constant.

Basic Conceptual Why do we drop constants and lower-order terms?

Because for large n the dominant term decides the growth, and constants depend on hardware and language. 5n^2 + 100n is O(n^2); the 5 and the 100n become minor as n grows.

Basic Conceptual What is the difference between O, Omega and Theta?

O is an upper bound, Omega a lower bound, Theta a tight bound (both). Everyday speech uses O for the tight worst case.

Basic Conceptual What is the complexity of: for i in range(n): for j in range(i, n): ...?

The inside runs n + (n-1) + ... + 1 = n(n+1)/2 times, which is O(n^2).

Basic Conceptual What is the complexity of: i = 1; while i < n: i *= 2?

O(log n). i doubles each time, so it takes log2(n) steps to reach n.

Basic Conceptual How would you reduce the time of checking if a list has duplicates?

Brute force compares all pairs in O(n^2). Put elements into a set while scanning; if an element is already in the set you found a duplicate. That is O(n) time and O(n) space.

Basic Conceptual What is the complexity of recursive Fibonacci and how can you improve it?

O(2^n) because each call makes two calls and subproblems repeat. Add memoisation (a dictionary or lru_cache) so each value is computed once: O(n) time, O(n) space.

Basic Conceptual Why does appending with s += ch in a loop matter for strings?

Strings are immutable, so each += builds a new string copying all previous characters. Over n steps this can be O(n^2). Better: collect characters in a list and use ''.join(list) at the end.

Basic Conceptual What is the space complexity of recursion?

O(depth of recursion) because each active call holds a frame. For a balanced tree that is O(log n); for a linked-list-shaped tree O(n).

Medium Tricky output What is the time complexity of this?
for i in range(n):
    for j in range(i):
        pass

O(n^2). The inner loop runs 0 + 1 + ... + (n-1) = n(n-1)/2 times, which is quadratic.

Medium Tricky output What is the complexity of this?
i = n
while i > 0:
    i //= 2

O(log n). i halves every iteration.

Medium Real-world Why does an O(n^2) feature work in testing and die in production?

Test data is small. Growth is invisible at n = 100 but at n = 10^6 the same feature does 10^12 steps. Reasoning about complexity before shipping avoids this.

Medium Coding Return True if any two numbers in a list sum to k. Give two solutions and their complexity.

Brute force: two nested loops, O(n^2) time, O(1) space. Hash set: for each x check k - x in the set, then add x; O(n) time, O(n) space.

Medium Why / Why not Why do we ignore constants in Big-O?

Constants depend on the machine and language. For large n the growth shape decides the winner, so 5n and 100n are both 'linear'.

Medium Why / Why not Why not just measure seconds?

Seconds change with hardware, input and noise. Complexity predicts behaviour before running and compares algorithms fairly.

Medium Why / Why not Why usually talk about the worst case?

It is a guarantee: no input can be slower. Best case is rarely realistic and average case needs assumptions about the data.

Medium Why / Why not Why does O(log n) feel almost free?

Doubling the input adds only one step. log2 of a billion is about 30.

Medium Why / Why not Why is O(n!) worse than O(2^n)?

n! multiplies by a bigger number each step (n, then n-1, ...) while 2^n multiplies by 2 each time. At n = 20, n! is about 2.4 x 10^18 versus 2^20 about 10^6.

Medium Why / Why not Why can an O(n^2) algorithm beat O(n log n) for small n?

Complexity hides constants and overhead. For tiny inputs a simple loop with small constants can be faster than a clever method with setup cost. Growth wins only at larger n.

Medium Coding What is the complexity of this code and why?
def f(n):
    s = 0
    for i in range(n):
        for j in range(10):
            s += 1
    return s

O(n). The inner loop always runs 10 times (a constant), so total steps are 10n.

Medium Tricky output What is the complexity of recursive code that calls f(n-1) twice?

O(2^n). Each call spawns two calls, so the number of calls doubles per level for n levels.

Medium Coding Optimise: for each number in a list count how many numbers are smaller than it.

Brute force is O(n^2). Sort a copy, then use binary search (bisect_left) for each number: O(n log n). If values are small, a counting + prefix sum approach is O(n + k).

Medium Real-world A report is slow because it concatenates strings in a loop. Why?

Each += copies the existing string, so n appends cost O(n^2) total. Collect parts in a list and ''.join them once.

Medium Why / Why not Why do nested loops multiply but sequential loops add?

A nested inner loop runs fully for every iteration of the outer loop (n x m). Sequential loops run one after another (n + m).

Medium Why / Why not Why must you count recursion depth as space?

Each active call holds a stack frame in memory. Depth d means d frames at once, which is O(d) extra space.

Medium Why / Why not Why is trading space for time common?

Memory is cheap compared with time limits. A set or dictionary can remove an entire inner loop.

Medium Why / Why not Why not always choose the lowest time complexity?

A lower complexity may use much more memory, be harder to write or be slower for small n. Choose the simplest solution that passes the limits.

Medium Why / Why not Why does slicing hide a cost?

a[i:j] copies j - i elements, so a slice inside a loop can turn O(n) into O(n^2).

Medium Why / Why not Why is 'x in list' risky inside a loop?

It scans the list: O(n) per check, so the loop becomes O(n^2). Use a set for O(1) average membership.

Medium Tricky output What is the complexity of sorting inside a loop that runs n times on a list of size n?

O(n^2 log n). Each sort costs O(n log n) and it runs n times.

Advanced Follow-up Your algorithm is O(n log n) and you have n = 10^6. Is that fine in Python?

About 2 x 10^7 basic steps: usually fine if the work per step is small and uses built-ins like sorted(); it may be tight with heavy Python loops. Prefer built-ins and avoid per-step overhead.

Advanced Follow-up Can you improve O(n log n) sorting-based duplicate detection?

Yes, use a set for O(n) average time at the price of O(n) space.

Advanced Follow-up How do you analyse a function that calls itself with n/2 twice and does O(1) extra work?

T(n) = 2T(n/2) + 1, which solves to O(n): the recursion tree has n leaves and about n total nodes.

Arrays and Lists (55)

Basic Conceptual How do you reverse a list in Python? Give two ways.
nums.reverse()        # in place, O(1) extra space
rev = nums[::-1]      # new reversed list, O(n) extra space

You can also write the two-pointer swap loop yourself.

Basic Conceptual Why is inserting at the front of a list slow?

Every existing element has to move one position to the right to make room, so it takes O(n). If you need fast inserts at both ends, use collections.deque.

Basic Conceptual How do you find the second largest element in one pass?

Keep two variables first and second. For each x: if x > first then second = first and first = x; elif first > x > second then second = x. Return second (or -1 if it never changed). O(n) time, O(1) space.

Basic Conceptual How do you remove duplicates from a sorted list in place?

Use a write pointer w starting at 1. For each element after the first, if it differs from nums[w-1], copy it to nums[w] and increase w. The first w items are the unique values.

Basic Conceptual What is the difference between a shallow copy and a deep copy?

A shallow copy (a[:] or list(a)) creates a new outer list but the inner objects are shared. For a list of lists, changing an inner list changes both copies. A deep copy (copy.deepcopy) copies everything recursively.

Basic Conceptual Why is array indexing O(1)?

Elements sit in contiguous memory in equal-sized slots, so the address of element i is base + i x size, computed in one step. In Python the slots hold pointers.

Basic Conceptual How do you find duplicates in a list in O(n)?

Count with a dictionary or Counter, then collect keys whose count is above 1. Or use a seen set and record an item when it is already in the set.

Basic Conceptual How do you find the missing number from 0..n in O(n) time and O(1) space?

expected = n * (n + 1) // 2 and the answer is expected - sum(nums). XOR of all indices and values also works.

Basic Conceptual How would you rotate an array by k in place?

Do k %= n, reverse the whole array, reverse the first k elements, reverse the remaining n - k elements. O(n) time, O(1) space.

Basic Conceptual How do you find the element that appears once when all others appear twice?

XOR all the numbers. Equal numbers cancel (x ^ x = 0) and 0 ^ y = y, so only the single number remains.

Basic Conceptual What is the Boyer-Moore voting algorithm?

It finds an element appearing more than n/2 times in O(1) space. Keep a candidate and a count. Same number: count + 1, different number: count - 1, when count is 0 pick a new candidate. The true majority cannot be fully cancelled out.

Basic Conceptual Why does XOR find the single number?

x ^ x = 0 and x ^ 0 = x, and XOR is order-independent, so every pair cancels and only the single number remains.

Basic Conceptual Explain Kadane's algorithm.

Scan once with cur = best sum of a subarray that ends at the current element. cur = max(x, cur + x) (extend or restart), best = max(best, cur). Time O(n), space O(1). Start best at nums[0] so all-negative arrays work.

Basic Conceptual How do prefix sums speed up range queries?

Precompute prefix[i] once in O(n). Then sum(l..r) = prefix[r+1] - prefix[l] in O(1) instead of looping each time.

Basic Conceptual How do you count subarrays with sum exactly k, even with negative numbers?

Keep a running prefix sum and a dictionary of prefix frequencies starting with {0: 1}. For each element add count[prefix - k] to the answer, then record the current prefix. O(n) time.

Basic Conceptual Why does sliding window fail when the array has negative numbers?

Window logic relies on 'adding an element increases the sum, removing decreases it'. With negatives that is not true, so you cannot decide whether to shrink or grow. Use prefix sums + hash map instead.

Basic Conceptual What do you return if the array is all negative in the maximum subarray problem?

The largest single element (the least negative). That is why best must start at nums[0], not 0.

Basic Conceptual Why do prefix sums fail for 'range maximum'?

Subtraction undoes addition but nothing undoes max. Use a sparse table or segment tree for range max.

Medium Coding Reverse an array in place and explain complexity.
def reverse(a):
    lo, hi = 0, len(a) - 1
    while lo < hi:
        a[lo], a[hi] = a[hi], a[lo]
        lo += 1
        hi -= 1

O(n) time, O(1) extra space.

Medium Real-world Why do image libraries use arrays instead of linked lists?

Pixel access by coordinates must be O(1) and processing scans memory sequentially, which is fast for contiguous data thanks to CPU caching.

Medium Why / Why not Why do list indexes start at 0?

The index is the distance from the first element. The first element is 0 steps away, so its offset is 0. It also makes address arithmetic simple.

Medium Why / Why not Why is inserting in the middle slow?

Items sit side by side, so everything after the insertion point must move one place to make room: O(n).

Medium Why / Why not Why not use a list as a queue?

pop(0) shifts every remaining element: O(n). Use collections.deque for O(1) at both ends.

Medium Why / Why not Why does b = a not copy a list?

Assignment copies the reference (the label), not the object. Both names point at the same list. Use a[:] or list(a) to copy.

Medium Why / Why not Why is append fast even though the list occasionally resizes?

Python allocates extra spare room, so most appends just use a free slot. The rare resize cost is spread over many appends (amortised O(1)).

Medium Why / Why not Why use enumerate instead of range(len(nums))?

enumerate gives index and value together, is clearer, and avoids indexing mistakes. Use range(len(...)) only when you really need to change items by index.

Medium Tricky output What does a = [1, 2, 3]; print(a[1:], a[:-1], a[::-1]) print?

[2, 3] [1, 2] [3, 2, 1].

Medium Coding Write a function that returns True if a list is sorted in non-decreasing order.
def is_sorted(a):
    return all(a[i] <= a[i + 1] for i in range(len(a) - 1))

O(n) time, stops at the first violation.

Medium Coding Find the first non-repeating number in a list in O(n).
from collections import Counter
def first_unique(a):
    c = Counter(a)
    for x in a:
        if c[x] == 1:
            return x
    return None
Medium Tricky output What does Counter('aab') - Counter('abb') produce?

Counter({'a': 1}). Subtraction keeps only positive counts: a has 2 - 1 = 1; b has 1 - 2 < 0 and is dropped.

Medium Real-world How would you find duplicate user IDs in a file with 10 million lines that does not fit memory?

Hash partition the IDs into many smaller files (same ID always lands in the same file) and check duplicates per file with a set, or use external sorting.

Medium Why / Why not Why use a dictionary to count instead of count() in a loop?

list.count(x) scans the whole list, so calling it for every element is O(n^2). One dictionary pass is O(n).

Medium Why / Why not Why does XOR find the single number?

XOR cancels equal numbers (x ^ x = 0) and does not care about order, so only the unpaired value survives.

Medium Why / Why not Why not just sort to find duplicates?

Sorting works (equal items become neighbours) but costs O(n log n). A set or Counter is O(n).

Medium Why / Why not Why take k %= n before rotating?

Rotating by n returns the original list, so only the remainder matters. It also prevents index errors for large k.

Medium Why / Why not Why is the sum formula safe in Python but risky elsewhere?

Python integers do not overflow. In C/Java n(n+1)/2 can exceed 32-bit limits, so XOR is safer there.

Medium Why / Why not Why not use a list of size max(nums) as a counter for any data?

If values are huge (10^9) the list needs gigabytes. Use a dictionary when the value range is large or unknown.

Medium Coding Return the element that appears exactly once when all others appear three times.

Count bits: for each bit position sum the bits across all numbers modulo 3; the remaining bits form the answer. O(32 n) time, O(1) space. A Counter is simpler (O(n) space).

Basic Conceptual Why is binary search O(log n)?

Each comparison halves the search window. After k steps the window has n / 2^k items; it becomes 1 when k = log2(n).

Basic Conceptual Can you use binary search on an unsorted array?

No. The decision 'go left or right' only works because the data is ordered. You would first have to sort it (O(n log n)), which only pays off for many searches.

Basic Conceptual What is the difference between lo <= hi and lo < hi loops?

With lo <= hi and both ends inclusive you check every position including the last one; you use mid + 1 / mid - 1. With lo < hi and hi = len(nums) (half-open) you use hi = mid to keep a candidate. Pick one style and stick with it.

Basic Conceptual Write iterative binary search.
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

Basic Conceptual Write insertion sort.
def insertion_sort(a):
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

def merge(a, b):
    out, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    return out + a[i:] + b[j:]

Basic Conceptual When can you use the two pointer technique?

When the data is sorted or has structure that tells you which pointer to move: pair sums in sorted arrays, palindromes, merging sorted lists, removing items in place, partitioning.

Basic Conceptual Explain pair sum in a sorted array with two pointers.

Basic Conceptual How does Container With Most Water work?

Start with the widest container. Area = width x min(height). Move the pointer at the shorter line inward, because moving the taller one can never improve the area.

Basic Conceptual What is the difference between two pointers and sliding window?

Two pointers is the general idea of two moving indices. Sliding window is a special case where the two pointers define a contiguous range (a window) whose contents you keep track of.

Basic Conceptual Why does the container-with-most-water pointer move the shorter side?

The area is limited by the shorter line. Moving the taller line can only shrink the width without improving the height limit, so the shorter side is the only move that might increase the area.

Basic Conceptual What is the sliding window technique?

Maintain a window (range) over the data and move it step by step, updating the result incrementally instead of recomputing from scratch.

Consecutive windows share k - 1 elements, so only the entering and leaving elements change the result.

Basic Conceptual Array vs linked list - when do you use which?

Array (Python list): fast random access O(1), cache friendly, slow insert/delete in the middle O(n). Linked list: O(1) insert/delete when you already hold the node, slow access O(n), extra memory for pointers.

Basic Conceptual How do you delete a node from a singly linked list?

Find the node before it (prev) and set prev.next = prev.next.next. For the head, set head = head.next (or use a dummy node).

Basic Conceptual What is a dummy node and why use it?

A fake node placed before the head. It makes inserting/deleting at the head the same as anywhere else, and you return dummy.next.

Basic Conceptual How do you find the length of a linked list?

Walk with a counter until the node is None. O(n).

Basic Conceptual What is the difference between singly, doubly and circular linked lists?

Singly: one pointer (next). Doubly: next and prev. Circular: the last node points back to the first.

Basic Conceptual Why is inserting at the front O(1) for a linked list but O(n) for an array?

A linked list only changes two pointers; an array must shift every element to make room.

Basic Conceptual Reverse a linked list iteratively.

    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev

O(n) time and O(1) space for the iterative version. Recursive version uses O(n) stack space.

Find the middle with slow/fast pointers, reverse the second half, compare both halves node by node (optionally restore the list).

Basic Conceptual What goes wrong if you flip the pointer before saving next?

You lose the reference to the rest of the list and cannot continue.

Basic Conceptual How do you reverse only a part of the list (positions m to n)?

Basic Conceptual How can you reverse a linked list recursively?

Reverse the rest (head.next), then set head.next.next = head and head.next = None, returning the new head.

Floyd's tortoise and hare: slow moves 1, fast moves 2. If they meet there is a cycle; if fast hits None there is none. O(n) time, O(1) space.

Basic Conceptual How do you find the middle of a linked list?

Slow/fast pointers. When fast reaches the end, slow is at the middle (second middle for even length).

Basic Conceptual How do you find where the cycle begins?

After the pointers meet, reset one pointer to the head and move both one step at a time; the meeting node is the start of the cycle.

Basic Conceptual How do you remove the N-th node from the end?

Use a dummy node. Move fast n steps ahead, then move slow and fast together until fast.next is None. Then slow.next = slow.next.next.

Recursion & Backtracking (55)

Basic Conceptual What are the parts of a recursive function?

A base case that stops the recursion, a recursive case that calls the function with a smaller input, and (usually) a way to combine the results.

Basic Conceptual Why is naive recursive Fibonacci slow?

It recomputes the same values exponentially many times (O(2^n)). Memoisation reduces it to O(n).

Basic Conceptual Recursion vs iteration - which is better?

Iteration is usually faster and uses O(1) stack. Recursion is clearer for trees, graphs and backtracking. Python has a recursion limit, so deep inputs need loops.

Basic Conceptual What is memoisation?

Caching results of function calls by their arguments so repeated calls return instantly.

It is the case answered without recursion. If missing, the recursion never stops and Python raises RecursionError.

Basic Conceptual Explain backtracking.

Build a solution step by step. At each step choose, recurse, then undo the choice. Prune branches that cannot lead to a valid answer.

Basic Conceptual Generate all subsets of a list.

        res.append(path[:])

Basic Conceptual How many solutions does 8-Queens have?

Basic Conceptual What is the time complexity?

Roughly O(n!) in the worst case, far smaller in practice due to pruning.

Basic Conceptual What are the tree traversals and their orders?

Inorder: left, node, right. Preorder: node, left, right. Postorder: left, right, node. Level order: level by level with a queue.

Basic Conceptual What does inorder traversal of a BST give?

The values in sorted ascending order.

height(node) = 0 if None else 1 + max(height(left), height(right)). O(n).

Basic Conceptual Difference between depth and height?

Depth is measured from the root down to a node; height is measured from a node down to its deepest leaf.

Basic Conceptual How do you do level order traversal?

Use a queue. Process the number of nodes currently in the queue as one level and add their children for the next level.

Basic Conceptual What is the space complexity of recursive DFS on a tree?

O(h) for the call stack, where h is the height.

Basic Conceptual What is the maximum number of nodes in a binary tree of height h (counting edges)?

2^(h+1) - 1.

Basic Conceptual What is a binary search tree?

A binary tree where for every node, all values in the left subtree are smaller and all values in the right subtree are larger.

Basic Conceptual Time complexity of BST operations?

O(h): O(log n) when balanced and O(n) when skewed.

Basic Conceptual How do you validate a BST?

Recurse with the allowed range: left child must be within (low, node.val) and right child within (node.val, high). Checking only the parent is wrong.

Replace its value with its inorder successor (smallest in the right subtree) and then delete that successor node.

Do an inorder traversal and stop at the k-th visited node (iterative stack solution is O(h + k)).

Basic Conceptual Why can a BST become O(n)?

If values are inserted in sorted order the tree becomes a chain.

Basic Conceptual Why can a BST degrade to O(n)?

Inserting sorted data produces a one-sided chain, so height is n and operations walk the whole chain. Self-balancing trees fix this.

Basic Conceptual How do you check if a tree is height balanced efficiently?

Compute heights bottom-up. A helper returns the height or -1 when unbalanced. This is O(n) instead of calling height at every node (O(n^2)).

Basic Conceptual What is the diameter of a binary tree and how do you compute it?

The number of edges on the longest path between any two nodes. For each node the longest path through it is height(left) + height(right); take the maximum while computing heights. O(n).

Basic Conceptual Find the lowest common ancestor of two nodes.

Recurse: if node is None or equals a target return node; get left and right answers; if both are non-null return node; else return whichever is non-null.

Basic Conceptual How do you check if a tree is symmetric?

Compare the left and right subtrees as mirrors: left.left with right.right and left.right with right.left, recursively.

Basic Conceptual How do you check if a root-to-leaf path has a given sum?

Subtract each node's value from the target while going down; at a leaf the remaining target must be 0.

Basic Conceptual What does 'post-order information passing' mean?

Each node computes its result after its children and returns it to its parent, combining the children's results.

Basic Conceptual What is a heap?

A complete binary tree stored in an array where each parent is smaller (min-heap) or larger (max-heap) than its children. The root is the minimum or maximum.

Basic Conceptual Complexity of heap operations?

Push and pop O(log n), peek O(1), build from a list O(n).

Basic Conceptual How do you create a max-heap in Python?

Basic Conceptual What is the difference between a heap and a BST?

A heap only orders parent versus children and gives fast min/max. A BST orders the whole tree (left < node < right) and supports sorted traversal and search.

Basic Conceptual Explain sift-up and sift-down.

Sift-up: after inserting at the end, swap with the parent while smaller. Sift-down: after replacing the root, swap with the smaller child while bigger.

Most nodes are near the bottom and sift only a short distance; the total work sums to a series that is O(n).

Keep a min-heap of size k. Push each number and pop the smallest when the size exceeds k. The root is the answer. O(n log k).

The root is the smallest of the K best so far, so it is the one to throw out when a better item arrives.

Two heaps: max-heap for the lower half, min-heap for the upper half, balanced in size. Median is the top of the bigger heap or the average of both tops.

Basic Conceptual Why use a min-heap to track the K largest?

Basic Conceptual Adjacency list vs adjacency matrix?

List: O(V + E) space, fast to iterate neighbours, good for sparse graphs. Matrix: O(V^2) space, O(1) edge check, good for dense graphs.

Basic Conceptual What is the difference between directed and undirected graphs?

In a directed graph edges have a direction (a -> b). In an undirected graph an edge works both ways.

Basic Conceptual What is a connected component?

A group of nodes where every node can reach every other node in the group, and no edge leaves the group.

Basic Conceptual How do you represent a grid as a graph?

Each cell is a node; its neighbours are the 4 (or 8) adjacent cells inside the bounds. No explicit adjacency list is needed.

Basic Conceptual What is the difference between a tree and a graph?

A tree is a connected graph without cycles (n nodes, n - 1 edges). A general graph can have cycles and multiple components.

Basic Conceptual Why are most graph algorithms O(V + E)?

Each vertex is processed once and each edge is examined once or twice (once per endpoint in undirected graphs).

Basic Conceptual Difference between BFS and DFS?

BFS uses a queue and explores level by level (shortest path in unweighted graphs). DFS uses a stack/recursion and goes deep first. Both O(V + E).

Basic Conceptual Why does BFS find the shortest path?

It visits nodes in increasing order of distance from the start, so the first visit to a node is via a shortest path.

Basic Conceptual When do you mark nodes visited in BFS?

When adding them to the queue, so each node is queued once.

Basic Conceptual How do you detect a cycle in an undirected graph?

During DFS, if you reach a visited node that is not the parent you found a cycle. Or use Union-Find.

Basic Conceptual What is the time complexity of BFS?

O(V + E) time, O(V) space.

Basic Conceptual Write BFS.
from collections import deque
def bfs(graph, start):
    seen, order = {start}, []
    q = deque([start])
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            if v not in seen:
                seen.add(v)
                q.append(v)
    return order

Basic Conceptual Explain the steps to solve a DP problem.

Define state, write the transition, set base cases, choose iteration order, find the answer cell, then optimise space if possible.

Advanced data structures (14)

Basic What problem does a Fenwick tree (BIT) solve?

Point updates and prefix-sum queries in O(log n) with O(n) memory and a very small constant, using lowbit (i & -i) to jump between nodes.

Basic When would you choose a segment tree over a Fenwick tree?

When the operation is not invertible (min, max, gcd) or you need range updates with lazy propagation. A Fenwick tree needs an invertible operation for range queries.

Basic What is a sparse table and what are its limits?

A table of answers for ranges of length 2^k, built in O(n log n), giving O(1) queries for idempotent operations like min and max. It does not support updates.

Medium Explain lazy propagation.

Store pending updates on internal nodes and push them to children only when a later operation needs to descend, so range updates and range queries both stay O(log n).

Medium How do AVL trees stay balanced?

Each node's subtree heights differ by at most one; insertions and deletions fix violations with single or double rotations, giving O(log n) operations.

Medium How do you implement an LFU cache in O(1)?

A hash map from key to node plus a map from frequency to an ordered list of keys, with a tracked minimum frequency that is updated on every access and eviction.

Medium What is a monotonic deque used for?

Sliding window maximum or minimum in O(n): keep indexes whose values are monotonic, pop dominated elements from the back and expired ones from the front.

Medium Compare a hash table with a balanced BST.

Hash tables give O(1) average lookups but no ordering. Balanced BSTs give O(log n) with ordered traversal, predecessor/successor and range queries.

Advanced How do you answer 'number of elements less than x in a range' with updates?

Offline with a Fenwick tree and coordinate compression, a merge sort tree, a persistent segment tree, or sqrt decomposition depending on constraints.

Advanced What is a persistent data structure?

One that preserves earlier versions after updates, usually by path copying so each update adds O(log n) new nodes while old roots remain valid.

Advanced Why do skip lists appear in practice?

They give expected O(log n) ordered operations with simple code and good concurrency properties; Redis sorted sets use them.

Advanced What is amortised O(1) for union-find and what makes it so fast?

With union by rank (or size) and path compression, any sequence of m operations costs O(m alpha(n)), where alpha is the inverse Ackermann function, below 5 for practical n.

Advanced What is a B-tree and why do databases use it?

A balanced multiway tree with large nodes sized to disk pages; the high fan-out keeps the tree very shallow, minimising disk reads.

Advanced How does a bloom filter work and what are its error properties?

k hash functions set bits in a bit array; a query reports present only if all k bits are set. It has false positives but no false negatives and cannot delete (without counting variants).

Advanced graphs (15)

Basic BFS versus DFS: when do you use each?

BFS for shortest paths in unweighted graphs and level order; DFS for cycle detection, topological order, components and backtracking.

Basic Why can't Dijkstra handle negative edges?

It finalises a node when popped assuming no later path can be shorter, which a negative edge can violate. Use Bellman-Ford instead.

Basic What is the complexity of Dijkstra with a binary heap?

O((V + E) log V) in the lazy-deletion form.

Medium Explain Bellman-Ford and negative cycles.

Relax every edge V - 1 times. If another pass still improves a distance, a negative cycle is reachable.

Medium Floyd-Warshall: what does it compute and what is the loop order?

All-pairs shortest paths in O(V^3). The intermediate vertex k must be the outermost loop.

Medium Kruskal versus Prim?

Kruskal sorts edges and joins components with union-find (good for sparse graphs). Prim grows a tree from a start node with a heap (good for dense graphs). Both are O(E log V).

Medium How do you find strongly connected components?

Tarjan's algorithm (low-link values in one DFS) or Kosaraju's (DFS finishing order, then DFS on the reversed graph). Both O(V + E).

Medium How do you test if a graph is bipartite?

BFS or DFS two-colouring; a conflict on an edge means an odd cycle, so it is not bipartite.

Medium What are bridges and articulation points?

A bridge is an edge, and an articulation point a vertex, whose removal disconnects the graph. Found with DFS discovery times and low-link values in O(V + E).

Advanced What is A* and when is it optimal?

Best-first search ordered by g + h, where h estimates the remaining cost. It is optimal with an admissible heuristic (never overestimates), and consistent heuristics avoid reopening nodes.

Advanced How does max flow relate to min cut?

The max-flow min-cut theorem: the maximum flow equals the capacity of the minimum cut. Ford-Fulkerson with BFS (Edmonds-Karp) runs in O(V E^2).

Advanced How is bipartite matching solved?

As a max-flow problem or with Hopcroft-Karp in O(E sqrt V); Konig's theorem links the maximum matching to the minimum vertex cover in bipartite graphs.

Advanced How do you solve 2-SAT?

Build the implication graph, compute SCCs; the formula is unsatisfiable iff a variable and its negation share a component, and a topological order yields an assignment.

Advanced How would you find the shortest path with at most k edges?

Bellman-Ford limited to k rounds (using a copy of the previous distances) or BFS/Dijkstra on a state graph of (node, edges used).

Advanced How do you detect a cycle in a directed versus undirected graph?

Directed: DFS with three colours or Kahn's algorithm. Undirected: DFS/BFS that sees a visited node other than its parent, or union-find.

Advanced DP (14)

Basic How do you recognise a DP problem?

Overlapping subproblems and optimal substructure: a recursive solution that recomputes the same states, where the best answer builds from best answers to smaller states.

Basic Top-down versus bottom-up DP?

Top-down memoises recursion and computes only needed states; bottom-up fills a table in dependency order, avoiding recursion depth and enabling space optimisation.

Basic Solve 0/1 knapsack and give its complexity.

dp[w] = max(dp[w], dp[w - wt] + val), iterating w downward for 0/1. O(nW) time, O(W) space; it is pseudo-polynomial.

Medium Why iterate capacity downward in 0/1 knapsack but upward for unbounded?

Downward prevents reusing an item within the same pass; upward intentionally allows reusing the same item.

Medium Longest increasing subsequence in O(n log n)?

Keep tails[k], the smallest tail of an increasing subsequence of length k + 1, and binary search each element's position.

Medium Define edit distance DP.

dp[i][j] is the cost to convert the first i characters to the first j: equal characters copy dp[i-1][j-1]; otherwise 1 + min(insert, delete, replace).

Medium How do you reconstruct the answer, not only its value?

Store the choice (parent pointer) at each state, or walk backwards through the table checking which transition produced the value.

Medium Interval DP: describe the pattern.

dp[l][r] combines dp over split points k in [l, r), iterating by increasing length. Examples: matrix chain, burst balloons, optimal BST.

Advanced When do you use bitmask DP?

When n is small (about 20) and the state is the subset of items used, as in TSP in O(2^n n^2), assignment problems and partitioning.

Advanced Explain digit DP.

Count numbers up to N with a property by processing digits left to right with state (position, tight, extra info like sum or last digit), memoising when not tight.

Advanced What is the knapsack optimisation for large weights but small values?

Swap the dimensions: dp[value] = minimum weight, giving O(n sum of values), the basis of the FPTAS.

Advanced How do convex hull trick and divide-and-conquer optimisation speed up DP?

When transitions are lines or satisfy monotone optimal split points, you can reduce O(n^2) transitions to O(n log n) or O(n).

Advanced Tree DP: how is it structured?

Compute states for children first (post-order) and combine them, e.g. maximum independent set with dp[v][taken] or rerooting to get answers for every root.

Advanced Why is the coin change count different from the minimum coins DP?

Counting combinations loops over coins outside and amounts inside (order ignored); counting sequences swaps the loops. Minimum uses min instead of sum.

String algorithms (14)

Basic Naive pattern matching complexity and when it is bad?

O(n m) worst case, such as aaaa...ab against aaa...a, because comparisons restart at every position.

Basic What is a trie and what are its operations' costs?

A prefix tree with insert, search and prefix queries in O(length) regardless of dictionary size, at the cost of memory.

Basic How do you check whether one string is a rotation of another?

Same length and the second occurs inside the first concatenated with itself.

Medium Explain the KMP prefix function.

pi[i] is the length of the longest proper prefix of s[0..i] that is also a suffix. On a mismatch the matcher falls back to pi[k - 1] instead of restarting, giving O(n + m).

Medium Why is KMP linear?

The fallback pointer only moves forward one step per character and each fallback decreases it, so total moves are bounded by 2n.

Medium What does the Z array give?

z[i] is the longest common prefix of s and s[i:]; pattern matching on P + '$' + T finds matches where z equals |P|.

Medium How does Rabin-Karp work and what is its failure mode?

It compares rolling hashes of windows with the pattern hash, verifying equal hashes. Collisions or adversarial inputs can degrade it to O(n m); use a large modulus and random base.

Medium How do you find the smallest repeating period of a string?

Take p = n - pi[n - 1]; if p divides n then p is the period, otherwise the string is primitive (period n).

Advanced Manacher's algorithm in one paragraph.

Insert separators, keep the centre and right edge of the rightmost palindrome, and initialise the radius at i from its mirror, then expand. Each expansion moves the right edge, so O(n) overall.

Advanced What is Aho-Corasick and where is it used?

A trie with failure links that finds all occurrences of many patterns in a single pass, O(n + total pattern length + matches). Used in malware scanners and filters.

Advanced What is a suffix array and what can you do with it?

The sorted order of all suffixes. With an LCP array it supports substring search by binary search, longest repeated substring, distinct substring counting and longest common substring.

Advanced Suffix array versus suffix tree versus suffix automaton?

All index all substrings. Suffix trees are the most flexible but memory heavy; suffix arrays are compact and cache friendly; suffix automata are small and build online in linear time.

Advanced How do you count distinct substrings?

n(n + 1)/2 minus the sum of the LCP array of the suffix array.

Advanced How do you find the shortest palindrome by prepending characters?

Compute the prefix function of s + '#' + reverse(s); the last value is the longest palindromic prefix, and the rest of the reversed string is prepended.

Math and number theory (14)

Basic How do you compute gcd and lcm?

Euclid: gcd(a, b) = gcd(b, a mod b), O(log). lcm = a / gcd * b, dividing first to limit overflow.

Basic How do you test primality quickly?

Trial division to sqrt(n) for small n, a sieve for many queries, and Miller-Rabin for very large numbers.

Basic How do you check if n is a power of two?

n > 0 and n & (n - 1) == 0.

Medium Why use 10^9 + 7 as a modulus?

It is a prime below 2^30, so products fit in 64 bits and every non-zero residue has a modular inverse by Fermat's little theorem.

Medium How do you compute a^b mod m efficiently?

Binary exponentiation: square the base and multiply when the bit is set, O(log b). Python: pow(a, b, m).

Medium How do you divide modulo a prime?

Multiply by the modular inverse, b^(p - 2) mod p, or pow(b, -1, p) in Python 3.8+.

Medium How do you compute nCr mod p for many queries?

Precompute factorials and inverse factorials up to n, then answer in O(1).

Medium Explain the sieve of Eratosthenes.

Mark multiples of each prime starting from p^2 as composite. O(n log log n) time and O(n) memory.

Medium What is the expected number of fixed points of a random permutation?

1, by linearity of expectation: n indicators each with probability 1/n.

Advanced State the Chinese remainder theorem.

For pairwise coprime moduli, x = r_i (mod m_i) has a unique solution modulo the product, found by combining congruences with modular inverses.

Advanced How do you compute Fibonacci(n) for huge n?

Matrix exponentiation of [[1,1],[1,0]] in O(log n) 2x2 multiplications, or fast doubling.

Advanced What is Euler's totient and its use?

phi(n) counts integers up to n coprime to n. Euler's theorem gives a^phi(n) = 1 (mod n) for coprime a, used for inverses and reducing exponents.

Advanced How do you uniformly sample one item from a stream of unknown length?

Reservoir sampling: replace the current pick with the i-th item with probability 1/i.

Advanced Why is a naive shuffle that swaps each element with a random index biased?

It generates n^n equally likely outcomes, which cannot divide evenly into n! permutations. Fisher-Yates swaps with a random later index and is uniform.

Complexity theory (14)

Basic Difference between O, Omega and Theta?

Upper bound, lower bound, and tight bound. They are independent of best/worst/average case.

Basic What is the complexity of nested loops where the inner runs i times?

Sum of i from 1 to n is n(n + 1)/2, which is Theta(n^2).

Basic What is amortised analysis?

Averaging the cost over a worst-case sequence of operations, e.g. dynamic array append is O(1) amortised although a resize costs O(n).

Medium State the Master theorem.

For T(n) = aT(n/b) + f(n): compare f with n^(log_b a). If f is polynomially smaller the answer is n^(log_b a); if equal, n^(log_b a) log n; if polynomially larger (with regularity), f(n).

Medium Why do comparison sorts need Omega(n log n)?

A decision tree with n! leaves has height at least log2(n!), which is Theta(n log n).

Medium What is the difference between P and NP?

P can be solved in polynomial time; NP can be verified in polynomial time given a certificate. P is a subset of NP; whether they are equal is open.

Medium What does NP-complete mean?

A problem in NP to which every problem in NP reduces in polynomial time.

Medium Name some NP-complete problems.

SAT, 3-SAT, clique, vertex cover, Hamiltonian cycle, subset sum, graph colouring, travelling salesman (decision).

Advanced What is pseudo-polynomial time?

Polynomial in the numeric value of the input rather than its bit length, like knapsack DP O(nW). The problem remains weakly NP-hard.

Advanced How do you prove a problem is NP-hard?

Reduce a known NP-hard problem to it in polynomial time, so a fast algorithm for the new problem would solve the known one.

Advanced What strategies exist for NP-hard problems in practice?

Exact search with pruning, DP over small parameters, approximation algorithms with guarantees, heuristics and local search, and exploiting special structure.

Advanced Give an approximation algorithm and its guarantee.

Vertex cover: take both endpoints of each edge in a maximal matching, giving at most twice the optimum.

Advanced Why is the 2-SAT problem in P but 3-SAT NP-complete?

2-SAT reduces to reachability in an implication graph, solved by SCCs in linear time; no such structure exists for three-literal clauses.

Advanced What is the time complexity of recursive Fibonacci and how do you improve it?

Exponential, about 1.618^n. Memoisation or iteration makes it O(n), matrix exponentiation O(log n).

Extra problems (19)

Basic Two Sum: what are the approaches?

Hash map of complement values in O(n) time; or sort and use two pointers in O(n log n) if indexes are not needed.

Basic How do you reverse a linked list?

Iterate keeping prev, curr and next, flipping each pointer. O(n) time, O(1) space; recursion uses O(n) stack.

Basic How do you detect a cycle in a linked list?

Floyd's tortoise and hare: a fast and a slow pointer meet inside a cycle. To find the start, reset one pointer to the head and move both one step at a time.

Basic Valid parentheses?

Use a stack: push openers, and each closer must match the top.

Medium Subarray sum equals k with negatives?

Prefix sums with a hash map counting earlier prefixes equal to current - k. O(n).

Medium Merge k sorted lists?

A min-heap of the current heads, popping the smallest and pushing its successor. O(N log k).

Medium Find the median of two sorted arrays in O(log(min(m, n)))?

Binary search the partition of the smaller array so that left halves are all <= right halves.

Medium Trapping rain water?

Water above each bar is min(left max, right max) - height. Two pointers do it in O(n) and O(1) space.

Medium Longest substring without repeating characters?

Sliding window with a map of last seen indexes; move the left edge past the previous occurrence.

Medium Group anagrams?

Key each word by its sorted letters (or a 26-count tuple) in a hash map.

Medium Number of islands?

Flood fill with DFS/BFS or union-find over the grid; count the components of land.

Medium Lowest common ancestor of a binary tree?

Recurse; return the node if it matches, and the current node is the LCA when both subtrees report a hit.

Advanced Serialise and deserialise a binary tree?

Pre-order with null markers (or level order), parsed with the same order; unambiguous because nulls mark every missing child.

Advanced Design an LRU cache.

A hash map to doubly linked list nodes (or OrderedDict) giving O(1) get and put, evicting from the tail.

Advanced Largest rectangle in a histogram?

Monotonic stack of increasing heights; when a shorter bar arrives, pop and compute the area using the popped bar as the minimum. O(n).

Advanced Word ladder shortest transformation?

BFS over words differing by one letter, using wildcard buckets or letter substitution to generate neighbours.

Advanced Course schedule feasibility?

Topological sort: Kahn's algorithm processes all nodes iff there is no cycle.

Advanced Kth largest element in an array?

Quickselect in O(n) expected, or a min-heap of size k in O(n log k).

Advanced How do you present a solution in an interview?

Clarify the input and constraints, give a brute force, state complexity, optimise by naming the pattern, code cleanly, test with small and edge cases, then restate the complexity.
