String algorithms: KMP, Z, Rabin-Karp, Manacher, tries and suffix structures

Module 4 covered everyday string handling. This part covers the algorithms that find patterns in linear time and structures that answer substring questions about huge texts. All are validated against the obvious quadratic version on random strings.

Advanced~5 hours

The pattern matching problem

Find every occurrence of a pattern P (length m) in a text T (length n). The naive method compares at each of n - m + 1 positions: O(n m) in the worst case (aaaa...ab against aaa...a). Linear-time methods avoid re-examining characters.

NaiveCompare at every positionO(n m)
KMPPrecompute how far to fall back using the pattern's own structureO(n + m)

KMP and the prefix function

The prefix function

For a string s, pi[i] is the length of the **longest proper prefix of s[0..i] that is also a suffix** of it. It tells how much of the current match can be kept after a mismatch.

def prefix_function(s):
    pi = [0] * len(s)
    k = 0
    for i in range(1, len(s)):
        while k and s[i] != s[k]:
            k = pi[k - 1]                   # fall back to a shorter border
        if s[i] == s[k]:
            k += 1
        pi[i] = k
    return pi
print(prefix_function("abacabab"))
print(prefix_function("aaaa"))

Output

[0, 0, 1, 0, 1, 2, 3, 2]
[0, 1, 2, 3]

For abacabab the entry for the first abacaba is 3 because aba is both a prefix and a suffix.

Searching

Run the same logic on P + "#" + T (with a separator not in either): every position where pi equals m is a match. Or reuse pi while scanning T.

import random
random.seed(0)
def kmp_search(text, pat):
    pi, k, out = prefix_function(pat), 0, []
    for i, ch in enumerate(text):
        while k and ch != pat[k]:
            k = pi[k - 1]
        if ch == pat[k]:
            k += 1
        if k == len(pat):
            out.append(i - k + 1)
            k = pi[k - 1]
    return out
def prefix_function(s):

        while k and s[i] != s[k]: k = pi[k - 1]
        if s[i] == s[k]: k += 1
        pi[i] = k
    return pi
def naive(text, pat):
    return [i for i in range(len(text) - len(pat) + 1) if text.startswith(pat, i)]
for _ in range(400):
    text = "".join(random.choice("ab") for _ in range(random.randint(0, 25)))
    pat = "".join(random.choice("ab") for _ in range(random.randint(1, 5)))
    assert kmp_search(text, pat) == naive(text, pat)
print("KMP matches naive search on 400 random cases (including overlaps)")

Uses of the prefix function

  • Smallest period of a string: len(s) - pi[-1] if it divides len(s) (repeated-substring problems).
  • Borders: all prefixes that are also suffixes, by following pi links.
  • Count occurrences of each prefix, automata for string matching, and "shortest palindrome by adding characters in front".
def smallest_period(s):
    pi = [0] * len(s)
    k = 0
    for i in range(1, len(s)):
        while k and s[i] != s[k]: k = pi[k - 1]
        if s[i] == s[k]: k += 1
        pi[i] = k
    p = len(s) - pi[-1]
    return p if len(s) % p == 0 else len(s)
print(smallest_period("abcabcabc"), smallest_period("abcab"), smallest_period("aaaa"))

Self-check

Why is KMP linear?

The fallback pointer k only decreases as often as it has increased, so total work is O(n + m).

The Z algorithm

z[i] is the length of the longest common prefix of s and s[i:]. It is computed in O(n) by maintaining a window [l, r) that matches a prefix and reusing earlier values inside it.

import random
random.seed(1)
def z_function(s):
    n, z, l, r = len(s), [0] * len(s), 0, 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z
def z_naive(s):
    return [0] + [next((k for k in range(len(s) - i + 1) if k == len(s) - i or s[k] != s[i + k]), 0) for i in range(1, len(s))]
for _ in range(300):
    s = "".join(random.choice("ab") for _ in range(random.randint(1, 20)))
    assert z_function(s) == z_naive(s)
print("Z function verified; example:", z_function("aabxaabxcaabxaabxay"))

Output

Z function verified; example: [0, 1, 0, 0, 4, 1, 0, 0, 0, 8, 1, 0, 0, 5, 1, 0, 0, 1, 0]

Search with P + "$" + T: positions where z == len(P) are matches. Z and the prefix function are interchangeable for most tasks; choose whichever you remember.

Rolling hashes: Rabin-Karp

Treat a string as a number in some base modulo a large prime, so the hash of a window can be updated in O(1) when it slides: h = (h - s[i] base^(m-1)) base + s[i+m] (mod p). Equal hashes are verified by direct comparison (collisions are possible). Use a large modulus and a random base to resist adversarial inputs.

import random
random.seed(2)
MOD = (1 << 61) - 1
def rabin_karp(text, pat):
    n, m = len(text), len(pat)
    if m > n: return []
    base = random.randrange(256, MOD - 1)
    hp = ht = 0
    for i in range(m):
        hp = (hp * base + ord(pat[i])) % MOD
        ht = (ht * base + ord(text[i])) % MOD
    top = pow(base, m - 1, MOD)
    out = []
    for i in range(n - m + 1):
        if hp == ht and text[i:i + m] == pat: out.append(i)
        if i + m < n:
            ht = ((ht - ord(text[i]) * top) * base + ord(text[i + m])) % MOD
    return out
def naive(text, pat): return [i for i in range(len(text) - len(pat) + 1) if text.startswith(pat, i)]
for _ in range(300):
    text = "".join(random.choice("abc") for _ in range(random.randint(0, 30)))
    pat = "".join(random.choice("abc") for _ in range(random.randint(1, 4)))
    assert rabin_karp(text, pat) == naive(text, pat)
print("Rabin-Karp matches naive search")

Output

Rabin-Karp matches naive search

Strengths: easily extends to multiple patterns of the same length, 2D patterns, finding repeated substrings (binary search on length plus a hash set) and plagiarism detection (winnowing). Weakness: probabilistic.

How this gets asked

Why does Rabin-Karp compare strings after a hash match?

  • To save time No.
  • Hashes can collide, so equal hashes must be verified Correct.
  • To update the hash No.
  • Because ASCII differs No.

Verification makes the result exact; collisions only cost time.

Self-check

How does a rolling hash slide?

Subtract the outgoing character times base^(m-1), multiply by the base and add the incoming character, modulo a prime.

Palindromes: Manacher's algorithm

The longest palindromic substring takes O(n^2) by expanding around centres; Manacher does it in O(n) by reusing mirror information. Insert a separator between characters so every palindrome has odd length.

import random
random.seed(3)
def manacher(s):
    t = "^#" + "#".join(s) + "#$"
    n, p, centre, right = len(t), [0] * len(t), 0, 0
    for i in range(1, n - 1):
        if i < right:
            p[i] = min(right - i, p[2 * centre - i])
        while t[i + 1 + p[i]] == t[i - 1 - p[i]]:
            p[i] += 1
        if i + p[i] > right:
            centre, right = i, i + p[i]
    best = max(range(1, n - 1), key=lambda i: p[i])
    start = (best - p[best]) // 2
    return s[start:start + p[best]]
def brute(s):
    best = ""
    for i in range(len(s)):
        for j in range(i, len(s)):
            sub = s[i:j + 1]
            if sub == sub[::-1] and len(sub) > len(best): best = sub
    return best
for _ in range(300):
    s = "".join(random.choice("ab") for _ in range(random.randint(1, 14)))
    assert len(manacher(s)) == len(brute(s))
print("Manacher finds a longest palindrome of the right length;", manacher("forgeeksskeegfor"))

Output

Manacher finds a longest palindrome of the right length; geeksskeeg

How this gets asked

Manacher's algorithm finds the longest palindromic substring in:

  • O(n^2) That is expand around centre.
  • O(n) Correct.
  • O(n log n) No.
  • O(2^n) No.

It reuses palindromes already found via a mirror.

Self-check

Why insert separators in Manacher?

So every palindrome, even or odd, has a centre character and can be handled uniformly.

Tries and Aho-Corasick

Trie

A tree where each edge is a character; a path from the root spells a prefix. Operations take O(length) regardless of how many words are stored: insert, exact lookup, prefix search and autocomplete, longest common prefix, word search on a grid with pruning, replacing words by roots.

class Trie:
    def __init__(self): self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word: node = node.setdefault(ch, {})
        node["$"] = True
    def starts_with(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node: return []
            node = node[ch]
        out = []
        def walk(n, acc):
            for k in sorted(n):
                if k == "$": out.append(acc)
                else: walk(n[k], acc + k)
        walk(node, prefix)
        return out
t = Trie()
for w in ["car", "card", "care", "cart", "cat", "dog"]: t.insert(w)
print(t.starts_with("car"), t.starts_with("ca"), t.starts_with("x"))

Output

['car', 'card', 'care', 'cart'] ['car', 'card', 'care', 'cart', 'cat'] []

Aho-Corasick

Search for many patterns at once. Build a trie of the patterns, then add failure links (the longest proper suffix of the current path that is also a path in the trie) with a BFS, exactly KMP's fallback generalised. One pass over the text reports all matches of all patterns: O(n + total pattern length + matches). Used in virus scanners, profanity filters, intrusion detection and DNA search.

from collections import deque
def aho_corasick(patterns, text):
    goto, fail, out = [{}], [0], [[]]
    for idx, p in enumerate(patterns):
        s = 0
        for ch in p:
            if ch not in goto[s]:
                goto.append({}); fail.append(0); out.append([])
                goto[s][ch] = len(goto) - 1
            s = goto[s][ch]
        out[s].append(idx)
    q = deque(goto[0].values())
    while q:
        u = q.popleft()
        for ch, v in goto[u].items():
            f = fail[u]
            while f and ch not in goto[f]: f = fail[f]
            fail[v] = goto[f].get(ch, 0) if goto[f].get(ch, 0) != v else 0
            out[v] = out[v] + out[fail[v]]
            q.append(v)
    s, found = 0, []
    for i, ch in enumerate(text):
        while s and ch not in goto[s]: s = fail[s]
        s = goto[s].get(ch, 0)
        for idx in out[s]: found.append((i - len(patterns[idx]) + 1, patterns[idx]))
    return sorted(found)
pats = ["he", "she", "his", "hers"]
text = "ushers"
expected = sorted((i, p) for p in pats for i in range(len(text)) if text.startswith(p, i))
print(aho_corasick(pats, text), aho_corasick(pats, text) == expected)

Output

[(1, 'she'), (2, 'he'), (2, 'hers')] True

Suffix arrays and substring queries

Suffix array

The suffix array lists the starting positions of all suffixes of s in sorted order. Any substring is a prefix of some suffix, so substring search is a binary search over the array: O(m log n). Build naively by sorting (O(n^2 log n) comparisons in the worst case, fine for small n) or in O(n log n) with prefix doubling, or O(n) with SA-IS.

import bisect
def suffix_array(s):
    return sorted(range(len(s)), key=lambda i: s[i:])
def lcp_array(s, sa):
    n, rank, lcp, h = len(s), [0] * len(s), [0] * len(s), 0
    for i, p in enumerate(sa): rank[p] = i
    for i in range(n):                       # Kasai: O(n) longest common prefix of neighbours
        if rank[i] > 0:
            j = sa[rank[i] - 1]
            while i + h < n and j + h < n and s[i + h] == s[j + h]: h += 1
            lcp[rank[i]] = h
            if h: h -= 1
        else:
            h = 0
    return lcp
def count_occurrences(s, sa, pat):
    suffixes = [s[i:i + len(pat)] for i in sa]
    return bisect.bisect_right(suffixes, pat) - bisect.bisect_left(suffixes, pat)
s = "banana"
sa = suffix_array(s)
print("suffix array:", sa, [s[i:] for i in sa])
lcp = lcp_array(s, sa)
print("LCP array   :", lcp, "| longest repeated substring length:", max(lcp))
print("occurrences of 'ana':", count_occurrences(s, sa, "ana"), "| of 'an':", count_occurrences(s, sa, "an"))

Output

suffix array: [5, 3, 1, 0, 4, 2] ['a', 'ana', 'anana', 'banana', 'na', 'nana']
LCP array   : [0, 1, 3, 0, 0, 2] | longest repeated substring length: 3
occurrences of 'ana': 2 | of 'an': 2

With the LCP array you can find the longest repeated substring (the maximum LCP), count distinct substrings (n(n+1)/2 - sum(lcp)), and compute the longest common substring of two strings (concatenate with a separator). Suffix automata solve many of the same problems online in linear time, and suffix trees answer them with a compressed trie of all suffixes.

def is_rotation(s, t):
    return len(s) == len(t) and t in s + s
def shortest_palindrome(s):
    r = s[::-1]
    comb = s + "#" + r
    pi, k = [0] * len(comb), 0
    for i in range(1, len(comb)):
        while k and comb[i] != comb[k]: k = pi[k - 1]
        if comb[i] == comb[k]: k += 1
        pi[i] = k
    return r[:len(s) - pi[-1]] + s

Key idea

Fast string algorithms are all about never rescanning: KMP and Z reuse what the pattern says about itself, hashing compares summaries, tries share common prefixes, suffix arrays sort all suffixes once. Test each against the naive version on small random strings over a tiny alphabet, where collisions and overlaps appear quickly.

Interview questions: String algorithms

14 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic Naive pattern matching complexity and when it is bad?

O(n m) worst case, such as aaaa...ab against aaa...a, because comparisons restart at every position.

Basic What is a trie and what are its operations' costs?

A prefix tree with insert, search and prefix queries in O(length) regardless of dictionary size, at the cost of memory.

Basic How do you check whether one string is a rotation of another?

Same length and the second occurs inside the first concatenated with itself.

Medium Explain the KMP prefix function.

pi[i] is the length of the longest proper prefix of s[0..i] that is also a suffix. On a mismatch the matcher falls back to pi[k - 1] instead of restarting, giving O(n + m).

Medium Why is KMP linear?

The fallback pointer only moves forward one step per character and each fallback decreases it, so total moves are bounded by 2n.

Medium What does the Z array give?

z[i] is the longest common prefix of s and s[i:]; pattern matching on P + '$' + T finds matches where z equals |P|.

Medium How does Rabin-Karp work and what is its failure mode?

It compares rolling hashes of windows with the pattern hash, verifying equal hashes. Collisions or adversarial inputs can degrade it to O(n m); use a large modulus and random base.

Medium How do you find the smallest repeating period of a string?

Take p = n - pi[n - 1]; if p divides n then p is the period, otherwise the string is primitive (period n).

Advanced Manacher's algorithm in one paragraph.

Insert separators, keep the centre and right edge of the rightmost palindrome, and initialise the radius at i from its mirror, then expand. Each expansion moves the right edge, so O(n) overall.

Advanced What is Aho-Corasick and where is it used?

A trie with failure links that finds all occurrences of many patterns in a single pass, O(n + total pattern length + matches). Used in malware scanners and filters.

Advanced What is a suffix array and what can you do with it?

The sorted order of all suffixes. With an LCP array it supports substring search by binary search, longest repeated substring, distinct substring counting and longest common substring.

Advanced Suffix array versus suffix tree versus suffix automaton?

All index all substrings. Suffix trees are the most flexible but memory heavy; suffix arrays are compact and cache friendly; suffix automata are small and build online in linear time.

Advanced How do you count distinct substrings?

n(n + 1)/2 minus the sum of the LCP array of the suffix array.

Advanced How do you find the shortest palindrome by prepending characters?

Compute the prefix function of s + '#' + reverse(s); the last value is the longest palindromic prefix, and the rest of the reversed string is prepended.
