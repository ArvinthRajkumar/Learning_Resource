Second Largest Element

Easy Arrays, single pass

Return the second largest DISTINCT value in the list, or -1 if it does not exist.

FieldDetail
DSA conceptArrays, single pass (Arrays and Lists)
Input formatA list of integers nums.
Output formatOne integer.
Constraints1 <= len(nums) <= 10^5; -10^9 <= nums[i] <= 10^9

Sample input

[3, 1, 4, 4, 2]

Sample output

Explanation: The largest is 4. The largest value strictly smaller than 4 is 3.

Stuck? Reveal hints one at a time

Hint 1

Hint 2

Recommended approach (spoiler)

Python solution (try first)

def second_largest(nums):
    first = second = float("-inf")
    for x in nums:
        if x > first:
            second = first     # old champion becomes runner-up
            first = x
        elif first > x > second:
            second = x
    return -1 if second == float("-inf") else second

Complexity: Time O(n); Space O(1).

Edge cases to test

  • All elements equal -> -1
  • Single element -> -1
  • Negative numbers (do not initialise with 0)

def move_zeroes(nums):
    w = 0                           # next slot for a non-zero value
    for x in nums:
        if x != 0:
            nums[w] = x
            w += 1
    for i in range(w, len(nums)):   # fill the rest with zeros
        nums[i] = 0
    return nums

Complexity: Time O(n); Space O(1).

def remove_duplicates(nums):
    if not nums:
        return 0
    w = 1
    for r in range(1, len(nums)):
        if nums[r] != nums[w - 1]:   # a new value
            nums[w] = nums[r]
            w += 1
    return w

Range Sum Queries

Easy Prefix sums

Given nums and a list of queries [l, r], return the sum of nums[l..r] (inclusive) for each query.

FieldDetail
DSA conceptPrefix sums (Arrays and Lists)
Input formatnums and queries.
Output formatA list of sums.
Constraintslen(nums), len(queries) <= 10^5

Sample input

def range_sum_queries(nums, queries):
    prefix = [0]
    for x in nums:
        prefix.append(prefix[-1] + x)
    return [prefix[r + 1] - prefix[l] for l, r in queries]

def merge_sorted(a, b):
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    out.extend(a[i:])
    out.extend(b[j:])
    return out

Plus One

Easy Arrays as numbers, carry LC 66

A non-negative number is stored as a list of digits (most significant first). Add one to it and return the digit list.

This is a well-known public interview classic (LeetCode-style problem #66). The guide does not claim any company asked it.

FieldDetail
DSA conceptArrays as numbers, carry (Arrays and Lists)
Input formatList digits.
Output formatList digits.
Constraintslen <= 100

Stuck? Reveal hints one at a time

Start from the last digit. If it is below 9 add one and stop. If it is 9 it becomes 0 and the carry moves left. If all digits were 9, add a new leading 1.

Python solution (try first)

def plus_one(digits):
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0                 # 9 + 1 -> 0 carry 1
    return [1] + digits               # all nines

Rotate Array Right by K

Medium Arrays, reversal trick LC 189

Rotate the list to the right by k steps and return the result (k can be larger than the length).

This is a well-known public interview classic (LeetCode-style problem #189). The guide does not claim any company asked it.

FieldDetail
DSA conceptArrays, reversal trick (Arrays and Lists)
Input formatA list nums and an integer k.
Output formatThe rotated list.
Constraints0 <= len(nums) <= 10^5; 0 <= k <= 10^9

Sample input

[1,2,3,4,5,6,7], k = 3

Sample output

Stuck? Reveal hints one at a time

Hint 1

Rotating by n gives back the same list, so reduce k modulo n.

Hint 2

Recommended approach (spoiler)

Reverse the whole list, then reverse the first k elements, then reverse the rest. This rotates in-place with O(1) extra space. Always take k %= n first.

Python solution (try first)

def rotate_right(nums, k):
    n = len(nums)
    if n == 0:
        return nums
    k %= n
    def rev(lo, hi):
        while lo < hi:
            nums[lo], nums[hi] = nums[hi], nums[lo]
            lo += 1
            hi -= 1
    rev(0, n - 1)       # whole list
    rev(0, k - 1)       # first k
    rev(k, n - 1)       # remaining
    return nums

Complexity: Time O(n); Space O(1).

Edge cases to test

  • Empty list
  • k = 0 or k multiple of n
  • k larger than n

Maximum Subarray Sum (Kadane)

Medium Arrays, Kadane's algorithm / DP LC 53 must-do

Return the largest possible sum of a non-empty contiguous subarray.

This is a well-known public interview classic (LeetCode-style problem #53, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptArrays, Kadane's algorithm / DP (Arrays and Lists)
Input formatA list nums.
Output formatOne integer.
Constraints1 <= len(nums) <= 10^5; -10^4 <= nums[i] <= 10^4

Sample input

[-2,1,-3,4,-1,2,1,-5,4]

Sample output

Hint 1

Recommended approach (spoiler)

Easy way: put numbers in a set until you see one twice (O(n) space). Smart way: treat each value as a pointer to the next index; the duplicate is where two pointers enter the same cycle, so Floyd's slow/fast pointers find it with O(1) space.

Python solution (try first)

def find_duplicate_number(nums):
    slow = fast = nums[0]
    while True:                        # phase 1: meet inside the cycle
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow = nums[0]                     # phase 2: find the cycle start
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow

Python solution (try first)

def trapping_rain(height):
    lo, hi = 0, len(height) - 1
    left_max = right_max = water = 0
    while lo < hi:
        if height[lo] < height[hi]:
            left_max = max(left_max, height[lo])
            water += left_max - height[lo]
            lo += 1
        else:
            right_max = max(right_max, height[hi])
            water += right_max - height[hi]
            hi -= 1
    return water
