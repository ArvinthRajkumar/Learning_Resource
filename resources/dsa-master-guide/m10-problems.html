Balanced Brackets

Easy Stack LC 20 must-do

Given a string of ()[]{} characters, return True if every opening bracket is closed by the same type in the correct order.

This is a well-known public interview classic (LeetCode-style problem #20, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Output formatTrue or False.

Sample output

Explanation: [ closes inside { correctly.

def valid_parens(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in pairs:                      # closing bracket
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)                 # opening bracket
    return not stack

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Empty string
  • Only closers ")"
  • Leftover openers "(("

Python solution (try first)

def next_greater(nums):
    res = [-1] * len(nums)
    stack = []                      # indices waiting for a greater value
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        stack.append(i)
    return res

Complexity: Time O(n) - each index is pushed and popped once; Space O(n).

Edge cases to test

  • Decreasing list -> all -1
  • Equal values (strictly greater needed)

Python solution (try first)

def eval_postfix(tokens):
    stack = []
    for t in tokens:
        if t in "+-*/" and len(t) == 1:
            b, a = stack.pop(), stack.pop()
            if t == "+": stack.append(a + b)
            elif t == "-": stack.append(a - b)
            elif t == "*": stack.append(a * b)
            else: stack.append(int(a / b))
        else:
            stack.append(int(t))
    return stack[0]

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Negative numbers such as "-11" (len > 1)
  • Subtraction / division operand order

Days Until a Warmer Temperature

Medium Monotonic stack LC 739

For each day, return how many days you must wait for a warmer temperature (0 if never).

This is a well-known public interview classic (LeetCode-style problem #739). The guide does not claim any company asked it.

FieldDetail
DSA conceptMonotonic stack (Stacks & Queues)
Input formatList temps.
Output formatList of waits.
Constraintslen <= 10^5

Sample input

[73,74,75,71,69,72,76,73]

Sample output

[1,1,4,2,1,1,0,0]

Explanation: Day 2 (75) waits 4 days until 76.

Stuck? Reveal hints one at a time

Hint 1

wait = i - popped_index.

Recommended approach (spoiler)

Same monotonic stack idea as Next Greater, but store the distance between indices.

Python solution (try first)

def daily_temperatures(temps):
    res = [0] * len(temps)
    stack = []
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Strictly decreasing temps -> all 0
  • Equal temperatures do not count

Queue Using Two Stacks

Medium Stacks and queues design LC 232

Implement a FIFO queue with push, pop, peek and empty using only two stacks (Python lists with append/pop).

This is a well-known public interview classic (LeetCode-style problem #232). The guide does not claim any company asked it.

FieldDetail
DSA conceptStacks and queues design (Stacks & Queues)
Input formatA sequence of operations.
Output formatResults of the operations.
Constraintsops <= 100

Sample input

push(1), push(2), peek(), pop(), empty()

Sample output

[None, None, 1, 1, False]

Explanation: Elements come out in insertion order.

Stuck? Reveal hints one at a time

Hint 1

Only refill the outbox when it is empty.

Recommended approach (spoiler)

Push onto an inbox stack. To pop/peek, if the outbox is empty move everything from inbox to outbox (this reverses the order); then use the top of outbox.

Python solution (try first)

class MyQueue:
    def __init__(self):
        self.inbox, self.outbox = [], []

    def push(self, x):
        self.inbox.append(x)

    def _shift(self):
        if not self.outbox:
            while self.inbox:
                self.outbox.append(self.inbox.pop())

    def pop(self):
        self._shift()
        return self.outbox.pop()

    def peek(self):
        self._shift()
        return self.outbox[-1]

    def empty(self):
        return not self.inbox and not self.outbox

Complexity: push O(1); pop/peek amortised O(1); Space O(n).

Edge cases to test

  • Pop on empty queue
  • Interleaved push and pop

Min Stack

Medium Stack design LC 155

Design a stack supporting push, pop, top and get_min, all in O(1).

This is a well-known public interview classic (LeetCode-style problem #155). The guide does not claim any company asked it.

FieldDetail
DSA conceptStack design (Stacks & Queues)
Input formatSequence of operations.
Output formatResults.
Constraintsops <= 10^4

Sample input

push(3), push(1), get_min(), pop(), get_min()

Sample output

[None, None, 1, 1, 3]

Explanation: After popping 1 the minimum goes back to 3.

Stuck? Reveal hints one at a time

Hint 1

Each stack entry is a (value, min_so_far) pair.

Recommended approach (spoiler)

Store each value together with the minimum so far. The top pair always knows the current minimum.

Python solution (try first)

class MinStack:
    def __init__(self):
        self.data = []                       # (value, min so far)

    def push(self, x):
        lowest = min(x, self.data[-1][1]) if self.data else x
        self.data.append((x, lowest))

    def pop(self):
        return self.data.pop()[0]

    def top(self):
        return self.data[-1][0]

    def get_min(self):
        return self.data[-1][1]

Complexity: All operations O(1); Space O(n).

Edge cases to test

  • Duplicates of the minimum
  • Pop the minimum

Python solution (try first)

def decode_string(s):
    stack, cur, num = [], "", 0
    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)
        elif ch == "[":
            stack.append((cur, num))       # save state
            cur, num = "", 0
        elif ch == "]":
            prev, k = stack.pop()
            cur = prev + cur * k           # repeat and attach
        else:
            cur += ch
    return cur

Complexity: Time O(output length); Space O(depth).

Edge cases to test

  • Multi-digit numbers like 10[a]

Basic Calculator II

Medium Stack, operator precedence LC 227

Evaluate an expression with non-negative integers and + - * / (integer division truncating toward zero), no parentheses.

This is a well-known public interview classic (LeetCode-style problem #227). The guide does not claim any company asked it.

Why interviewers ask this: A stack-and-precedence problem that appears in many forms (calculator, expression evaluation).

FieldDetail
DSA conceptStack, operator precedence (Stacks & Queues)
Input formatString s.
Output formatInteger.
Constraintslen <= 10^5

Sample input

"3+2*2"

Sample output

7

Explanation: 2*2 is done first: 3 + 4.

Stuck? Reveal hints one at a time

Hint 1

Multiplication and division are resolved immediately.

Recommended approach (spoiler)

Keep the previous operator. When a number ends, apply: + pushes it, - pushes its negative, * and / combine with the stack top. The answer is the sum of the stack.

Python solution (try first)

def basic_calculator_ii(s):
    stack, num, op = [], 0, "+"
    for i, ch in enumerate(s):
        if ch.isdigit():
            num = num * 10 + int(ch)
        if (not ch.isdigit() and ch != " ") or i == len(s) - 1:
            if op == "+":
                stack.append(num)
            elif op == "-":
                stack.append(-num)
            elif op == "*":
                stack.append(stack.pop() * num)
            else:
                stack.append(int(stack.pop() / num))
            op, num = ch, 0
    return sum(stack)

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Spaces
  • Single number
  • Division truncating negatives

LRU Cache

Medium Design: hash map + ordered recency LC 146

Design a cache with a fixed capacity. get(key) returns the value or -1; put(key, value) inserts or updates. When full, evict the least recently used key.

This is a well-known public interview classic (LeetCode-style problem #146). The guide does not claim any company asked it.

Why interviewers ask this: The most famous design question: a hash map plus recency order gives O(1) get and put.

FieldDetail
DSA conceptDesign: hash map + ordered recency (Stacks & Queues)
Input formatSequence of operations.
Output formatResults.
Constraintscapacity <= 3000

Sample input

capacity 2: put(1,1), put(2,2), get(1), put(3,3), get(2)

Sample output

[None, None, 1, None, -1]

Explanation: Putting 3 evicts key 2, the least recently used.

Stuck? Reveal hints one at a time

Hint 1

Use move_to_end and popitem(last=False).

Recommended approach (spoiler)

Python's OrderedDict keeps insertion order and can move a key to the end in O(1). Move a key to the end on every get/put and pop from the front when over capacity. (Interviewers may ask for the dict + doubly linked list version.)

Python solution (try first)

from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)          # most recently used
        return self.data[key]

    def put(self, key, value):
        if key in self.data:
            self.data.move_to_end(key)
        self.data[key] = value
        if len(self.data) > self.cap:
            self.data.popitem(last=False)   # evict the least recently used

Complexity: get and put O(1); Space O(capacity).

Edge cases to test

  • Capacity 1
  • Updating an existing key refreshes it

Asteroid Collision

Medium Stack simulation LC 735

Positive numbers move right, negative move left, same speed. When two meet the smaller (absolute value) explodes, equal ones both explode. Return the survivors.

This is a well-known public interview classic (LeetCode-style problem #735). The guide does not claim any company asked it.

Why interviewers ask this: A stack simulation with several cases; checks you handle chain reactions.

FieldDetail
DSA conceptStack simulation (Stacks & Queues)
Input formatList asteroids.
Output formatList.
Constraintslen <= 10^4

Sample input

[5,10,-5]

Sample output

[5,10]

Explanation: -5 hits 10 and explodes.

Stuck? Reveal hints one at a time

Hint 1

A new asteroid may destroy many.

Recommended approach (spoiler)

Use a stack. A negative asteroid collides with the stack top only if the top is positive. Pop smaller ones; stop if the top is bigger; destroy both if equal.

Python solution (try first)

def asteroid_collision(asteroids):
    stack = []
    for a in asteroids:
        alive = True
        while alive and a < 0 and stack and stack[-1] > 0:
            if stack[-1] < -a:
                stack.pop()             # the top explodes, keep checking
            elif stack[-1] == -a:
                stack.pop()
                alive = False
            else:
                alive = False
        if alive:
            stack.append(a)
    return stack

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Equal sizes
  • All moving the same way

Scan digits; while the previous kept digit is larger than the current one and removals remain, pop it. After the scan remove from the end if needed, then strip leading zeros.

Python solution (try first)

def remove_k_digits(num, k):
    stack = []
    for d in num:
        while k and stack and stack[-1] > d:
            stack.pop()
            k -= 1
        stack.append(d)
    if k:
        stack = stack[:-k]
    return "".join(stack).lstrip("0") or "0"

Complexity: Time O(n); Space O(n).

Return the maximum of every window of size k as it slides over the list.

Stuck? Reveal hints one at a time

Hint 1

collections.deque gives O(1) popleft.

Hint 2

Pop from the back while the back value is smaller than the new one.

Recommended approach (spoiler)

Brute force O(nk). Keep a deque of indices whose values decrease from front to back. The front is always the window maximum; drop indices that left the window and smaller values behind the new element.

Python solution (try first)

from collections import deque

def sliding_window_max(nums, k):
    dq, res = deque(), []              # dq holds indices, values decreasing
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:             # front slid out of the window
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

Complexity: Time O(n); Space O(k).

  • k = n

Largest Rectangle in a Histogram

Hard Monotonic stack LC 84

Bars of width 1 have the given heights. Return the area of the largest rectangle that fits inside the histogram.

FieldDetail
DSA conceptMonotonic stack (Stacks & Queues)
Input formatList heights.
Output formatInteger area.
Constraintslen <= 10^5

Sample input

[2,1,5,6,2,3]

Sample output

10

Explanation: Bars 5 and 6 form a rectangle of height 5 and width 2.

Stuck? Reveal hints one at a time

Hint 1

Add a 0 bar at the end to flush the stack.

Recommended approach (spoiler)

Keep a stack of bar indices with increasing heights. When a lower bar arrives, pop taller bars: each popped bar is the height of a rectangle that extends from the previous stack item to the current index.

Python solution (try first)

def largest_rectangle(heights):
    stack, best = [], 0                    # stack holds indices, heights increasing
    for i, h in enumerate(heights + [0]):  # extra 0 empties the stack
        while stack and heights[stack[-1]] >= h:
            height = heights[stack.pop()]
            left = stack[-1] if stack else -1
            best = max(best, height * (i - left - 1))
        stack.append(i)
    return best

Complexity: Time O(n); Space O(n).

  • Increasing / decreasing bars
  • Empty list
