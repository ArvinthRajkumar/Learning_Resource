Binary Search

Easy Binary search

Given a sorted list and a target, return its index or -1.

FieldDetail
DSA conceptBinary search (Searching Algorithms)
Input formatSorted list nums and an integer target.
Output formatAn index or -1.
Constraintslen(nums) <= 10^5

Sample input

nums=[-1,0,3,5,9,12], target=9

Sample output

4

Explanation: nums[4] is 9.

Stuck? Reveal hints one at a time

Hint 1

mid = lo + (hi - lo) // 2.

Hint 2

Loop while lo <= hi.

Recommended approach (spoiler)

Keep a search window [lo, hi]. Look at the middle: if equal, done; if smaller, discard the left half; else discard the right half.

Python solution (try first)

def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1       # target is in the right half
        else:
            hi = mid - 1       # target is in the left half
    return -1

Complexity: Time O(log n); Space O(1).

Edge cases to test

  • Empty list
  • Target smaller than all / larger than all
  • Single element

Integer Square Root

Easy Binary search on the answer LC 69

Return floor(sqrt(x)) without using sqrt or **0.5.

This is a well-known public interview classic (LeetCode-style problem #69). The guide does not claim any company asked it.

FieldDetail

Input formatInteger x.
Output formatInteger.
Constraints0 <= x <= 2^31 - 1

Sample output

def my_sqrt(x):
    lo, hi, ans = 0, x, 0
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= x:
            ans = mid          # mid works, try bigger
            lo = mid + 1
        else:
            hi = mid - 1
    return ans

Complexity: Time O(log x); Space O(1).

  • Large x (no overflow in Python, but think about it in other languages)

First and Last Occurrence

Medium Binary search variants LC 34

In a sorted list with duplicates, return [first_index, last_index] of target, or [-1, -1].

This is a well-known public interview classic (LeetCode-style problem #34). The guide does not claim any company asked it.

FieldDetail
DSA conceptBinary search variants (Searching Algorithms)
Input formatSorted list and target.
Output formatA list of two indices.
Constraintslen <= 10^5

Sample input

[5,7,7,8,8,10], target=8

Sample output

[3, 4]

Explanation: The 8s occupy indices 3 and 4.

Stuck? Reveal hints one at a time

Hint 1

Store the candidate answer, then keep narrowing.

Hint 2

One helper with a flag avoids duplicated code.

Recommended approach (spoiler)

Run binary search twice. When you find the target, do not stop: keep searching left (hi = mid - 1) for the first occurrence, right (lo = mid + 1) for the last.

Step-by-step dry run

Python solution (try first)

def first_last(nums, target):
    def search(go_left):
        lo, hi, ans = 0, len(nums) - 1, -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid] == target:
                ans = mid
                if go_left:
                    hi = mid - 1
                else:
                    lo = mid + 1
            elif nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
    return [search(True), search(False)]

Complexity: Time O(log n); Space O(1).

Edge cases to test

  • Target absent
  • Single occurrence
  • Whole list equals target

Search in Rotated Sorted Array

Medium Binary search on a twisted array LC 33 must-do

A sorted list of distinct values was rotated at an unknown pivot. Return the index of target or -1 in O(log n).

This is a well-known public interview classic (LeetCode-style problem #33, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Python solution (try first)

def search_rotated(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:                 # left half is sorted
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                     # right half is sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

Complexity: Time O(log n); Space O(1).

  • Target absent

Search a Sorted Matrix

Medium Binary search in 2D LC 74

Each row is sorted and the first number of each row is bigger than the last of the previous row. Return True if target is in the matrix.

This is a well-known public interview classic (LeetCode-style problem #74). The guide does not claim any company asked it.

FieldDetail
DSA conceptBinary search in 2D (Searching Algorithms)
Input formatMatrix and target.
Output formatTrue or False.
Constraintsrows, cols <= 100

Sample input

[[1,3,5],[7,9,11]], 9

Sample output

True

Explanation: 9 is in the second row.

Stuck? Reveal hints one at a time

Hint 1

Convert a flat index into row and column with // and %.

Recommended approach (spoiler)

Treat the matrix as one long sorted list of rows*cols items. The item at flat index i is matrix[i // cols][i % cols]. Binary search over the flat indices.

Python solution (try first)

def search_matrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    rows, cols = len(matrix), len(matrix[0])
    lo, hi = 0, rows * cols - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        val = matrix[mid // cols][mid % cols]
        if val == target:
            return True
        if val < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return False

Complexity: Time O(log(rows*cols)); Space O(1).

Edge cases to test

  • Empty matrix
  • Single cell

Find K Closest Elements

Medium Binary search for the window start LC 658

In a sorted list return the k elements closest to x (ties prefer the smaller value), in sorted order.

This is a well-known public interview classic (LeetCode-style problem #658). The guide does not claim any company asked it.

Why interviewers ask this: Combines binary search with a window; checks you can search for the left edge of the answer.

FieldDetail
DSA conceptBinary search for the window start (Searching Algorithms)
Input formatSorted list, k, x.
Output formatList.
Constraintslen <= 10^4

Sample input

[1,2,3,4,5], k=4, x=3

Sample output

[1,2,3,4]

Explanation: 1,2,3,4 are the closest four.

Stuck? Reveal hints one at a time

Hint 1

Search over the window start, not over values.

Recommended approach (spoiler)

The answer is a window of length k. Binary search its left edge in [0, n - k]: compare x - a[mid] with a[mid + k] - x to decide whether to move right.

Python solution (try first)

def k_closest_elements(arr, k, x):
    lo, hi = 0, len(arr) - k
    while lo < hi:
        mid = (lo + hi) // 2
        if x - arr[mid] > arr[mid + k] - x:
            lo = mid + 1
        else:
            hi = mid
    return arr[lo:lo + k]

Complexity: Time O(log(n - k) + k); Space O(1).

Edge cases to test

  • x smaller or larger than all elements
  • k = n

Minimum Capacity to Ship in D Days

Packages with the given weights must be shipped in order within days days. Each day the ship carries consecutive packages up to its capacity. Return the least capacity that works.

Python solution (try first)

def ship_capacity(weights, days):
    def can_ship(cap):
        need, load = 1, 0
        for w in weights:
            if load + w > cap:      # start a new day
                need += 1
                load = 0
            load += w
        return need <= days
    lo, hi = max(weights), sum(weights)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_ship(mid):
            hi = mid                # try smaller
        else:
            lo = mid + 1
    return lo

Complexity: Time O(n log(sum)); Space O(1).

  • days = n -> max weight

Median of Two Sorted Arrays

Hard Binary search on a partition LC 4

Return the median of two sorted lists in O(log(min(n, m))).

This is a well-known public interview classic (LeetCode-style problem #4). The guide does not claim any company asked it.

Why interviewers ask this: The famous hard binary-search question: partition two sorted arrays so left and right halves balance.

FieldDetail
DSA conceptBinary search on a partition (Searching Algorithms)
Input formatTwo sorted lists.
Output formatFloat median.
Constraintsn + m >= 1

Sample input

[1,3], [2]

Sample output

2.0

Explanation: Merged: 1,2,3.

Stuck? Reveal hints one at a time

Hint 1

Search on the shorter list.

Hint 2

Use infinity for out-of-range borders.

Recommended approach (spoiler)

Binary search how many elements to take from the shorter list. A partition is correct when every left element <= every right element: check the two cross comparisons. The median comes from the borders.

Python solution (try first)

def median_two_sorted(a, b):
    if len(a) > len(b):
        a, b = b, a
    n, m = len(a), len(b)
    half = (n + m + 1) // 2
    lo, hi = 0, n
    INF = float("inf")
    while lo <= hi:
        i = (lo + hi) // 2            # elements taken from a
        j = half - i                  # elements taken from b
        a_left = a[i - 1] if i > 0 else -INF
        a_right = a[i] if i < n else INF
        b_left = b[j - 1] if j > 0 else -INF
        b_right = b[j] if j < m else INF
        if a_left <= b_right and b_left <= a_right:
            if (n + m) % 2:
                return float(max(a_left, b_left))
            return (max(a_left, b_left) + min(a_right, b_right)) / 2
        if a_left > b_right:
            hi = i - 1
        else:
            lo = i + 1

Complexity: Time O(log(min(n, m))); Space O(1).

Edge cases to test

  • One list empty
  • Different sizes
  • Even and odd total length
