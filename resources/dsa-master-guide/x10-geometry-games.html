Part X10

Computational geometry and game theory: convex hull, intersections, sweep lines, Nim and minimax

Geometry problems fail on precision and special cases; game problems fail when you try to simulate everything. This part shows how to avoid both: use exact integer predicates for geometry, and use invariants (XOR, Grundy values) or pruned search for games.

Advanced~5 hours

Geometry without floating-point pain

Avoid angles, division and square roots when you can. Almost everything reduces to the cross product of two vectors, which is an exact integer when coordinates are integers:

cross(a, b) = a.x * b.y - a.y * b.x

Its sign gives the orientation of three points p, q, r: positive means counter-clockwise (a left turn), negative clockwise, zero collinear. Its magnitude is twice the area of the triangle.

def cross(o, a, b): return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
def orient(p, q, r):
    c = cross(p, q, r)
    return "left turn (counter-clockwise)" if c > 0 else "right turn (clockwise)" if c < 0 else "collinear"
print(orient((0, 0), (4, 0), (4, 3)), "|", orient((0, 0), (4, 0), (4, -3)), "|", orient((0, 0), (2, 2), (5, 5)))
def polygon_area2(pts):                                                  # shoelace formula: twice the area, exact integer
    return sum(pts[i][0] * pts[(i + 1) % len(pts)][1] - pts[(i + 1) % len(pts)][0] * pts[i][1] for i in range(len(pts)))
square = [(0, 0), (4, 0), (4, 4), (0, 4)]
print("twice the area of a 4x4 square:", polygon_area2(square), "| clockwise order gives a negative value:", polygon_area2(square[::-1]))

Output

left turn (counter-clockwise) | right turn (clockwise) | collinear
twice the area of a 4x4 square: 32 | clockwise order gives a negative value: -32

Use doubled quantities (twice the area) to stay in integers; compare squared distances instead of distances; use fractions.Fraction if you need exact rationals, and math.isclose or an epsilon only when floats are unavoidable.

Segment intersection

Two segments AB and CD intersect if C and D lie on opposite sides of line AB and A and B lie on opposite sides of line CD, with special handling when points are collinear (check whether the projections overlap).

import random
random.seed(1)
def sign(x): return (x > 0) - (x < 0)
def on_segment(a, b, p): return min(a[0], b[0]) <= p[0] <= max(a[0], b[0]) and min(a[1], b[1]) <= p[1] <= max(a[1], b[1])
def cross(o, a, b): return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
def segments_intersect(a, b, c, d):
    d1, d2, d3, d4 = sign(cross(a, b, c)), sign(cross(a, b, d)), sign(cross(c, d, a)), sign(cross(c, d, b))
    if d1 * d2 < 0 and d3 * d4 < 0: return True                           # proper crossing
    if d1 == 0 and on_segment(a, b, c): return True                       # touching or collinear overlap cases
    if d2 == 0 and on_segment(a, b, d): return True
    if d3 == 0 and on_segment(c, d, a): return True
    if d4 == 0 and on_segment(c, d, b): return True
    return False
def brute_intersect(a, b, c, d):                                          # exact rational check by sampling lattice points is not possible; use parametric form with Fractions
    from fractions import Fraction as F
    r = (b[0] - a[0], b[1] - a[1]); s = (d[0] - c[0], d[1] - c[1]); den = r[0] * s[1] - r[1] * s[0]
    qp = (c[0] - a[0], c[1] - a[1])
    if den == 0:
        if qp[0] * r[1] - qp[1] * r[0] != 0: return False                  # parallel, not collinear
        rr = r[0] * r[0] + r[1] * r[1]
        if rr == 0: return on_segment(c, d, a)                             # degenerate segment ab is a point
        t0 = F(qp[0] * r[0] + qp[1] * r[1], rr); t1 = t0 + F(s[0] * r[0] + s[1] * r[1], rr)
        lo, hi = sorted((t0, t1)); return hi >= 0 and lo <= 1
    t = F(qp[0] * s[1] - qp[1] * s[0], den); u = F(qp[0] * r[1] - qp[1] * r[0], den)
    return 0 <= t <= 1 and 0 <= u <= 1
for _ in range(3000):
    pts = [(random.randint(0, 6), random.randint(0, 6)) for _ in range(4)]
    a, b, c, d = pts
    if a == b or c == d: continue
    assert segments_intersect(a, b, c, d) == brute_intersect(a, b, c, d), pts
print("segment intersection (orientation tests) agrees with an exact parametric check on 3000 random small cases, including collinear and touching ones")

Output

Point in polygon

Ray casting: shoot a ray from the point to the right and count how many polygon edges it crosses; an odd count means inside. Handle vertices carefully by using a half-open rule (an edge counts if one endpoint is strictly above the ray and the other is at or below).

import random
def inside(poly, p):
    x, y, c = p[0], p[1], False
    for i in range(len(poly)):
        (x1, y1), (x2, y2) = poly[i], poly[(i + 1) % len(poly)]
        if (y1 > y) != (y2 > y):                                          # the edge straddles the horizontal line through p
            x_cross = x1 + (y - y1) * (x2 - x1) / (y2 - y1)
            if x < x_cross: c = not c
    return c
square = [(0, 0), (10, 0), (10, 10), (0, 10)]
concave = [(0, 0), (10, 0), (10, 10), (5, 3), (0, 10)]                       # a notch cut into the top
print("square:", inside(square, (5, 5)), inside(square, (11, 5)), "| concave notch point (5, 8) is outside:", not inside(concave, (5, 8)), "| (5, 2) inside:", inside(concave, (5, 2)))

Output

square: True False | concave notch point (5, 8) is outside: True | (5, 2) inside: True

For convex polygons you can also test that the point is on the same side of every edge (all cross products with the same sign).

Convex hull

The convex hull is the smallest convex polygon containing all points (a rubber band around nails). Andrew's monotone chain: sort points; build the lower hull then the upper hull, popping the last point while the last three do not make a left turn. O(n log n) for the sort.

import random, itertools
random.seed(2)
def cross(o, a, b): return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
def convex_hull(points):
    pts = sorted(set(points))
    if len(pts) <= 2: return pts
    lower, upper = [], []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0: lower.pop()
        lower.append(p)
    for p in reversed(pts):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0: upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]                                           # counter-clockwise, no repeated endpoints
def hull_brute(points):                                                       # a point is a hull vertex if no triangle of the others contains it strictly or on an edge
    pts = list(set(points)); keep = []
    for p in pts:
        others = [q for q in pts if q != p]
        def in_tri(a, b, c):
            d1, d2, d3 = cross(a, b, p), cross(b, c, p), cross(c, a, p)
            has_neg = d1 < 0 or d2 < 0 or d3 < 0; has_pos = d1 > 0 or d2 > 0 or d3 > 0
            return not (has_neg and has_pos) and cross(a, b, c) != 0
        collinear_between = any(cross(a, b, p) == 0 and min(a[0], b[0]) <= p[0] <= max(a[0], b[0]) and min(a[1], b[1]) <= p[1] <= max(a[1], b[1]) for a, b in itertools.combinations(others, 2))
        if not any(in_tri(a, b, c) for a, b, c in itertools.combinations(others, 3)) and not collinear_between: keep.append(p)
    return sorted(keep)
for _ in range(300):
    pts = [(random.randint(0, 8), random.randint(0, 8)) for _ in range(random.randint(3, 9))]
    assert sorted(convex_hull(pts)) == hull_brute(pts) or len(set(pts)) < 3, pts
print("monotone chain hull matches the brute-force definition on 300 random point sets")
print("hull of a square with an interior point:", convex_hull([(0, 0), (4, 0), (4, 4), (0, 4), (2, 2)]))

Output

Closest pair of points and sweep lines

The naive closest pair checks all O(n^2) pairs. Divide and conquer solves it in O(n log n): split by x, solve both halves (best distance d), then only points within d of the dividing line can improve it, and each needs comparing with at most a constant number of neighbours when sorted by y.

A sweep line moves a vertical line across the plane, processing events in order and keeping a structure of the "active" objects. It turns many 2D problems into 1D ones: count overlapping intervals, find any segment intersection (Bentley-Ottmann), skyline, rectangle union area.

import random, math
random.seed(3)
def closest_pair(points):
    pts = sorted(points)
    def rec(lo, hi):                                                          # points sorted by x in [lo, hi)
        if hi - lo <= 3:
            return min((math.dist(pts[i], pts[j]) for i in range(lo, hi) for j in range(i + 1, hi)), default=float("inf"))
        mid = (lo + hi) // 2; midx = pts[mid][0]
        d = min(rec(lo, mid), rec(mid, hi))
        strip = sorted((p for p in pts[lo:hi] if abs(p[0] - midx) < d), key=lambda p: p[1])
        for i in range(len(strip)):
            for j in range(i + 1, len(strip)):
                if strip[j][1] - strip[i][1] >= d: break                      # only a few neighbours are ever checked
                d = min(d, math.dist(strip[i], strip[j]))
        return d
    return rec(0, len(pts))
for _ in range(200):
    pts = list({(random.randint(0, 50), random.randint(0, 50)) for _ in range(random.randint(2, 25))})
    if len(pts) < 2: continue
    brute = min(math.dist(a, b) for i, a in enumerate(pts) for b in pts[i + 1:])
    assert abs(closest_pair(pts) - brute) < 1e-9
print("closest pair (divide and conquer) verified against all-pairs")
# sweep line: the maximum number of overlapping intervals (meeting rooms)
def max_overlap(intervals):
    events = sorted([(s, 1) for s, e in intervals] + [(e, -1) for s, e in intervals])    # ends sort before starts at equal times (-1 < 1)
    cur = best = 0
    for _, delta in events: cur += delta; best = max(best, cur)
    return best
for _ in range(300):
    iv = [(s, s + random.randint(1, 5)) for s in [random.randint(0, 12) for _ in range(random.randint(1, 8))]]
    brute = max(sum(s <= t < e for s, e in iv) for t in range(0, 20))
    assert max_overlap(iv) == brute
print("sweep line maximum overlap verified | [(1,4),(2,5),(7,9)] overlaps at most:", max_overlap([(1, 4), (2, 5), (7, 9)]))

Output

Skyline by sweep line

Process building edges left to right while keeping a max-heap of active heights; whenever the maximum height changes, output a key point.

import heapq
def skyline(buildings):
    events = sorted([(l, -h, r) for l, r, h in buildings] + [(r, 0, 0) for l, r, h in buildings])
    result, heap = [], [(0, float("inf"))]                                     # (negative height, end)
    for x, negh, r in events:
        while heap[0][1] <= x: heapq.heappop(heap)                           # drop buildings that have ended
        if negh: heapq.heappush(heap, (negh, r))
        top = -heap[0][0]
        if not result or result[-1][1] != top: result.append([x, top])
    return result
print(skyline([(2, 9, 10), (3, 7, 15), (5, 12, 12), (15, 20, 10), (19, 24, 8)]))

Output

[[2, 10], [3, 15], [7, 12], [12, 0], [15, 10], [20, 8], [24, 0]]

Combinatorial games

An impartial game has the same moves available to both players (only the position matters), players alternate, and the player who cannot move loses (normal play). Positions are either N (the player to move wins) or P (the previous player wins). Compute by recursion: a position is N if some move leads to a P position, and P if all moves lead to N positions.

from functools import lru_cache
@lru_cache(None)
def wins(n):                                                   # take 1, 2 or 3 stones; taking the last stone wins
    return any(not wins(n - k) for k in (1, 2, 3) if k <= n)
print("losing positions (multiples of 4):", [n for n in range(0, 21) if not wins(n)])

Output

losing positions (multiples of 4): [0, 4, 8, 12, 16, 20]

Nim and the XOR rule

In Nim there are piles; a move removes any positive number of stones from one pile; the player who takes the last stone wins. Bouton's theorem: the position is P (losing for the mover) exactly when the XOR of all pile sizes is 0. From a nonzero XOR you can always move to XOR 0 by reducing one pile to pile ^ xor.

import random, itertools
from functools import lru_cache
random.seed(4)
@lru_cache(None)
def nim_wins(piles):
    for i, p in enumerate(piles):
        for take in range(1, p + 1):
            nxt = tuple(sorted(piles[:i] + (p - take,) + piles[i + 1:]))
            if not nim_wins(nxt): return True
    return False
def nim_by_xor(piles):
    x = 0
    for p in piles: x ^= p
    return x != 0
for _ in range(100):
    piles = tuple(sorted(random.randint(0, 5) for _ in range(random.randint(1, 4))))
    assert nim_wins(piles) == nim_by_xor(piles), piles
print("Bouton's theorem verified against exhaustive game search on 100 random Nim positions")
def winning_move(piles):
    x = 0
    for p in piles: x ^= p
    for i, p in enumerate(piles):
        if p ^ x < p: return i, p - (p ^ x)                 # reduce pile i by this many stones
print("from piles (3, 4, 5) the winning move is (pile index, stones to take):", winning_move((3, 4, 5)))

Output

Bouton's theorem verified against exhaustive game search on 100 random Nim positions
from piles (3, 4, 5) the winning move is (pile index, stones to take): (0, 2)

Sprague-Grundy theorem

Every impartial game position has a Grundy number (nimber): grundy(position) = mex { grundy(next) for each move }, where mex is the smallest non-negative integer not in the set. A game that is a sum of independent games (you choose one component and move in it) has Grundy number equal to the XOR of the components' numbers, and is a loss for the mover exactly when that XOR is zero. So any such game reduces to Nim.

import random
from functools import lru_cache
random.seed(5)
MOVES = (1, 3, 4)                                            # subtraction game: remove 1, 3 or 4 stones from a pile
@lru_cache(None)
def grundy(n):
    reach = {grundy(n - m) for m in MOVES if m <= n}
    g = 0
    while g in reach: g += 1                                 # mex
    return g
print("Grundy numbers of pile sizes 0..15:", [grundy(n) for n in range(16)])
@lru_cache(None)
def sum_wins(piles):                                         # exhaustive search of the sum of subtraction games
    for i, p in enumerate(piles):
        for m in MOVES:
            if m <= p and not sum_wins(tuple(sorted(piles[:i] + (p - m,) + piles[i + 1:]))): return True
    return False
for _ in range(100):
    piles = tuple(sorted(random.randint(0, 9) for _ in range(random.randint(1, 3))))
    x = 0
    for p in piles: x ^= grundy(p)
    assert sum_wins(piles) == (x != 0), piles
print("XOR of Grundy numbers predicts the winner of sums of subtraction games on 100 random positions")

Output

Grundy numbers of pile sizes 0..15: [0, 1, 0, 1, 2, 3, 2, 0, 1, 0, 1, 2, 3, 2, 0, 1]
XOR of Grundy numbers predicts the winner of sums of subtraction games on 100 random positions

Recipe for a new impartial game: define the moves, compute Grundy numbers for single components (by DP, often with a visible pattern), XOR them, and a nonzero result means the first player wins. Examples: Nim, subtraction games, Kayles, Wythoff (needs more theory), and "cutting" games.

Minimax and alpha-beta pruning

For two-player zero-sum games with alternating turns and perfect information (tic-tac-toe, checkers, chess), minimax assigns each position the value under optimal play: the maximiser picks the child with the largest value, the minimiser the smallest. Alpha-beta pruning skips branches that cannot affect the result (alpha = best the maximiser can already guarantee, beta = best the minimiser can guarantee; if alpha >= beta stop), preserving the answer while exploring about sqrt as many nodes with good move ordering. Depth limits plus an evaluation function, iterative deepening, transposition tables and move ordering make real engines feasible; MCTS (Monte Carlo tree search) handles huge branching factors such as Go.

import itertools
LINES = [(0, 1, 2), (3, 4, 5), (6, 7, 8), (0, 3, 6), (1, 4, 7), (2, 5, 8), (0, 4, 8), (2, 4, 6)]
def winner(b):
    for a, c, d in LINES:
        if b[a] != " " and b[a] == b[c] == b[d]: return b[a]
    return None
nodes = {"plain": 0, "alpha_beta": 0}
def minimax(b, player):                                               # returns +1 if X wins, -1 if O wins, 0 draw
    nodes["plain"] += 1
    w = winner(b)
    if w: return 1 if w == "X" else -1
    if " " not in b: return 0
    vals = [minimax(b[:i] + player + b[i + 1:], "O" if player == "X" else "X") for i in range(9) if b[i] == " "]
    return max(vals) if player == "X" else min(vals)
def alphabeta(b, player, alpha=-2, beta=2):
    nodes["alpha_beta"] += 1
    w = winner(b)
    if w: return 1 if w == "X" else -1
    if " " not in b: return 0
    if player == "X":
        best = -2
        for i in range(9):
            if b[i] == " ":
                best = max(best, alphabeta(b[:i] + "X" + b[i + 1:], "O", alpha, beta)); alpha = max(alpha, best)
                if alpha >= beta: break
        return best
    best = 2
    for i in range(9):
        if b[i] == " ":
            best = min(best, alphabeta(b[:i] + "O" + b[i + 1:], "X", alpha, beta)); beta = min(beta, best)
            if alpha >= beta: break
    return best
start = "         "
v1, v2 = minimax(start, "X"), alphabeta(start, "X")
print("value of tic-tac-toe with perfect play (0 = draw):", v1, v2, "| same answer:", v1 == v2)
print(f"positions examined: plain minimax {nodes['plain']:,} vs alpha-beta {nodes['alpha_beta']:,}")

Output

value of tic-tac-toe with perfect play (0 = draw): 0 0 | same answer: True
positions examined: plain minimax 549,946 vs alpha-beta 18,297
Key idea

For geometry, work in exact integers with cross products and sort-based algorithms (hull, sweep). For impartial games, reduce positions to Nim with Grundy numbers and XOR; for two-player scoring games use minimax with alpha-beta and good move ordering. Validate every geometric predicate and game theory claim with a brute-force check on tiny inputs.

  • It randomises moves No.
  • It needs no ordering Ordering improves it.

Good move ordering gives the biggest savings.
