Pattern playbook

Most interview problems are one of about 30 patterns. For each: when to use it, the steps, a short Python template and the practice problems that use it. Learn to recognise the pattern first; the code follows.

Hash map / set (complement and counting)

Use it when: "Seen before?", "count of each", "pair that sums to", "group by key". Any time a nested search can become a lookup.

  1. Decide what to store: value -> index, value -> count, canonical key -> list.
  2. Loop once; look up what you need BEFORE inserting the current item.
  3. State the O(n) time / O(n) space trade.
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i

Prefix sums

Use it when: Many range-sum questions; "subarray with sum k"; counts of remainders.

  1. Build prefix with a leading 0.
  2. Range sum = prefix[r+1] - prefix[l].
  3. For "count subarrays" store prefix frequencies in a dict.
def count_subarrays(nums, k):
    seen, pre, ans = {0: 1}, 0, 0
    for x in nums:
        pre += x
        ans += seen.get(pre - k, 0)
        seen[pre] = seen.get(pre, 0) + 1
    return ans

Practise: Range Sum Queries, Subarrays with Sum K (LC 560), Subarray Sums Divisible by K (LC 974), Product of Array Except Self (LC 238), 2D Range Sum Queries

Kadane's / running best

Use it when: Maximum or minimum contiguous subarray; best time to buy and sell.

  1. cur = best ending here: extend or restart.
  2. best = max(best, cur).
  3. If negatives flip signs (product), track both max and min.
def kadane(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best

Practise: Maximum Subarray Sum (Kadane) (LC 53), Maximum Product Subarray (LC 152), Maximum Sum Circular Subarray (LC 918), Best Time to Buy and Sell Stock (LC 121)

Two pointers (opposite ends)

Use it when: Sorted array pair/triple sums, palindromes, container, trapping water.

  1. lo at start, hi at end.
  2. Compare, then move the pointer that can improve the result.
  3. Each move must permanently discard an element.
def pair_sum_sorted(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return [lo, hi]
        if s < target:
            lo += 1
        else:
            hi -= 1
    return [-1, -1]

Practise: Pair Sum in a Sorted Array (LC 167), Three Sum (LC 15), Container With Most Water (LC 11), Trapping Rain Water (LC 42), Valid Palindrome II (LC 680)

Reader / writer pointers (in place)

Use it when: Remove or move items in place with O(1) extra space.

  1. write = 0.
  2. For each item (reader): if it should be kept, store at write and increase write.
  3. Return write or fill the rest.
def remove_value(nums, val):
    w = 0
    for x in nums:
        if x != val:
            nums[w] = x
            w += 1
    return w

Fast / slow pointers

Use it when: Linked list middle, cycle detection, nth from end, repeated states.

  1. slow moves 1, fast moves 2.
  2. Meeting means a cycle; fast at the end means no cycle or slow is the middle.
  3. For cycle start reset one pointer to head and move both by 1.
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False

Sliding window (fixed size)

Use it when: "Every subarray/substring of length k".

  1. Build the first window.
  2. Slide: add the new element, remove the old one.
  3. Update the answer each step.
def best_window(nums, k):
    w = sum(nums[:k])
    best = w
    for i in range(k, len(nums)):
        w += nums[i] - nums[i - k]
        best = max(best, w)
    return best

Practise: Maximum Sum of K Consecutive Elements, Permutation in String (LC 567), Find All Anagrams in a String (LC 438), Sliding Window Maximum (LC 239)

Sliding window (variable size)

Use it when: Longest/shortest substring or subarray satisfying a condition; non-negative numbers.

  1. Expand right.
  2. While the window is invalid (or valid, for shortest) shrink from the left.
  3. Record the answer at the right moment.
def longest_at_most_k_distinct(s, k):
    cnt, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        cnt[ch] = cnt.get(ch, 0) + 1
        while len(cnt) > k:
            cnt[s[left]] -= 1
            if cnt[s[left]] == 0:
                del cnt[s[left]]
            left += 1
        best = max(best, right - left + 1)
    return best

Binary search (boundary / lower bound)

Use it when: Sorted data, first/last position, insertion point, rotated arrays, peaks.

  1. Define the invariant: answer is inside [lo, hi].
  2. Pick the style (lo <= hi or lo < hi) and keep it consistent.
  3. Test length 0, 1, 2.
def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

Binary search on the answer

Use it when: "Minimum possible maximum", "smallest x such that", feasibility check is monotonic.

  1. Bound the answer range.
  2. Write can_do(x) (usually a greedy simulation).
  3. Minimise: hi = mid on success. Maximise: lo = mid with mid rounded up.
def smallest_feasible(lo, hi, can_do):
    while lo < hi:
        mid = (lo + hi) // 2
        if can_do(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

Practise: Integer Square Root (LC 69), Minimum Capacity to Ship in D Days (LC 1011)

Monotonic stack

Use it when: Next greater/smaller element, spans, histogram rectangles, remove digits.

  1. Keep a stack of INDICES with decreasing (or increasing) values.
  2. While the new item breaks the order, pop and resolve.
  3. Push the new index.
def next_greater(nums):
    res, st = [-1] * len(nums), []
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:
            res[st.pop()] = x
        st.append(i)
    return res

Heap (top-K, merge, scheduling)

Use it when: K largest/smallest, merge K sorted, repeated min/max with inserts, running median.

  1. Min-heap of size K keeps the K largest.
  2. Push tuples (priority, tie-breaker, item).
  3. Negate values for a max-heap.
import heapq

def kth_largest(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k:
            heapq.heappop(h)
    return h[0]

Intervals (sort then sweep)

Use it when: Merge, insert, schedule, count overlaps.

  1. Sort by start (merge) or end (selection).
  2. Compare with the last kept interval.
  3. Use max for the merged end.
def merge(intervals):
    out = []
    for s, e in sorted(intervals):
        if out and s <= out[-1][1]:
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out

Linked list reversal and dummy node

Use it when: Reverse (part of) a list, reorder, merge, delete with head cases.

  1. dummy = ListNode(0, head) removes the head special case.
  2. Save next before changing next.
  3. Draw the pointers for 3 nodes.
def reverse(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev

Tree DFS (return a value up)

Use it when: Height, balance, diameter, path sums, LCA, validate BST.

  1. Base case: None.
  2. Get answers from left and right.
  3. Combine; if the answer differs from what you return, update a nonlocal best.
def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

Tree BFS (levels)

Use it when: Level order, right view, zigzag, minimum depth.

  1. Queue the root.
  2. Process len(queue) nodes per level.
  3. Append children for the next level.
from collections import deque

def level_order(root):
    res, q = [], deque([root] if root else [])
    while q:
        res.append([n.val for n in q])
        for _ in range(len(q)):
            n = q.popleft()
            if n.left: q.append(n.left)
            if n.right: q.append(n.right)
    return res

Backtracking (choose, explore, un-choose)

Use it when: "All subsets / permutations / combinations", constraint puzzles, grid paths.

  1. Record the answer when complete.
  2. For each option: choose, recurse, undo.
  3. Store a COPY of the path.
  4. Prune early; skip duplicates by sorting.
def subsets(nums):
    res, path = [], []
    def go(start):
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            go(i + 1)
            path.pop()
    go(0)
    return res

Graph BFS (shortest path, levels)

Use it when: Fewest steps in an unweighted graph or grid, multi-source spreading.

  1. Queue the start (or all sources).
  2. Mark visited when enqueuing.
  3. Distance = BFS level.
from collections import deque

def bfs_dist(graph, start):
    dist, q = {start: 0}, deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

Graph DFS (components, cycles, flood fill)

Use it when: Count regions, connectivity, cycle detection, backtracking on graphs.

  1. Visited set.
  2. Recurse on unvisited neighbours (or use a stack).
  3. Count a component each time you start a fresh DFS.
def count_components(n, edges):
    g = [[] for _ in range(n)]
    for a, b in edges:
        g[a].append(b); g[b].append(a)
    seen = set()
    def dfs(u):
        seen.add(u)
        for v in g[u]:
            if v not in seen:
                dfs(v)
    comps = 0
    for i in range(n):
        if i not in seen:
            comps += 1
            dfs(i)
    return comps

Topological sort (Kahn)

Use it when: Prerequisites, build order, detect a cycle in a directed graph.

  1. Compute in-degrees.
  2. Queue in-degree 0 nodes.
  3. Pop, output, decrement neighbours.
  4. If output is shorter than n there is a cycle.
from collections import deque

def topo(n, edges):
    g, indeg = [[] for _ in range(n)], [0] * n
    for a, b in edges:
        g[a].append(b); indeg[b] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []

Practise: Course Schedule (Topological Sort) (LC 207), Course Schedule II (LC 210)

Union-Find

Use it when: Dynamic connectivity, redundant edge, number of groups, Kruskal.

  1. parent = list(range(n)).
  2. find with path compression.
  3. union returns False if already connected.
parent = list(range(10))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

Dijkstra (weighted shortest path)

Use it when: Non-negative weights, cheapest route from one source.

  1. dist = infinity; dist[src] = 0.
  2. Min-heap of (distance, node).
  3. Skip stale entries; relax edges.
import heapq

def dijkstra(graph, src):
    dist, heap = {src: 0}, [(0, src)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist.get(u, float("inf")):
            continue
        for v, w in graph[u]:
            if d + w < dist.get(v, float("inf")):
                dist[v] = d + w
                heapq.heappush(heap, (d + w, v))
    return dist

DP 1D (linear decisions)

Use it when: "Number of ways", "minimum cost", adjacent restrictions, stairs, robber, coin change.

  1. State: dp[i] means ... (say it in words).
  2. Transition from smaller states.
  3. Base cases and answer cell.
  4. Reduce to two variables if only the last two are needed.
def climb(n):
    a, b = 1, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

DP 2D (grids and two strings)

Use it when: Grid paths, LCS, edit distance, palindromic subsequence, regex matching.

  1. Add a zero row/column for the empty prefix.
  2. dp[i][j] from up, left and diagonal.
  3. Check loop order and index offsets (dp is 1-based, strings 0-based).
def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[-1][-1]

Knapsack / subset sum

Use it when: Choose items under a capacity; split into equal sums; count ways to a target.

  1. dp[w] = best/possible/ways with capacity w.
  2. 0/1: iterate capacity downward. Unbounded: upward.
  3. Reduce sign problems to subset sums.
def can_make(nums, target):
    reach = [True] + [False] * target
    for x in nums:
        for s in range(target, x - 1, -1):
            if reach[s - x]:
                reach[s] = True
    return reach[target]

Practise: 0/1 Knapsack, Partition Equal Subset Sum (LC 416), Target Sum (LC 494), Coin Change II (LC 518)

Greedy (sort then scan)

Use it when: Intervals, scheduling, jumping, assigning; a local choice is provably safe.

  1. Choose the sort key (end time, difference, ratio).
  2. Scan once keeping the greedy choice.
  3. Try a counterexample before trusting it.
def max_activities(intervals):
    count, last_end = 0, float("-inf")
    for s, e in sorted(intervals, key=lambda x: x[1]):
        if s >= last_end:
            count += 1
            last_end = e
    return count

Bit manipulation / XOR

Use it when: Appears twice except one, powers of two, subsets by mask, counting bits.

  1. x ^ x = 0, x ^ 0 = x.
  2. n & (n - 1) clears the lowest set bit.
  3. Use masks for subsets.
def single(nums):
    r = 0
    for x in nums:
        r ^= x
    return r

Trie (prefix tree)

Use it when: Prefix queries, autocomplete, word dictionaries with wildcards.

  1. Node = dict of children plus an end flag.
  2. Insert/search walk one character at a time.
  3. Wildcards recurse over children.
def insert(root, word):
    node = root
    for ch in word:
        node = node.setdefault(ch, {})
    node["$"] = True

Matrix traversal and in-place tricks

Use it when: Spiral, rotate, zero rows/columns, simulation grids.

  1. Draw a 3 x 3 with indices.
  2. Use four boundaries for layered traversals.

def rotate(matrix):

Design (hash map + ordering)

Use it when: LRU cache, O(1) random set, min stack, queue from stacks.

  1. List the required operations and their target complexity.
  2. Combine structures: dict for lookup, list/linked list/OrderedDict for order.
  3. Keep both structures consistent on every operation.
from collections import OrderedDict

class LRU:
    def __init__(self, cap):
        self.cap, self.d = cap, OrderedDict()
    def get(self, k):
        if k not in self.d:
            return -1
        self.d.move_to_end(k)
        return self.d[k]
    def put(self, k, v):
        self.d[k] = v
        self.d.move_to_end(k)
        if len(self.d) > self.cap:
            self.d.popitem(last=False)
