Single Number (XOR)

Every element appears twice except one. Find it using O(1) extra space.

This is a well-known public interview classic (LeetCode-style problem #136). The guide does not claim any company asked it.

Power of Two

Easy Bit tricks LC 231

Return True if n is a power of two (1, 2, 4, 8, ...).

This is a well-known public interview classic (LeetCode-style problem #231). The guide does not claim any company asked it.

FieldDetail
DSA conceptBit tricks (Bit Manipulation & Mathematics)
Input formatInteger n.
Output formatTrue or False.
Constraints-2^31 <= n <= 2^31 - 1

Sample input

16

Sample output

True

Explanation: 16 = 10000 in binary.

Stuck? Reveal hints one at a time

Hint 1

n must be positive.

Recommended approach (spoiler)

A power of two has exactly one set bit. n & (n - 1) clears the lowest set bit, so the result is 0 only for powers of two (when n > 0).

Python solution (try first)

def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

Complexity: Time O(1); Space O(1).

GCD and LCM

Easy Number theory (Euclid)

Return (gcd, lcm) of two positive integers.

FieldDetail
DSA conceptNumber theory (Euclid) (Bit Manipulation & Mathematics)
Input formatIntegers a and b.
Output formatTuple (gcd, lcm).
Constraintsa, b <= 10^9

Sample input

12 18

Sample output

(6, 36)

Explanation: gcd = 6; lcm = 12 * 18 / 6 = 36.

Stuck? Reveal hints one at a time

Hint 1

Remainders shrink quickly, so it takes O(log) steps.

Recommended approach (spoiler)

Euclid's algorithm: gcd(a, b) = gcd(b, a % b) until b is 0. Then lcm = a // gcd * b (divide first to avoid overflow in other languages).

Step-by-step dry run

Python solution (try first)

def gcd_lcm(a, b):
    x, y = a, b
    while y:
        x, y = y, x % y     # Euclid
    return x, a // x * b

Complexity: Time O(log min(a, b)); Space O(1).

def hamming_distance(x, y):
    diff = x ^ y
    count = 0
    while diff:
        diff &= diff - 1       # clear the lowest set bit

    return count

This is a well-known public interview classic (LeetCode-style problem #190, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Sample input

Stuck? Reveal hints one at a time

Hint 1

Recommended approach (spoiler)

Python solution (try first)

def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result

Count Primes (Sieve of Eratosthenes)

Medium Number theory, sieve LC 204

Count the primes strictly less than n.

This is a well-known public interview classic (LeetCode-style problem #204). The guide does not claim any company asked it.

FieldDetail
DSA conceptNumber theory, sieve (Bit Manipulation & Mathematics)
Input formatInteger n.
Output formatInteger.
Constraintsn <= 5*10^6

Sample input

10

Sample output

4

Explanation: Primes below 10: 2, 3, 5, 7.

Stuck? Reveal hints one at a time

Hint 1

Start crossing off at p * p.

Hint 2

Only primes up to sqrt(n) need to cross off multiples.

Recommended approach (spoiler)

Testing each number is O(n sqrt n). The sieve marks multiples of each prime starting at p*p as composite: about O(n log log n).

Python solution (try first)

def count_primes(n):
    if n < 3:
        return 0
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    p = 2
    while p * p < n:
        if is_prime[p]:
            for m in range(p * p, n, p):
                is_prime[m] = False
        p += 1
    return sum(is_prime)

Complexity: Time O(n log log n); Space O(n).

Edge cases to test

  • n = 0, 1, 2 -> 0
  • n = 3 -> 1

Recommended approach (spoiler)

def subsets_bitmask(nums):
    n = len(nums)
    res = []
    for mask in range(1 << n):
        res.append([nums[i] for i in range(n) if (mask >> i) & 1])
    return res

Single Number II

Medium Bit counting modulo 3 LC 137

Every element appears three times except one that appears once. Find it with O(1) extra space.

This is a well-known public interview classic (LeetCode-style problem #137). The guide does not claim any company asked it.

Why interviewers ask this: A harder XOR-style question: count bits modulo 3.

FieldDetail
DSA conceptBit counting modulo 3 (Bit Manipulation & Mathematics)
Input formatList nums.
Output formatInteger.
Constraintslen <= 3*10^4

Sample input

[2,2,3,2]

Sample output

3

Explanation: The others appear three times.

Stuck? Reveal hints one at a time

Hint 1

Handle negative numbers by masking to 32 bits.

Recommended approach (spoiler)

For every bit position count how many numbers have that bit set. Counts of the repeated numbers are multiples of 3, so count % 3 is the bit of the single number.

Python solution (try first)

def single_number_ii(nums):
    result = 0
    for bit in range(32):
        count = sum((x >> bit) & 1 for x in nums)
        if count % 3:
            result |= 1 << bit
    return result - (1 << 32) if result >= 1 << 31 else result

Complexity: Time O(32 n); Space O(1).

Bitwise AND of Numbers Range

Medium Bit manipulation (common prefix) LC 201

Return the bitwise AND of all numbers from left to right inclusive.

This is a well-known public interview classic (LeetCode-style problem #201). The guide does not claim any company asked it.

Why interviewers ask this: The answer is the common binary prefix: a neat observation question.

FieldDetail
DSA conceptBit manipulation (common prefix) (Bit Manipulation & Mathematics)
Input formatleft and right.
Output formatInteger.
Constraints0 <= left <= right <= 2^31 - 1

Sample input

5, 7

Sample output

4

Explanation: 101 & 110 & 111 = 100.

Stuck? Reveal hints one at a time

Hint 1

Count how many shifts were needed.

Recommended approach (spoiler)

Any bit that changes somewhere in the range becomes 0. The result is the common binary prefix of left and right: shift both right until they are equal, then shift back.

Python solution (try first)

def range_bitwise_and(left, right):
    shift = 0
    while left != right:
        left >>= 1
        right >>= 1
        shift += 1
    return left << shift

Complexity: Time O(32); Space O(1).

Python solution (try first)

def my_pow(x, n):
    if n < 0:
        x, n = 1 / x, -n
    result = 1.0
    while n:
        if n & 1:
            result *= x
        x *= x
        n >>= 1
    return result

Complexity: Time O(log n); Space O(1).

nCr Modulo a Prime

Hard Modular arithmetic

Return C(n, r) modulo 1_000_000_007 (a prime).

FieldDetail

Explanation: C(5,2) = 10.

Stuck? Reveal hints one at a time

Hint 1

Python pow(a, b, m) is fast modular exponentiation.

Hint 2

Apply % MOD after every multiplication.

Recommended approach (spoiler)

C(n, r) = n! / (r! (n-r)!). With a prime modulus, division becomes multiplication by the modular inverse: inv(x) = pow(x, MOD-2, MOD) (Fermat).

Python solution (try first)

MOD = 1_000_000_007

def ncr_mod(n, r):
    if r < 0 or r > n:
        return 0
    num = den = 1
    for i in range(r):
        num = num * (n - i) % MOD
        den = den * (i + 1) % MOD
    return num * pow(den, MOD - 2, MOD) % MOD

Complexity: Time O(r + log MOD); Space O(1).

Edge cases to test

  • r = 0 or r = n -> 1
  • r > n -> 0
