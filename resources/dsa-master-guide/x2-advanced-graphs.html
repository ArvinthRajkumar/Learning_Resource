import heapq, random
random.seed(0)
INF = float("inf")

def make_graph(n, m, lo=1, hi=9):
    edges = []
    for _ in range(m):
        u, v = random.randrange(n), random.randrange(n)
        if u != v: edges.append((u, v, random.randint(lo, hi)))
    return edges

def dijkstra(n, edges, src):
    adj = [[] for _ in range(n)]
    for u, v, w in edges: adj[u].append((v, w))
    dist = [INF] * n; dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue                      # stale entry
        for v, w in adj[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

def bellman_ford(n, edges, src):
    dist = [INF] * n; dist[src] = 0
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w; changed = True
        if not changed: break
    for u, v, w in edges:                              # one more pass: any improvement means a negative cycle
        if dist[u] + w < dist[v]: return None
    return dist

n = 30
edges = make_graph(n, 120)
assert dijkstra(n, edges, 0) == bellman_ford(n, edges, 0)
print("Dijkstra equals Bellman-Ford on a random graph with non-negative weights")
neg = [(0, 1, 2), (1, 2, -5), (2, 0, 1)]               # cycle total -2
print("negative cycle detected:", bellman_ford(3, neg, 0) is None)

Output

Dijkstra equals Bellman-Ford on a random graph with non-negative weights
negative cycle detected: True

Why Dijkstra fails with negative edges

Dijkstra assumes that when a vertex is popped its distance is final, which holds only if adding an edge cannot decrease a path's length. A negative edge can later improve a vertex already settled. Bellman-Ford simply **relaxes every edge V - 1 times**, enough for the shortest path (at most V - 1 edges) to propagate; a further improvement reveals a negative cycle.

0-1 BFS

When every weight is 0 or 1 push 0-weight neighbours to the front of a deque and 1-weight neighbours to the back; this is Dijkstra in linear time.

from collections import deque
def zero_one_bfs(n, adj, src):
    dist = [float("inf")] * n; dist[src] = 0
    dq = deque([src])
    while dq:
        u = dq.popleft()
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                dq.appendleft(v) if w == 0 else dq.append(v)
    return dist
adj = [[(1, 0), (2, 1)], [(3, 1)], [(3, 0)], []]
print(zero_one_bfs(4, adj, 0))

Output

[0, 0, 1, 1]

All pairs: Floyd-Warshall

Dynamic programming over intermediate vertices: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) for k from 0 to V - 1. The loop order matters: **k must be the outermost loop**. It handles negative edges (a negative number on the diagonal means a negative cycle) and is the simplest all-pairs solution when V is a few hundred.

INF = float("inf")
def floyd(n, edges):
    d = [[0 if i == j else INF for j in range(n)] for i in range(n)]
    for u, v, w in edges: d[u][v] = min(d[u][v], w)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d
edges = [(0, 1, 3), (1, 2, -2), (0, 2, 4), (2, 3, 2), (3, 0, 7)]
for row in floyd(4, edges): print(row)

Output

[0, 3, 1, 3]
[7, 0, -2, 0]
[9, 12, 0, 2]
[7, 10, 8, 0]

For path reconstruction store the next vertex. Johnson's algorithm reweights edges so Dijkstra can be used from every source on sparse graphs.

A* search

A* is Dijkstra guided by a heuristic h(v) estimating the remaining cost to the goal; it expands vertices in order of g(v) + h(v). If h is admissible (never overestimates) the first time the goal is popped the path is optimal; if also consistent (h(u) <= w(u, v) + h(v)) no vertex is reopened. On a grid use Manhattan distance for 4-way moves, Chebyshev for 8-way, Euclidean for any direction.

import heapq
def astar(grid, start, goal):
    h = lambda p: abs(p[0] - goal[0]) + abs(p[1] - goal[1])
    pq, g, expanded = [(h(start), 0, start)], {start: 0}, 0
    while pq:
        f, cost, cur = heapq.heappop(pq)
        if cost > g[cur]: continue
        expanded += 1
        if cur == goal: return cost, expanded
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nxt = (cur[0] + dr, cur[1] + dc)
            if 0 <= nxt[0] < len(grid) and 0 <= nxt[1] < len(grid[0]) and grid[nxt[0]][nxt[1]] == 0:
                if cost + 1 < g.get(nxt, 10 ** 9):
                    g[nxt] = cost + 1
                    heapq.heappush(pq, (cost + 1 + h(nxt), cost + 1, nxt))
    return None, expanded
grid = [[0] * 20 for _ in range(20)]
for r in range(1, 18): grid[r][10] = 1             # a wall with gaps at the top and bottom
cost, expanded = astar(grid, (10, 0), (10, 19))
print("shortest path length", cost, "| A* expanded", expanded, "of", 20 * 20, "cells")

Output

shortest path length 35 | A* expanded 252 of 400 cells

How this gets asked

A* returns an optimal path if the heuristic is:

  • Overestimating That can miss the optimum.
  • Admissible: never overestimates the remaining cost Correct.
  • Random No.
  • Always zero only Zero gives Dijkstra, which is also fine but not the requirement.

Admissible heuristics guarantee optimality (consistency avoids reopening vertices).

Minimum spanning trees

A spanning tree connects all vertices with V - 1 edges; the minimum one has least total weight. Two classic greedy algorithms rely on the cut property (the cheapest edge crossing any cut belongs to some MST):

  • Kruskal: sort edges by weight; add an edge if it connects two different components (use union-find). O(E log E); good for sparse graphs.
  • Prim: grow one tree from a start vertex, always adding the cheapest edge leaving it (heap). O(E log V); good for dense graphs.
import heapq, random
random.seed(1)
class DSU:
    def __init__(self, n): self.p, self.sz = list(range(n)), [1] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b: return False
        if self.sz[a] < self.sz[b]: a, b = b, a
        self.p[b] = a; self.sz[a] += self.sz[b]
        return True
def kruskal(n, edges):
    d, total = DSU(n), 0
    for u, v, w in sorted(edges, key=lambda e: e[2]):
        if d.union(u, v): total += w
    return total
def prim(n, edges):
    adj = [[] for _ in range(n)]
    for u, v, w in edges:
        adj[u].append((w, v)); adj[v].append((w, u))
    seen, total, pq = set(), 0, [(0, 0)]
    while pq and len(seen) < n:
        w, u = heapq.heappop(pq)
        if u in seen: continue
        seen.add(u); total += w
        for e in adj[u]:
            if e[1] not in seen: heapq.heappush(pq, e)
    return total
n = 25
edges = [(i, i + 1, random.randint(1, 20)) for i in range(n - 1)]                  # a path guarantees connectivity
edges += [(random.randrange(n), random.randrange(n), random.randint(1, 20)) for _ in range(60)]
edges = [e for e in edges if e[0] != e[1]]
assert kruskal(n, edges) == prim(n, edges)
print("Kruskal and Prim agree: MST weight", kruskal(n, edges))

Output

Kruskal and Prim agree: MST weight 80

Strongly connected components and bridges

Strongly connected components (SCC)

In a directed graph, an SCC is a maximal set where every vertex reaches every other. Collapsing each SCC gives a DAG, which is why SCCs are the first step in analysing cyclic dependencies, 2-SAT and reachability. Kosaraju: DFS to get finish order, DFS on the reversed graph in decreasing finish order. Tarjan does it in one DFS with low-link values.

import sys
sys.setrecursionlimit(10000)
def scc(n, edges):
    adj = [[] for _ in range(n)]; radj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v); radj[v].append(u)
    seen, order = [False] * n, []
    def dfs1(u):
        seen[u] = True
        for v in adj[u]:
            if not seen[v]: dfs1(v)
        order.append(u)
    for u in range(n):
        if not seen[u]: dfs1(u)
    comp = [-1] * n
    def dfs2(u, c):
        comp[u] = c
        for v in radj[u]:
            if comp[v] < 0: dfs2(v, c)
    c = 0
    for u in reversed(order):
        if comp[u] < 0:
            dfs2(u, c); c += 1
    return comp, c
edges = [(0, 1), (1, 2), (2, 0), (2, 3), (3, 4), (4, 5), (5, 3), (6, 5)]
comp, k = scc(7, edges)
print("components:", k, "labels:", comp)

Output

components: 3 labels: [1, 1, 1, 2, 2, 2, 0]

Bridges and articulation points (undirected)

A bridge is an edge whose removal disconnects the graph; an articulation point is such a vertex. Run a DFS recording each vertex's discovery time tin and the earliest discovery time reachable low. A tree edge (u, v) is a bridge if low[v] > tin[u].

import sys
sys.setrecursionlimit(10000)
def bridges(n, edges):
    adj = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        adj[u].append((v, i)); adj[v].append((u, i))
    tin, low, timer, out = [-1] * n, [0] * n, [0], []
    def dfs(u, parent_edge):
        tin[u] = low[u] = timer[0]; timer[0] += 1
        for v, i in adj[u]:
            if i == parent_edge: continue
            if tin[v] != -1:
                low[u] = min(low[u], tin[v])
            else:
                dfs(v, i)
                low[u] = min(low[u], low[v])
                if low[v] > tin[u]: out.append(edges[i])
    for u in range(n):
        if tin[u] == -1: dfs(u, -1)
    return out
edges = [(0, 1), (1, 2), (2, 0), (1, 3), (3, 4), (4, 5), (5, 3), (5, 6)]
print("bridges:", bridges(7, edges))

Output

bridges: [(5, 6), (1, 3)]

How this gets asked

In Tarjan's bridge-finding, a tree edge (u, v) is a bridge when:

  • low[v] > tin[u] Correct.
  • low[v] < tin[u] No.
  • tin[v] = low[v] That identifies an SCC or component root.
  • v is a leaf Not sufficient.

No back edge from v's subtree reaches u or above.

Topological orders, cycles and bipartite graphs

  • Kahn's algorithm (repeatedly remove zero in-degree vertices) gives an order and detects a cycle when it cannot place all vertices; lexicographically smallest order uses a min-heap instead of a queue. The number of orderings and longest path in a DAG follow from DP over this order.
  • Bipartite check: two-colour the graph with BFS; an edge between equal colours (equivalently an odd cycle) means it is not bipartite. Bipartite graphs model matchings and two-team splits.
from collections import deque
def is_bipartite(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges: adj[u].append(v); adj[v].append(u)
    color = [-1] * n
    for s in range(n):
        if color[s] != -1: continue
        color[s] = 0; q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1: color[v] = 1 - color[u]; q.append(v)
                elif color[v] == color[u]: return False
    return True
print("even cycle:", is_bipartite(4, [(0, 1), (1, 2), (2, 3), (3, 0)]), "| triangle:", is_bipartite(3, [(0, 1), (1, 2), (2, 0)]))

Output

even cycle: True | triangle: False

Maximum flow

A flow network has capacities on edges, a source s and a sink t. A flow respects capacities and conserves flow at intermediate vertices. The max-flow min-cut theorem: the maximum flow equals the capacity of the minimum cut separating s from t.

Ford-Fulkerson repeatedly finds an augmenting path in the residual graph (edges with remaining capacity, plus reverse edges for undoing flow) and pushes flow along it. With BFS to choose shortest paths it is Edmonds-Karp, O(V E^2); Dinic is faster in practice.

from collections import deque
def max_flow(n, cap, s, t):
    flow = 0
    while True:
        parent = [-1] * n; parent[s] = s
        q = deque([s])
        while q and parent[t] == -1:
            u = q.popleft()
            for v in range(n):
                if parent[v] == -1 and cap[u][v] > 0:
                    parent[v] = u; q.append(v)
        if parent[t] == -1: return flow
        bottleneck, v = float("inf"), t
        while v != s:
            bottleneck = min(bottleneck, cap[parent[v]][v]); v = parent[v]
        v = t
        while v != s:
            cap[parent[v]][v] -= bottleneck; cap[v][parent[v]] += bottleneck; v = parent[v]
        flow += bottleneck
cap = [[0, 10, 10, 0, 0, 0],
       [0, 0, 2, 4, 8, 0],
       [0, 0, 0, 0, 9, 0],
       [0, 0, 0, 0, 0, 10],
       [0, 0, 0, 6, 0, 10],
       [0, 0, 0, 0, 0, 0]]
print("maximum flow:", max_flow(6, cap, 0, 5))

Output

maximum flow: 19

Applications: bipartite matching (unit capacities: maximum matching equals maximum flow; Hopcroft-Karp is faster), assignment and scheduling, project selection, image segmentation, edge-disjoint paths, minimum cut for network reliability.

Key idea

Graph problems become easy once you name the model: weights or not, directed or not, cyclic or not, and whether you want a path, a tree, an order or a cut. Then pick the matching algorithm from the table.

Interview questions: Advanced graphs

15 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic BFS versus DFS: when do you use each?

BFS for shortest paths in unweighted graphs and level order; DFS for cycle detection, topological order, components and backtracking.

Basic Why can't Dijkstra handle negative edges?

It finalises a node when popped assuming no later path can be shorter, which a negative edge can violate. Use Bellman-Ford instead.

Basic What is the complexity of Dijkstra with a binary heap?

O((V + E) log V) in the lazy-deletion form.

Medium Explain Bellman-Ford and negative cycles.

Relax every edge V - 1 times. If another pass still improves a distance, a negative cycle is reachable.

Medium Floyd-Warshall: what does it compute and what is the loop order?

All-pairs shortest paths in O(V^3). The intermediate vertex k must be the outermost loop.

Medium Kruskal versus Prim?

Kruskal sorts edges and joins components with union-find (good for sparse graphs). Prim grows a tree from a start node with a heap (good for dense graphs). Both are O(E log V).

Medium How do you find strongly connected components?

Tarjan's algorithm (low-link values in one DFS) or Kosaraju's (DFS finishing order, then DFS on the reversed graph). Both O(V + E).

Medium How do you test if a graph is bipartite?

BFS or DFS two-colouring; a conflict on an edge means an odd cycle, so it is not bipartite.

Medium What are bridges and articulation points?

A bridge is an edge, and an articulation point a vertex, whose removal disconnects the graph. Found with DFS discovery times and low-link values in O(V + E).

Advanced What is A* and when is it optimal?

Best-first search ordered by g + h, where h estimates the remaining cost. It is optimal with an admissible heuristic (never overestimates), and consistent heuristics avoid reopening nodes.

Advanced How does max flow relate to min cut?

The max-flow min-cut theorem: the maximum flow equals the capacity of the minimum cut. Ford-Fulkerson with BFS (Edmonds-Karp) runs in O(V E^2).

Advanced How is bipartite matching solved?

As a max-flow problem or with Hopcroft-Karp in O(E sqrt V); Konig's theorem links the maximum matching to the minimum vertex cover in bipartite graphs.

Advanced How do you solve 2-SAT?

Build the implication graph, compute SCCs; the formula is unsatisfiable iff a variable and its negation share a component, and a topological order yields an assignment.

Advanced How would you find the shortest path with at most k edges?

Bellman-Ford limited to k rounds (using a copy of the previous distances) or BFS/Dijkstra on a state graph of (node, edges used).

Advanced How do you detect a cycle in a directed versus undirected graph?

Directed: DFS with three colours or Kahn's algorithm. Undirected: DFS/BFS that sees a visited node other than its parent, or union-find.
