Arrays and hashing

1. Subarray sum equals k (negative numbers allowed)

Prefix sums plus a hash map of seen prefix counts: a subarray ending here sums to k if prefix - k was seen. O(n).

import random
from collections import defaultdict
random.seed(0)
def subarray_sum(a, k):
    seen, cur, ans = defaultdict(int), 0, 0
    seen[0] = 1
    for x in a:
        cur += x
        ans += seen[cur - k]
        seen[cur] += 1
    return ans
brute = lambda a, k: sum(sum(a[i:j]) == k for i in range(len(a)) for j in range(i + 1, len(a) + 1))
for _ in range(300):
    a = [random.randint(-3, 3) for _ in range(random.randint(0, 10))]
    k = random.randint(-4, 4)
    assert subarray_sum(a, k) == brute(a, k)
print("subarray sum = k verified; example:", subarray_sum([1, 2, 3, -3, 3], 3))

Output

2. Product of array except self (no division)

Left products times right products. O(n) time, O(1) extra besides the output.

import random
random.seed(1)
def product_except_self(a):
    n, out = len(a), [1] * len(a)
    left = 1
    for i in range(n):
        out[i] = left; left *= a[i]
    right = 1
    for i in range(n - 1, -1, -1):
        out[i] *= right; right *= a[i]
    return out
def brute(a):
    out = []
    for i in range(len(a)):
        p = 1
        for j, x in enumerate(a):
            if j != i: p *= x
        out.append(p)
    return out
for _ in range(200):
    a = [random.randint(-3, 3) for _ in range(random.randint(1, 8))]
    assert product_except_self(a) == brute(a)
print("verified;", product_except_self([1, 2, 3, 4]))

Output

verified; [24, 12, 8, 6]

3. Longest consecutive sequence in O(n)

Put values in a set; start counting only from values with no predecessor.

import random
random.seed(2)
def longest_consecutive(a):
    s, best = set(a), 0
    for x in s:
        if x - 1 not in s:
            y = x
            while y + 1 in s: y += 1
            best = max(best, y - x + 1)
    return best
def brute(a):
    s, best = set(a), 0
    for x in s:
        y = x
        while y in s: y += 1
        best = max(best, y - x)
    return best
for _ in range(300):
    a = [random.randint(0, 15) for _ in range(random.randint(0, 12))]
    assert longest_consecutive(a) == brute(a)
print("verified;", longest_consecutive([100, 4, 200, 1, 3, 2]))

Output

verified; 4

4. Majority element (Boyer-Moore voting)

Keep a candidate and a counter; a true majority survives cancellation. O(n) time, O(1) space.

import random
from collections import Counter
random.seed(3)
def majority(a):
    cand, cnt = None, 0
    for x in a:
        if cnt == 0: cand = x
        cnt += 1 if x == cand else -1
    return cand if a.count(cand) > len(a) // 2 else None
for _ in range(300):
    a = [random.randint(0, 2) for _ in range(random.randint(1, 11))]
    c, f = Counter(a).most_common(1)[0]
    assert majority(a) == (c if f > len(a) // 2 else None)
print("verified;", majority([2, 2, 1, 1, 2, 2, 3]))

Output

verified; 2

5. Trapping rain water (two pointers)

Water above a bar is min(maxLeft, maxRight) - height. Move the pointer on the smaller side.

import random
random.seed(4)
def trap(h):
    l, r, lm, rm, water = 0, len(h) - 1, 0, 0, 0
    while l < r:
        if h[l] < h[r]:
            lm = max(lm, h[l]); water += lm - h[l]; l += 1
        else:
            rm = max(rm, h[r]); water += rm - h[r]; r -= 1
    return water
brute = lambda h: sum(max(0, min(max(h[:i + 1]), max(h[i:])) - h[i]) for i in range(len(h)))
for _ in range(300):
    h = [random.randint(0, 6) for _ in range(random.randint(1, 12))]
    assert trap(h) == brute(h)
print("verified;", trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]))

Output

verified; 6

In Boyer-Moore voting, why does the majority element survive?

  • It appears first No.

6. K most frequent elements

Count, then take the top k by frequency with a heap: O(n log k).

import heapq, random
from collections import Counter
random.seed(5)
def top_k(a, k):
    cnt = Counter(a)
    return sorted(heapq.nlargest(k, cnt, key=lambda x: (cnt[x], -x)))
def brute(a, k):
    cnt = Counter(a)
    return sorted(sorted(cnt, key=lambda x: (-cnt[x], x))[:k])
for _ in range(300):
    a = [random.randint(0, 5) for _ in range(random.randint(1, 15))]
    k = random.randint(1, len(set(a)))
    assert top_k(a, k) == brute(a, k)
print("verified;", top_k([1, 1, 1, 2, 2, 3], 2))

7. Merge intervals and the minimum meeting rooms

Sort by start. Merging extends the last interval; meeting rooms use a min-heap of end times (or sweep the sorted starts and ends).

import heapq, random
random.seed(6)
def merge(iv):
    out = []
    for s, e in sorted(iv):
        if out and s <= out[-1][1]: out[-1][1] = max(out[-1][1], e)
        else: out.append([s, e])
    return out
def min_rooms(iv):
    heap, best = [], 0
    for s, e in sorted(iv):
        while heap and heap[0] <= s: heapq.heappop(heap)
        heapq.heappush(heap, e)
        best = max(best, len(heap))
    return best
def rooms_brute(iv):
    return max((sum(s <= t < e for s, e in iv) for t in range(0, 20)), default=0)
for _ in range(300):
    iv = []
    for _ in range(random.randint(1, 8)):
        s = random.randint(0, 15); iv.append((s, s + random.randint(1, 4)))
    assert min_rooms(iv) == rooms_brute(iv)
print("rooms verified;", merge([(1, 3), (2, 6), (8, 10), (15, 18)]), min_rooms([(0, 30), (5, 10), (15, 20)]))

Output

rooms verified; [[1, 6], [8, 10], [15, 18]] 2

8. Median of a data stream

Two heaps: a max-heap for the lower half and a min-heap for the upper half, kept balanced. O(log n) per insert, O(1) per median.

import heapq, random, statistics
random.seed(7)
class MedianFinder:
    def __init__(self): self.lo, self.hi = [], []
    def add(self, x):
        heapq.heappush(self.lo, -x)
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        if len(self.hi) > len(self.lo): heapq.heappush(self.lo, -heapq.heappop(self.hi))
    def median(self):
        return -self.lo[0] if len(self.lo) > len(self.hi) else (-self.lo[0] + self.hi[0]) / 2
m, seen = MedianFinder(), []
for _ in range(500):
    x = random.randint(-50, 50); m.add(x); seen.append(x)
    assert m.median() == statistics.median(seen)
print("running median verified over 500 inserts")

Output

running median verified over 500 inserts

Minimum meeting rooms is best computed by:

9. Lowest common ancestor in a binary tree

If both sides return a node, the current node is the LCA.

import random
random.seed(8)
class Node:
    def __init__(self, v): self.v, self.l, self.r = v, None, None
def build(vals):
    nodes = [Node(v) for v in vals]
    for i, n in enumerate(nodes):
        if 2 * i + 1 < len(nodes): n.l = nodes[2 * i + 1]
        if 2 * i + 2 < len(nodes): n.r = nodes[2 * i + 2]
    return nodes
def lca(root, p, q):
    if root is None or root is p or root is q: return root
    L, R = lca(root.l, p, q), lca(root.r, p, q)
    return root if L and R else (L or R)
def path(root, target, acc=()):
    if root is None: return None
    acc = acc + (root,)
    if root is target: return acc
    return path(root.l, target, acc) or path(root.r, target, acc)
nodes = build(list(range(15)))
for _ in range(200):
    p, q = random.sample(nodes, 2)
    a, b = path(nodes[0], p), path(nodes[0], q)
    expected = [x for x, y in zip(a, b) if x is y][-1]
    assert lca(nodes[0], p, q) is expected
print("LCA verified on a 15-node tree")

Output

LCA verified on a 15-node tree

10. Validate a BST and the k-th smallest element

Pass min and max bounds down. In-order traversal of a BST is sorted, so the k-th element is the k-th visited.

import random
random.seed(9)
class T:
    def __init__(self, v, l=None, r=None): self.v, self.l, self.r = v, l, r
def insert(t, v):
    if not t: return T(v)
    if v < t.v: t.l = insert(t.l, v)
    else: t.r = insert(t.r, v)
    return t
def is_bst(t, lo=float("-inf"), hi=float("inf")):
    return t is None or (lo < t.v < hi and is_bst(t.l, lo, t.v) and is_bst(t.r, t.v, hi))
def inorder(t): return inorder(t.l) + [t.v] + inorder(t.r) if t else []
vals = random.sample(range(100), 20)
root = None
for v in vals: root = insert(root, v)
assert is_bst(root) and inorder(root) == sorted(vals)
bad = T(5, T(1), T(4, T(3), T(6)))
print("valid BST:", is_bst(root), "| invalid tree detected:", not is_bst(bad), "| 5th smallest:", inorder(root)[4] == sorted(vals)[4])

11. Number of islands (grid components) and word ladder (BFS)

Islands: flood fill each unvisited land cell. Word ladder: BFS where neighbours differ by one letter.

import random
from collections import deque
random.seed(10)
def islands(g):
    R, C, seen, count = len(g), len(g[0]), set(), 0
    for r in range(R):
        for c in range(C):
            if g[r][c] == 1 and (r, c) not in seen:
                count += 1
                stack = [(r, c)]; seen.add((r, c))
                while stack:
                    y, x = stack.pop()
                    for dy, dx in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        ny, nx = y + dy, x + dx
                        if 0 <= ny < R and 0 <= nx < C and g[ny][nx] == 1 and (ny, nx) not in seen:
                            seen.add((ny, nx)); stack.append((ny, nx))
    return count
def islands_uf(g):
    R, C = len(g), len(g[0]); p = list(range(R * C))
    def f(x):
        while p[x] != x: p[x] = p[p[x]]; x = p[x]
        return x
    for r in range(R):
        for c in range(C):
            if g[r][c]:
                for dr, dc in ((1, 0), (0, 1)):
                    if r + dr < R and c + dc < C and g[r + dr][c + dc]: p[f(r * C + c)] = f((r + dr) * C + c + dc)
    return len({f(r * C + c) for r in range(R) for c in range(C) if g[r][c]})
for _ in range(200):
    g = [[random.randint(0, 1) for _ in range(5)] for _ in range(4)]
    assert islands(g) == islands_uf(g)
def ladder(begin, end, words):
    words, q = set(words), deque([(begin, 1)])
    while q:
        w, d = q.popleft()
        if w == end: return d
        for i in range(len(w)):
            for ch in "abcdefghijklmnopqrstuvwxyz":
                nw = w[:i] + ch + w[i + 1:]
                if nw in words: words.remove(nw); q.append((nw, d + 1))
    return 0
print("islands verified two ways; ladder length:", ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"]))

Output

islands verified two ways; ladder length: 5

12. Course schedule: detect a cycle with topological sort

Kahn's algorithm: if fewer than n nodes are output, a cycle exists.

import random, itertools
from collections import deque
random.seed(11)
def can_finish(n, pre):
    g, indeg = [[] for _ in range(n)], [0] * n
    for a, b in pre: g[b].append(a); indeg[a] += 1
    q, seen = deque(i for i in range(n) if indeg[i] == 0), 0
    while q:
        u = q.popleft(); seen += 1
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return seen == n
def brute(n, pre):
    return any(all(pos[b] < pos[a] for a, b in pre) for perm in itertools.permutations(range(n)) for pos in [{v: i for i, v in enumerate(perm)}])
for _ in range(300):
    n = random.randint(1, 5)
    pre = [(random.randrange(n), random.randrange(n)) for _ in range(random.randint(0, 6))]
    assert can_finish(n, pre) == brute(n, pre)
print("verified;", can_finish(2, [(1, 0)]), can_finish(2, [(1, 0), (0, 1)]))

Output

verified; True False

13. Subsets, permutations and combination sum

Choose, explore, un-choose. Counts: 2^n, n!, and for combination sum, the count of multisets reaching the target.

import itertools
def subsets(a):
    out = []
    def go(i, cur):
        if i == len(a): out.append(cur[:]); return
        go(i + 1, cur)
        cur.append(a[i]); go(i + 1, cur); cur.pop()
    go(0, []); return out
def combination_sum(c, t):
    out = []
    def go(i, rem, cur):
        if rem == 0: out.append(cur[:]); return
        for j in range(i, len(c)):
            if c[j] <= rem:
                cur.append(c[j]); go(j, rem - c[j], cur); cur.pop()
    go(0, t, []); return out
assert len(subsets([1, 2, 3, 4])) == 16
assert sorted(map(tuple, subsets([1, 2, 3]))) == sorted(sum((list(itertools.combinations([1, 2, 3], r)) for r in range(4)), []))
print(combination_sum([2, 3, 6, 7], 7), len(combination_sum([1, 2, 5], 11)))

Output

[[2, 2, 3], [7]] 11

14. N-Queens count

Place one queen per row; track used columns and both diagonals.

def n_queens(n):
    cols, d1, d2 = set(), set(), set()
    def go(r):
        if r == n: return 1
        total = 0
        for c in range(n):
            if c in cols or r - c in d1 or r + c in d2: continue
            cols.add(c); d1.add(r - c); d2.add(r + c)
            total += go(r + 1)
            cols.remove(c); d1.remove(r - c); d2.remove(r + c)
        return total
    return go(0)
known = {1: 1, 4: 2, 5: 10, 6: 4, 7: 40, 8: 92}
assert all(n_queens(n) == v for n, v in known.items())
print("n-queens counts match the known sequence:", [n_queens(n) for n in range(1, 9)])

Output

15. LRU cache and an iterator over nested lists

LRU uses a hash map plus recency order (OrderedDict). A flattening iterator keeps an explicit stack.

from collections import OrderedDict
class LRU:
    def __init__(self, cap): self.cap, self.d = cap, OrderedDict()
    def get(self, k):
        if k not in self.d: return -1
        self.d.move_to_end(k); return self.d[k]
    def put(self, k, v):
        self.d[k] = v; self.d.move_to_end(k)
        if len(self.d) > self.cap: self.d.popitem(last=False)
c = LRU(2)
c.put(1, 1); c.put(2, 2); assert c.get(1) == 1
c.put(3, 3); assert c.get(2) == -1
c.put(4, 4); assert c.get(1) == -1 and c.get(3) == 3 and c.get(4) == 4
def flatten(x):
    stack = [iter(x)]
    while stack:
        for item in stack[-1]:
            if isinstance(item, list): stack.append(iter(item)); break
            yield item
        else:
            stack.pop()
print("LRU behaves; flatten:", list(flatten([1, [2, [3, [4]], 5], [], [[6]]])))

Output

LRU behaves; flatten: [1, 2, 3, 4, 5, 6]

16. Search in a rotated sorted array and find the minimum

Binary search; one half is always sorted.

import random
random.seed(12)
def search_rotated(a, t):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t: return mid
        if a[lo] <= a[mid]:
            if a[lo] <= t < a[mid]: hi = mid - 1
            else: lo = mid + 1
        else:
            if a[mid] < t <= a[hi]: lo = mid + 1
            else: hi = mid - 1
    return -1
def find_min(a):
    lo, hi = 0, len(a) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] > a[hi]: lo = mid + 1
        else: hi = mid
    return a[lo]
for _ in range(300):
    base = sorted(random.sample(range(40), random.randint(1, 10)))
    k = random.randrange(len(base))
    a = base[k:] + base[:k]
    t = random.randint(-1, 41)
    got = search_rotated(a, t)
    assert (got == -1 and t not in a) or a[got] == t
    assert find_min(a) == min(a)
print("rotated search and min verified")

17. Kth largest element with quickselect

Partition around a pivot and recurse into one side: O(n) expected.

import random
random.seed(13)
def quickselect(a, k):  # k-th smallest, 0-indexed
    a = a[:]
    lo, hi = 0, len(a) - 1
    while True:
        p = a[random.randint(lo, hi)]
        lt = [x for x in a[lo:hi + 1] if x < p]
        eq = [x for x in a[lo:hi + 1] if x == p]
        gt = [x for x in a[lo:hi + 1] if x > p]
        if k - lo < len(lt): hi = lo + len(lt) - 1; a[lo:hi + 1] = lt
        elif k - lo < len(lt) + len(eq): return p
        else:
            new_lo = lo + len(lt) + len(eq)
            a[lo:hi + 1] = lt + eq + gt
            lo = new_lo
for _ in range(300):
    a = [random.randint(0, 20) for _ in range(random.randint(1, 15))]
    k = random.randrange(len(a))
    assert quickselect(a, k) == sorted(a)[k]
print("quickselect verified")

18. Dutch national flag, next permutation and rotate

Three-way partition sorts 0/1/2 in one pass. Next permutation: find the rightmost ascent, swap with the next larger suffix element, reverse the suffix.

import itertools
def dutch(a):
    lo, mid, hi = 0, 0, len(a) - 1
    while mid <= hi:
        if a[mid] == 0: a[lo], a[mid] = a[mid], a[lo]; lo += 1; mid += 1
        elif a[mid] == 1: mid += 1
        else: a[mid], a[hi] = a[hi], a[mid]; hi -= 1
    return a
def next_perm(a):
    a = a[:]
    i = len(a) - 2
    while i >= 0 and a[i] >= a[i + 1]: i -= 1
    if i >= 0:
        j = len(a) - 1
        while a[j] <= a[i]: j -= 1
        a[i], a[j] = a[j], a[i]
    a[i + 1:] = a[i + 1:][::-1]
    return a
assert dutch([2, 0, 2, 1, 1, 0]) == [0, 0, 1, 1, 2, 2]
perms = list(itertools.permutations([1, 2, 3, 4]))
assert all(tuple(next_perm(list(perms[i]))) == perms[i + 1] for i in range(len(perms) - 1))
print("verified; next of [3,2,1] wraps to", next_perm([3, 2, 1]))

19. Largest rectangle in a histogram

A monotonic stack finds, for each bar, how far it extends. O(n).

import random
random.seed(14)
def largest_rect(h):
    stack, best = [], 0
    for i, x in enumerate(h + [0]):
        start = i
        while stack and stack[-1][1] >= x:
            idx, height = stack.pop()
            best = max(best, height * (i - idx)); start = idx
        stack.append((start, x))
    return best
brute = lambda h: max((min(h[i:j + 1]) * (j - i + 1) for i in range(len(h)) for j in range(i, len(h))), default=0)
for _ in range(300):
    h = [random.randint(0, 6) for _ in range(random.randint(1, 10))]
    assert largest_rect(h) == brute(h)
print("verified;", largest_rect([2, 1, 5, 6, 2, 3]))

20. Maximum subarray, the circular variant

Kadane for the linear case; for circular, the answer is the larger of the Kadane maximum and total - minimum subarray.

import random
random.seed(15)
def kadane(a, f=max):
    best = cur = a[0]
    for x in a[1:]:
        cur = f(x, cur + x); best = f(best, cur)
    return best
def circular(a):
    mx, mn, total = kadane(a), kadane(a, min), sum(a)
    return mx if mx < 0 else max(mx, total - mn)
def brute(a):
    n = len(a)
    return max(sum(a[(i + k) % n] for k in range(L)) for i in range(n) for L in range(1, n + 1))
for _ in range(300):
    a = [random.randint(-5, 5) for _ in range(random.randint(1, 9))]
    assert circular(a) == brute(a)
print("circular Kadane verified")

Key idea

For every new problem, name the pattern first (prefix sums, two pointers, heap, monotonic stack, BFS, backtracking), write the brute force, then the optimised version, then cross-check them on random small inputs. That routine finds off-by-one bugs before the interviewer does.

How this gets asked

In a rotated sorted array, binary search works because:

  • It is fully sorted No.
  • At every step at least one half is sorted, so you can tell which half holds the target Correct.
  • It uses hashing No.
  • Duplicates are absent Not the reason.

Compare the target with the sorted half's endpoints.

Interview questions: Extra problems

19 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic Two Sum: what are the approaches?

Hash map of complement values in O(n) time; or sort and use two pointers in O(n log n) if indexes are not needed.

Basic How do you reverse a linked list?

Iterate keeping prev, curr and next, flipping each pointer. O(n) time, O(1) space; recursion uses O(n) stack.

Basic How do you detect a cycle in a linked list?

Floyd's tortoise and hare: a fast and a slow pointer meet inside a cycle. To find the start, reset one pointer to the head and move both one step at a time.

Basic Valid parentheses?

Use a stack: push openers, and each closer must match the top.

Medium Subarray sum equals k with negatives?

Prefix sums with a hash map counting earlier prefixes equal to current - k. O(n).

Medium Merge k sorted lists?

A min-heap of the current heads, popping the smallest and pushing its successor. O(N log k).

Medium Find the median of two sorted arrays in O(log(min(m, n)))?

Binary search the partition of the smaller array so that left halves are all <= right halves.

Medium Trapping rain water?

Water above each bar is min(left max, right max) - height. Two pointers do it in O(n) and O(1) space.

Medium Longest substring without repeating characters?

Sliding window with a map of last seen indexes; move the left edge past the previous occurrence.

Medium Group anagrams?

Key each word by its sorted letters (or a 26-count tuple) in a hash map.

Medium Number of islands?

Flood fill with DFS/BFS or union-find over the grid; count the components of land.

Medium Lowest common ancestor of a binary tree?

Recurse; return the node if it matches, and the current node is the LCA when both subtrees report a hit.

Advanced Serialise and deserialise a binary tree?

Pre-order with null markers (or level order), parsed with the same order; unambiguous because nulls mark every missing child.

Advanced Design an LRU cache.

A hash map to doubly linked list nodes (or OrderedDict) giving O(1) get and put, evicting from the tail.

Advanced Largest rectangle in a histogram?

Monotonic stack of increasing heights; when a shorter bar arrives, pop and compute the area using the popped bar as the minimum. O(n).

Advanced Word ladder shortest transformation?

BFS over words differing by one letter, using wildcard buckets or letter substitution to generate neighbours.

Advanced Course schedule feasibility?

Topological sort: Kahn's algorithm processes all nodes iff there is no cycle.

Advanced Kth largest element in an array?

Quickselect in O(n) expected, or a min-heap of size k in O(n log k).

Advanced How do you present a solution in an interview?

Clarify the input and constraints, give a brute force, state complexity, optimise by naming the pattern, code cleanly, test with small and edge cases, then restate the complexity.
