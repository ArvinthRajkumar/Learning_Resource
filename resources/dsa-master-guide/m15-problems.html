Assign Cookies

Easy Greedy matching with sorting LC 455

Child i needs a cookie of size >= g[i]; cookie j has size s[j]. Each child gets at most one cookie. Maximise the number of satisfied children.

This is a well-known public interview classic (LeetCode-style problem #455). The guide does not claim any company asked it.

FieldDetail
DSA conceptGreedy matching with sorting (Greedy Algorithms)
Input formatLists g and s.
Output formatInteger.
Constraintslen <= 3*10^4

Sample input

g=[1,2,3], s=[1,1]

Sample output

1

Explanation: Only the child with greed 1 can be satisfied.

Stuck? Reveal hints one at a time

Hint 1

Two pointers over sorted lists.

Recommended approach (spoiler)

Sort both. Give the smallest sufficient cookie to the least greedy child: walk through cookies; if the cookie satisfies the current child, move to the next child.

Python solution (try first)

def assign_cookies(g, s):
    g, s = sorted(g), sorted(s)
    child = 0
    for cookie in s:
        if child < len(g) and cookie >= g[child]:
            child += 1
    return child

Complexity: Time O(n log n + m log m); Space O(1) extra.

Edge cases to test

  • No cookies
  • More cookies than children

def lemonade_change(bills):
    fives = tens = 0
    for b in bills:
        if b == 5:
            fives += 1
        elif b == 10:
            if not fives:
                return False
            fives -= 1
            tens += 1
        else:
            if tens and fives:
                tens -= 1
                fives -= 1
            elif fives >= 3:
                fives -= 3
            else:
                return False
    return True

Complexity: Time O(n); Space O(1).

nums[i] is the maximum jump length from index i. Starting at index 0, can you reach the last index?

def can_jump(nums):
    farthest = 0
    for i, x in enumerate(nums):
        if i > farthest:
            return False          # unreachable position
        farthest = max(farthest, i + x)
    return True

Fractional Knapsack

Medium Greedy by ratio

Items can be broken into fractions. Maximise the total value in a bag of capacity W.

FieldDetail
DSA conceptGreedy by ratio (Greedy Algorithms)
Input formatvalues, weights, W.
Output formatFloat maximum value.
Constraintsn <= 10^5

Sample input

values=[60,100,120], weights=[10,20,30], W=50

Sample output

240.0

Explanation: Take items 1 and 2 fully (160) and 2/3 of item 3 (80).

Stuck? Reveal hints one at a time

Hint 1

Ratio = value / weight.

Recommended approach (spoiler)

Sort items by value/weight descending and take as much as possible of each. (This greedy is correct for FRACTIONAL knapsack but NOT for 0/1 knapsack.)

Python solution (try first)

def fractional_knapsack(values, weights, W):
    items = sorted(zip(values, weights), key=lambda p: p[0] / p[1], reverse=True)
    total = 0.0
    for v, w in items:
        if W >= w:
            total += v
            W -= w
        else:
            total += v * W / w     # take a fraction
            break
    return total

Complexity: Time O(n log n); Space O(n).

Edge cases to test

  • Capacity 0
  • Capacity larger than the total weight

Gas Station

Medium Greedy LC 134

Stations are in a circle. gas[i] is fuel you collect at i and cost[i] is fuel needed to reach the next station. Return the starting index that lets you complete one lap, or -1.

This is a well-known public interview classic (LeetCode-style problem #134). The guide does not claim any company asked it.

FieldDetail
DSA conceptGreedy (Greedy Algorithms)
Input formatgas and cost.
Output formatIndex or -1.
Constraintsn <= 10^5

Sample input

gas=[1,2,3,4,5], cost=[3,4,5,1,2]

Sample output

3

Explanation: Starting at 3 you never run out.

Stuck? Reveal hints one at a time

Hint 1

One pass is enough.

Recommended approach (spoiler)

If total gas < total cost it is impossible. Otherwise scan once keeping the tank; whenever it drops below 0, the start must be after this point, so reset the start to the next index.

Python solution (try first)

def gas_station(gas, cost):
    if sum(gas) < sum(cost):
        return -1
    tank = start = 0
    for i in range(len(gas)):
        tank += gas[i] - cost[i]
        if tank < 0:                 # cannot start from any station up to i
            start, tank = i + 1, 0
    return start

Complexity: Time O(n); Space O(1).

Edge cases to test

  • Not enough total gas
  • Single station

Non-overlapping Intervals

Medium Greedy by end time LC 435 must-do

Return the minimum number of intervals to remove so the rest do not overlap (touching is allowed).

This is a well-known public interview classic (LeetCode-style problem #435, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Why interviewers ask this: Activity selection in disguise: minimum removals = n - maximum kept.

FieldDetail
DSA conceptGreedy by end time (Greedy Algorithms)
Input formatList of intervals.
Output formatInteger.
Constraintslen <= 10^5

Sample input

[[1,2],[2,3],[3,4],[1,3]]

Sample output

1

Explanation: Remove [1,3].

Stuck? Reveal hints one at a time

Hint 1

Sort by END time.

Recommended approach (spoiler)

Sort by end. Keep an interval if it starts at or after the last kept end; otherwise count a removal.

Python solution (try first)

def non_overlapping_intervals(intervals):
    removed, last_end = 0, float("-inf")
    for start, end in sorted(intervals, key=lambda x: x[1]):
        if start >= last_end:
            last_end = end
        else:
            removed += 1
    return removed

Complexity: Time O(n log n); Space O(1) extra.

Partition Labels

Medium Greedy with last positions LC 763

Split the string into as many parts as possible so each letter appears in at most one part. Return the part sizes.

This is a well-known public interview classic (LeetCode-style problem #763). The guide does not claim any company asked it.

Why interviewers ask this: Greedy with last occurrences: extend the current part until it is closed.

FieldDetail
DSA conceptGreedy with last positions (Greedy Algorithms)
Input formatString s.
Output formatList.
Constraintslen <= 500

Sample input

"ababcbacadefegdehijhklij"

Sample output

[9, 7, 8]

Explanation: Parts: ababcbaca, defegde, hijhklij.

Stuck? Reveal hints one at a time

Hint 1

end = max(end, last[ch]).

Recommended approach (spoiler)

Record the last index of each letter. Scan while extending the current part end to the farthest last index; when the index reaches the end, cut.

Python solution (try first)

def partition_labels(s):
    last = {ch: i for i, ch in enumerate(s)}
    sizes, start, end = [], 0, 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])
        if i == end:
            sizes.append(end - start + 1)
            start = i + 1
    return sizes

Complexity: Time O(n); Space O(1).

Edge cases to test

  • All same letter
  • All distinct letters

Two City Scheduling

Medium Greedy by cost difference LC 1029

Each person costs [a, b] to fly to city A or B. Send exactly half to each city with minimum total cost.

This is a well-known public interview classic (LeetCode-style problem #1029). The guide does not claim any company asked it.

Why interviewers ask this: Sort by the DIFFERENCE: a nice example of choosing the right greedy key.

FieldDetail
DSA conceptGreedy by cost difference (Greedy Algorithms)
Input formatList of [a, b].
Output formatInteger.
Constraints2n people, n <= 50

Sample input

[[10,20],[30,200],[400,50],[30,20]]

Sample output

110

Explanation: Send two people to each city.

Stuck? Reveal hints one at a time

Hint 1

The key is a - b.

Recommended approach (spoiler)

Sort people by a - b (how much cheaper A is than B). The first half go to A, the rest to B.

Python solution (try first)

def two_city_cost(costs):
    costs = sorted(costs, key=lambda c: c[0] - c[1])
    n = len(costs) // 2
    return sum(c[0] for c in costs[:n]) + sum(c[1] for c in costs[n:])

Minimum Platforms (Meeting Rooms)

Hard Greedy with sorting / sweep line

Given train arrival and departure times (24h as integers like 900, 1130), find the minimum number of platforms so that no train waits. A train arriving at the same time another departs needs a separate platform.

FieldDetail
DSA conceptGreedy with sorting / sweep line (Greedy Algorithms)
Input formatarr and dep lists.
Output formatInteger.
Constraintsn <= 10^5

Sample input

arr=[900,940,950,1100,1500,1800], dep=[910,1200,1120,1130,1900,2000]

Sample output

3

Explanation: Between 1100 and 1120 three trains are at the station.

Stuck? Reveal hints one at a time

Hint 1

Process arrival first when times are equal (<=).

Recommended approach (spoiler)

Sort arrivals and departures separately. Sweep: if the next event is an arrival, one more platform is occupied; if a departure, one is freed. The maximum occupancy is the answer.

Python solution (try first)

def min_platforms(arr, dep):
    arr, dep = sorted(arr), sorted(dep)
    i = j = 0
    cur = best = 0
    while i < len(arr):
        if arr[i] <= dep[j]:       # next event is an arrival
            cur += 1
            i += 1
            best = max(best, cur)
        else:                      # a train leaves
            cur -= 1
            j += 1
    return best

Complexity: Time O(n log n); Space O(1) extra.

Edge cases to test

  • Single train
  • Same arrival and departure times

Candy

Hard Greedy two passes LC 135

Children in a row have ratings. Each gets at least one candy and a child with a higher rating than a neighbour gets more candies than that neighbour. Return the minimum total candies.

This is a well-known public interview classic (LeetCode-style problem #135). The guide does not claim any company asked it.

Why interviewers ask this: A two-pass greedy: satisfy the left neighbour rule, then the right neighbour rule.

FieldDetail
DSA conceptGreedy two passes (Greedy Algorithms)
Input formatList ratings.
Output formatInteger.
Constraintslen <= 2*10^4

Sample input

[1,0,2]

Sample output

5

Explanation: Candies 2, 1, 2.

Stuck? Reveal hints one at a time

Hint 1

Two independent passes then combine with max.

Recommended approach (spoiler)

Pass left to right: if rating > left neighbour, candies = left + 1. Pass right to left: if rating > right neighbour, candies = max(current, right + 1).

Python solution (try first)

def candy(ratings):
    n = len(ratings)
    c = [1] * n
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            c[i] = c[i - 1] + 1
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            c[i] = max(c[i], c[i + 1] + 1)
    return sum(c)

Complexity: Time O(n); Space O(n).

Edge cases to test
