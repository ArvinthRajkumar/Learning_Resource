Two Sum

Easy Hash map LC 1 must-do

Return the indices of the two numbers that add up to target. Exactly one solution exists; do not reuse the same element.

This is a well-known public interview classic (LeetCode-style problem #1, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptHash map (Hashing)
Input formatList nums and target.
Output formatA list of two indices.
Constraints2 <= len(nums) <= 10^5

Sample input

nums=[2,7,11,15], target=9

Sample output

[0, 1]

Explanation: nums[0] + nums[1] = 2 + 7 = 9.

Stuck? Reveal hints one at a time

Hint 1

What number do you need to pair with x?

Hint 2

Check the dict BEFORE inserting x (so you do not reuse it).

Recommended approach (spoiler)

Brute force checks all pairs in O(n^2). Instead store each value seen so far with its index in a dict. For every x, check whether target - x was already seen.

Python solution (try first)

def two_sum(nums, target):
    seen = {}                          # value -> index
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Duplicates such as [3,3] with target 6
  • Negative numbers
  • Target 0

Return True if any value appears at least twice.

This is a well-known public interview classic (LeetCode-style problem #217, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

def contains_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False

Python solution (try first)

def first_repeating(nums):
    seen = set()
    answer = -1
    for x in reversed(nums):
        if x in seen:
            answer = x            # overwritten until we reach the left-most one
        else:
            seen.add(x)
    return answer

Complexity: Time O(n); Space O(n).

def isomorphic(s, t):
    if len(s) != len(t):
        return False
    a_to_b, b_to_a = {}, {}
    for x, y in zip(s, t):
        if a_to_b.setdefault(x, y) != y or b_to_a.setdefault(y, x) != x:
            return False
    return True

Ransom Note

Easy Counting letters LC 383

Can the note be built using the letters of the magazine (each magazine letter used at most once)?

This is a well-known public interview classic (LeetCode-style problem #383). The guide does not claim any company asked it.

def ransom_note(note, magazine):

Most Frequent Word

Easy Counter

Return the word that appears most often (if tied, the one that is alphabetically smallest).

FieldDetail

Output formatA word.
Constraintslen <= 10^5

Sample input

["b","a","b","a","c"]

Sample output

Explanation: a and b appear twice; a is alphabetically first.

Stuck? Reveal hints one at a time

Hint 1

Negate the count to find the maximum with min().

Recommended approach (spoiler)

Count with Counter, then take min of the words using the key (-count, word).

Python solution (try first)

from collections import Counter

def most_frequent_word(words):
    freq = Counter(words)
    return min(freq, key=lambda w: (-freq[w], w))

Word Pattern

Easy Two-way hash maps LC 290

Does the string s follow the pattern? A letter must always map to the same word and different letters to different words.

This is a well-known public interview classic (LeetCode-style problem #290). The guide does not claim any company asked it.

Why interviewers ask this: Same two-way mapping idea as isomorphic strings but between letters and words.

FieldDetail
DSA conceptTwo-way hash maps (Hashing)
Input formatpattern and s.
Output formatTrue or False.
Constraintslen <= 300

Sample input

"abba", "dog cat cat dog"

Sample output

True

Explanation: a=dog, b=cat.

Stuck? Reveal hints one at a time

Hint 1

Lengths must match.

Recommended approach (spoiler)

Split s into words. Map pattern letters to words and words to letters, checking both directions stay consistent.

Python solution (try first)

def word_pattern(pattern, s):
    words = s.split()
    if len(words) != len(pattern):
        return False
    p2w, w2p = {}, {}
    for p, w in zip(pattern, words):
        if p2w.setdefault(p, w) != w or w2p.setdefault(w, p) != p:
            return False
    return True

Complexity: Time O(n); Space O(k).

  • Same word for different letters

Group Anagrams

Medium Hash map with canonical key LC 49 must-do

Group words that are anagrams of each other. For deterministic output, sort each group alphabetically and then sort the groups.

This is a well-known public interview classic (LeetCode-style problem #49, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptHash map with canonical key (Hashing)
Input formatA list of words.
Output formatA list of groups.
Constraintslen <= 10^4

Sample input

["eat","tea","tan","ate","nat","bat"]

Sample output

[["ate","eat","tea"],["bat"],["nat","tan"]]

Explanation: Words with the same sorted letters share a key.

Stuck? Reveal hints one at a time

Hint 1

sorted("eat") gives a list; join it into a string so it can be a dict key.

Recommended approach (spoiler)

The key "sorted letters of the word" is identical for all anagrams. Use a dict key -> list of words.

Python solution (try first)

from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:
        groups["".join(sorted(w))].append(w)   # canonical key
    return sorted(sorted(g) for g in groups.values())

Complexity: Time O(n * k log k) for k = word length; Space O(n * k).

Edge cases to test

  • Empty list
  • Single word
  • Empty string as a word

Valid Sudoku

Medium Hash sets LC 36

A partially filled 9 x 9 board uses digits 1-9 and ".". Return True if no digit repeats in a row, a column or a 3 x 3 box.

This is a well-known public interview classic (LeetCode-style problem #36). The guide does not claim any company asked it.

Why interviewers ask this: Checks careful use of sets for rows, columns and boxes.

FieldDetail
DSA conceptHash sets (Hashing)
Input formatList of 9 strings.
Output formatTrue or False.
Constraintsboard is 9 x 9

Sample input

a valid partial board

Sample output

True

Explanation: Only filled cells are checked.

Stuck? Reveal hints one at a time

Hint 1

Use (r // 3, c // 3) as the box key.

Recommended approach (spoiler)

Keep a set for every row, column and box. The box of cell (r, c) is (r // 3, c // 3). If a digit is already in any of its three sets the board is invalid.

Python solution (try first)

def valid_sudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = {}
    for r in range(9):
        for c in range(9):
            d = board[r][c]
            if d == ".":
                continue
            box = boxes.setdefault((r // 3, c // 3), set())
            if d in rows[r] or d in cols[c] or d in box:
                return False
            rows[r].add(d); cols[c].add(d); box.add(d)
    return True

Complexity: Time O(81) = O(1); Space O(81).

Edge cases to test

  • Duplicate in a box only
  • Empty board

4Sum II

Medium Hash map of pair sums LC 454

Given four lists of equal length, count tuples (i, j, k, l) with a[i] + b[j] + c[k] + d[l] = 0.

This is a well-known public interview classic (LeetCode-style problem #454). The guide does not claim any company asked it.

Why interviewers ask this: Teaches the meet-in-the-middle trick: split four lists into two pairs.

FieldDetail
DSA conceptHash map of pair sums (Hashing)
Input formatFour lists.
Output formatInteger.
Constraintslen <= 200

Sample input

[1,2],[-2,-1],[-1,2],[0,2]

Sample output

2

Explanation: Two index combinations sum to zero.

Stuck? Reveal hints one at a time

Hint 1

Split the four lists into two groups.

Recommended approach (spoiler)

Store every a + b sum with its count. For every c + d look up the negative in the map. O(n^2) instead of O(n^4).

Python solution (try first)

from collections import Counter

def four_sum_count(a, b, c, d):
    ab = Counter(x + y for x in a for y in b)
    return sum(ab[-(x + y)] for x in c for y in d)

Complexity: Time O(n^2); Space O(n^2).

Insert Delete GetRandom O(1)

Medium Design: list + hash map LC 380

Design a set with insert(val), remove(val) and get_random() all in average O(1).

This is a well-known public interview classic (LeetCode-style problem #380). The guide does not claim any company asked it.

Why interviewers ask this: A design question: combine a list and a dictionary to get O(1) insert, delete and random pick.

FieldDetail
DSA conceptDesign: list + hash map (Hashing)
Input formatSequence of operations.
Output formatResults.
Constraintsops <= 2*10^5

Sample input

insert(1), insert(1), remove(2), insert(2), remove(1), insert(2)

Sample output

[True, False, False, True, True, False]

Explanation: Duplicates and missing values return False.

Stuck? Reveal hints one at a time

Hint 1

Swap with the last element to delete in O(1).

Recommended approach (spoiler)

Keep values in a list and a dict from value to list index. To delete, swap the target with the last element, pop, and fix the moved element's index.

Python solution (try first)

import random

class RandomizedSet:
    def __init__(self):
        self.items, self.pos = [], {}

    def insert(self, val):
        if val in self.pos:
            return False
        self.pos[val] = len(self.items)
        self.items.append(val)
        return True

    def remove(self, val):
        if val not in self.pos:
            return False
        i, last = self.pos[val], self.items[-1]
        self.items[i], self.pos[last] = last, i    # move the last item into the hole
        self.items.pop()
        del self.pos[val]
        return True

    def get_random(self):
        return random.choice(self.items)

Complexity: Each operation O(1) average; Space O(n).

Edge cases to test

  • Remove the last element
  • Empty set

Python solution (try first)

def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for x in s:
        if x - 1 not in s:          # x starts a run
            y = x
            while y + 1 in s:
                y += 1
            best = max(best, y - x + 1)
    return best

Complexity: Time O(n); Space O(n).

Subarrays with Sum K

Hard Prefix sum + hash map LC 560

Count the contiguous subarrays whose sum equals k. Values may be negative.

This is a well-known public interview classic (LeetCode-style problem #560). The guide does not claim any company asked it.

FieldDetail
DSA conceptPrefix sum + hash map (Hashing)
Input formatList nums and integer k.
Output formatInteger count.
Constraintslen <= 2*10^4

Sample input

nums=[1,2,3], k=3

Sample output

2

Explanation: Subarrays [1,2] and [3].

Stuck? Reveal hints one at a time

Hint 1

sum(i..j) = prefix[j] - prefix[i-1].

Hint 2

Initialise counts with {0: 1} for subarrays starting at index 0.

Recommended approach (spoiler)

Sliding window fails with negatives. Let prefix be the running sum. A subarray ending here has sum k if (prefix - k) appeared earlier as a prefix. Store counts of prefixes in a dict (start with {0: 1}).

Python solution (try first)

def subarray_sum_k(nums, k):
    counts = {0: 1}          # prefix sum -> times seen
    prefix = total = 0
    for x in nums:
        prefix += x
        total += counts.get(prefix - k, 0)
        counts[prefix] = counts.get(prefix, 0) + 1
    return total

Complexity: Time O(n); Space O(n).

Edge cases to test

  • Negative numbers
  • k = 0 with zeros in the list
  • Whole array equals k
