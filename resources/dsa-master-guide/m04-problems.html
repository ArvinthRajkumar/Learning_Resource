def count_vowels(s):
    vowels = set("aeiou")
    count = 0
    for ch in s.lower():

    return count

Valid Palindrome (ignore punctuation)

Easy Strings, two pointers LC 125 must-do

Return True if the string is a palindrome after keeping only letters/digits and ignoring case.

This is a well-known public interview classic (LeetCode-style problem #125, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Python solution (try first)

def valid_palindrome(s):
    lo, hi = 0, len(s) - 1
    while lo < hi:
        if not s[lo].isalnum():
            lo += 1
        elif not s[hi].isalnum():
            hi -= 1
        elif s[lo].lower() != s[hi].lower():
            return False
        else:
            lo += 1
            hi -= 1
    return True

Complexity: Time O(n); Space O(1).

  • Empty string / only punctuation -> True
  • Mixed case
  • Digits

Return True if t is a rearrangement of the letters of s.

This is a well-known public interview classic (LeetCode-style problem #242, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Hint 1

Different lengths can never be anagrams.

Hint 2

collections.Counter compares with ==.

Recommended approach (spoiler)

Sorting both strings is O(n log n). Counting characters with Counter is O(n): equal frequency maps means anagram.

from collections import Counter

def is_anagram(s, t):
    if len(s) != len(t):
        return False
    return Counter(s) == Counter(t)

from collections import Counter

def first_unique_char(s):
    freq = Counter(s)
    for i, ch in enumerate(s):

            return i
    return -1

Python solution (try first)

def compress_string(s):
    if not s:
        return ""
    out = []
    count = 1
    for i in range(1, len(s)):
        if s[i] == s[i - 1]:
            count += 1
        else:
            out.append(s[i - 1] + str(count))
            count = 1
    out.append(s[-1] + str(count))   # last run
    return "".join(out)

Complexity: Time O(n); Space O(n).

  • No repeated characters
  • Whole string is one run

def longest_common_prefix(strs):
    prefix = strs[0]
    for word in strs[1:]:
        while not word.startswith(prefix):
            prefix = prefix[:-1]
            if not prefix:
                return ""
    return prefix

Complexity: Time O(total characters); Space O(1).

Valid Palindrome II

Easy Two pointers LC 680

Return True if the string can become a palindrome after deleting at most one character.

This is a well-known public interview classic (LeetCode-style problem #680). The guide does not claim any company asked it.

Why interviewers ask this: Two pointers with one allowed mistake; tests whether you can branch only once.

FieldDetail
DSA conceptTwo pointers (Strings)
Input formatString s.
Output formatTrue or False.
Constraintslen <= 10^5

Sample input

"abca"

Sample output

True

Explanation: Delete c to get "aba".

Stuck? Reveal hints one at a time

Hint 1

Only one mismatch may be skipped.

Recommended approach (spoiler)

Move inward while characters match. At the first mismatch try skipping the left or the right character and check the rest is a palindrome.

Python solution (try first)

def valid_palindrome_ii(s):
    def ok(lo, hi):
        while lo < hi:
            if s[lo] != s[hi]:
                return False
            lo += 1
            hi -= 1
        return True
    lo, hi = 0, len(s) - 1
    while lo < hi:
        if s[lo] != s[hi]:
            return ok(lo + 1, hi) or ok(lo, hi - 1)
        lo += 1
        hi -= 1
    return True

Complexity: Time O(n); Space O(1).

Edge cases to test

  • Already a palindrome
  • Two characters

Python solution (try first)

def add_binary(a, b):
    i, j, carry, out = len(a) - 1, len(b) - 1, 0, []
    while i >= 0 or j >= 0 or carry:
        total = carry
        if i >= 0:
            total += int(a[i]); i -= 1
        if j >= 0:
            total += int(b[j]); j -= 1
        out.append(str(total % 2))
        carry = total // 2
    return "".join(reversed(out))

Complexity: Time O(max(n, m)); Space O(max(n, m)).

  • Final carry

Roman to Integer

Easy Hash map + one pass LC 13

Convert a Roman numeral to an integer.

This is a well-known public interview classic (LeetCode-style problem #13). The guide does not claim any company asked it.

Why interviewers ask this: A classic easy mapping question: why subtract when a smaller symbol comes before a larger one?

FieldDetail
DSA conceptHash map + one pass (Strings)
Input formatString s.
Output formatInteger.
Constraintslen <= 15

Sample input

"MCMXCIV"

Sample output

1994

Explanation: M=1000, CM=900, XC=90, IV=4.

Stuck? Reveal hints one at a time

Hint 1

Compare each value with the next.

Recommended approach (spoiler)

If a symbol is smaller than the next one, subtract it; otherwise add it.

Python solution (try first)

def roman_to_int(s):
    val = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
    total = 0
    for i, ch in enumerate(s):
        if i + 1 < len(s) and val[ch] < val[s[i + 1]]:
            total -= val[ch]
        else:
            total += val[ch]
    return total

Complexity: Time O(n); Space O(1).

Greatest Common Divisor of Strings

Easy Strings + gcd LC 1071

Return the largest string x such that both s and t can be made by repeating x. Return "" if none.

This is a well-known public interview classic (LeetCode-style problem #1071). The guide does not claim any company asked it.

Why interviewers ask this: A string-meets-math puzzle: the answer relates to the gcd of the lengths.

FieldDetail

Input formatStrings s and t.
Output formatString.
Constraintslen <= 1000

Sample input

"ABCABC", "ABC"

Sample output

Explanation: ABC repeated twice and once.

Stuck? Reveal hints one at a time

Hint 1

Check commutative concatenation.

Recommended approach (spoiler)

If s + t != t + s no common divisor exists. Otherwise the answer is the prefix of length gcd(len(s), len(t)).

Python solution (try first)

from math import gcd

def gcd_of_strings(s, t):
    if s + t != t + s:
        return ""
    return s[:gcd(len(s), len(t))]

Complexity: Time O(n + m); Space O(n + m).

Find All Pattern Occurrences

Medium String matching (naive and KMP)

Return all starting indices where pattern appears in text (overlaps allowed).

FieldDetail
DSA conceptString matching (naive and KMP) (Strings)
Input formatStrings text and pat.
Output formatA list of indices.
Constraintslen(text) <= 10^5

Sample input

text="abababa", pat="aba"

Sample output

[0, 2, 4]

Explanation: Matches at 0, 2 and 4 (overlapping).

Stuck? Reveal hints one at a time

Hint 1

What do you do after a full match to allow overlaps?

Hint 2

lps[i] = length of longest proper prefix of pat[:i+1] that is also a suffix.

Recommended approach (spoiler)

Naive: try every start index and compare, worst case O(n*m). KMP precomputes the longest-prefix-suffix (lps) table so the text pointer never moves backwards: O(n + m).

Python solution (try first)

def find_all(text, pat):
    n, m = len(text), len(pat)
    if m == 0:
        return []
    lps = [0] * m                      # build the KMP failure table
    k = 0
    for i in range(1, m):
        while k > 0 and pat[i] != pat[k]:
            k = lps[k - 1]
        if pat[i] == pat[k]:
            k += 1
        lps[i] = k
    res, k = [], 0
    for i in range(n):                 # scan text, never move i backwards
        while k > 0 and text[i] != pat[k]:
            k = lps[k - 1]
        if text[i] == pat[k]:
            k += 1
        if k == m:
            res.append(i - m + 1)
            k = lps[k - 1]
    return res

Complexity: Time O(n + m); Space O(m).

Edge cases to test

  • Pattern longer than text
  • Overlapping matches
  • Empty pattern

Return the longest substring that is a palindrome (any one if there is a tie, here the leftmost).

This is a well-known public interview classic (LeetCode-style problem #5, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptExpand around the centre (Strings)
Input formatString s.
Output formatString.
Constraintslen <= 1000

Sample input

"babad"

Sample output

"bab"

Explanation: "bab" and "aba" both work; we return the first found.

Stuck? Reveal hints one at a time

Hint 1

There are 2n - 1 centres.

Recommended approach (spoiler)

Every palindrome grows outward from its centre. Try each position as a centre (odd length) and each gap between letters (even length), expand while both ends match, and keep the longest.

Python solution (try first)

def longest_palindrome_substring(s):
    best = ""
    def expand(lo, hi):
        while lo >= 0 and hi < len(s) and s[lo] == s[hi]:
            lo -= 1
            hi += 1
        return s[lo + 1:hi]            # last valid palindrome
    for i in range(len(s)):
        for cand in (expand(i, i), expand(i, i + 1)):   # odd and even centres
            if len(cand) > len(best):
                best = cand
    return best

Complexity: Time O(n^2); Space O(1) extra.

  • All same letters
  • No repeated letters

Find All Anagrams in a String

Return all start indices of substrings of s that are anagrams of p.

This is a well-known public interview classic (LeetCode-style problem #438). The guide does not claim any company asked it.

Why interviewers ask this: Fixed window with letter counts: a standard follow-up to permutation-in-string.

FieldDetail
DSA conceptFixed sliding window + counters (Strings)
Input formatStrings s and p.
Output formatList of indices.
Constraintslen <= 3*10^4

Sample input

s="cbaebabacd", p="abc"

Sample output

Explanation: "cba" at 0 and "bac" at 6.

Stuck? Reveal hints one at a time

Hint 1

Update by adding the new letter and removing the old.

Recommended approach (spoiler)

Slide a window of length len(p) and keep its letter counts; record the start whenever the counts equal those of p.

Python solution (try first)

from collections import Counter

def find_all_anagrams(s, p):
    k = len(p)
    need = Counter(p)
    window = Counter(s[:k - 1])
    res = []
    for i in range(k - 1, len(s)):
        window[s[i]] += 1
        if window == need:
            res.append(i - k + 1)
        out = s[i - k + 1]
        window[out] -= 1
        if window[out] == 0:
            del window[out]
    return res

Complexity: Time O(n * alphabet); Space O(alphabet).

This is a well-known public interview classic (LeetCode-style problem #424, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Constraintslen <= 10^5

Sample input

Sample output

Explanation: Change one B to A to get "AAAA".

Stuck? Reveal hints one at a time

Hint 1

Track the maximum frequency inside the window.

Recommended approach (spoiler)

A window is valid if (length - count of its most frequent letter) <= k. Expand right; shrink left when invalid.

Python solution (try first)

from collections import defaultdict

def longest_repeating_replace(s, k):
    count = defaultdict(int)
    left = best = most = 0
    for right, ch in enumerate(s):
        count[ch] += 1
        most = max(most, count[ch])
        while (right - left + 1) - most > k:
            count[s[left]] -= 1
            left += 1
        best = max(best, right - left + 1)
    return best

Complexity: Time O(n); Space O(alphabet).

Hint 1

Recommended approach (spoiler)

Digit i of a times digit j of b lands at positions i + j and i + j + 1 of the result. Accumulate into an array and propagate carries.

Python solution (try first)

def multiply_strings(a, b):
    if a == "0" or b == "0":
        return "0"
    res = [0] * (len(a) + len(b))
    for i in range(len(a) - 1, -1, -1):
        for j in range(len(b) - 1, -1, -1):
            total = int(a[i]) * int(b[j]) + res[i + j + 1]
            res[i + j + 1] = total % 10
            res[i + j] += total // 10
    return "".join(map(str, res)).lstrip("0")

Python solution (try first)

def palindromic_substrings(s):
    count = 0
    for centre in range(2 * len(s) - 1):
        lo = centre // 2
        hi = lo + centre % 2
        while lo >= 0 and hi < len(s) and s[lo] == s[hi]:
            count += 1
            lo -= 1
            hi += 1
    return count

Minimum Window Substring

Hard Variable sliding window + counters LC 76 must-do

Return the smallest substring of s that contains every character of t (with multiplicity), or "".

This is a well-known public interview classic (LeetCode-style problem #76, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Why interviewers ask this: The hardest common sliding-window question: expand until valid, then shrink while still valid.

FieldDetail
DSA conceptVariable sliding window + counters (Strings)
Input formatStrings s and t.
Output formatString.
Constraintslen <= 10^5

Sample input

s="ADOBECODEBANC", t="ABC"

Sample output

"BANC"

Explanation: BANC is the shortest window containing A, B and C.

Stuck? Reveal hints one at a time

Hint 1

Track how many distinct letters are fully satisfied.

Recommended approach (spoiler)

Count what is needed. Expand right; when every needed letter is covered, shrink from the left while still covered, recording the smallest window.

Python solution (try first)

from collections import Counter

def min_window(s, t):
    need = Counter(t)
    missing = len(need)
    left = 0
    best = (float("inf"), 0, 0)
    for right, ch in enumerate(s):
        if ch in need:
            need[ch] -= 1
            if need[ch] == 0:
                missing -= 1
        while missing == 0:                      # window is valid: shrink
            if right - left + 1 < best[0]:
                best = (right - left + 1, left, right)
            out = s[left]
            if out in need:
                need[out] += 1
                if need[out] > 0:
                    missing += 1
            left += 1
    return "" if best[0] == float("inf") else s[best[1]:best[2] + 1]

Complexity: Time O(n + m); Space O(m).

Edge cases to test

  • t longer than s
  • Repeated letters in t
