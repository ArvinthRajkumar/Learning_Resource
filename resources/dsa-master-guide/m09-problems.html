Reverse a Linked List

Easy Linked list pointers LC 206 must-do

Reverse a singly linked list and return the new head.

This is a well-known public interview classic (LeetCode-style problem #206, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail

Input formatHead of a list.
Output formatHead of the reversed list.
Constraints0 <= length <= 5000

Sample input

Sample output

Explanation: Every arrow flips direction.

Stuck? Reveal hints one at a time

Hint 1

Save the next node BEFORE overwriting cur.next.

Hint 2

Recommended approach (spoiler)

Walk through the list with three names: prev, cur, nxt. Save cur.next, point cur backwards to prev, then step forward.

Python solution (try first)

def reverse_list(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next      # remember the rest
        cur.next = prev     # flip the arrow
        prev = cur          # advance both pointers
        cur = nxt
    return prev
Helper code used by this problem (ListNode, TreeNode and builders)
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
    def __repr__(self):
        return "Node(%r)" % (self.val,)

def build(values, cycle_pos=-1):
    """Build a linked list from a Python list (cycle_pos links the tail back to that index)."""
    dummy = ListNode()
    cur, nodes = dummy, []
    for v in values:
        cur.next = ListNode(v)
        cur = cur.next
        nodes.append(cur)
    if 0 <= cycle_pos < len(nodes):
        cur.next = nodes[cycle_pos]
    return dummy.next

def to_list(head):
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out

Complexity: Time O(n); Space O(1).

Merge Two Sorted Linked Lists

Easy Linked list, dummy node LC 21 must-do

Merge two sorted linked lists into one sorted list.

This is a well-known public interview classic (LeetCode-style problem #21, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail
DSA conceptLinked list, dummy node (Linked Lists)
Input formatHeads of two sorted lists.
Output formatHead of merged list.
Constraintslength <= 50 each

Sample input

1->2->4 and 1->3->4

Sample output

1->1->2->3->4->4

Explanation: Always attach the smaller head.

Stuck? Reveal hints one at a time

Hint 1

A dummy node returns dummy.next at the end.

Recommended approach (spoiler)

Use a dummy node to avoid special-casing the head. Compare the two current nodes, attach the smaller one to the tail, advance. Attach the leftover.

Python solution (try first)

def merge_two_lists(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b          # attach what is left
    return dummy.next

Remove Duplicates from a Sorted List

Easy Linked list pointers LC 83

The list is sorted. Delete nodes so each value appears once.

This is a well-known public interview classic (LeetCode-style problem #83). The guide does not claim any company asked it.

FieldDetail

Output formatHead.
Constraintslength <= 300

1->1->2->3->3

Stuck? Reveal hints one at a time

Hint 1

Do not move cur while you are still deleting.

Recommended approach (spoiler)

Walk with cur. While cur.next has the same value, skip it by pointing cur.next to cur.next.next; otherwise move forward.

Python solution (try first)

def delete_duplicates_list(head):
    cur = head
    while cur and cur.next:
        if cur.val == cur.next.val:
            cur.next = cur.next.next      # unlink the duplicate
        else:
            cur = cur.next
    return head

Detect a Cycle (Floyd)

Medium Floyd's tortoise and hare LC 141 must-do

Return True if the linked list has a cycle.

This is a well-known public interview classic (LeetCode-style problem #141, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

Hint 1

If a loop exists, the fast pointer gains one step per round on the slow one.

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:         # same node object
            return True
    return False

def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)
    slow = fast = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:
        slow = slow.next
        fast = fast.next
    slow.next = slow.next.next      # unlink the target
    return dummy.next

Palindrome Linked List

Medium Slow/fast pointers + reversal LC 234

Return True if the linked list reads the same forward and backward.

This is a well-known public interview classic (LeetCode-style problem #234). The guide does not claim any company asked it.

FieldDetail
DSA conceptSlow/fast pointers + reversal (Linked Lists)
Input formatHead of a list.
Output formatTrue or False.
Constraintslength <= 10^5

Sample input

1->2->2->1

Sample output

True

Explanation: Reads 1 2 2 1 both ways.

Stuck? Reveal hints one at a time

Hint 1

Combine two earlier techniques.

Recommended approach (spoiler)

Find the middle with slow/fast, reverse the second half, then compare both halves node by node.

Python solution (try first)

def is_palindrome_list(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    prev = None
    while slow:                       # reverse the second half
        slow.next, prev, slow = prev, slow, slow.next
    left, right = head, prev
    while right:
        if left.val != right.val:
            return False
        left, right = left.next, right.next
    return True

def add_two_numbers(a, b):
    dummy = tail = ListNode()
    carry = 0
    while a or b or carry:
        total = carry + (a.val if a else 0) + (b.val if b else 0)
        carry, digit = divmod(total, 10)
        tail.next = ListNode(digit)
        tail = tail.next
        a = a.next if a else None
        b = b.next if b else None
    return dummy.next

Reorder List

Medium Linked list: middle + reverse + merge LC 143 must-do

Reorder L0 -> L1 -> ... -> Ln into L0 -> Ln -> L1 -> Ln-1 -> ... in place.

This is a well-known public interview classic (LeetCode-style problem #143, also on widely shared must-practise lists such as Blind 75). The guide does not claim any company asked it.

FieldDetail

def reorder_list(head):
    if not head or not head.next:
        return
    slow = fast = head
    while fast.next and fast.next.next:
        slow, fast = slow.next, fast.next.next
    prev, cur = None, slow.next
    slow.next = None                       # split into two lists
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    first, second = head, prev
    while second:
        n1, n2 = first.next, second.next
        first.next, second.next = second, n1
        first, second = n1, n2

def sort_list(head):
    if not head or not head.next:
        return head
    slow, fast = head, head.next
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    mid, slow.next = slow.next, None
    a, b = sort_list(head), sort_list(mid)
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next

def rotate_list(head, k):
    if not head or not head.next or k == 0:
        return head
    n, tail = 1, head
    while tail.next:
        tail = tail.next
        n += 1
    k %= n
    if k == 0:
        return head
    tail.next = head                      # make a ring
    new_tail = head
    for _ in range(n - k - 1):
        new_tail = new_tail.next
    new_head, new_tail.next = new_tail.next, None
    return new_head

Hint 1

Phase 1: detect. Phase 2: reset one pointer to head.

Recommended approach (spoiler)

After slow and fast meet, restart one pointer from the head. Move both one step at a time; they meet exactly at the cycle start. (Distance head->start equals distance meeting point->start, going around.)

Python solution (try first)

def cycle_start(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            slow = head                 # phase 2
            while slow is not fast:
                slow, fast = slow.next, fast.next
            return slow.val
    return None

Reverse Nodes in k-Group

Hard Linked list reversal in blocks LC 25

Reverse the nodes of the list k at a time. If fewer than k nodes remain at the end, leave them as they are.

This is a well-known public interview classic (LeetCode-style problem #25). The guide does not claim any company asked it.

Why interviewers ask this: A hard pointer problem made of a repeated reversal; checks careful reconnection.

FieldDetail
DSA conceptLinked list reversal in blocks (Linked Lists)
Input formatHead and k.
Output formatHead.
Constraintslength <= 5000

Sample input

1->2->3->4->5, k=2

Sample output

2->1->4->3->5

Explanation: The last single node stays.

Stuck? Reveal hints one at a time

Hint 1

Count k nodes ahead before reversing.

Recommended approach (spoiler)

Check that k nodes remain; reverse that block with the prev/cur loop; reconnect the previous block to the new head and the block tail to the rest.

Python solution (try first)

def reverse_k_group(head, k):
    dummy = ListNode(0, head)
    group_prev = dummy
    while True:
        kth = group_prev
        for _ in range(k):
            kth = kth.next
            if not kth:
                return dummy.next          # fewer than k nodes left
        group_next = kth.next
        prev, cur = group_next, group_prev.next
        while cur is not group_next:       # reverse this block
            cur.next, prev, cur = prev, cur, cur.next
        tail = group_prev.next
        group_prev.next = kth
        group_prev = tail
