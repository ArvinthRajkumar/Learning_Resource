Count Bubble Sort Swaps

Easy Bubble sort

Run bubble sort on the list and return how many swaps were performed.

FieldDetail
DSA conceptBubble sort (Sorting Algorithms)
Input formatA list of integers.
Output formatInteger.
Constraintslen <= 1000

Sample input

[3, 2, 1]

Sample output

3

Explanation: (3,2) swap, (3,1) swap, then (2,1) swap = 3 swaps.

Stuck? Reveal hints one at a time

Hint 1

Only swap when left > right (strictly) to keep it stable.

Recommended approach (spoiler)

Implement bubble sort literally and add a counter. The swap count equals the number of inversions.

Python solution (try first)

def bubble_swaps(nums):
    nums = nums[:]
    swaps = 0
    n = len(nums)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
                swaps += 1
                swapped = True
        if not swapped:        # already sorted - stop early
            break
    return swaps

Complexity: Time O(n^2) worst, O(n) best (already sorted, with early exit); Space O(1) extra.

Edge cases to test

  • Already sorted -> 0
  • Reverse sorted -> n(n-1)/2

Implement Insertion Sort

Easy Sorting by hand

Sort the list using insertion sort and return it.

DSA conceptSorting by hand (Sorting Algorithms)
Input formatList nums.

Python solution (try first)

def insertion_sort_impl(nums):
    for i in range(1, len(nums)):
        key, j = nums[i], i - 1
        while j >= 0 and nums[j] > key:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = key
    return nums

Complexity: Time O(n^2), O(n) if nearly sorted; Space O(1).

Edge cases to test

  • Duplicates

Sort Words by Length then Alphabet

Easy Sorting with key

Sort words by length (shortest first). Words of equal length are sorted alphabetically.

FieldDetail

Output formatSorted list.
Constraintslen <= 10^4

Sample input

["pear","fig","apple","kiwi"]

Sample output

["fig","kiwi","pear","apple"]

Explanation: Length 3, then the two length-4 words alphabetically, then length 5.

Stuck? Reveal hints one at a time

Hint 1

Tuples sort item by item.

def sort_by_length(words):

Sort 0s, 1s and 2s (Dutch National Flag)

Medium Sorting, three pointers LC 75

The list contains only 0, 1 and 2. Sort it in place in one pass without calling sort().

This is a well-known public interview classic (LeetCode-style problem #75). The guide does not claim any company asked it.

FieldDetail
DSA conceptSorting, three pointers (Sorting Algorithms)
Input formatA list.
Output formatThe sorted list.
Constraintslen <= 10^5

Sample input

[2,0,2,1,1,0]

Sample output

[0,0,1,1,2,2]

Explanation: All 0s first, then 1s, then 2s.

Stuck? Reveal hints one at a time

Hint 1

After swapping with hi, do NOT advance mid - the swapped-in value is unchecked.

Recommended approach (spoiler)

Keep three zones with pointers lo (next slot for 0), mid (scanner), hi (next slot for 2 from the right). Swap 0s to the front, 2s to the back, skip 1s.

Python solution (try first)

def sort_colors(nums):
    lo, mid, hi = 0, 0, len(nums) - 1
    while mid <= hi:
        if nums[mid] == 0:
            nums[lo], nums[mid] = nums[mid], nums[lo]
            lo += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[hi] = nums[hi], nums[mid]
            hi -= 1
    return nums

Complexity: Time O(n); Space O(1).

  • Already sorted
  • Empty list

Sort by Frequency

Medium Sorting with a key, hashing

Sort numbers by decreasing frequency; break ties by smaller value first.

FieldDetail
DSA conceptSorting with a key, hashing (Sorting Algorithms)
Input formatA list of integers.
Output formatThe sorted list.
Constraintslen <= 10^5

Sample input

[2,3,1,3,2]

Sample output

[2,2,3,3,1]

Explanation: 2 and 3 both appear twice (2 first as it is smaller), 1 appears once.

Stuck? Reveal hints one at a time

Hint 1

Negate the frequency to sort descending.

Recommended approach (spoiler)

Count with Counter, then sort with key=lambda x: (-freq[x], x). A tuple key sorts by the first item, then the second.

Python solution (try first)

from collections import Counter

def sort_by_frequency(nums):
    freq = Counter(nums)
    return sorted(nums, key=lambda x: (-freq[x], x))

Complexity: Time O(n log n); Space O(n).

Edge cases to test

  • All same

Implement Merge Sort

Medium Divide and conquer

Sort a list with merge sort (no calling sort()).

FieldDetail
DSA conceptDivide and conquer (Sorting Algorithms)
Input formatList nums.
Output formatSorted list.
Constraintslen <= 10^5

Sample input

[5,1,4,2,3]

Sample output

[1,2,3,4,5]

Explanation: Split, sort halves, merge.

Stuck? Reveal hints one at a time

Hint 1

Base case: a list of length 0 or 1 is already sorted.

Recommended approach (spoiler)

Split in the middle, sort each half recursively, then merge the two sorted halves with two pointers.

Python solution (try first)

def merge_sort_impl(nums):
    if len(nums) <= 1:
        return nums
    mid = len(nums) // 2
    left, right = merge_sort_impl(nums[:mid]), merge_sort_impl(nums[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]

Complexity: Time O(n log n); Space O(n).

Edge cases to test

  • Single element
  • Duplicates

Count Inversions

Hard Merge sort application

An inversion is a pair i < j with nums[i] > nums[j]. Count them in O(n log n).

FieldDetail
DSA conceptMerge sort application (Sorting Algorithms)
Input formatA list of integers.
Output formatInteger.
Constraintslen <= 10^5

Sample input

[2,4,1,3,5]

Sample output

3

Explanation: Pairs: (2,1), (4,1), (4,3).

Stuck? Reveal hints one at a time

Hint 1

Modify the merge step, not the divide step.

Hint 2

Left elements remaining = len(left) - i.

Recommended approach (spoiler)

Brute force is O(n^2). During merge sort, when you take an element from the RIGHT half while the left half still has k elements left, all k of them are greater, so add k inversions.

Python solution (try first)

def count_inversions(nums):
    def sort(a):
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        left, x = sort(a[:mid])
        right, y = sort(a[mid:])
        merged, i, j, cross = [], 0, 0, 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i]); i += 1
            else:
                merged.append(right[j]); j += 1
                cross += len(left) - i     # every remaining left item is bigger
        merged += left[i:] + right[j:]
        return merged, x + y + cross
    return sort(nums)[1]

Complexity: Time O(n log n); Space O(n).

Edge cases to test

  • Sorted list -> 0
  • Reverse sorted -> n(n-1)/2
  • Equal elements are not inversions

Arrange Numbers to Form the Largest Number

Hard Custom sort order

Arrange the non-negative integers so that joined together they form the largest possible number. Return it as a string.

FieldDetail
DSA conceptCustom sort order (Sorting Algorithms)
Input formatList nums.
Output formatString.
Constraintslen <= 100

Sample input

[3,30,34,5,9]

Sample output

"9534330"

Explanation: Putting 9, 5, 34, 3, 30 gives the biggest value.

Stuck? Reveal hints one at a time

Hint 1

Strings a+b vs b+a decide the order.

Recommended approach (spoiler)

Compare two numbers a, b by which of a+b or b+a (as strings) is larger. Python sorts with a custom comparison via functools.cmp_to_key.

Python solution (try first)

from functools import cmp_to_key

def largest_number(nums):
    strs = [str(x) for x in nums]
    strs.sort(key=cmp_to_key(lambda a, b: -1 if a + b > b + a else 1))
    result = "".join(strs)
    return "0" if result[0] == "0" else result   # all zeros

Complexity: Time O(n log n * L); Space O(n).

Edge cases to test

  • All zeros -> "0"
  • Single number
