How to use this guide

  • Read in order the first time. Each topic section runs: intuition, mechanism, example, traps, then quiz questions and a self-check.
  • Click Mark as done at the end of each section. The bars above and the parts menu update.
  • Quiz answers feed the weak-areas box. Retry with shuffle on later passes.
  • Every Python and SQL example shown with a result was executed when the guide was built, and the files live in solutions/. Run python3 resources/system-design-guide/solutions/test_snippets.py to check them yourself.
