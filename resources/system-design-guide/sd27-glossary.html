System design glossary: terms, acronyms and patterns

How this gets asked

What is an error budget?

  • Money for bug fixes No.
  • The permitted unreliability (1 - SLO) that can be spent on releases and experiments Correct.
  • A log level No.
  • A test suite No.

When the budget is spent, focus shifts to reliability work.

SLI, SLO, SLA?

The measurement, the internal target for it, and the contractual promise with consequences.

How this gets asked

Which statement describes the CAP theorem?

  • You can have all three always No.
  • Under a network partition a system must choose between consistency and availability Correct.
  • It only applies to SQL No.
  • It is about caching No.

Partitions are a fact of life, so the choice is C or A during them.

Self-check

Quorum rule for overlap?

R + W > N guarantees that reads and writes intersect.

What is a cache stampede?

  • Cache is empty at start Not exactly.

What does the outbox pattern guarantee?

  • Exactly-once delivery No.

Self-check

Queue versus log?

A queue deletes messages once consumed; a log retains an ordered stream that many consumers can replay.

How this gets asked

RTO is:

  • Maximum tolerable data loss That is RPO.
  • Maximum tolerable time to restore service Correct.
  • Request throughput No.

Self-check

Blue-green versus canary?

Blue-green switches all traffic between two full environments; canary sends a small share to the new version first.

Interview questions: Glossary and terminology

14 questions. Try to answer aloud in under a minute, then reveal. Tags show the level. All questions are also in the interview bank.

Basic Define latency and throughput.

Latency is the time for one request; throughput is the amount of work completed per unit time.

Basic SLI, SLO and SLA?

The measured indicator, the target set for it, and the contractual commitment with penalties.

Basic What is idempotency?

Repeating an operation has the same effect as doing it once, enabling safe retries.

Basic What is a CDN?

A network of edge caches near users that serves static and cacheable content with low latency.

Medium What is eventual consistency?

If no new updates are made, all replicas eventually converge to the same value.

Medium What is a quorum?

A majority or configured number of replicas that must respond; R + W > N makes reads and writes overlap.

Medium What is consistent hashing?

A hashing scheme on a ring where adding or removing a node moves only a small share of keys.

Medium What is a circuit breaker?

A guard that stops calling a failing dependency for a while, failing fast and letting it recover.

Medium What is backpressure?

A mechanism for slow consumers to tell producers to slow down instead of being overwhelmed.

Medium What is a cache stampede and how do you prevent it?

Many requests rebuild an expired hot entry at once. Use request coalescing or locks, jittered TTLs, and refresh-ahead.

Medium What is split brain?

Two nodes both act as leader after a partition, risking conflicting writes. Prevent with quorum-based election and fencing.

Advanced Differentiate CAP and PACELC.

CAP covers behaviour during partitions (consistency or availability); PACELC adds that without partitions there is still a trade-off between latency and consistency.

Advanced What is a CRDT?

A data type whose concurrent updates merge deterministically without coordination, such as counters, sets and registers.

Advanced What is a service mesh?

A layer of sidecar proxies that provide mTLS, retries, routing and telemetry for service-to-service calls without changing application code.
