Python basics (10)

Basic What is the difference between a list and a tuple?

Lists are mutable and tuples are immutable. Tuples can be dictionary keys and are good for fixed records; lists suit collections that change.

Basic What are Python's main built-in types?

int, float, bool, str, None, list, tuple, dict, set, plus bytes and complex. Everything is an object.

Basic What does it mean that Python is dynamically typed?

Names are not bound to types; the type belongs to the object and is checked at runtime. Type hints can add optional static checking.

Basic What is the difference between == and is?

== compares values; is compares object identity (same object). Use is only for None, True and False.

Medium Explain the mutable default argument problem.

Default values are evaluated once when the function is defined, so a list or dict default is shared across calls. Use None and create the object inside the function.

Medium Explain LEGB scope.

Names resolve in Local, Enclosing function, Global, then Built-in scope. Assignment creates a local unless declared global or nonlocal.

Medium What are *args and **kwargs?

*args collects extra positional arguments into a tuple and **kwargs collects extra keyword arguments into a dict; at call sites * and ** unpack sequences and mappings.

Medium Why does 0.1 + 0.2 != 0.3?

Binary floating point cannot represent these decimals exactly. Compare with math.isclose or use Decimal for money.

Advanced How does Python pass arguments: by value or by reference?

By object reference (pass by assignment): the parameter name is bound to the same object. Mutating a mutable argument is visible to the caller; rebinding the name is not.

Advanced What is the difference between a shallow and a deep copy?

A shallow copy creates a new container holding references to the same inner objects; a deep copy recursively copies everything. Use copy.deepcopy when inner objects are mutable and must be independent.

Python data (10)

Basic How do you remove duplicates from a list while keeping order?

list(dict.fromkeys(items)). A set removes duplicates but loses order.

Basic What is a list comprehension and a generator expression?

A list comprehension builds a whole list in one expression. A generator expression uses parentheses and yields items lazily, using little memory.

Basic How do you read a file safely?

Use with open(path, encoding='utf-8') as f so the file is closed even on errors, and iterate over lines for large files.

Medium What can be a dictionary key?

Any hashable object: immutable types such as str, int, tuples of hashables and frozensets. Lists and dicts cannot be keys.

Medium How does a dict work and what is its complexity?

A hash table: lookup, insert and delete are O(1) on average. Insertion order is preserved since Python 3.7.

Medium What is the time complexity of common list operations?

Index and append O(1); insert or delete in the middle, pop(0), membership test O(n); sort O(n log n).

Medium How do you count items and group items?

collections.Counter for counts and collections.defaultdict(list) for grouping; itertools.groupby for consecutive groups after sorting.

Advanced Why is sorting stable, and why does that matter?

Equal elements keep their original order, so you can sort by several keys in passes or use a tuple key. Timsort guarantees stability.

Advanced What is the bug in [[0] * 3] * 3?

It repeats a reference to one inner list, so changing one row changes all. Use [[0] * 3 for _ in range(3)].

Advanced Regular expressions: greedy versus non-greedy?

Quantifiers like * and + match as much as possible (greedy); adding ? makes them match as little as possible. Use raw strings and compile patterns reused often.

Python OOP (10)

Basic What is self?

The instance the method is called on, passed automatically as the first argument.

Basic Class attribute versus instance attribute?

Class attributes are shared by all instances; instance attributes belong to one object. Assigning through an instance creates an instance attribute that shadows the class one.

Medium Explain @staticmethod, @classmethod and instance methods.

Instance methods receive self, classmethods receive the class (alternative constructors), staticmethods receive neither and are just namespaced functions.

Medium What are dunder methods? Give examples.

Special methods that integrate classes with the language: __init__, __repr__, __eq__, __hash__, __len__, __iter__, __enter__ and __exit__, __call__.

Medium What does @dataclass give you?

Generated __init__, __repr__ and __eq__ from annotated fields, plus options for ordering, immutability (frozen) and slots. Use field(default_factory=...) for mutable defaults.

Medium What is duck typing?

Behaviour matters, not declared type: an object works if it has the needed methods. Protocols describe such interfaces for type checkers.

Advanced Explain the method resolution order and super().

The MRO is the C3 linearisation: children before parents, parents in the declared order. super() delegates to the next class in the instance's MRO, which makes cooperative multiple inheritance work.

Advanced Composition or inheritance?

Prefer composition (has-a) for flexibility and loose coupling. Use inheritance for genuine is-a relationships and shared behaviour, and keep hierarchies shallow, using mixins sparingly.

Advanced Do type hints enforce types?

No. They are annotations checked by tools such as mypy and pyright, and used by libraries like pydantic or dataclasses, but the interpreter does not enforce them.

Advanced What does __hash__ need when you define __eq__?

Equal objects must have equal hashes. Defining __eq__ alone sets __hash__ to None, making the class unhashable; define both for set and dict use, based on immutable fields.

Python advanced (11)

Basic What is a generator and why use one?

A function with yield that returns a lazy iterator. It produces values on demand, saving memory and enabling pipelines and infinite sequences.

Basic What is a decorator?

A callable that takes a function and returns a replacement, usually adding behaviour. @dec above def f means f = dec(f). Use functools.wraps to keep metadata.

Medium Explain context managers.

Objects defining __enter__ and __exit__ (or built with contextlib.contextmanager) used with the with statement to guarantee setup and cleanup, even when exceptions occur.

Medium What is a closure and what is late binding?

A closure captures variables from its enclosing scope. Late binding means the variable is looked up when the function runs, so lambdas in a loop all see the final value unless bound with a default argument.

Medium Iterable versus iterator?

An iterable has __iter__ returning an iterator. An iterator has __next__ and is exhausted after one pass. Lists are iterables; generators are iterators.

Medium What does yield from do?

It delegates to a sub-generator, passing values through, and returns the sub-generator's result. It simplifies recursive generators.

Advanced Explain the GIL.

A lock in CPython allowing only one thread to execute Python bytecode at a time. CPU-bound threads do not run in parallel; I/O-bound threads still overlap. Use multiprocessing or native extensions for CPU parallelism.

Advanced How does Python manage memory?

Reference counting frees objects when counts drop to zero, and a cyclic garbage collector handles reference cycles. Weak references avoid keeping objects alive.

Advanced What are descriptors?

Objects with __get__, __set__ or __delete__ defined on a class that control attribute access. Properties, methods, classmethods and staticmethods are implemented with descriptors.

Advanced When would you use a metaclass?

Rarely: to customise class creation (registries, validation, ORMs). Prefer class decorators or __init_subclass__ when they are enough.

Advanced What is the difference between __new__ and __init__?

__new__ creates the instance (a static method returning it) and __init__ initialises it. Override __new__ for immutable types or singletons.

Python concurrency (9)

Basic Concurrency versus parallelism?

Concurrency is overlapping progress of tasks, possibly on one core. Parallelism is simultaneous execution on multiple cores.

Basic When use threads, processes or asyncio?

Threads for modest I/O-bound work with blocking libraries, asyncio for very many I/O-bound connections with async libraries, processes for CPU-bound work.

Medium How do you avoid race conditions with threads?

Protect shared state with locks, use thread-safe queues to pass messages, or avoid shared mutable state.

Medium How does asyncio work?

A single-threaded event loop runs coroutines; await suspends a coroutine until its operation completes, letting others run. Blocking calls stall the loop.

Medium What does asyncio.gather do?

Runs awaitables concurrently and returns their results in the order passed. Use TaskGroup for structured error handling.

Medium Why must multiprocessing code use the __main__ guard?

On Windows and macOS, child processes import the main module (spawn); without the guard they would start processes recursively.

Advanced How do you call blocking code from async code?

Use asyncio.to_thread or loop.run_in_executor so the blocking call runs in a thread pool and does not freeze the event loop.

Advanced What is a deadlock and how do you avoid it?

Threads waiting on each other's locks forever. Acquire locks in a consistent global order, use timeouts, or reduce shared locks.

Advanced How do you limit concurrency?

Semaphores or bounded worker pools (ThreadPoolExecutor with max_workers, asyncio.Semaphore, bounded queues) so you do not overload dependencies.

Python engineering (9)

Basic Why use a virtual environment?

To isolate each project's dependencies and versions from the system and other projects, and to reproduce environments from a requirements or lock file.

Basic What is PEP 8?

The Python style guide: naming (snake_case, CapWords), indentation of four spaces, line length and import ordering. Automate with ruff or black.

Medium unittest versus pytest?

unittest is in the standard library with class-based tests. pytest uses plain asserts, fixtures, parametrisation and plugins, and also runs unittest tests.

Medium How do you test code with external dependencies?

Replace slow or non-deterministic dependencies with fakes or mocks (unittest.mock), inject them as parameters, and use a real test database or container for integration tests.

Medium How do you profile and speed up Python code?

Measure with cProfile, timeit and tracemalloc. Fix algorithms and data structures first, use built-ins and comprehensions, cache pure functions, vectorise with NumPy, and use processes or native code for CPU work.

Medium How should you handle configuration and secrets?

Keep them out of code: environment variables or config files, secret managers in production, never commit secrets or log them.

Advanced Why is pickle unsafe, and what is the alternative?

Unpickling untrusted data can execute arbitrary code. Use JSON or other data-only formats for untrusted input.

Advanced How would you package and distribute a library?

pyproject.toml with metadata and dependencies, a src layout, semantic versioning, build with python -m build, publish wheels to an index, and test across supported Python versions in CI.

Advanced What belongs in a logging setup for a service?

Structured logs with levels, request ids, no secrets, configured by the application (handlers and formatters) while libraries only get a logger by __name__.

SQL basics (10)

Basic What is the difference between WHERE and HAVING?

WHERE filters rows before grouping; HAVING filters groups after aggregates are computed.

Basic Difference between DELETE, TRUNCATE and DROP?

DELETE removes selected rows (logged, can be rolled back, fires triggers). TRUNCATE removes all rows quickly (resets state, limited rollback in some engines). DROP removes the table itself.

Basic What are primary and foreign keys?

A primary key uniquely identifies a row. A foreign key references another table's key and lets the database enforce referential integrity.

Basic What is NULL and how do you test for it?

NULL means unknown or missing. Comparisons with it are unknown, so use IS NULL and IS NOT NULL, and COALESCE to supply defaults.

Medium COUNT(*) versus COUNT(column) versus COUNT(DISTINCT column)?

COUNT(*) counts rows, COUNT(column) counts non-NULL values, COUNT(DISTINCT column) counts distinct non-NULL values.

Medium What is the logical order of query evaluation?

FROM and JOIN, WHERE, GROUP BY, HAVING, SELECT, DISTINCT, ORDER BY, LIMIT.

Medium What are the SQL constraint types?

PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK and DEFAULT.

Medium What is the difference between CHAR and VARCHAR, and why use DECIMAL for money?

CHAR is fixed length and VARCHAR variable length. DECIMAL is exact, while floating point types are approximate and cause rounding errors.

Advanced Why can SELECT without ORDER BY return rows in different orders?

SQL tables are unordered sets; the order depends on the plan, indexes and storage. Always specify ORDER BY (with a unique tiebreaker) when order matters.

Advanced Explain three-valued logic.

A condition can be true, false or unknown. Comparisons with NULL are unknown; AND, OR and NOT follow truth tables for three values, and WHERE keeps only true rows.

SQL joins (10)

Basic Explain INNER, LEFT, RIGHT and FULL joins.

Inner returns matching rows only. Left keeps all left rows with NULLs for missing right matches. Right is the mirror. Full keeps unmatched rows from both sides.

Basic What is a self join?

Joining a table to itself with aliases, for example employees to their managers.

Basic UNION versus UNION ALL?

UNION removes duplicates (extra work); UNION ALL keeps all rows and is faster.

Medium How do you find rows in A with no match in B?

LEFT JOIN and filter B's key IS NULL, or NOT EXISTS. Prefer NOT EXISTS over NOT IN when NULLs are possible.

Medium IN versus EXISTS?

IN compares to a list or subquery result; EXISTS checks whether a correlated subquery returns any row, stops early and is NULL-safe.

Medium Why does a WHERE filter on the right table turn a LEFT JOIN into an INNER JOIN?

Unmatched rows have NULLs in right columns, which fail the condition. Put the condition in the ON clause instead.

Medium What is a CROSS JOIN and when is it useful?

The Cartesian product of two tables. Useful for generating combinations such as all dates by all products.

Advanced How does row multiplication happen and how do you avoid double counting?

Joining one-to-many tables repeats the parent row. Aggregate the child table in a subquery or CTE first, then join the result.

Advanced What is a correlated subquery and what are alternatives?

A subquery referencing the outer row, evaluated per outer row. Alternatives are joins to a pre-aggregated derived table or window functions.

Advanced Explain NOT IN with NULLs.

If the subquery returns any NULL, x NOT IN (...) is never true, so no rows return. Use NOT EXISTS or filter NULLs out.

SQL advanced (10)

Basic What is a CTE?

A named temporary result defined with WITH, used to structure a query into readable steps.

Medium Window function versus GROUP BY?

GROUP BY collapses rows into one per group; a window function computes across related rows and keeps every row.

Medium ROW_NUMBER, RANK and DENSE_RANK?

ROW_NUMBER gives unique numbers; RANK gives ties the same rank and leaves gaps; DENSE_RANK gives ties the same rank without gaps.

Medium How do you get the top N rows per group?

Rank rows with a window function partitioned by the group in a subquery or CTE, then filter rank <= N.

Medium What do LAG and LEAD do?

Return a value from a previous or following row in the window order, useful for differences and period over period change.

Medium How do you compute a running total or moving average?

SUM or AVG as a window function with ORDER BY and a frame such as ROWS BETWEEN 2 PRECEDING AND CURRENT ROW.

Advanced Explain recursive CTEs.

An anchor query seeds rows and a recursive query joined with UNION ALL generates more until none appear. Used for hierarchies, paths and sequences; include a stopping condition.

Advanced Explain the gaps and islands technique.

Subtract ROW_NUMBER from the sequence value (or use LAG flags with a running sum) to create a constant group id per consecutive run, then aggregate by it.

Advanced What is an upsert?

A single atomic statement that inserts or updates on conflict: ON CONFLICT DO UPDATE (PostgreSQL, SQLite), ON DUPLICATE KEY UPDATE (MySQL), MERGE (SQL Server, Oracle).

Advanced How do you pivot rows to columns?

Conditional aggregation with SUM(CASE WHEN ...) per output column, or the PIVOT operator where available.

SQL design (11)

Basic What is normalisation and why do it?

Organising tables so each fact is stored once, to avoid update, insert and delete anomalies. Typically to third normal form.

Basic Explain 1NF, 2NF and 3NF.

1NF: atomic values, no repeating groups. 2NF: every non-key column depends on the whole key. 3NF: no non-key column depends on another non-key column.

Medium When would you denormalise?

When measured read performance needs fewer joins, such as reporting or read-heavy paths, accepting duplicate data that must be kept in sync.

Medium Surrogate versus natural keys?

Surrogate keys are artificial ids, stable and compact. Natural keys are real attributes, which can change or collide. Use a surrogate primary key with a unique constraint on the natural key.

Medium Explain ACID.

Atomicity, consistency, isolation, durability: all-or-nothing, valid states, no interference between concurrent transactions, committed data survives crashes.

Medium What are the transaction isolation levels?

Read uncommitted, read committed, repeatable read and serializable, trading anomalies (dirty, non-repeatable and phantom reads) against concurrency.

Medium What is a view and a materialised view?

A view is a stored query used like a table. A materialised view stores the result and must be refreshed.

Advanced Optimistic versus pessimistic locking?

Pessimistic locks rows up front (SELECT FOR UPDATE). Optimistic reads a version and updates only if unchanged, retrying on conflict.

Advanced What causes deadlocks and how do you reduce them?

Transactions holding locks in different orders. Access rows in a consistent order, keep transactions short and retry on deadlock errors.

Advanced What is MVCC?

Multi-version concurrency control keeps several row versions so readers see snapshots without blocking writers.

Advanced Triggers: when and when not?

Use for audit trails and invariants that must hold for every writer. Avoid for business logic that hides side effects and complicates debugging.

SQL performance (10)

Basic What is an index and what does it cost?

A sorted structure that speeds lookups and sorting. It uses space and slows inserts, updates and deletes.

Basic How do you find why a query is slow?

Read its execution plan with EXPLAIN (ANALYZE), look for full scans, bad estimates and sorts, and check indexes and statistics.

Medium What is a composite index and the leftmost prefix rule?

An index on several columns. It serves filters on a leftmost prefix of its columns, with equality columns first and the range column last.

Medium What is a covering index?

An index containing every column the query needs, so the table is not read.

Medium What makes a predicate non-sargable?

Applying a function or expression to the indexed column (YEAR(col), LOWER(col), col + 1) or a leading wildcard prevents index use. Rewrite or use an expression index.

Medium Why is deep OFFSET pagination slow and what is the alternative?

The database reads and discards the skipped rows. Use keyset pagination: WHERE id > :last ORDER BY id LIMIT n.

Advanced Nested loop, hash and merge joins?

Nested loop probes the inner side per outer row (good with indexes and small outer sets); hash join builds a hash table (large unsorted equality joins); merge join merges sorted inputs.

Advanced What is partitioning and when does it help?

Splitting a large table by range, list or hash so queries on the key touch fewer partitions and old data can be dropped quickly.

Advanced Order of scaling a database?

Fix queries and indexes, add caching and read replicas, partition, then shard. Each later step adds complexity.

Advanced Stale statistics?

The optimiser relies on row counts and distributions; outdated ones lead to bad plans. Run ANALYZE or autovacuum regularly.

SQL problems (10)

Basic Write a query for the second highest salary.

Use DENSE_RANK and filter rank = 2, or SELECT DISTINCT salary ORDER BY salary DESC LIMIT 1 OFFSET 1.

Medium Find duplicate emails.

SELECT email, COUNT(*) FROM person GROUP BY email HAVING COUNT(*) > 1.

Medium Delete duplicates keeping the lowest id.

DELETE FROM person WHERE id NOT IN (SELECT MIN(id) FROM person GROUP BY email), or delete rows with ROW_NUMBER over email greater than 1.

Medium Employees who earn more than their manager.

Self join employees e to employees m on e.manager_id = m.id and filter e.salary > m.salary.

Medium Customers who never ordered.

LEFT JOIN orders and keep rows where the order id IS NULL, or NOT EXISTS.

Medium Running total of monthly revenue.

Aggregate to months in a CTE then SUM(revenue) OVER (ORDER BY month).

Advanced Month over month growth.

Use LAG(revenue) OVER (ORDER BY month) and compute (revenue - prev) / prev, remembering the first month is NULL.

Advanced Longest consecutive login streak.

Compute date minus ROW_NUMBER per user as a group key, count per group, then take the maximum per user.

Advanced Customers who bought every product category.

Join to categories, GROUP BY customer and compare COUNT(DISTINCT category) to the total number of categories (relational division).

Advanced Merge overlapping intervals in SQL.

Order by start, track the running maximum end with a window frame, flag a new group when the start exceeds it, running-sum the flags and aggregate.

Python with SQL (10)

Basic How do you run a safe query from Python?

Use parameter placeholders: cursor.execute('SELECT ... WHERE id = ?', (id,)). Never concatenate or format user input into SQL.

Basic What is SQL injection?

An attack where user input is interpreted as SQL. Prevent with parameterised queries, allow-listed identifiers and least-privilege accounts.

Medium How do you make a multi-statement change atomic in Python?

Run the statements in one transaction: with connection: ... commits on success and rolls back on exception.

Medium What is the N+1 query problem?

One query for a list plus one per item. Fix with a join, an IN batch or ORM eager loading (selectinload, joinedload, select_related, prefetch_related).

Medium How do you insert many rows efficiently?

executemany in a single transaction, or the database's bulk loader (COPY, LOAD DATA) for very large loads.

Medium ORM versus raw SQL?

ORMs reduce boilerplate and manage relationships and migrations but can hide inefficient SQL. Use them for routine CRUD and raw SQL for complex reports and bulk work.

Medium What is a connection pool?

A set of reusable open connections shared by requests, avoiding the cost of reconnecting and capping load on the database.

Advanced How do you do database migrations safely?

Version every change, apply in order with a tool (Alembic, Django, Flyway), make changes backward compatible (expand then contract) and test on production-like data.

Advanced How do you test database code?

Use a real engine (a container or in-memory SQLite for simple cases), fresh schema or rolled-back transaction per test, and test constraints, concurrency and query counts.

Advanced When to use pandas versus SQL?

Filter, join and aggregate in SQL near the data; use pandas for reshaping, statistics and visualisation on the smaller result. Use chunking, DuckDB or Polars for large data.

Python problems (8)

Basic How would you count word frequencies?

Normalise with lower() and a regex, then collections.Counter and most_common or a sort by (-count, word).

Medium How do you group anagrams?

Use the sorted letters as a dictionary key with defaultdict(list).

Medium How do you flatten a nested list lazily?

A recursive generator with yield from for lists and tuples, yielding other items.

Medium How do you process a huge file?

Iterate over it line by line or in chunks with generators, keeping only aggregates in memory.

Medium Explain why this prints [2, 2, 2]: fs = [lambda: i for i in range(3)].

Late binding: each lambda looks up i when called, after the loop ended at 2. Bind with a default argument lambda i=i: i.

Advanced Implement a decorator with arguments.

A three-level function: the outer takes the arguments and returns a decorator that returns a wrapper, using functools.wraps.

Advanced How do you limit concurrent downloads in asyncio?

Wrap each task body in an asyncio.Semaphore and gather the tasks, or use a bounded queue with a fixed worker pool.

Advanced How do you write a safe dynamic SQL search with optional filters?

Append fixed SQL fragments for each provided filter, collect values in a parameter list, and allow-list any column used in ORDER BY.

Standard library (14)

Basic Why prefer pathlib over os.path string handling?

Path objects are cross-platform, support the / operator, and bundle operations such as read_text, glob, exists and mkdir, producing more readable code.

Basic How do you read a large file without loading it all?

Iterate over the file object line by line (or in chunks) inside a with block, so memory stays constant.

Basic What does Counter do?

A dict subclass for counting hashable items, with most_common, arithmetic between counters, and zero for missing keys.

Medium Why use Decimal for money and how do you create one?

Binary floats cannot represent most decimal fractions exactly. Create Decimals from strings (Decimal('19.99')), never from floats, and quantize with an explicit rounding mode.

Medium How should you handle time zones?

Store and compute in timezone-aware UTC, convert to local zones only for display with zoneinfo, and never mix naive and aware datetimes.

Medium Why is round(2.5) equal to 2 in Python 3?

round uses banker's rounding (round half to even) to avoid statistical bias; use Decimal with ROUND_HALF_UP when a business rule needs conventional rounding.

Medium random versus secrets?

random is a deterministic pseudo-random generator for simulations; secrets uses the operating system's cryptographic source for tokens, passwords and keys.

Medium When would you use deque, heapq and bisect?

deque for O(1) operations at both ends and bounded windows; heapq for priority queues and top-k; bisect for binary search and keeping a list sorted.

Medium How do you run an external command safely?

subprocess.run with an argument list (no shell=True), a timeout, capture_output and check or an explicit return-code test.

Medium What is the difference between hashing, encoding and encryption?

Hashing is one-way and fixed length, encoding (base64) is reversible with no secret, encryption is reversible only with a key.

Advanced How do you format numbers in f-strings?

Use format specs: {x:.2f}, {x:,}, {x:>10}, {x:08.3f}, {x:.1%}, {n:#x}, and {name=} for debugging output.

Advanced How would you time two implementations fairly?

timeit with the same setup and enough repetitions, taking the minimum of several runs, avoiding one-time effects such as imports and warm-up.

Advanced Why add encoding= when opening text files?

The default depends on the platform and locale, so behaviour differs between machines. Specify encoding='utf-8' (or utf-8-sig for Excel files).

Advanced What does struct do?

Packs and unpacks Python values to fixed binary layouts with explicit byte order, used for binary file formats and network protocols.

Data formats and web (14)

Basic Why use the csv module instead of split(',')?

Fields may be quoted and contain commas, quotes and newlines. The csv module implements these rules and dialects.

Basic What types does JSON support?

Objects, arrays, strings, numbers, booleans and null. There is no date, bytes or set type, so serialise those explicitly.

Basic What do 200, 201, 204, 400, 401, 403, 404, 409, 429 and 500 mean?

OK, created, no content, bad request, unauthenticated, forbidden, not found, conflict, too many requests, server error.

Medium Which HTTP methods are idempotent and which are safe?

GET, HEAD and OPTIONS are safe; GET, HEAD, PUT, DELETE and OPTIONS are idempotent. POST is neither and PATCH is not guaranteed idempotent.

Medium How do you build a URL with query parameters safely?

Use urllib.parse.urlencode and urljoin or a client library's params argument so special characters are percent-encoded.

Medium What makes an HTTP client robust?

Timeouts on every call, retries with exponential backoff and jitter for transient errors on idempotent requests, respect for Retry-After, connection reuse, and clear handling of non-2xx responses.

Medium Why is pickle unsafe for untrusted data?

Unpickling can call arbitrary functions, so loading attacker-supplied bytes can execute code. Use JSON or a schema-based format.

Medium How do you validate incoming JSON?

Parse, then check structure, types, ranges and unknown fields with a schema library such as pydantic or jsonschema, returning specific errors.

Medium What is zip slip?

An archive entry with ../ in its path writes outside the extraction directory. Resolve and verify each target path before extracting.

Advanced How would you parse a 20 GB CSV?

Stream rows with csv.reader or pandas chunks, process incrementally, avoid holding everything in memory, and write results in a columnar format such as Parquet.

Advanced SSRF: what is it and how do you prevent it?

A server fetches a user-supplied URL and is tricked into reaching internal services or cloud metadata. Allow-list hosts, resolve and check IPs, block private ranges and disable redirects or re-validate them.

Advanced REST versus gRPC versus GraphQL in one line each?

REST uses resources over HTTP and is cacheable and simple; gRPC uses Protobuf over HTTP/2 for fast typed service calls; GraphQL lets clients specify exactly the fields they need from one endpoint.

Advanced How does an HTTP server handle many clients in Python?

Using threads, processes, or an async event loop (ASGI servers such as uvicorn); the framework routes requests while the server manages concurrency.

Advanced Why are XML parsers a security concern?

Entity expansion (billion laughs) and external entity (XXE) features can exhaust memory or read files. Use defusedxml for untrusted input.

Python internals (15)

Basic What does it mean that everything in Python is an object?

Values, functions, classes and modules all have identity, type and value, and names are references to them.

Basic is versus ==?

is tests whether two names refer to the same object; == tests value equality. Use is for None.

Basic Why is a mutable default argument a bug?

The default is created once at function definition and shared across calls, so mutations persist. Use None and create the object inside.

Medium Explain LEGB.

Names are resolved in Local, Enclosing function, Global then Built-in scopes. nonlocal and global declare which scope to rebind.

Medium What is the MRO and how is it computed?

The method resolution order is the linearisation of a class and its bases using C3, used by attribute lookup and super(). Inspect it with Class.__mro__.

Medium How does attribute lookup work?

Data descriptors on the type, then the instance __dict__, then non-data descriptors and class attributes along the MRO, then __getattr__ as a fallback.

Medium How does CPython manage memory?

Reference counting frees objects immediately at zero, and a cyclic garbage collector reclaims reference cycles.

Medium What is the GIL and what does it imply?

A lock allowing one thread to execute Python bytecode at a time in CPython. CPU-bound threads do not speed up; I/O-bound threads do. Use multiprocessing or native extensions for CPU work.

Medium Why define __hash__ with __eq__?

Equal objects must hash equally for dict and set correctness. Defining __eq__ alone makes instances unhashable.

Advanced What is a descriptor?

An object with __get__, __set__ or __delete__ stored on a class that controls attribute access. property, methods, classmethod and staticmethod are descriptors.

Advanced What are __slots__ for?

They replace the per-instance dict with fixed attributes, reducing memory and preventing arbitrary new attributes, at some cost in flexibility.

Advanced How does import work?

Python checks sys.modules, then uses finders on sys.path to locate and load the module, executes it once and caches it, which is also why circular imports can see partially initialised modules.

Advanced Why is s += x in a loop slow for strings?

Strings are immutable, so each concatenation can copy the whole string (O(n^2) total). Collect pieces and use ''.join().

Advanced What are weak references used for?

To refer to an object without keeping it alive, for caches, observers and parent pointers, avoiding leaks from cycles.

Advanced What does the dis module show?

The bytecode instructions the interpreter runs for a function. Useful for understanding evaluation order and cost; opcodes vary between versions.

Design patterns (14)

Basic What is the single responsibility principle?

A class or function should have one reason to change; split unrelated concerns such as parsing, validation, storage and reporting.

Basic Why prefer composition over inheritance?

Composition is more flexible and avoids tight coupling and fragile hierarchies. Use inheritance for true is-a relationships and shared behaviour.

Medium How is the strategy pattern implemented in Python?

Pass a function or callable that performs the varying step; a dict of functions can select among strategies.

Medium What is dependency injection and why use it?

Passing collaborators (database, clock, notifier) to a class or function instead of creating them inside, so they can be replaced in tests and configuration.

Medium What is a Protocol in Python?

A structural interface from typing: any class with the required methods satisfies it without inheriting, enabling duck typing with static checking.

Medium How do you implement a singleton in Python?

Usually a module-level object, since modules are imported once. Prefer passing the shared object explicitly to keep tests simple.

Medium Observer pattern in Python?

A publisher keeps a list of callables per event and calls them when the event fires; useful for decoupled notifications.

Medium Explain the Liskov substitution principle.

Instances of a subclass must be usable wherever the base class is expected without breaking behaviour: do not strengthen preconditions or weaken postconditions.

Advanced Factory versus builder?

A factory chooses which object to create; a builder constructs one complex object step by step, often immutably.

Advanced What is the repository pattern?

An abstraction of data access that the domain code uses, hiding SQL or an ORM behind an interface so storage can be swapped and tested with fakes.

Advanced State pattern versus a big if-chain?

State uses a transition table or state objects so each state's behaviour is explicit and illegal transitions are rejected centrally.

Advanced What is a code smell and name five?

A symptom of a design problem: long function, large class, duplicated code, feature envy, long parameter list, primitive obsession, deep nesting.

Advanced How do you refactor safely?

Cover the behaviour with tests first, make small steps, run tests after each, and avoid mixing refactoring with feature changes.

Advanced Ports and adapters (hexagonal) architecture?

Domain logic sits at the centre with no I/O; external systems connect through interfaces (ports) implemented by adapters, so dependencies point inward.

SQL dialects and NoSQL (14)

Basic How do you limit rows in MySQL, PostgreSQL, SQL Server and Oracle?

LIMIT n in MySQL, PostgreSQL and SQLite; TOP n or OFFSET FETCH in SQL Server; FETCH FIRST n ROWS ONLY (or ROWNUM) in Oracle.

Basic What is an upsert and how is it written in different engines?

Insert or update on conflict: ON CONFLICT DO UPDATE in PostgreSQL and SQLite, ON DUPLICATE KEY UPDATE in MySQL, MERGE in SQL Server and Oracle.

Medium Name PostgreSQL features not in standard SQL that you find useful.

JSONB with GIN indexes, arrays, DISTINCT ON, range types and exclusion constraints, partial and expression indexes, LATERAL joins, extensions such as PostGIS.

Medium Why does 7/2 differ between engines?

Some engines do integer division for integer operands (PostgreSQL, SQL Server, SQLite give 3) while MySQL gives 3.5 and uses DIV for integers. Cast explicitly.

Medium How does collation affect queries?

It defines text comparison and sort order (case, accents, language), affecting ORDER BY, LIKE, UNIQUE and joins. Choose it deliberately and consistently.

Medium Why is OFFSET pagination a problem and what replaces it?

Large offsets scan and discard rows. Keyset pagination uses WHERE (key) > last_seen ORDER BY key LIMIT n with an index for constant-cost pages.

Medium When would you choose a document database?

For varied, nested records read and written as a unit, with a flexible schema and few cross-document joins.

Medium When would you choose a key-value store?

For simple lookups by key at very high throughput and low latency: sessions, caches, counters, feature flags.

Medium What is a wide-column store good at?

Huge write volumes and time-series-like data with known query patterns, partitioned by key, as in Cassandra and Bigtable.

Advanced Relational versus document modelling: embed or reference?

Embed data read together and owned by the parent; reference data that is shared, large or unbounded. Embedding speeds reads and complicates updates of duplicated data.

Advanced What is polyglot persistence?

Using several specialised stores, such as a relational database, a cache, a search engine and a warehouse, kept consistent through events or change data capture.

Advanced How does MySQL's sql_mode matter?

Strict modes make invalid data raise errors instead of being silently truncated or coerced; ONLY_FULL_GROUP_BY rejects ambiguous aggregates.

Advanced What is QUALIFY?

A clause in warehouses such as Snowflake and BigQuery that filters on window function results without a subquery.

Advanced Does eventual consistency mean data may be lost?

No. It means replicas may temporarily disagree and converge later; conflicts need a resolution rule, and durability is a separate property.

Analytics SQL (14)

Basic How do you compute a conversion rate in SQL?

Count distinct users at each step with conditional aggregation and divide, using a decimal literal to avoid integer division.

Basic Why COUNT(DISTINCT user_id) in a funnel?

A user can generate many events at a step but should count once.

Medium How do you compute cohort retention?

Assign each user a cohort (signup period), compute the activity period offset from it, count distinct active users per cohort and offset, and divide by cohort size.

Medium How do you compute a running total and a moving average?

SUM(x) OVER (ORDER BY day) and AVG(x) OVER (ORDER BY day ROWS BETWEEN n PRECEDING AND CURRENT ROW).

Medium How do you sessionise events?

Compute the gap from the previous event per user with LAG, flag gaps over a threshold, then take a running SUM of the flags to number sessions.

Medium How do you fill missing dates in a time series?

Generate a date spine with a recursive CTE or calendar table and LEFT JOIN the data, using COALESCE for zeros.

Medium How do you compute a median without a MEDIAN function?

Number rows with ROW_NUMBER and count with COUNT OVER, then average the one or two middle rows.

Medium What is join fan-out and how do you avoid it?

Joining two one-to-many tables multiplies rows and inflates sums. Aggregate each table to the join grain first, or use subqueries or CTEs.

Advanced Why is averaging averages wrong?

Groups with different sizes carry different weight. Sum the numerators and denominators across groups, then divide.

Advanced What is RFM analysis?

Segmenting customers by recency of last purchase, frequency of purchases and monetary value, often with NTILE scores.

Advanced How do you compute year-over-year growth?

Join or window each period to the same period a year earlier (LAG 12 for monthly data) and divide the difference by the earlier value, handling zero or missing prior values.

Advanced What is sample ratio mismatch in an A/B test?

Observed group sizes deviating from the planned split, indicating assignment or logging bugs that invalidate the result.

Advanced How do you handle time zones in daily metrics?

Convert timestamps to the business time zone before truncating to a date, and define the day boundary once in a shared view or model.

Advanced How would you design an events table for analytics?

Append-only rows with user_id, event name, timestamp (UTC), properties as columns or JSON, partitioned by date and clustered by user, plus a deduplication key.

Transactions in depth (14)

Basic State the ACID properties.

Atomicity, Consistency, Isolation, Durability: all-or-nothing changes, valid states, concurrent transactions behave as if separate, committed data survives crashes.

Basic What is a dirty read?

Reading another transaction's uncommitted change, which may later roll back.

Medium List the isolation levels and what each prevents.

Read uncommitted allows dirty reads; read committed prevents them; repeatable read also prevents non-repeatable reads; serializable also prevents phantoms and write skew.

Medium What is a lost update and how do you prevent it?

Two read-modify-write cycles overwrite each other. Use an atomic UPDATE expression, SELECT FOR UPDATE, optimistic versioning, or serializable isolation.

Medium Optimistic versus pessimistic locking?

Pessimistic locks rows up front and blocks others; optimistic checks at write time (version column) and retries on conflict. Optimistic suits low contention.

Medium What is a deadlock and how do you avoid it?

A cycle of transactions each waiting for a lock the other holds. Lock in a consistent order, keep transactions short, and retry when the database aborts one.

Medium What is MVCC?

Multi-version concurrency control keeps several versions of rows so readers see a snapshot and do not block writers, at the cost of cleanup of old versions.

Medium What does SELECT ... FOR UPDATE SKIP LOCKED do?

Locks selected rows and skips rows already locked by others, letting workers claim distinct jobs from a queue table.

Advanced What is write skew?

Two transactions read overlapping data, make decisions on it and write different rows, jointly violating an invariant. Snapshot isolation allows it; serializable, explicit locks or constraints prevent it.

Advanced How do savepoints help?

They allow rolling back part of a transaction, such as handling a duplicate key error and continuing, without aborting everything (essential in PostgreSQL).

Advanced How do you make a transaction safe to retry?

Use idempotency keys with a unique constraint so repeated attempts have no extra effect, and retry on serialization failure, deadlock and timeout with backoff.

Advanced Why do long-running transactions hurt?

They hold locks, block cleanup of old versions causing bloat, and widen conflict windows. Keep them short and never wait on users inside.

Advanced What is the default isolation level in PostgreSQL and MySQL InnoDB?

Read committed in PostgreSQL; repeatable read in InnoDB. SQL Server and Oracle default to read committed.

Advanced What is two-phase commit and why is it avoided across services?

A protocol to commit atomically across multiple resources via prepare and commit phases. It blocks on coordinator failure and couples availability, so sagas are often preferred.

More SQL problems (14)

Basic Find the second highest salary.

Rank with DENSE_RANK() OVER (ORDER BY salary DESC) and pick rank 2, or use a subquery on MAX(salary) < MAX; LIMIT/OFFSET fails with ties.

Basic Find customers with no orders.

LEFT JOIN orders and filter orders.id IS NULL, or use NOT EXISTS.

Medium Why prefer NOT EXISTS over NOT IN?

NOT IN yields no rows if the subquery returns any NULL because of three-valued logic. NOT EXISTS is NULL-safe.

Medium Find employees who earn more than their manager.

Self-join employees e to employees m on e.manager_id = m.id and filter e.salary > m.salary.

Medium Get the top N rows per group.

Number rows with ROW_NUMBER() OVER (PARTITION BY group ORDER BY metric DESC) in a subquery and keep rn <= N; use RANK to keep ties.

Medium Pivot rows into columns.

Conditional aggregation: SUM(CASE WHEN category = 'x' THEN value END) AS x for each column, grouped by the row key.

Medium Compute percent of total.

Divide each group's sum by SUM(sum) OVER (), or by a scalar subquery of the total.

Medium Delete duplicate rows keeping one.

DELETE rows whose id is not the MIN(id) of its duplicate group, or use ROW_NUMBER() PARTITION BY the duplicate key and delete rn > 1; preview first.

Advanced Find the longest consecutive login streak.

Subtract ROW_NUMBER() per user from the date to get a group key for consecutive runs, then count rows per group and take the maximum.

Advanced Relational division: customers who bought all products in a set.

Join and group by customer, then HAVING COUNT(DISTINCT product) equals the number of products in the set.

Advanced Find gaps in a sequence of ids.

Use LEAD(id) OVER (ORDER BY id) and report where next_id - id > 1.

Advanced List the management chain for each employee.

A recursive CTE: start at employees with no manager, join children each step, tracking level and path.

Advanced Find the median.

ROW_NUMBER and COUNT windows, then AVG of the rows at positions (n + 1) / 2 and (n + 2) / 2 (integer division), or percentile_cont where available.

Advanced Compare each row with the group average without a self-join.

Use AVG(x) OVER (PARTITION BY group) beside each row.

Python and SQL projects (14)

Basic Why store money as integer cents?

Integers are exact, avoiding floating-point rounding. Convert to a decimal for display.

Basic Why use parameter binding instead of string formatting for SQL?

It prevents injection by sending values separately from the SQL text and lets the database cache plans.

Medium What does a migration runner do?

Applies ordered schema scripts once each, records applied versions in a table, and runs each in a transaction so environments converge to the same schema.

Medium What are the rules for writing safe migrations?

Never edit applied ones, keep them backward compatible with running code, avoid long locks, batch big backfills, and test them on production-sized data.

Medium What is the repository pattern for databases?

A class that encapsulates queries for one aggregate behind methods, letting services and tests ignore SQL details.

Medium How do you let users choose a sort column safely?

Check it against an allow-list and interpolate only the verified identifier; bind values separately.

Medium How do you test code that uses a database?

Inject the connection, use an in-memory or disposable database, build fixtures per test, and run key tests against the real engine in CI.

Medium How do you design data quality checks?

Express each as a query returning offending rows (nulls, duplicates, referential integrity, ranges, freshness, volume), run on a schedule or in the pipeline, and define whether failures block or alert.

Advanced How do you make a batch job idempotent?

Write results to a deterministic partition by overwriting or upserting on natural keys, record watermarks, and avoid appending without dedupe.

Advanced Half-open date ranges: why use them?

start <= ts AND ts < next_start never double counts or misses boundary timestamps, unlike BETWEEN.

Advanced How would you move from SQLite to PostgreSQL?

Keep access behind a repository, replace SQLite-specific SQL, fix type strictness and booleans, adopt a migration tool, run the same tests on both, and tune connection pooling.

Advanced Where should validation live?

In layers: input parsing at the edge, business rules in services, and constraints in the database as the last line of defence.

Advanced How do you avoid N+1 queries in a repository?

Fetch related rows in one query with a join or an IN list, or use eager loading, instead of one query per parent row.

Advanced How do you expose database results as an API safely?

Allow-list filters and sort fields, bound parameters, pagination limits, authorization on every request and a stable response schema.
