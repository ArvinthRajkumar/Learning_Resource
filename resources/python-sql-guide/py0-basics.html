Python from scratch: values, control flow and functions

Python is a general-purpose language that reads almost like English. This part assumes you have never programmed. Every idea is shown with a short program, and every output below was produced by actually running the code.

Basic~4 hours

Running Python and your first programs

What Python is

Python is an interpreted, dynamically typed language. You write text in a file, and the Python interpreter reads it line by line and carries out the instructions. Dynamically typed means a variable can hold any kind of value and its type is checked while the program runs.

Two ways to run code

  • Interactive (the REPL): type python in a terminal and enter lines one at a time. Great for experiments.
  • Script: save code in hello.py and run python hello.py.
print("Hello, world")
print(2 + 3)

Output

Hello, world
5

print is a function that shows values. Text in quotes is a string. Lines starting with # are comments: Python ignores them, so you can explain your code.

Variables

A variable is a name that refers to a value. Use = to attach a name to a value.

price = 20          # a whole number (int)
rate = 0.15         # a decimal number (float)
name = "Ada"        # text (str)
total = price * (1 + rate)
print(name, "pays", total)

Output

Ada pays 23.0

Names: letters, digits, underscore, not starting with a digit, case sensitive (Total and total differ). Convention (PEP 8): snake_case for variables and functions, CapWords for classes, UPPER_CASE for constants.

Remember

Variables are labels on objects, not boxes holding values. b = a makes two labels on the same object. This explains many surprises later.

How this gets asked

After a = [1, 2] and b = a, then b.append(3), what is a?

  • [1, 2] The label b points to the same list.
  • [1, 2, 3] Correct.
  • Error No error occurs.
  • [3] No.

Variables are labels; both names refer to the same list object.

Floats are approximate

Computers store decimals in binary, so some decimals cannot be exact.

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
import math
print(math.isclose(0.1 + 0.2, 0.3))
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))
print(round(2.675, 2), round(3.5), round(4.5))   # banker's rounding to even

False

Use math.isclose to compare floats and decimal.Decimal for money. Integers have unlimited size: 2 ** 200 works.

How this gets asked

What does -7 // 2 evaluate to?

Floor division rounds toward negative infinity: -3.5 becomes -4.

Which is the best way to compare two floats for near equality?

  • a == b Rounding error may make this false.
  • math.isclose(a, b) Correct.
  • a is b Identity, not equality.
  • str(a) == str(b) Fragile.

Floats are approximations, so compare with a tolerance.

match (structural pattern matching)

def describe(cmd):
    match cmd.split():
        case ["go", direction]:
            return "going " + direction
        case ["quit"]:
            return "bye"
        case _:
            return "unknown"
print(describe("go north"), describe("quit"), describe("jump"))

Output

going north bye unknown

Functions

Defining and calling

def area(width, height=1):
    """Return the area of a rectangle."""      # docstring
    return width * height

print(area(3, 4), area(5), area(height=2, width=6))

Output

12 5 12

A function takes parameters, returns a value with return (otherwise None), and has a docstring describing it. Calling it passes arguments.

Flexible arguments

def report(first, *args, sep="-", **kwargs):
    print(first, args, kwargs, sep)
report(1, 2, 3, sep="+", color="red", size=3)

def add(a, b): return a + b
nums = (4, 5)
opts = {"a": 1, "b": 2}
print(add(*nums), add(**opts))

Output

1 (2, 3) {'color': 'red', 'size': 3} +
9 3

*args collects extra positional arguments into a tuple, **kwargs collects keyword arguments into a dict. At a call site * and ** unpack.

The mutable default argument trap

def bad(item, bucket=[]):
    bucket.append(item)
    return bucket
print(bad(1), bad(2))          # the same list is reused!

def good(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
print(good(1), good(2))

Output

[1, 2] [1, 2]
[1] [2]

Default values are evaluated once, when the function is defined. Never use a list or dict as a default; use None and create it inside.

Scope (LEGB)

Python looks up a name in order: Local, Enclosing function, Global, Built-in.

x = "global"
def outer():
    x = "enclosing"
    def inner():
        nonlocal x
        x = "changed by inner"
    inner()
    return x
print(outer(), x)

Output

changed by inner global

Assignment inside a function makes the name local unless you declare global or nonlocal. Reading a global is fine without a declaration.

Errors and exceptions

Reading an error

When something goes wrong Python raises an exception and prints a traceback: read it bottom to top. The last line names the exception type and message; the lines above show where it happened.

try, except, else, finally

def safe_div(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        return "cannot divide by zero"
    except TypeError as e:
        return "bad types: %s" % e
    else:
        return result            # only when no exception
    finally:
        print("done")            # always runs

print(safe_div(6, 3))
print(safe_div(1, 0))
print(safe_div(1, "a"))

Output

done
2.0
done
cannot divide by zero
done
bad types: unsupported operand type(s) for /: 'int' and 'str'

Raising and custom exceptions

class InsufficientFunds(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFunds(f"need {amount - balance} more")
    return balance - amount

try:
    withdraw(10, 25)
except InsufficientFunds as e:
    print("caught:", e)

Output

caught: need 15 more

Catch the most specific exception you can handle; avoid a bare except: that hides bugs. Use raise to signal errors and assert for internal sanity checks.

Interview questions: Python basics

10 questions. Try to answer aloud in under a minute, then reveal. Tags show the level. All questions are also in the interview bank.

Basic What is the difference between a list and a tuple?

Lists are mutable and tuples are immutable. Tuples can be dictionary keys and are good for fixed records; lists suit collections that change.

Basic What are Python's main built-in types?

int, float, bool, str, None, list, tuple, dict, set, plus bytes and complex. Everything is an object.

Basic What does it mean that Python is dynamically typed?

Names are not bound to types; the type belongs to the object and is checked at runtime. Type hints can add optional static checking.

Basic What is the difference between == and is?

== compares values; is compares object identity (same object). Use is only for None, True and False.

Medium Explain the mutable default argument problem.

Default values are evaluated once when the function is defined, so a list or dict default is shared across calls. Use None and create the object inside the function.

Medium Explain LEGB scope.

Names resolve in Local, Enclosing function, Global, then Built-in scope. Assignment creates a local unless declared global or nonlocal.

Medium What are *args and **kwargs?

*args collects extra positional arguments into a tuple and **kwargs collects extra keyword arguments into a dict; at call sites * and ** unpack sequences and mappings.

Medium Why does 0.1 + 0.2 != 0.3?

Binary floating point cannot represent these decimals exactly. Compare with math.isclose or use Decimal for money.

Advanced How does Python pass arguments: by value or by reference?

By object reference (pass by assignment): the parameter name is bound to the same object. Mutating a mutable argument is visible to the caller; rebinding the name is not.

Advanced What is the difference between a shallow and a deep copy?

A shallow copy creates a new container holding references to the same inner objects; a deep copy recursively copies everything. Use copy.deepcopy when inner objects are mutable and must be independent.
