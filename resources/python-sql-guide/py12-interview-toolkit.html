Python for coding interviews: built-in complexity, idioms, recursion and typing

In a coding interview, Python lets you write less, but only if you know what each operation costs and which idiom to reach for. This part is a compact toolkit: the complexity table, the idioms, the traps and a routine for checking your own code.

import timeit
n = 20_000
lst, st = list(range(n)), set(range(n))
t_list = timeit.timeit("n - 1 in lst", globals={"n": n, "lst": lst}, number=300)
t_set = timeit.timeit("n - 1 in st", globals={"n": n, "st": st}, number=300)
front_list = timeit.timeit("l.insert(0, 1); l.pop(0)", setup="l = list(range(50000))", number=2000)
front_deque = timeit.timeit("d.appendleft(1); d.popleft()", setup="from collections import deque; d = deque(range(50000))", number=2000)
print("membership: set is faster than list by more than 20x:", t_list / t_set > 20)
print("front operations: deque is faster than list by more than 20x:", front_list / front_deque > 20)

Output

membership: set is faster than list by more than 20x: True
front operations: deque is faster than list by more than 20x: True

  • Both O(1) No.

  • O(1) for the list No.
  • O(log n) for both No.

Which structure gives O(1) removal from the front?

  • list pop(0) is O(n).
  • collections.deque Correct.
  • tuple Immutable.
  • str Immutable.

Idioms that save time and bugs

from collections import Counter, defaultdict, deque
import heapq, bisect, itertools, functools
nums = [4, 1, 3, 1, 5, 9, 2, 6]
print("enumerate:", [(i, x) for i, x in enumerate(nums, start=1)][:3])
print("zip + unpack:", [a * b for a, b in zip(nums, nums[1:])][:4])
print("sorted with key and reverse:", sorted(["bb", "a", "ccc", "dd"], key=lambda s: (-len(s), s)))
print("min/max with key:", max(["pear", "fig", "banana"], key=len), min(nums, default=None))
print("any/all:", any(x > 8 for x in nums), all(x > 0 for x in nums))
print("Counter:", Counter("mississippi").most_common(2))
d = defaultdict(list)
for w in ["eat", "tea", "tan", "ate", "nat", "bat"]: d["".join(sorted(w))].append(w)
print("group anagrams:", sorted(d.values()))
print("swap and chained comparison:", (lambda a, b: (b, a))(1, 2), 1 < 3 < 5)
print("slicing:", nums[::-1][:3], nums[-3:], nums[1:6:2])
print("ternary and walrus:", "even" if len(nums) % 2 == 0 else "odd", (n := len(nums)) > 5, n)
print("unpacking with *:", (lambda first, *rest: (first, rest))(*nums[:4]))
print("itertools:", list(itertools.combinations([1, 2, 3], 2)), list(itertools.accumulate([1, 2, 3, 4])), list(itertools.islice(itertools.count(10, 5), 3)))
print("string tricks:", "a,b,,c".split(","), " x ".strip(), "abc".startswith(("a", "z")), "x".join("123"), "Hello"[::-1], "ab" * 3)
print("ord/chr:", ord("a"), chr(ord("a") + 2), [chr(i) for i in range(97, 100)])
print("integer tricks:", divmod(17, 5), 17 // 5, -17 // 5, -17 % 5, pow(3, 4, 5), 10 ** 20, int("101", 2), bin(10), 7 & 3, 7 | 8, 7 ^ 2, 1 << 5)

The 2D grid idiom

grid = ["#..", ".#.", "..#"]
R, C = len(grid), len(grid[0])
DIRS = [(1, 0), (-1, 0), (0, 1), (0, -1)]
def neighbours(r, c):
    for dr, dc in DIRS:
        nr, nc = r + dr, c + dc
        if 0 <= nr < R and 0 <= nc < C: yield nr, nc
print(list(neighbours(0, 0)), "| transpose:", ["".join(col) for col in zip(*grid)], "| matrix without shared rows:", [[0] * 3 for _ in range(2)])
bad = [[0] * 3] * 2; bad[0][0] = 1
print("the aliasing trap [[0]*3]*2:", bad)

Output

[(1, 0), (0, 1)] | transpose: ['#..', '.#.', '..#'] | matrix without shared rows: [[0, 0, 0], [0, 0, 0]]
the aliasing trap [[0]*3]*2: [[1, 0, 0], [1, 0, 0]]

How this gets asked

What does -17 // 5 evaluate to in Python?

Floor division rounds toward negative infinity: -3.4 becomes -4.

What is wrong with grid = [[0] * 3] * 2?

  • It is invalid It runs.
  • Both rows are the same list object, so changing one changes both Correct.
  • It is too slow No.
  • Nothing No.

Use [[0] * 3 for _ in range(2)].

Recursion, limits and memoisation

CPython's default recursion limit is about 1000 frames, and each frame costs memory, so deep recursion (a path graph with 100,000 nodes) raises RecursionError. Options: convert to an explicit stack or iteration, or raise the limit carefully with sys.setrecursionlimit (risky: can crash the interpreter). Memoise overlapping subproblems with functools.lru_cache (or cache).

import sys
from functools import lru_cache
@lru_cache(maxsize=None)
def fib(n): return n if n < 2 else fib(n - 1) + fib(n - 2)
print("fib(80) with memoisation:", fib(80), "| cache info:", fib.cache_info().misses, "misses")
def depth(n): return 0 if n == 0 else 1 + depth(n - 1)
print("recursion limit is about", sys.getrecursionlimit() // 100 * 100)
try: depth(1_000_000)
except RecursionError: print("RecursionError for depth one million, so iterate or use an explicit stack")
def depth_iter(n):
    stack, d = [n], 0
    while stack:
        x = stack.pop()
        if x: stack.append(x - 1); d += 1
    return d
print("iterative version handles it:", depth_iter(1_000_000))

Output

fib(80) with memoisation: 23416728348467685 | cache info: 81 misses
recursion limit is about 1000
RecursionError for depth one million, so iterate or use an explicit stack
iterative version handles it: 1000000

For lru_cache, arguments must be hashable (convert lists to tuples). Clear the cache between independent test cases if you cache a function that reads global state.

How this gets asked

  • Use more RAM Not the limit.
  • Use globals No.

The limit is about 1000 frames by default.

Iterators, generators and laziness

Use generators to stream large data without building lists; know that generators are single-use.

def numbers():
    n = 0
    while True: yield n; n += 1
def take(it, k): return [next(it) for _ in range(k)]
squares = (x * x for x in numbers())
print(take(squares, 5), "| continues:", take(squares, 3))
gen = (x for x in range(3))
print(list(gen), list(gen), "(the second pass is empty: a generator is exhausted once consumed)")
print("sum of squares below one million, streamed:", sum(x * x for x in range(1_000_000)))

Output

[0, 1, 4, 9, 16] | continues: [25, 36, 49]
[0, 1, 2] [] (the second pass is empty: a generator is exhausted once consumed)
sum of squares below one million, streamed: 333332833333500000

How this gets asked

What happens if you iterate a generator twice?

  • The second pass is empty because the generator is exhausted Correct.
  • An error No.
  • It doubles the values No.

Create a new generator or materialise a list.

Numbers and precision

Python integers are arbitrary precision (no overflow), floats are 64-bit doubles. // floors toward negative infinity (-7 // 2 == -4), % takes the sign of the divisor, round is banker's rounding, and float("inf") is a convenient sentinel. When simulating 32-bit overflow (LeetCode style), mask explicitly.

print(-7 // 2, -7 % 2, int(-7 / 2), round(0.5), round(1.5), round(2.5))
print("exact big integers:", 2 ** 100, "| float limit:", 1e308 * 10, "| inf comparisons:", float("inf") > 10 ** 100)
to_int32 = lambda x: (x + 2**31) % 2**32 - 2**31
print("simulated int32 overflow:", to_int32(2**31), to_int32(2**31 - 1 + 5))
print("float equality pitfalls:", 0.1 + 0.2 == 0.3, abs(0.1 + 0.2 - 0.3) < 1e-9)

Output

-4 1 -3 0 2 2
exact big integers: 1267650600228229401496703205376 | float limit: inf | inf comparisons: True
simulated int32 overflow: -2147483648 -2147483644
float equality pitfalls: False True

Type hints in interviews

Hints document intent and help tools; they are not enforced at runtime. Interviewers like simple, accurate hints.

from typing import Optional, Iterable, Callable, TypeVar, Protocol
T = TypeVar("T")
def first(items: Iterable[T], default: Optional[T] = None) -> Optional[T]:
    return next(iter(items), default)
def apply_all(fns: list[Callable[[int], int]], x: int) -> list[int]:
    return [f(x) for f in fns]
class Shape(Protocol):
    def area(self) -> float: ...
class Sq:
    def __init__(self, s: float): self.s = s
    def area(self) -> float: return self.s ** 2
def total_area(shapes: list[Shape]) -> float: return sum(s.area() for s in shapes)
print(first([]), first("xyz"), apply_all([lambda v: v + 1, lambda v: v * 2], 5), total_area([Sq(2), Sq(3)]))
print("hints are metadata only:", first.__annotations__["default"])

Output

None x [6, 10] 13
hints are metadata only: ~T | None

Modern syntax: list[int], dict[str, int], int | None (3.10+), tuple[int, ...], TypedDict, dataclass, Literal, Final, and mypy/pyright for static checking.

A routine for coding questions

  1. Clarify: input types and ranges, duplicates, empty input, negative numbers, ordering, memory limits. Repeat the examples back.
  2. Brute force first: state it and its complexity.
  3. Optimise: name the pattern (hash map, two pointers, sort + scan, stack, heap, BFS, DP) and the target complexity.
  4. Code cleanly: small helper functions, meaningful names, no dead code. Python's expressiveness is an advantage; do not be so clever that it is unreadable.
  5. Test by hand: a normal case, the smallest case (empty, one element), duplicates, the largest or tricky boundary. Trace your code line by line.
  6. State complexity for time and space and mention trade-offs and follow-ups.

Pre-submission checklist

  • Off-by-one in ranges and slices (range(n) stops at n - 1).
  • Mutating a list while iterating it.
  • [[0]*c]*r aliasing; shallow versus deep copy.
  • Mutable default arguments.
  • is versus ==; None checks with is None.
  • Returning None by accident (list.sort(), append return None).
  • Integer division and negative modulo.
  • Recursion depth and cycles in graphs (use a visited set).
  • Empty input and single-element input.
Key idea

Choose structures by operation cost (set for membership, deque for both ends, heap for priorities), reach for the idioms (Counter, defaultdict, zip, enumerate, sorted with key), beware aliasing and recursion limits, and always test boundaries by hand before you say you are done.

Medium Why does [[0]*3]*2 cause bugs?

Both rows reference the same inner list, so mutating one row changes both. Use a comprehension.

Medium How do you sort by one key descending and another ascending?

Use a tuple key with the numeric field negated, or sort twice relying on stability.

Medium What is the default recursion limit and how do you avoid hitting it?

About 1000 frames. Convert to iteration or an explicit stack, or memoise to reduce depth; raise the limit cautiously.

Medium Why use collections.deque for BFS?

popleft is O(1), whereas list.pop(0) is O(n).

Medium What does functools.lru_cache require of arguments?

They must be hashable; convert lists to tuples.

Medium What can go wrong with a generator?

It is exhausted after one pass, so a second iteration yields nothing; recreate or materialise it.

Advanced How would you simulate 32-bit integer overflow in Python?

Python ints are unbounded, so mask explicitly, for example (x + 2**31) % 2**32 - 2**31.

Advanced Heap in Python: how do you get a max-heap?

heapq is a min-heap; push negated values or use tuples with negated priority.

Advanced What does sorted() guarantee that helps in multi-key sorts?

Stability: equal keys keep their original relative order, so you can sort by secondary keys first.

Advanced How do you structure your answer in a coding interview?

Clarify, state a brute force and its complexity, optimise by naming the pattern, code cleanly, test by hand with edge cases, and state time and space.

Advanced What are common sources of off-by-one errors in Python?

Half-open ranges and slices, range(n) stopping at n - 1, inclusive versus exclusive bounds in binary search and sliding windows.
