Concurrency versus parallelism, threads and locks, race conditions, queues, process pools, concurrent.futures, asyncio, tasks, gather, timeouts and how to choose.

Unit testing with unittest and pytest, mocking, logging, command-line tools, virtual environments, packaging, profiling, optimisation and security habits.

Readable code and refactoring, SOLID principles, and the design patterns Python programmers use: strategy, factory, observer, decorator, adapter, command, state, singleton alternatives, dependency injection, protocols and the repository pattern.

The core data-manipulation operations (filter, map, group, aggregate, join, sort, window, pivot) implemented in plain Python so you understand them, then mapped to pandas and NumPy code, plus cleaning, missing data, dates, memory and performance habits.

MediumAdvanced

PY11 Testing, debugging and profiling in depth: fixtures, mocks, property tests, tracing and performance

MediumAdvanced

The costs of Python's built-in operations, the idioms that make interview code short and correct, recursion limits and memoisation, iterators and itertools recipes, sorting keys, string and number tricks, type hints and a pre-submission checklist.

Relational ideas, creating tables, inserting and changing data, SELECT, WHERE, ORDER BY, LIMIT, NULL, DISTINCT, aggregate functions, GROUP BY and HAVING, with a sample shop database.

INNER, LEFT, RIGHT, FULL, CROSS and self joins, join pitfalls, subqueries, correlated subqueries, EXISTS, set operations, CASE, string, number and date functions.
