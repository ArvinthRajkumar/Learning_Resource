The standard library tour: pathlib, datetime, decimal, collections and friends

Python's slogan is batteries included. Knowing the standard library is the fastest way to write less code. This tour covers the modules that appear in real programs and interviews, each with an executed example.

Medium~5 hours

Files and paths: pathlib

pathlib.Path replaces string path juggling. It is cross-platform, readable and has the file operations built in.

import tempfile
from pathlib import Path
root = Path(tempfile.mkdtemp())
(root / "data").mkdir()
f = root / "data" / "notes.txt"
f.write_text("line one\nline two\nline three\n", encoding="utf8")
print("name:", f.name, "| stem:", f.stem, "| suffix:", f.suffix, "| parent:", f.parent.name)
print("exists:", f.exists(), "| is_file:", f.is_file(), "| non-empty:", f.stat().st_size > 0)
print("lines:", f.read_text(encoding="utf8").splitlines())
(root / "data" / "b.csv").write_text("x\n1\n"); (root / "data" / "a.csv").write_text("x\n2\n")
print("csv files:", sorted(p.name for p in (root / "data").glob("*.csv")))
print("recursive:", sorted(str(p.relative_to(root)).replace("\\", "/") for p in root.rglob("*") if p.is_file()))
print("with_suffix:", f.with_suffix(".md").name)

Output

name: notes.txt | stem: notes | suffix: .txt | parent: data
exists: True | is_file: True | non-empty: True
lines: ['line one', 'line two', 'line three']
csv files: ['a.csv', 'b.csv']
recursive: ['data/a.csv', 'data/b.csv', 'data/notes.txt']
with_suffix: notes.md

Always pass encoding= when opening text files. Use with open(...) or Path.read_text(); never leave files open. For large files iterate line by line, do not read() everything. shutil copies and deletes trees (shutil.copytree, shutil.rmtree); tempfile creates safe temporary files and directories.

Path objects are cross-platform and readable.

Dates and times

datetime has date, time, datetime, timedelta and (3.9+) zoneinfo for time zones.

from datetime import date, datetime, timedelta, timezone
d = date(2024, 1, 31)
print("weekday (Mon=0):", d.weekday(), "| iso:", d.isoformat(), "| +30 days:", d + timedelta(days=30))
a, b = datetime(2024, 3, 1, 9, 0), datetime(2024, 3, 3, 17, 30)
delta = b - a
print("difference:", delta, "| total hours:", delta.total_seconds() / 3600)
print("parsed:", datetime.strptime("25/12/2024 18:45", "%d/%m/%Y %H:%M"), "| formatted:", a.strftime("%A, %d %B %Y"))
utc = datetime(2024, 7, 1, 12, 0, tzinfo=timezone.utc)
ist = utc.astimezone(timezone(timedelta(hours=5, minutes=30), "IST"))
print("UTC:", utc.isoformat(), "| fixed-offset IST:", ist.isoformat())

Output

weekday (Mon=0): 2 | iso: 2024-01-31 | +30 days: 2024-03-01
difference: 2 days, 8:30:00 | total hours: 56.5
parsed: 2024-12-25 18:45:00 | formatted: Friday, 01 March 2024
UTC: 2024-07-01T12:00:00+00:00 | fixed-offset IST: 2024-07-01T17:30:00+05:30

Named zones come from zoneinfo (Python 3.9+), which reads the operating system's tz database (on Windows install the tzdata package):

from zoneinfo import ZoneInfo
utc.astimezone(ZoneInfo("America/New_York")).isoformat()   # '2024-07-01T08:00:00-04:00'  (daylight saving applied)
utc.astimezone(ZoneInfo("Asia/Kolkata")).isoformat()       # '2024-07-01T17:30:00+05:30'

Rules that prevent bugs: store and compute in UTC, convert to local time only for display; use timezone-aware datetimes (naive and aware cannot be compared); never add timedelta(days=30) to mean "one month" (use dateutil.relativedelta or calendar logic); datetime.now() is local and naive, datetime.now(timezone.utc) is aware.

from datetime import datetime, timezone
import calendar
print("days in Feb 2024:", calendar.monthrange(2024, 2)[1], "| leap 2100?", calendar.isleap(2100))
naive, aware = datetime(2024, 1, 1), datetime(2024, 1, 1, tzinfo=timezone.utc)
try:
    naive < aware
except TypeError as e:
    print("mixing naive and aware fails:", e)

Output

days in Feb 2024: 29 | leap 2100? False
mixing naive and aware fails: can't compare offset-naive and offset-aware datetimes

How this gets asked

How should you store timestamps?

  • Local naive time Ambiguous around DST.
  • UTC, timezone-aware, converting to local time for display Correct.
  • Strings in any format Hard to compare.
  • Two-digit years No.

UTC avoids daylight-saving and zone bugs.

Self-check

Why compare aware datetimes only with aware ones?

Naive and aware datetimes cannot be ordered; mixing raises TypeError.

Exact numbers: decimal and fractions

Binary floating point cannot represent most decimals exactly.

from decimal import Decimal, ROUND_HALF_UP, getcontext
from fractions import Fraction
print("0.1 + 0.2 =", 0.1 + 0.2, "| equal to 0.3?", 0.1 + 0.2 == 0.3)
print("Decimal:", Decimal("0.1") + Decimal("0.2"), "| equal to 0.3?", Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))
price = Decimal("19.995")
print("round half up:", price.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP), "| built-in round (banker's):", round(2.5), round(3.5))
print("Fraction:", Fraction(1, 3) + Fraction(1, 6), "| from float string:", Fraction("0.75"), "| limit_denominator:", Fraction(3.14159).limit_denominator(100))
getcontext().prec = 30
print("high precision 1/7:", Decimal(1) / Decimal(7))

Output

0.1 + 0.2 = 0.30000000000000004 | equal to 0.3? False
Decimal: 0.3 | equal to 0.3? True
round half up: 20.00 | built-in round (banker's): 2 4
Fraction: 1/2 | from float string: 3/4 | limit_denominator: 311/99
high precision 1/7: 0.142857142857142857142857142857

Use Decimal for money (construct from strings, never from floats), Fraction for exact rational arithmetic, and math.isclose to compare floats.

How this gets asked

Which type should hold money in Python?

  • float Binary rounding errors.
  • Decimal constructed from strings Correct.
  • complex No.
  • bytes No.

Never construct Decimal from a float.

What does round(2.5) return in Python 3? (banker's rounding)

Round half to even: 2.5 -> 2, 3.5 -> 4.

Self-check

Why is 0.1 + 0.2 not 0.3?

Decimal fractions like 0.1 have no exact binary floating-point representation.

import statistics as st, random, math, secrets
data = [2, 4, 4, 4, 5, 5, 7, 9]
print("mean", st.mean(data), "| median", st.median(data), "| mode", st.mode(data), "| pstdev", round(st.pstdev(data), 3), "| stdev", round(st.stdev(data), 3))

Collections, heapq and bisect

import heapq, bisect
from collections import Counter, defaultdict, deque, OrderedDict, namedtuple, ChainMap
words = "to be or not to be that is the question to".split()
c = Counter(words)
print("most common:", c.most_common(2), "| total:", sum(c.values()), "| c['be']:", c["be"], "| missing:", c["xyz"])
groups = defaultdict(list)
for w in words: groups[len(w)].append(w)
print("by length:", dict(groups))
dq = deque(maxlen=3)
for i in range(6): dq.append(i)
print("bounded deque keeps last three:", list(dq))
heap = [5, 1, 8, 3, 2]
heapq.heapify(heap)
print("heap pops in order:", [heapq.heappop(heap) for _ in range(3)], "| nlargest:", heapq.nlargest(2, [5, 1, 8, 3, 2]))
scores = [10, 20, 30, 40]
print("bisect insertion index for 25:", bisect.bisect(scores, 25), "| keeps list sorted:", (bisect.insort(scores, 25), scores)[1])
Point = namedtuple("Point", "x y")
p = Point(3, 4)
print(p, p.x, p._asdict(), "| ChainMap lookup:", ChainMap({"a": 1}, {"a": 2, "b": 3})["b"])

Output

most common: [('to', 3), ('be', 2)] | total: 11 | c['be']: 2 | missing: 0
by length: {2: ['to', 'be', 'or', 'to', 'be', 'is', 'to'], 3: ['not', 'the'], 4: ['that'], 8: ['question']}
bounded deque keeps last three: [3, 4, 5]
heap pops in order: [1, 2, 3] | nlargest: [8, 5]
bisect insertion index for 25: 2 | keeps list sorted: [10, 20, 25, 30, 40]
Point(x=3, y=4) 3 {'x': 3, 'y': 4} | ChainMap lookup: 3

How this gets asked

What does Counter.most_common(2) return?

  • The two smallest counts No.
  • The two most frequent items with their counts Correct.
  • Random items No.
  • A set No.

A list of (item, count) pairs.

Self-check

When do you use deque instead of list?

For fast appends and pops at both ends, e.g. queues and sliding windows.

Hashing, encoding and binary data

import hashlib, base64, struct, zlib, uuid, binascii
msg = "hello".encode("utf8")
print("sha256:", hashlib.sha256(msg).hexdigest()[:16], "... | md5 (non-security):", hashlib.md5(msg).hexdigest()[:16], "...")
print("base64:", base64.b64encode(msg).decode(), "| decoded:", base64.b64decode("aGVsbG8=").decode(), "| hex:", msg.hex())
packed = struct.pack("<IHf", 1_000_000, 7, 2.5)
print("struct bytes:", len(packed), "| unpacked:", struct.unpack("<IHf", packed))
data = b"abc" * 1000
print("zlib: ", len(data), "->", len(zlib.compress(data)), "bytes | crc32:", zlib.crc32(b"hello"))
print("uuid5 is deterministic:", uuid.uuid5(uuid.NAMESPACE_DNS, "example.com") == uuid.uuid5(uuid.NAMESPACE_DNS, "example.com"), "| uuid4 length:", len(str(uuid.uuid4())))
text = "héllo wörld"
print("utf-8 bytes:", len(text.encode("utf8")), "for", len(text), "characters |", text.encode("ascii", errors="replace"))

Output

sha256: 2cf24dba5fb0a30e ... | md5 (non-security): 5d41402abc4b2a76 ...
base64: aGVsbG8= | decoded: hello | hex: 68656c6c6f
struct bytes: 10 | unpacked: (1000000, 7, 2.5)
zlib:  3000 -> 30 bytes | crc32: 907060870
uuid5 is deterministic: True | uuid4 length: 36
utf-8 bytes: 13 for 11 characters | b'h?llo w?rld'

Hashes are one way and not encryption; for passwords use a slow salted function (hashlib.scrypt, pbkdf2_hmac); base64 is encoding, not secrecy. Always decode bytes to text with a stated encoding.

Running other programs: subprocess

import subprocess, sys
r = subprocess.run([sys.executable, "-c", "print('child says hi'); import sys; sys.exit(3)"], capture_output=True, text=True)
print("stdout:", r.stdout.strip(), "| return code:", r.returncode)
try:
    subprocess.run([sys.executable, "-c", "raise SystemExit(1)"], check=True)
except subprocess.CalledProcessError as e:
    print("check=True raised: exit status", e.returncode)
try:
    subprocess.run([sys.executable, "-c", "import time; time.sleep(5)"], timeout=0.3)
except subprocess.TimeoutExpired:
    print("timeout enforced")

Output

stdout: child says hi | return code: 3
check=True raised: exit status 1
timeout enforced

Pass a list, not a string with shell=True (shell injection risk). Always set timeout, capture output deliberately, and check return codes. Prefer library APIs over shelling out.

How this gets asked

Why avoid subprocess.run('cmd ' + user_input, shell=True)?

  • It is slower Minor.
  • Shell injection: user input can run arbitrary commands Correct.
  • It prints too much No.
  • It needs root No.

Pass an argument list without a shell.

Self-check

What three arguments make subprocess.run safe and reliable?

An argument list (not shell=True), a timeout, and checking the return code or check=True.

Key idea

Before writing a helper, check the standard library: pathlib for paths, datetime and zoneinfo for time, decimal for money, collections for counting and queues, heapq and bisect for ordered data, subprocess with a list and timeout, and secrets for anything security related.

Interview questions: Standard library

14 questions. Try to answer aloud in under a minute, then reveal. Tags show the level. All questions are also in the interview bank.

Basic Why prefer pathlib over os.path string handling?

Path objects are cross-platform, support the / operator, and bundle operations such as read_text, glob, exists and mkdir, producing more readable code.

Basic How do you read a large file without loading it all?

Iterate over the file object line by line (or in chunks) inside a with block, so memory stays constant.

Basic What does Counter do?

A dict subclass for counting hashable items, with most_common, arithmetic between counters, and zero for missing keys.

Medium Why use Decimal for money and how do you create one?

Binary floats cannot represent most decimal fractions exactly. Create Decimals from strings (Decimal('19.99')), never from floats, and quantize with an explicit rounding mode.

Medium How should you handle time zones?

Store and compute in timezone-aware UTC, convert to local zones only for display with zoneinfo, and never mix naive and aware datetimes.

Medium Why is round(2.5) equal to 2 in Python 3?

round uses banker's rounding (round half to even) to avoid statistical bias; use Decimal with ROUND_HALF_UP when a business rule needs conventional rounding.

Medium random versus secrets?

random is a deterministic pseudo-random generator for simulations; secrets uses the operating system's cryptographic source for tokens, passwords and keys.

Medium When would you use deque, heapq and bisect?

deque for O(1) operations at both ends and bounded windows; heapq for priority queues and top-k; bisect for binary search and keeping a list sorted.

Medium How do you run an external command safely?

subprocess.run with an argument list (no shell=True), a timeout, capture_output and check or an explicit return-code test.

Medium What is the difference between hashing, encoding and encryption?

Hashing is one-way and fixed length, encoding (base64) is reversible with no secret, encryption is reversible only with a key.

Advanced How do you format numbers in f-strings?

Use format specs: {x:.2f}, {x:,}, {x:>10}, {x:08.3f}, {x:.1%}, {n:#x}, and {name=} for debugging output.

Advanced How would you time two implementations fairly?

timeit with the same setup and enough repetitions, taking the minimum of several runs, avoiding one-time effects such as imports and warm-up.

Advanced Why add encoding= when opening text files?

The default depends on the platform and locale, so behaviour differs between machines. Specify encoding='utf-8' (or utf-8-sig for Excel files).

Advanced What does struct do?

Packs and unpacks Python values to fixed binary layouts with explicit byte order, used for binary file formats and network protocols.
