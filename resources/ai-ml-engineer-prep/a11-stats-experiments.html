Part A11

Statistics and experimentation for ML

Models are judged with numbers that are noisy. Statistics tells you how much to trust a difference. This part covers the tools interviewers ask about most: intervals, tests, power, multiple comparisons and A/B experiments, each verified by simulation.

MediumAdvanced~5 hours

Sampling and uncertainty

Population versus sample

We observe a sample and want to learn about a population. Any statistic computed from the sample (mean, accuracy) varies from sample to sample. Its spread is the standard error: for a mean it is s / sqrt(n), so quadrupling the data halves the uncertainty.

import random, math
random.seed(0)
population = [random.gauss(100, 15) for _ in range(100000)]
for n in (10, 100, 1000):
    means = []
    for _ in range(2000):
        sample = random.sample(population, n)
        means.append(sum(sample) / n)
    m = sum(means) / len(means)
    se = math.sqrt(sum((x - m) ** 2 for x in means) / len(means))
    print("n=%4d  spread of sample means %.2f   theory 15/sqrt(n) = %.2f" % (n, se, 15 / math.sqrt(n)))

Output

n=  10  spread of sample means 4.74   theory 15/sqrt(n) = 4.74
n= 100  spread of sample means 1.50   theory 15/sqrt(n) = 1.50
n=1000  spread of sample means 0.47   theory 15/sqrt(n) = 0.47

Central limit theorem (CLT)

The sample mean is approximately normal for large n regardless of the data's shape (given finite variance), with mean mu and standard deviation sigma / sqrt(n). This justifies most standard intervals and tests. It is slow for heavy-tailed data (income, revenue, latency) where outliers dominate: use medians, trimmed means, log transforms or the bootstrap.

How this gets asked

The standard deviation of a population is 20. What is the standard error of the mean for n = 100?

20 / sqrt(100) = 2.

The central limit theorem says that:

  • All data is normal No.
  • Sample means are approximately normal for large n, whatever the data's shape (finite variance) Correct.
  • Variance equals the mean No.
  • p-values are uniform No.

That is why many tests work even for non-normal data.

Self-check

Standard error of a mean?

sigma / sqrt(n); four times the data halves it.

Confidence intervals

A 95 percent confidence interval is built by a procedure that, over many repetitions, captures the true value 95 percent of the time. It does not mean "95 percent probability the true value is in this particular interval". For a mean: mean +/- 1.96 x s / sqrt(n). For a proportion p_hat (accuracy, click rate): p_hat +/- 1.96 sqrt(p_hat (1 - p_hat) / n), or the better-behaved Wilson interval for small samples or extreme p.

import random, math
random.seed(1)
true_p, n, trials, covered = 0.7, 200, 2000, 0
for _ in range(trials):
    x = sum(random.random() < true_p for _ in range(n))
    p = x / n
    se = math.sqrt(p * (1 - p) / n)
    if p - 1.96 * se <= true_p <= p + 1.96 * se:
        covered += 1
print("coverage of 95%% intervals: %.1f%%" % (100 * covered / trials))
def wilson(x, n, z=1.96):
    p = x / n; d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return round(c - h, 3), round(c + h, 3)
print("accuracy 95/100 -> Wilson interval", wilson(95, 100))
print("accuracy 950/1000 -> Wilson interval", wilson(950, 1000))

Output

coverage of 95% intervals: 94.8%
accuracy 95/100 -> Wilson interval (0.888, 0.978)
accuracy 950/1000 -> Wilson interval (0.935, 0.962)

The same 95 percent accuracy is far less certain with 100 test examples than with 1,000. Always report an interval with a metric, and be wary of leaderboard differences smaller than the interval.

How this gets asked

What does a 95 percent confidence interval mean?

  • 95 percent of the data lies in it No.
  • The procedure captures the true value in 95 percent of repeated experiments Correct.
  • There is a 95 percent chance the truth is in this interval A common misreading.
  • The effect is large No.

It is a statement about the long-run behaviour of the method.

Hypothesis testing

The logic

  1. State a null hypothesis H0 (no difference, no effect) and an alternative H1.
  2. Choose a significance level alpha (commonly 0.05).
  3. Compute a test statistic from the data.
  4. The p-value is the probability, if H0 were true, of seeing data at least as extreme as observed. If p < alpha, reject H0.
ErrorMeaningProbability
Type I (false positive)Reject a true H0alpha
Type II (false negative)Fail to reject a false H0beta
PowerDetect a real effect1 - beta (aim for 80 percent or more)

Common tests

QuestionTest
Mean of one group versus a valueOne-sample t-test
Two independent group meansWelch's t-test (does not assume equal variances)
Same units before and afterPaired t-test
Two proportions (A/B conversion)Two-proportion z-test
Categories versus expected countsChi-square test
Non-normal or ordinal dataMann-Whitney U (independent), Wilcoxon signed-rank (paired)
Two classifiers on the same test setMcNemar's test or exact sign test on disagreements (04)
Several groupsANOVA (then post-hoc tests)
Any statistic, any shapePermutation test or bootstrap
 
import random, math
random.seed(2)
a = [random.gauss(100, 15) for _ in range(40)]
b = [random.gauss(108, 15) for _ in range(40)]
def welch_t(x, y):
    mx, my = sum(x) / len(x), sum(y) / len(y)
    vx = sum((v - mx) ** 2 for v in x) / (len(x) - 1)
    vy = sum((v - my) ** 2 for v in y) / (len(y) - 1)
    return (my - mx) / math.sqrt(vx / len(x) + vy / len(y))
t = welch_t(a, b)
# permutation test: shuffle group labels many times
obs = abs(sum(b) / len(b) - sum(a) / len(a))
pool, count = a + b, 0
for _ in range(5000):
    random.shuffle(pool)
    if abs(sum(pool[40:]) / 40 - sum(pool[:40]) / 40) >= obs:
        count += 1
print("Welch t = %.2f, permutation p-value = %.4f" % (t, count / 5000))

Output

Welch t = 2.20, permutation p-value = 0.0312

What a p-value is not

  • Not the probability that H0 is true, nor that the result will replicate.
  • Not the size or importance of the effect: with huge samples trivial differences are "significant"; report an effect size and its interval.
  • A non-significant result is not proof of no effect (the test may be underpowered).
  • A p-value just below 0.05 from a single run is weak evidence.

How this gets asked

What is a p-value?

  • The probability the null is true No.
  • The probability of data at least this extreme if the null hypothesis were true Correct.
  • The effect size No.
  • The power No.

It is computed assuming H0.

Self-check

Type I and II errors and power?

False positive (alpha), false negative (beta), and power = 1 - beta.

Power and sample size

Before an experiment decide the minimum detectable effect (MDE) you care about. The sample needed per group for two proportions with alpha = 0.05 (two-sided) and power 80 percent is approximately n = 2 (1.96 + 0.84)^2 p (1 - p) / MDE^2.

def n_per_group(p, mde, z_alpha=1.96, z_beta=0.84):
    return int(2 * (z_alpha + z_beta) ** 2 * p * (1 - p) / mde ** 2) + 1
for mde in (0.02, 0.01, 0.005):
    print("baseline 10%%, detect %.1f point lift: %d users per group" % (mde * 100, n_per_group(0.10, mde)))

Output

baseline 10%, detect 2.0 point lift: 3528 users per group
baseline 10%, detect 1.0 point lift: 14112 users per group
baseline 10%, detect 0.5 point lift: 56448 users per group

Halving the detectable effect quadruples the sample. If you cannot get enough data, accept a larger MDE, use a more sensitive metric, reduce variance (CUPED: adjust by pre-experiment behaviour), or run longer.

How this gets asked

To halve the minimum detectable effect, how many times larger must the sample become?

n is proportional to 1 / MDE^2, so halving the MDE quadruples n.

Self-check

How do you size an A/B test?

Choose baseline rate, minimum detectable effect, alpha and power, then compute n (about 2 (1.96 + 0.84)^2 p(1 - p) / MDE^2 per group).

Multiple comparisons

Test 20 independent true-null hypotheses at alpha = 0.05 and you expect one false positive; the chance of at least one is 1 - 0.95^20 = 64 percent. This is p-hacking when it happens by accident (many metrics, segments, model variants). Corrections: Bonferroni (use alpha / m, conservative), Holm (step-down, uniformly better), and Benjamini-Hochberg (controls the false discovery rate, preferred for many tests).

import random
random.seed(3)
m, alpha = 100, 0.05
pvals = sorted(random.random() for _ in range(m))             # 100 tests where the null is true everywhere
print("raw 'significant' results:", sum(p < alpha for p in pvals))
print("Bonferroni significant   :", sum(p < alpha / m for p in pvals))
bh = max([i for i, p in enumerate(pvals, 1) if p <= alpha * i / m], default=0)
print("Benjamini-Hochberg       :", bh)

Output

raw 'significant' results: 6
Bonferroni significant   : 0
Benjamini-Hochberg       : 0

With every null true, about 5 raw tests look significant by chance, while corrected procedures report none. In model comparison the same applies when you try many hyperparameter settings on one validation set: the winner is partly luck (winner's curse); confirm on untouched data.

How this gets asked

You test 10 independent true nulls at alpha = 0.05. What is the probability of at least one false positive? (percent, nearest whole number)

1 - 0.95^10 = 0.401, about 40 percent.

Which correction controls the false discovery rate?

  • Bonferroni Controls family-wise error.
  • Benjamini-Hochberg Correct.
  • None No.
  • Tukey Different purpose.

BH is less conservative when many tests are run.

Self-check

Why correct for multiple comparisons?

With many tests some are significant by chance; corrections control the family-wise error or false discovery rate.

Bootstrap

Resample your data with replacement many times, recompute the statistic each time, and use the spread of those values as its uncertainty. No distributional formulas needed: works for medians, AUC, F1 and ratios.

import random
random.seed(4)
latency = [random.lognormvariate(3.0, 0.8) for _ in range(300)]       # skewed data
def p95(x): return sorted(x)[int(0.95 * len(x))]
boots = sorted(p95([random.choice(latency) for _ in latency]) for _ in range(2000))
print("p95 latency %.1f ms, 95%% bootstrap interval (%.1f, %.1f)" % (p95(latency), boots[50], boots[1949]))

Output

p95 latency 87.7 ms, 95% bootstrap interval (74.6, 116.6)

Cautions: needs independent observations (resample whole users, not rows, when rows cluster), can fail for extreme statistics (the maximum) and small samples.

Self-check

What does the bootstrap do?

Resamples the data with replacement to estimate the sampling distribution of any statistic.

Bayesian view and A/B decisions

A Bayesian A/B test models each conversion rate with a Beta distribution, updates it with the data (Beta(1 + successes, 1 + failures)), and reports the probability that B beats A and the expected loss from choosing wrongly. It answers the question people actually ask, and handles peeking more gracefully, though the prior and decision threshold still matter.

import random
random.seed(5)
a_conv, a_n, b_conv, b_n = 480, 10000, 540, 10000
wins, diffs = 0, []
for _ in range(20000):
    pa = random.betavariate(1 + a_conv, 1 + a_n - a_conv)
    pb = random.betavariate(1 + b_conv, 1 + b_n - b_conv)
    wins += pb > pa
    diffs.append(pb - pa)
diffs.sort()
print("P(B beats A) = %.3f, 95%% credible interval for the lift (%.4f, %.4f)" % (wins / 20000, diffs[500], diffs[19499]))

Output

P(B beats A) = 0.973, 95% credible interval for the lift (-0.0001, 0.0121)

Pitfalls in online experiments

PitfallRemedy
Peeking and stopping earlyFix sample size in advance, or use sequential or Bayesian methods
Sample ratio mismatch (SRM): traffic split differs from plannedCheck with a chi-square test; investigate bugs before trusting results
Novelty and primacy effectsRun long enough; look at effect over time
Network effects and interference (marketplaces, social)Cluster or switchback randomisation
Many metricsOne primary metric, guardrails, corrections for the rest
Simpson's paradoxA trend in each segment reverses in the aggregate; analyse by segment, and know the causal structure
Survivorship and selection biasCompare randomised groups, not self-selected ones

How this gets asked

Sample ratio mismatch in an A/B test indicates:

  • A great result No.
  • A problem with assignment or logging that invalidates the analysis until fixed Correct.
  • High power No.
  • A Bayesian prior No.

If the traffic split differs from plan, the groups may not be comparable.

Correlation, causation and causal thinking

Correlation is not causation. Confounders cause both variables (ice cream sales and drownings both rise in summer). The gold standard is a randomised controlled experiment, which balances confounders on average. When you cannot randomise: natural experiments, difference-in-differences, instrumental variables, regression discontinuity, matching or propensity scores, and causal graphs (DAGs) to decide what to adjust for (adjusting for a collider introduces bias). For ML: a model trained on observational data predicts, but does not tell you what happens if you intervene; recommender and policy decisions are interventions.

Key idea

Report effect sizes with intervals, size experiments by power, decide metrics in advance, correct for multiple looks, and remember a significant difference is a statement about noise, not about whether the effect matters.

Interview questions: Statistics and experiments

13 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What is a p-value?

The probability of data at least as extreme as observed if the null hypothesis were true; it is not the probability that the null is true.

Basic What is a confidence interval?

A range produced by a procedure that covers the true value in a stated fraction (such as 95 percent) of repeated experiments.

Basic Type I and Type II errors?

Type I is a false positive (probability alpha); Type II is a false negative (beta); power is 1 minus beta.

Medium What does the central limit theorem say?

Sample means are approximately normal for large n regardless of the data's distribution, with standard error sigma over sqrt(n).

Medium How do you size an A/B test?

Pick the baseline rate, minimum detectable effect, alpha and power, then n per group is about 2 (1.96 + 0.84)^2 p (1 - p) / MDE^2 for proportions.

Medium Why is peeking at an A/B test a problem?

Repeated looks inflate the false positive rate; fix the sample size in advance or use sequential or Bayesian methods.

Medium What are multiple comparisons and how do you correct them?

Many tests produce false positives by chance. Use Bonferroni or Holm to control family-wise error or Benjamini-Hochberg to control false discovery rate.

Medium When use the bootstrap?

To estimate uncertainty of any statistic (median, AUC, F1) without distributional assumptions, resampling independent units with replacement.

Advanced Explain Simpson's paradox.

A trend appearing in every subgroup reverses in the aggregate because group sizes differ; analyse by segment and understand the causal structure.

Advanced Frequentist versus Bayesian A/B testing?

Frequentist tests give p-values and intervals about long-run error rates; Bayesian tests give the probability that B beats A and expected loss from a prior and the data, which is easier to interpret.

Advanced How do you compare two classifiers on the same test set?

Use a paired test on disagreements (McNemar or exact sign test) or a paired bootstrap, not just the accuracy difference.

Advanced What is CUPED?

A variance reduction method that adjusts the metric using pre-experiment covariates, shrinking confidence intervals and the sample needed.

Advanced What is a confounder and how do you handle it?

A variable affecting both treatment and outcome. Randomise, or adjust using matching, regression, propensity scores, instrumental variables or causal graphs.
