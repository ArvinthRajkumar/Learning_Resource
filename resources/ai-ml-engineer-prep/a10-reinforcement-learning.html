Part A10

Reinforcement learning from scratch

In reinforcement learning an agent learns by trying actions and observing rewards. This part builds the theory from scratch and implements value iteration, Q-learning and a policy-gradient learner on tiny problems you can run and verify.

MediumAdvanced~5 hours

The framework

Agent, environment, reward

At each step the agent observes a state s, takes an action a, receives a reward r and moves to a new state s'. The goal is to maximise the cumulative reward, not just the immediate one. Unlike supervised learning there are no correct-answer labels, only a delayed, noisy scalar signal, and the agent's actions change the data it sees.

Markov decision process (MDP)

A formal model: states S, actions A, transition probabilities P(s' | s, a), rewards R(s, a), and a discount factor gamma between 0 and 1. The Markov property: the next state depends only on the current state and action, not the earlier history.

Return, policy, value

  • The return G_t = r_t + gamma r_(t+1) + gamma^2 r_(t+2) + ... is the discounted sum of future rewards. Discounting makes sums finite and prefers sooner rewards.
  • A policy pi(a | s) says which action to take in each state (deterministic or probabilistic).
  • The state-value V^pi(s) is the expected return starting in s and following pi; the action-value Q^pi(s, a) is the expected return after taking a in s, then following pi.
Bellman optimality equation
Q*(s, a) = R(s, a) + gamma sum over s' of P(s' | s, a) max over a' of Q*(s', a')
Q*
the best achievable value
gamma
discount factor
gamma = 0.9
rewards = [1, 1, 1, 10]
G = sum(gamma ** t * r for t, r in enumerate(rewards))
print("discounted return: %.3f" % G)
print("same rewards with gamma=0.5: %.3f" % sum(0.5 ** t * r for t, r in enumerate(rewards)))

A low gamma makes the agent short-sighted (the final 10 counts for little); a high gamma makes it plan far ahead.

Dynamic programming: when the model is known

If we know P and R, we can plan. Value iteration applies the Bellman optimality update repeatedly until values stop changing, then reads off the best action.

# A 1D corridor of 5 states. Actions: left or right. Reaching the right end (state 4) gives reward 1 and ends.
N, gamma = 5, 0.9
V = [0.0] * N
def step(s, a):                          # deterministic transitions; a = -1 or +1
    s2 = min(max(s + a, 0), N - 1)
    return s2, (1.0 if s2 == N - 1 and s != N - 1 else 0.0)
for it in range(50):
    new = V[:]
    for s in range(N - 1):               # state N-1 is terminal with value 0
        best = -1e9
        for a in (-1, 1):
            s2, r = step(s, a)
            best = max(best, r + gamma * (0.0 if s2 == N - 1 else V[s2]))
        new[s] = best
    V = new
print("values:", [round(v, 3) for v in V])
policy = []
for s in range(N - 1):
    qs = {a: step(s, a)[1] + gamma * (0.0 if step(s, a)[0] == N - 1 else V[step(s, a)[0]]) for a in (-1, 1)}
    policy.append("right" if qs[1] >= qs[-1] else "left")
print("policy:", policy)

Output

values: [0.729, 0.81, 0.9, 1.0, 0.0]
policy: ['right', 'right', 'right', 'right']

Values decay by gamma per step away from the goal (1, 0.9, 0.81, 0.729) and the policy is to head right. Variants: policy iteration (alternate evaluating a policy and improving it). Dynamic programming needs the model and a state space small enough to enumerate.

Learning without a model: Q-learning

Temporal-difference learning

Without the model, learn from sampled experience. After each step update the estimate towards a target built from the observed reward and the current estimate of the next state (bootstrapping):

Q-learning update
Q(s, a) <- Q(s, a) + alpha ( r + gamma max over a' of Q(s', a') - Q(s, a) )
alpha
learning rate
the bracket is the TD error
how wrong the old estimate was

Q-learning is off-policy: it learns the value of the greedy policy while behaving with an exploratory one. SARSA is on-policy: its target uses the action actually taken next, so it learns the value of the exploring policy (it is more cautious near hazards).

import random
random.seed(0)
# Gridworld 4 wide, 3 tall. Start (0,0). Goal (3,2) gives +1. Pit (3,1) gives -1. Both end the episode. Step cost -0.04.
W, H = 4, 3
GOAL, PIT = (3, 2), (3, 1)
actions = [(0, 1), (0, -1), (1, 0), (-1, 0)]              # up, down, right, left (y up)
def move(s, a):
    x, y = s[0] + a[0], s[1] + a[1]
    if not (0 <= x < W and 0 <= y < H): x, y = s
    return (x, y)
Q = {((x, y), a): 0.0 for x in range(W) for y in range(H) for a in range(4)}
alpha, gamma, eps = 0.2, 0.95, 0.2
for episode in range(5000):
    s = (0, 0)
    for _ in range(100):
        a = random.randrange(4) if random.random() < eps else max(range(4), key=lambda i: Q[(s, i)])
        s2 = move(s, actions[a])
        r = 1.0 if s2 == GOAL else -1.0 if s2 == PIT else -0.04
        done = s2 in (GOAL, PIT)
        target = r + (0 if done else gamma * max(Q[(s2, i)] for i in range(4)))
        Q[(s, a)] += alpha * (target - Q[(s, a)])
        s = s2
        if done: break
arrows = "^v><"
for y in reversed(range(H)):
    print(" ".join("G" if (x, y) == GOAL else "X" if (x, y) == PIT else arrows[max(range(4), key=lambda i: Q[((x, y), i)])] for x in range(W)))

Output

> > > G
^ ^ ^ X
^ ^ ^ <

The printed grid is the learned policy: arrows point towards the goal in the top-right row and away from the pit. The agent never knew the transition rules; it learned them through trial and error.

Exploration

If the agent only exploits its current beliefs it may never discover better actions. Strategies: epsilon-greedy, decaying epsilon, optimistic initial values, UCB and Thompson sampling (A9), entropy bonuses in policy gradients, and intrinsic motivation (curiosity, novelty) for sparse rewards.

How this gets asked

Q-learning is called off-policy because:

  • It never uses a policy No.
  • It learns the value of the greedy policy while behaving with a different, exploratory policy Correct.
  • It needs no rewards No.
  • It uses a model No.

The max in the target ignores the action actually taken next.

Deep reinforcement learning

When states are images or huge, a table is impossible; use a neural network to approximate Q or the policy.

The deadly triad: function approximation, bootstrapping and off-policy learning together can diverge; replay buffers, target networks and careful tuning counter it.

Policy gradients in a runnable example

import math, random
random.seed(2)
# A 2-armed bandit with a softmax policy; REINFORCE with a running baseline.
arm_reward = [0.3, 0.7]
theta = [0.0, 0.0]
def pi(th):
    m = max(th); e = [math.exp(t - m) for t in th]; s = sum(e); return [x / s for x in e]
baseline = 0.0
for _ in range(3000):
    p = pi(theta)
    a = random.choices([0, 1], p)[0]
    r = 1.0 if random.random() < arm_reward[a] else 0.0
    adv = r - baseline
    baseline += 0.01 * (r - baseline)
    for i in range(2):
        theta[i] += 0.1 * adv * ((1 if i == a else 0) - p[i])
print("policy probabilities:", [round(x, 3) for x in pi(theta)])

Output

policy probabilities: [0.003, 0.997]

The policy shifts towards the arm with higher success probability. The baseline does not change the expected gradient but cuts its variance.

How this gets asked

Why does DQN use a target network and experience replay?

  • To save memory No.
  • To stabilise learning by breaking correlation between samples and keeping the bootstrap target from shifting every step Correct.
  • To speed up the GPU No.
  • To add noise No.

They tackle the instability of bootstrapping with function approximation.

What does a baseline do in policy gradient methods?

  • Biases the gradient It does not.
  • Reduces the variance of the gradient estimate without changing its expectation Correct.
  • Increases the reward No.
  • Replaces the policy No.

Advantage = return minus baseline.

Self-check

Value-based versus policy-based methods?

Value-based learn Q and act greedily; policy-based optimise the policy directly and handle continuous actions; actor-critic combines both.

RL and language models

Language generation is a sequential decision problem: the state is the prompt plus tokens so far, an action is the next token, and the reward arrives at the end (a preference model's score or a correctness check). RLHF with PPO (A6) fine-tunes the policy with a KL leash to a reference model; GRPO and other methods use sampled groups; verifiable-reward RL trains reasoning models. Differences from classic RL: a gigantic action space (the vocabulary), a deterministic transition (append the token), a single sparse terminal reward, and the policy starts from a strong pretrained model, which makes exploration far easier.

Key idea

RL turns a delayed reward into a value estimate through the Bellman equation, then improves the policy using it. Q-learning does this with a table, DQN with a network, policy gradients by directly following the gradient of expected return.

How this gets asked

In RLHF the KL penalty keeps the policy close to a model.

It limits drift and reward hacking.

How does RLHF map onto RL?

State is the prompt plus generated tokens, action is the next token, reward is a preference model or verifier score at the end.

Interview questions: Reinforcement learning

13 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What is a Markov decision process?

States, actions, transition probabilities, rewards and a discount factor, with the next state depending only on the current state and action.

Basic What is the discount factor?

A number between 0 and 1 that weights future rewards; low values make the agent short-sighted, high values far-sighted.

Basic Exploration versus exploitation?

Exploitation uses the best known action; exploration tries others to learn. Methods include epsilon-greedy, UCB, Thompson sampling and entropy bonuses.

Medium State the Bellman equation.

The value of a state-action equals the immediate reward plus the discounted expected value of the best next state-action.

Medium Q-learning versus SARSA?

Both are TD methods; Q-learning is off-policy (target uses the max over next actions), SARSA is on-policy (target uses the action actually taken), making it more conservative near hazards.

Medium Why does DQN use experience replay and a target network?

Replay breaks correlations between consecutive samples and reuses data; the target network keeps the bootstrap target stable.

Medium What is a policy gradient and why use a baseline?

It increases the probability of actions in proportion to the return. A baseline reduces variance without biasing the gradient.

Medium Actor-critic methods?

An actor updates the policy using a critic's value estimates as the baseline or advantage, combining low variance with direct policy optimisation.

Advanced What is the deadly triad?

Function approximation, bootstrapping and off-policy training together can make value learning diverge; mitigated by replay, target networks and careful design.

Advanced Why is PPO popular?

Its clipped objective limits how far each update moves the policy, giving stable and simple on-policy training; it is used in robotics, games and RLHF.

Advanced How does RLHF map onto RL?

The prompt plus generated tokens is the state, the next token is the action, a reward model or verifier gives a terminal reward, and a KL penalty keeps the policy near the reference.

Advanced What is reward hacking and how do you reduce it?

Optimising a flawed reward without achieving the intent. Improve reward design, add constraints and penalties, use human feedback, adversarial testing and monitor behaviour.

Advanced What is offline RL?

Learning a policy from a fixed dataset without interacting; the challenge is avoiding actions poorly covered by the data, handled with conservative value estimates or policy constraints.
