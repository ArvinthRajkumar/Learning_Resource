Every LLM question rests on one architecture. This page builds it piece by piece: a neuron, a layer, embeddings, attention computed by hand, the transformer block, positions, and how to count its parameters exactly.

BasicMedium~2.5 hours

Neural networks and activations

Intuition

A neuron computes a weighted sum of its inputs plus a bias, then applies a non-linear "squash". A layer is many neurons side by side, which is a matrix multiply. Stacking layers lets the network build features of features. Without the non-linearity, any stack of layers collapses into one linear map, so the activation function is what gives depth its power.

The mechanism

ActivationFormulaNotes
Sigmoid1 / (1 + e^-z)squashes to (0, 1). Saturates, so gradients vanish. Used for probabilities and gates.
Tanh(e^z - e^-z)/(e^z + e^-z)(-1, 1), zero-centered, still saturates
ReLUmax(0, z)cheap, no saturation for z > 0. Can leave "dead" units.
GELUz x Phi(z)smooth ReLU. Used in BERT and GPT-2.
SwiGLU(Swish(x W) * (x V)) W2gated MLP used in Llama-family models. Three weight matrices.
Softmaxe^z_i / sum e^z_jturns a vector of scores into a probability distribution (output layer, attention)

Common traps

  • "More layers without activations add expressiveness." Composed linear maps are still linear.
  • Forgetting biases when counting parameters (transformer LLMs like Llama often have no biases, but classic MLPs do).
  • Sigmoid hidden layers in deep nets cause vanishing gradients. ReLU-family activations plus residuals fixed this.

How this gets asked

An MLP maps 3 inputs to 4 hidden units to 2 outputs, with biases. How many parameters?

(3 x 4 + 4) + (4 x 2 + 2) = 16 + 10 = 26.

Self-check

Why are non-linear activations necessary?

Without them, stacked layers collapse to a single linear transformation.

What is a vanishing gradient?

Gradients shrink as they backpropagate through many saturating layers, so early layers barely learn.

Which activation and MLP style do Llama models use?

SwiGLU: a gated MLP with gate, up and down projections.

Embeddings: turning tokens into vectors

Intuition

A neural network needs numbers, so each token ID indexes a row in a big learned table, its embedding vector (for example 4,096 numbers). Training arranges these vectors so related meanings sit close together. The famous word2vec picture: king - man + woman lands near queen. Distance in this space approximates similarity in meaning, which is exactly what semantic search (part 03) exploits.

The mechanism

  • Token embedding table: vocab x d. Llama 3 has 128,256 x 4,096, about 525M numbers, 1.05 GB in bf16. Lookup is just row indexing.
  • LM head: the final d x vocab matrix maps the last hidden state to logits over the vocabulary. Some models tie it to the embedding table to save parameters.
  • Contextual embeddings: after attention layers, a token's vector depends on its context ("bank" by a river vs a bank account). Static word2vec vectors could not do that.
  • Sentence or document embeddings (for retrieval): pool token vectors (mean or a special token) from an encoder trained with a contrastive loss, so that matching query and passage pairs score high.
Contrastive (InfoNCE) loss for embedding models, with in-batch negatives
L = -log( exp(sim(q, p+)/tau) / sum_j exp(sim(q, p_j)/tau) )
p+
the positive (matching) passage
p_j
all passages in the batch, used as negatives
tau
temperature (for example 0.05)

How this gets asked

How are sentence-embedding models for retrieval typically trained?

  • Next-token prediction only That gives a language model, not well-separated sentence vectors.
  • Contrastive learning on (query, relevant passage) pairs with other passages as negatives Correct.
  • k-means on word counts That is clustering.
  • PCA on one-hot vectors Not how modern models are trained.

Pull matching pairs together and push others apart (InfoNCE with in-batch and hard negatives).

Self-check

Size of a 128k x 4096 embedding table in bf16?

About 1.05 GB.

Static vs contextual embeddings?

Static: one vector per word (word2vec). Contextual: the vector depends on the surrounding words (transformer outputs).

What are weight-tied embeddings?

Using the same matrix for the input embedding and the output LM head.

Attention, computed by hand

Intuition

Each token asks a question (its query), every token advertises what it contains (its key), and every token carries information to hand over (its value). A token's output is a weighted average of all values, weighted by how well its query matches each key. "It" in "The animal didn't cross the street because it was tired" learns to put high weight on "animal".

The formula

Scaled dot-product attention (Vaswani et al., 2017)
Attention(Q, K, V) = softmax( Q K^T / sqrt(d_k) + M ) V Q = X W_Q, K = X W_K, V = X W_V
X
n x d token representations
d_k
key/query dimension per head
M
mask: 0 where allowed, -inf where blocked (causal: future positions)
sqrt(d_k)
keeps dot products at unit scale. For random unit-variance vectors, q.k has variance d_k (std 11.3 at d_k = 128), which would saturate the softmax.

Worked example

d_k = 2. Query q = [1, 0]. Keys k1 = [1, 0], k2 = [0, 1], k3 = [1, 1]. Values v1 = [1, 0], v2 = [0, 1], v3 = [1, 1]
  1. Dot products: q.k1 = 1, q.k2 = 0, q.k3 = 1. Divide by sqrt(2): [0.7071, 0, 0.7071].
  2. Softmax: exp gives [2.028, 1, 2.028], sum 5.056, so weights [0.4011, 0.1978, 0.4011].
  3. Output: 0.4011 x [1, 0] + 0.1978 x [0, 1] + 0.4011 x [1, 1] = [0.8022, 0.5989].
output [0.8022, 0.5989]

Common traps

  • "Attention is linear in sequence length." Standard attention is O(n^2 d) in compute. KV caching makes each decode step O(n), not the whole thing.
  • Mask applied after the softmax. It must be added before, so the allowed weights renormalize to 1.
  • Forgetting the 1/sqrt(d_k) scale.

How this gets asked

Why does scaled dot-product attention divide by sqrt(d_k)?

  • To make attention linear time It does not change complexity.
  • To normalize the values It scales the scores, not V.
  • Dot products grow in magnitude with d_k, which pushes the softmax into saturated regions with tiny gradients Correct.
  • To implement the causal mask The mask is separate.

For random unit-variance vectors, Var(q.k) = d_k. Dividing by sqrt(d_k) restores unit variance.

Self-check

Write the attention formula.

softmax(Q K^T / sqrt(d_k) + mask) V.

What does the causal mask do?

It stops position i from attending to positions after i, by adding -inf before the softmax.

Self-attention vs cross-attention?

Self: Q, K, V come from the same sequence. Cross: Q from one sequence (decoder), K and V from another (encoder outputs).

Multi-head attention and the transformer block

Intuition

One attention pattern cannot capture everything (syntax, coreference, position). Multi-head attention runs several smaller attentions in parallel, each with its own projections, and concatenates the results. A transformer block is: attention (tokens exchange information), then an MLP (each token processes what it gathered), each wrapped in a residual connection and normalization. Stack dozens of these blocks.

  • Multi-head: d = n_heads x head_dim (4096 = 32 x 128). Each head attends in its own subspace. The concatenated output goes through W_O (d x d).
  • Residual connections: output = x + f(x). This gives a "highway" for gradients and lets layers learn refinements.
  • LayerNorm vs RMSNorm: LayerNorm subtracts the mean and divides by the std, with a learned scale and shift. RMSNorm only divides by the root mean square, which is cheaper and works as well (used in Llama).
  • Pre-norm (normalize before each sub-layer) trains more stably at depth than the original post-norm.
  • MLP width: classic 4d (GELU). SwiGLU uses about (8/3)d per matrix, but three matrices (Llama 2 7B: 11,008).
  • Dropout is often 0 in modern LLM pretraining, since one epoch over huge data rarely overfits.

How this gets asked

Select all true statements about transformer blocks.

  • Residual connections help gradients flow through deep stacks True.
  • The MLP mixes information across token positions False: the MLP is applied per token. Attention mixes across positions.
  • RMSNorm skips mean-centering compared with LayerNorm True.
  • Multi-head attention multiplies the parameter count by the number of heads False: heads split d. W_Q, W_K, W_V, W_O stay d x d in total for MHA.

Attention mixes across positions, the MLP works within each position, and residuals plus normalization keep it trainable.

Self-check

Pre-norm vs post-norm?

Pre-norm normalizes the input of each sub-layer (x + f(norm(x))), which is more stable for deep models. Post-norm normalizes after the residual add (the original Transformer).

head_dim for d = 4096 with 32 heads?

128.

Which sub-layer moves information between tokens?

Self-attention.

Positional encodings: sinusoidal, learned, RoPE, ALiBi

Intuition

Attention by itself is order-blind: shuffle the tokens and each token sees the same set of keys. Positional information must be injected. Early transformers added a position vector to each embedding. Modern LLMs rotate queries and keys by an angle that depends on position (RoPE), so the attention score depends on the relative distance between tokens.

Sinusoidal (original Transformer) and RoPE
PE(pos, 2i) = sin(pos / 10000^(2i/d)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d)) RoPE: rotate each 2-D pair of q and k by angle pos * theta_i, theta_i = base^(-2i/d) then q_m . k_n depends only on (m - n)
pos
token position
i
dimension pair index
base
10,000 in the original papers. Long-context models raise it (Llama 3 uses 500,000).

Example: position 1, the first dimension pair (i = 0): PE = [sin 1, cos 1] = [0.8415, 0.5403]. Low dimensions rotate fast (fine position), high dimensions rotate slowly (coarse position). With base 10,000 and d = 128, the slowest pair has a wavelength of about 54,000 positions.

Sinusoidalfixed vectors added to embeddingsoriginal Transformerlimited

How this gets asked

What property makes RoPE attractive for LLMs?

  • It removes the need for attention No.
  • It adds no computation at all It adds a cheap rotation.
  • It gives every position the same vector Then there would be no position information.
  • The q.k score depends on relative position, and the context can be extended by rescaling the rotation frequencies Correct.

Relative-position behavior comes from rotations: R(m)^T R(n) = R(n - m).

Self-check

Why does a transformer need positional information?

Self-attention is permutation-invariant. Without positions, word order is lost.

RoPE in one sentence?

Rotate each pair of query and key dimensions by a position-dependent angle, so their dot product encodes relative distance.

Name one context-extension method for RoPE models.

Position interpolation, NTK-aware scaling or YaRN, usually followed by some long-context fine-tuning.

Mixture of experts (MoE)

  • Total parameters are large, but active parameters per token are small. Mixtral 8x7B, per Mistral: about 46.7B total, about 12.9B active (top-2 of 8 experts), so about 28% of the weights are used per token.
  • Compute per token scales with active parameters. Memory scales with total parameters: all experts must be loaded.
  • Challenges: load balancing (auxiliary loss so experts get used evenly), communication when experts are spread over GPUs (expert parallelism), and batching efficiency.

How this gets asked

For an MoE model with 47B total and 13B active parameters, which is true at inference?

  • It needs memory for only 13B parameters All experts must be resident (or offloaded with a speed penalty).
  • FLOPs per token are roughly those of a 13B dense model, but memory is roughly that of a 47B model Correct.
  • It is always faster than a 7B dense model More active parameters and routing overhead.
  • The router picks experts per document Usually per token, per layer.

MoE decouples compute (active) from capacity (total).

Self-check

Why are encoder models used for embeddings and rerankers?

Bidirectional attention sees the whole input at once, which suits understanding and scoring tasks.

What does an MoE router do?

It scores the experts for each token and sends the token to the top-k, weighting their outputs.

MoE memory vs compute?

Memory ~ total parameters. Compute ~ active parameters.

Counting a transformer's parameters exactly

Intuition

Almost all the weights live in a few big matrices per layer: four attention projections and the MLP matrices. Count those per layer, multiply by the number of layers, and add the embedding table and LM head. You can then reproduce a model's published size, which is a great interview flex.

Llama-style decoder (no biases)
per layer = attention + MLP + norms attention = d*d (Q) + d*d (O) + 2 * d * (n_kv * head_dim) (K, V) MLP = 3 * d * ffn (SwiGLU: gate, up, down) norms = 2 * d total = L * per_layer + vocab * d (embed) + vocab * d (LM head, if untied) + d rule of thumb (MHA, ffn = 4d, 2 MLP matrices): ~ 12 * L * d^2
Llama 2 7B: vocab 32,000, d 4,096, L 32, ffn 11,008, MHA (32 KV heads), untied
  1. Attention per layer: 4 x 4096^2 = 67,108,864.
  2. MLP per layer: 3 x 4096 x 11,008 = 135,266,304.
  3. Norms per layer: 8,192. Layer total: 202,383,360. Times 32: 6,476,267,520.
  4. Embedding + LM head: 2 x 32,000 x 4,096 = 262,144,000. Final norm: 4,096.
  5. Total: 6,738,415,616. That is the "6.74B" on the model card. The 12Ld^2 rule gives 6.44B, close.
6,738,415,616 parameters (exact)

Llama 3 8B (vocab 128,256, ffn 14,336, 8 KV heads): the same formula gives 8,030,261,248. GQA shrinks K and V to 4096 x 1024 each, and the bigger vocabulary adds about 0.8B in embeddings alone. Code: part 08.

How this gets asked

Roughly how many parameters does one MHA transformer layer with d = 4096 and a 4d two-matrix MLP have?

  • ~16M That is one d x d matrix.
  • ~67M That is attention only (4d^2).
  • ~201M 12 d^2 = 12 x 16.8M = 201M.

Self-check

Where do most parameters of a 7B model live?

The MLPs (about two thirds), then the attention projections. Embeddings are a few percent (more with large vocabularies).

How does GQA change the parameter count?

K and V projections become d x (n_kv x head_dim) instead of d x d.

12 L d^2 for L = 32, d = 4096?

About 6.44B.

Interview questions: deep learning and transformers

Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What problem does self-attention solve compared with RNNs?

Every token can directly attend to every other token in one step (no long sequential chain), which captures long-range dependencies better and parallelizes across the sequence during training.

Basic What are Q, K and V in attention?

Learned projections of each token: the query says what a token is looking for, the key what it offers, the value what it passes along. Weights come from softmax(QK^T / sqrt(d_k)), and the output is the weighted sum of V.

Basic Why do transformers need positional encodings?

Self-attention is permutation-invariant, so without position information word order is lost. Positions are added (sinusoidal or learned) or injected into attention (RoPE, ALiBi).

Basic What is an embedding?

A learned dense vector representing a token (or item) such that similar meanings are close in vector space. Token embeddings are rows of a vocab x d table.

Basic Encoder-only vs decoder-only vs encoder-decoder: when do you use each?

Encoder-only (BERT) for understanding tasks, embeddings and rerankers. Decoder-only (GPT, Llama) for generation and chat. Encoder-decoder (T5) for sequence-to-sequence tasks like translation.

Medium Why divide by sqrt(d_k) in attention?

Dot products of random unit-variance vectors have variance d_k. Large scores saturate the softmax and kill gradients. Scaling restores unit variance.

Medium What is multi-head attention and why use it?

Several attention operations in parallel on lower-dimensional projections (d split across heads), concatenated and projected by W_O. Different heads can capture different relations (syntax, coreference, position).

Medium What is the role of residual connections and layer normalization?

Residuals (x + f(x)) give gradients a direct path and let layers learn refinements. Normalization keeps activations well scaled. Pre-norm placement stabilizes deep training.

Medium What is the causal mask?

A mask adding -inf to attention scores for future positions before the softmax, so token i only attends to tokens up to i. It makes next-token training valid and enables parallel teacher forcing.

Medium What is the computational complexity of self-attention?

O(n^2 d) compute and O(n^2) memory for the score matrix per head, for sequence length n. FlashAttention keeps compute exact but avoids materializing the n x n matrix in HBM.

Medium Explain RoPE.

Rotary position embedding rotates each 2-D pair of query and key dimensions by an angle proportional to position, so q_m . k_n depends on m - n (relative position). Context can be extended by rescaling frequencies (position interpolation, NTK, YaRN).

Medium What is the difference between LayerNorm and RMSNorm?

LayerNorm subtracts the mean and divides by the standard deviation, with a learned scale and bias. RMSNorm divides by the root mean square only (no centering), which is cheaper and works as well. Llama uses RMSNorm.

Medium How many parameters are in a transformer layer, roughly?

For MHA with a 4d MLP: about 4d^2 attention + 8d^2 MLP = 12d^2. For Llama 2 7B (d = 4096, SwiGLU 11,008) it is 202M per layer, and 32 layers plus embeddings gives 6.74B.

Advanced What is mixture of experts and what are its tradeoffs?

MLP layers are replaced by many experts, with a router sending each token to the top-k. Compute scales with active parameters, memory with total parameters. Tradeoffs: load balancing, communication (expert parallelism), and higher memory per unit of compute.

Advanced MQA vs GQA vs MHA: what changes and why does it matter?

They differ in the number of K/V heads: MHA has one per query head, GQA groups query heads to share K/V heads, MQA has a single K/V head. Fewer KV heads shrink the KV cache and memory bandwidth at decode, with usually small quality loss for GQA.

Advanced How does FlashAttention speed up attention without approximation?

It tiles Q, K, V into on-chip SRAM blocks and computes softmax incrementally (online softmax with running max and sum), never writing the n x n matrix to HBM. Fewer memory reads and writes give faster, exact attention.

Advanced How would you extend a model's context window from 8k to 128k?

Rescale RoPE frequencies (position interpolation, NTK-aware scaling, or YaRN), then continue training on long documents. Ensure efficient attention kernels, and evaluate with long-context benchmarks (needle-in-a-haystack, multi-doc QA). Watch KV cache memory.
