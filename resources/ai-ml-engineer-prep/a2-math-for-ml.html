Math for machine learning: linear algebra, calculus, probability and information theory

You do not need a maths degree for machine learning, but you do need a handful of ideas used everywhere: dot products, gradients, probability, entropy and optimisation. Each is explained from scratch and verified with a short program.

BasicMedium~6 hours

Vectors and matrices

Vectors and the dot product

A vector is a list of numbers, a point or direction in space. The dot product a . b = sum(a_i b_i) measures alignment: large and positive when the vectors point the same way, zero when perpendicular. The length (norm) is ||a|| = sqrt(a . a). Cosine similarity a . b / (||a|| ||b||) compares direction only, which is why it is used for embeddings.

import math
a, b = [1.0, 2.0, 3.0], [4.0, 0.0, -1.0]
dot = sum(x * y for x, y in zip(a, b))
norm = lambda v: math.sqrt(sum(x * x for x in v))
print("dot", dot, "norms", round(norm(a), 3), round(norm(b), 3))
print("cosine", round(dot / (norm(a) * norm(b)), 3))
print("cosine of a with 2a:", round(sum(x * 2 * x for x in a) / (norm(a) * norm([2 * x for x in a])), 3))

Output

dot 1.0 norms 3.742 4.123
cosine 0.065
cosine of a with 2a: 1.0

Matrices as transformations

A matrix W (with m rows and n columns) maps an n-dimensional vector to an m-dimensional one: y = W x. A neural-network layer is exactly this plus a bias and a non-linearity. Matrix multiplication C = A B has C_ij = sum_k A_ik B_kj, takes m x n times n x p to m x p, costs about 2 m n p floating point operations, and is not commutative.

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
A = [[1, 2], [3, 4]]
B = [[0, 1], [1, 0]]
print("AB =", matmul(A, B))
print("BA =", matmul(B, A))
rot = [[0, -1], [1, 0]]            # rotate by 90 degrees
print("rotate (1, 0):", [sum(rot[i][j] * [1, 0][j] for j in range(2)) for i in range(2)])

Output

AB = [[2, 1], [4, 3]]
BA = [[3, 4], [1, 2]]
rotate (1, 0): [0, 1]

Eigenvalues, eigenvectors and SVD

An eigenvector v of a matrix A satisfies A v = lambda v: it is only stretched by lambda, not turned. For a covariance matrix the eigenvectors are the principal directions and the eigenvalues the variances along them (PCA, A1). The singular value decomposition A = U S V^T exists for any matrix; truncating to the largest singular values gives the best low-rank approximation (compression, LoRA, latent semantic analysis).

import math
A = [[2.0, 1.0], [1.0, 2.0]]       # eigenvalues 3 and 1, eigenvectors (1,1) and (1,-1)
v = [1.0, 0.0]
for _ in range(60):                 # power iteration converges to the dominant eigenvector
    w = [A[0][0] * v[0] + A[0][1] * v[1], A[1][0] * v[0] + A[1][1] * v[1]]
    n = math.hypot(*w); v = [w[0] / n, w[1] / n]
lam = v[0] * (A[0][0] * v[0] + A[0][1] * v[1]) + v[1] * (A[1][0] * v[0] + A[1][1] * v[1])
print("eigenvector", [round(x, 3) for x in v], "eigenvalue", round(lam, 3))

Output

eigenvector [0.707, 0.707] eigenvalue 3.0

Calculus and gradients

Derivatives and gradients

The derivative f'(x) is the slope of f at x: how fast the output changes per unit input. For a function of many inputs the gradient is the vector of partial derivatives; it points in the direction of steepest increase. Training moves parameters against the gradient of the loss.

f = lambda x: x ** 3 - 2 * x
fprime = lambda x: 3 * x ** 2 - 2
x, h = 1.5, 1e-6
numeric = (f(x + h) - f(x - h)) / (2 * h)       # central difference
print("analytic", fprime(x), "numeric", round(numeric, 6))

Output

analytic 4.75 numeric 4.75

A numerical gradient check like this is the standard way to test a hand-written backward pass.

The chain rule is backpropagation

If y = f(g(x)) then dy/dx = f'(g(x)) g'(x). A neural network is a long composition of functions, and backpropagation applies the chain rule layer by layer from the loss back to each weight, reusing intermediate results.

import math
# y = sigmoid(w * x + b), loss = (y - t)^2 for one example
x, t = 2.0, 1.0
w, b = 0.3, -0.1
z = w * x + b
y = 1 / (1 + math.exp(-z))
loss = (y - t) ** 2
# chain rule: dL/dw = dL/dy * dy/dz * dz/dw
dL_dy = 2 * (y - t)
dy_dz = y * (1 - y)
dz_dw = x
grad_w = dL_dy * dy_dz * dz_dw
def L(w_):
    return (1 / (1 + math.exp(-(w_ * x + b))) - t) ** 2
numeric = (L(w + 1e-6) - L(w - 1e-6)) / 2e-6
print("chain rule", round(grad_w, 6), "numeric", round(numeric, 6))

Output

chain rule -0.354894 numeric -0.354894

Convexity

A function is convex if the line between any two points lies above the graph; a convex function has a single global minimum, so gradient descent cannot get stuck (linear and logistic regression losses). Neural-network losses are non-convex, with many local minima and saddle points, yet gradient descent still finds good solutions in practice.

How this gets asked

  • Chain rule Correct.
  • L'Hopital's rule No.
  • Bayes' rule No.

The loss is a composition of layer functions and gradients are chained backwards.

Probability and statistics

Basics

A random variable takes values with given probabilities. Expectation E[X] = sum(x p(x)), variance Var(X) = E[(X - E[X])^2]. Conditional probability P(A|B) = P(A and B) / P(B). Independence: P(A and B) = P(A) P(B).

Bayes' rule

Bayes' rule
P(H | D) = P(D | H) P(H) / P(D)
P(H)
prior belief
P(D | H)
likelihood of the data under H
P(H | D)
posterior

Classic example: a disease affects 1 percent of people; a test is 95 percent sensitive and 90 percent specific. A positive result means far less than 95 percent chance of disease:

prior, sens, spec = 0.01, 0.95, 0.90
p_pos = sens * prior + (1 - spec) * (1 - prior)
posterior = sens * prior / p_pos
print("P(disease | positive) = %.3f" % posterior)

Output

P(disease | positive) = 0.088

Only about 9 percent: the rare condition dominates. This base-rate reasoning appears in fraud, spam and medical models, and explains why precision falls when the positive class is rare.

The central limit theorem: the average of many independent samples is approximately normal, whatever the original distribution (with finite variance).

import random
random.seed(0)
means = [sum(random.random() for _ in range(30)) / 30 for _ in range(5000)]   # averages of uniform draws
m = sum(means) / len(means)
sd = (sum((x - m) ** 2 for x in means) / len(means)) ** 0.5
inside = sum(abs(x - m) < sd for x in means) / len(means)
print("mean %.3f, std %.3f (theory %.3f), within 1 std: %.2f (normal: 0.68)" % (m, sd, (1 / 12 / 30) ** 0.5, inside))

Output

mean 0.500, std 0.052 (theory 0.053), within 1 std: 0.68 (normal: 0.68)

Maximum likelihood and MAP

Maximum likelihood estimation (MLE) picks the parameters that make the observed data most probable. It is the origin of most losses: Gaussian noise gives mean squared error, Bernoulli gives binary cross-entropy, categorical gives cross-entropy. MAP adds a prior: a Gaussian prior on weights equals L2 regularisation; a Laplace prior equals L1.

import math
data = [1, 0, 1, 1, 0, 1, 1, 1]          # coin flips
def loglik(p): return sum(math.log(p if x else 1 - p) for x in data)
best = max((i / 100 for i in range(1, 100)), key=loglik)
print("MLE of p: %.2f (sample mean %.2f)" % (best, sum(data) / len(data)))

Output

MLE of p: 0.75 (sample mean 0.75)

Information theory

Entropy, cross-entropy and KL divergence

  • Entropy H(p) = -sum p log p: the average surprise; how unpredictable a distribution is. A fair coin has 1 bit; a certain outcome has 0.
  • Cross-entropy H(p, q) = -sum p log q: the average cost of coding events from p using a code built for q. This is the classification loss with p the true labels.
  • KL divergence KL(p || q) = H(p, q) - H(p) >= 0: the extra cost of using q instead of p; zero only when they are equal; not symmetric.
import math
def H(p): return -sum(x * math.log2(x) for x in p if x > 0)
def CE(p, q): return -sum(a * math.log2(b) for a, b in zip(p, q) if a > 0)
def KL(p, q): return CE(p, q) - H(p)
fair, biased = [0.5, 0.5], [0.9, 0.1]
print("H(fair)=%.3f H(biased)=%.3f" % (H(fair), H(biased)))
print("CE(fair, biased)=%.3f KL(fair||biased)=%.3f KL(biased||fair)=%.3f" % (CE(fair, biased), KL(fair, biased), KL(biased, fair)))

Output

H(fair)=1.000 H(biased)=0.469
CE(fair, biased)=1.737 KL(fair||biased)=0.737 KL(biased||fair)=0.531

The asymmetry (0.737 versus 0.531) matters: forward KL KL(data || model) punishes the model for missing modes; reverse KL punishes it for putting mass where there is no data. Perplexity is 2^H (or e^H with natural logs): the effective number of equally likely choices (F3). Mutual information measures how much knowing one variable tells about another.

Softmax and temperature

softmax(z)_i = e^(z_i) / sum_j e^(z_j) turns scores into probabilities. Dividing the scores by a temperature T changes sharpness: low T approaches argmax, high T approaches uniform (06). Subtract the maximum before exponentiating for numerical stability.

How this gets asked

KL divergence KL(p || q) is:

  • Symmetric It is not.
  • Always non-negative and zero only when p = q Correct.
  • Equal to entropy No.
  • Negative for similar distributions No.

Gibbs' inequality guarantees non-negativity.

Cross-entropy minus entropy equals the divergence.

H(p, q) - H(p) = KL(p || q).

Cross-entropy = entropy + KL divergence.

Optimisation

Gradient descent and its relatives

theta <- theta - lr x gradient. Variants:

MethodUpdate ideaNotes
SGDGradient on a mini-batchNoisy but cheap
MomentumKeep a running average of gradientsSmooths noise, speeds along valleys
RMSPropDivide by a running average of squared gradientsPer-parameter step sizes
AdamMomentum plus RMSProp with bias correctionThe default for deep learning
AdamWAdam with decoupled weight decayStandard for transformers
 
import math
# Minimise f(x, y) = x^2 + 10 y^2 (a narrow valley) with plain GD, momentum and Adam.
grad = lambda x, y: (2 * x, 20 * y)
def run(update, steps=60):
    x, y, state = 1.0, 1.0, {}
    for t in range(1, steps + 1):
        gx, gy = grad(x, y)
        x, y = update(x, y, gx, gy, state, t)
    return x * x + 10 * y * y
def gd(x, y, gx, gy, s, t, lr=0.05): return x - lr * gx, y - lr * gy
def momentum(x, y, gx, gy, s, t, lr=0.05, b=0.9):
    vx, vy = s.get("v", (0, 0)); vx, vy = b * vx + gx, b * vy + gy; s["v"] = (vx, vy)
    return x - lr * vx, y - lr * vy
def adam(x, y, gx, gy, s, t, lr=0.1, b1=0.9, b2=0.999):
    m = s.get("m", (0, 0)); v = s.get("v", (0, 0))
    m = (b1 * m[0] + (1 - b1) * gx, b1 * m[1] + (1 - b1) * gy)
    v = (b2 * v[0] + (1 - b2) * gx * gx, b2 * v[1] + (1 - b2) * gy * gy)
    s["m"], s["v"] = m, v
    mh = (m[0] / (1 - b1 ** t), m[1] / (1 - b1 ** t)); vh = (v[0] / (1 - b2 ** t), v[1] / (1 - b2 ** t))
    return x - lr * mh[0] / (math.sqrt(vh[0]) + 1e-8), y - lr * mh[1] / (math.sqrt(vh[1]) + 1e-8)
for name, u in (("gradient descent", gd), ("momentum", momentum), ("adam", adam)):
    print("%-16s final loss %.6f" % (name, run(u)))

Learning rate

Too small: slow. Too large: oscillation or divergence. Common practice: warm-up (ramp up the rate), then decay (cosine or linear). Tune the learning rate first, since it matters more than almost any other hyperparameter.

Local minima, saddles, generalisation

In high dimensions most critical points are saddle points, not bad minima. Flat minima tend to generalise better; SGD noise, large learning rates and regularisation bias solutions toward them.

Key idea

Almost all of ML is: write a loss from a probabilistic assumption (MLE), compute its gradient with the chain rule, and descend it with a good optimiser while watching a held-out set.

Interview questions: Math for ML

13 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What is a dot product and what does it measure?

The sum of element-wise products; it measures alignment, large and positive when vectors point the same way, zero when perpendicular.

Basic What is a gradient?

The vector of partial derivatives of a function; it points in the direction of steepest increase, so gradient descent moves against it.

Basic State Bayes' rule.

P(H | D) = P(D | H) P(H) / P(D): the posterior equals likelihood times prior divided by evidence.

Basic What is the chain rule and why is it central to deep learning?

The derivative of a composition is the product of derivatives. Backpropagation applies it layer by layer from the loss back to each weight.

Medium Why does a rare disease test with high accuracy often give a low positive predictive value?

Base rates dominate: with 1 percent prevalence, 95 percent sensitivity and 90 percent specificity, false positives from the large healthy group outnumber true positives, giving about 9 percent.

Medium What are eigenvalues and eigenvectors and where do they appear in ML?

A v = lambda v: directions only scaled by the matrix. Covariance eigenvectors are principal components; eigenvalues are variances along them. Also used in spectral methods and stability analysis.

Medium Entropy, cross-entropy and KL divergence?

Entropy is average surprise; cross-entropy is the cost of coding p with a code for q; KL(p||q) equals cross-entropy minus entropy, is non-negative and asymmetric.

Medium Why does MLE with Gaussian noise give squared error?

The Gaussian log likelihood is a constant minus the squared residual over twice the variance, so maximising it minimises squared error.

Medium What does a Gaussian prior on weights correspond to?

L2 regularisation (MAP estimation); a Laplace prior corresponds to L1.

Advanced Why is the SVD important?

Every matrix factors as U S V^T; truncating to the largest singular values gives the best low-rank approximation, used in compression, PCA, recommender systems and LoRA.

Advanced Compare SGD, momentum, RMSProp and Adam.

SGD follows noisy gradients; momentum averages gradients to smooth them; RMSProp scales steps by running squared gradients; Adam combines both with bias correction.

Advanced What is convexity and why does it matter?

A convex loss has a single global minimum, so gradient descent converges to it. Neural network losses are non-convex, yet SGD still finds good solutions in practice.

Advanced Why subtract the maximum before computing softmax?

It prevents overflow in exp without changing the result, since softmax is invariant to adding a constant to all logits.
