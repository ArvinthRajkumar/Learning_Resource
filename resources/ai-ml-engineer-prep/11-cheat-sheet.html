Formulas and numbers

ML basics

P = TP/(TP+FP) R = TP/(TP+FN) F1 = 2PR/(P+R) CE = -log p(correct); perplexity = exp(CE) Bias^2 + Variance + noise = expected squared error
  • TP 40, FP 10, FN 20, TN 930: P 0.8, R 0.667, F1 0.727, accuracy 0.97 (misleading).
  • AUC = P(random positive scores above random negative). PR-AUC for rare positives.
  • Overfit (train much better than val): more data, L2/dropout, early stopping. L1 gives sparse weights.
  • Fit scalers and imputers on train only (leakage). Split time series by time.

Optimization

SGD: w -= lr * g Adam: m = b1 m + (1-b1) g; v = b2 v + (1-b2) g^2; w -= lr * m_hat / (sqrt(v_hat)+eps)
  • lr too high diverges ((w-3)^2 with lr 1.1 explodes). Warmup + cosine decay + gradient clipping.
  • AdamW = decoupled weight decay. Backprop = chain rule. Training stores activations.

Transformer basics

Attention = softmax(Q K^T / sqrt(d_k) + mask) V params/layer ~ 12 d^2 (MHA, 4d MLP); SwiGLU MLP = 3 d ffn
  • Llama 2 7B: 32 x (4d^2 + 3 d 11008 + 2d) + 2 x 32000 d + d = 6,738,415,616.
  • sqrt(d_k): unit variance for the scores. Causal mask: -inf before the softmax. Cost O(n^2 d).
  • RoPE rotates q, k so scores depend on relative position. RMSNorm, pre-norm, residuals.
  • Encoder (BERT): embeddings and rerankers. Decoder (GPT): generation. MoE: compute ~ active, memory ~ total.

Training, scaling, system design

train FLOPs ~ 6 N D; inference ~ 2 N per token; Chinchilla ~ 20 tokens/param Little's law: concurrency = rate x time; QPS = per_day / 86,400
  • 6.74B x 2T tokens = 8.1e22 FLOPs, about 180k A100-hours at 40% MFU.
  • ZeRO 1/2/3 shards optimizer states / + gradients / + parameters. bf16 needs no loss scaling.
  • pass@k = 1 - C(n-c, k)/C(n, k). n = 10, c = 3: pass@5 = 0.917.
  • Cascade 80% at cost 1 + 20% at cost 10 = 2.8. Autoscale on queue depth and KV use, not CPU.

KV cache

2 x L x H_kv x d_head x S x B x bytes
  • H_kv = KV heads (GQA), NOT query heads. The 2 is for K and V.
  • 32 L, 8 KV, 128, fp16: 128 KiB/token. x 4 x 8192 = 4 GiB.
  • Llama-2-7B (MHA): 512 KiB/token. Llama-3-8B: 128 KiB. 70B (80 L, 8 KV): 320 KiB.
  • MHA : GQA(8) : MQA = 32 : 8 : 1 for a 32-head model. fp8 KV halves it.

Roofline and decoding speed

intensity = FLOPs / bytes; ridge = peak FLOP/s / bandwidth t_token ~ weight_bytes / bandwidth (batch 1)
  • Decode at batch 1 is about 1 FLOP/byte (bf16), so memory bound. Prefill is compute bound.
  • Ridge: A100 about 153, H100 about 295 FLOP/byte.
  • 8B bf16 on H100: 4.78 ms/token (about 209 tok/s ceiling). int4: 1.23 ms.
  • W4A16: dequantize to 16-bit, then multiply. No int4 matmul and no fewer layers.

Throughput: helps / hurts

  • Helps: continuous batching, PagedAttention, prefix caching, chunked prefill, TP/PP, FlashAttention, fp8 KV cache, quantized weights.
  • Hurts: disabling the KV cache, raising max_new_tokens for all requests.
  • TTFT = prefill (+ queue). ITL = decode.

Speculative decoding

accept x w.p. min(1, p(x)/q(x)); on reject sample max(0, p - q) normalized E[tokens/pass] = (1 - a^(k+1)) / (1 - a)
  • Output distribution is exactly the target's. Works at any temperature. Quality is not capped by the draft.
  • A rejection does not cost an extra full pass. a = 0.8, k = 4 gives 3.36 tokens per pass.

Constrained decoding and prompt caching

  • Masks illegal tokens to -inf. Guarantees syntax and schema, not values, and you still need evals.
  • Add "unknown" to enums. Put the reasoning field BEFORE the answer field.
  • Cache = longest identical prefix. Order: static (system, tools), then semi-static (manual), then dynamic (question).
  • Tamil: 3 bytes per char in UTF-8, plus English-heavy BPE merges, gives about 3x the tokens.

LoRA / QLoRA / DPO

h = W x + (alpha/r) B A x; params/module = r (d_in + d_out)
  • r = 16 on q, v (4096 x 4096) over 32 layers = 8,388,608. alpha 32 / r 16 = scale 2.
  • Only A, B trained. B is initialized to 0. Merge for zero latency. Saves gradient and optimizer memory, NOT activations.
  • QLoRA: NF4 frozen base + bf16 adapters + double quantization + paged optimizers.
DPO: -log sig(beta[(log pi(y_w) - log ref(y_w)) - (log pi(y_l) - log ref(y_l))])

Frozen reference, no reward model, offline. Init loss = ln 2. KTO: unpaired labels. ORPO: no reference model. GRPO: group-relative advantages, no critic.

BM25

sum_t idf(t) f (k1+1) / (f + k1 (1 - b + b |D|/avgdl)) idf = ln(1 + (N - n + 0.5)/(n + 0.5)); k1 = 1.2, b = 0.75
  • Distinct query terms. avgdl over ALL docs. n = number of docs containing t. No stemming.
  • The tf part saturates at k1 + 1 = 2.2. Average-length doc: f = 1 gives 1.0, f = 2 gives 1.375.

RRF, metrics

RRF = sum 1/(k + rank), rank 1-based, k = 60 DCG@k = sum gain_i / log2(i + 1); nDCG = DCG / IDCG(all judged)
  • recall@k = hits / all relevant. precision@k = hits / k.
  • MRR = mean of 1/first-hit rank (0 if none). AP = sum of P@rank over hits / all relevant.
  • Jaccard >= 0.8 in integers: 5|A∩B| >= 4|A∪B|.

RAG diagnosis

  • Low recall@k: fix retrieval (hybrid BM25 + dense, chunking, query rewrite).
  • High recall, low accuracy: cross-encoder rerank, then pass the top 3 to 5.
  • New embedding model: re-embed EVERYTHING (blue/green, dual-write).
  • Cosine = dot product after L2 normalization. HNSW: efSearch. IVF: nprobe.

Paired significance

sign test: p = 2 sum_{k=max(b,c)}^{n} C(n,k)/2^n, n = b + c McNemar: (b-c)^2/(b+c); corrected (|b-c|-1)^2/(b+c)
  • Only discordant pairs matter. 18 vs 12 gives p = 0.3616, not significant.
  • With 30 discordant you need at least 21 to 9 for p < 0.05. The unpaired z-test is the wrong tool.
  • SE = sqrt(p(1-p)/n). 80% on 200 gives about +/- 5.5 points. Prefer Wilson intervals.
  • m tests: 1 - 0.95^m false-positive risk (20 tests: 0.64). Bonferroni alpha/m.

Decoding

p_i = exp((z_i - max z)/T) / sum exp((z_j - max z)/T)
  • [2, 1, 0]: T = 1 gives .665/.245/.090. T = 0.5 gives .867/.117/.016.
  • top-p: shortest prefix with sum >= p, then renormalize. min-p keeps p >= min_p x p_max.
  • Beam prunes by prefix score, so it is not optimal. Width 1 = greedy. Normalize by length^alpha.
  • Perplexity = exp(-mean logprob).

Agents

  • Timeout = unknown outcome. Idempotency key generated ONCE per logical operation and reused on retries.
  • At-least-once + idempotent = exactly-once effect.
  • Backoff: uniform(0, min(cap, base x 2^n)). Retry 429, 5xx and timeouts only, with bounded attempts.
  • Outbox: DB write + message in one transaction. Saga: compensating actions.
  • Injection: least privilege + human approval for risky actions.

Coding problem gotchas

  • (a) sort (-score, i). Does not fit: continue. Dedup only vs picked. Return sorted.
  • (b) distinct terms, fixed summation order, sort (-score, i), drop score 0.
  • (c) depth, in_str, esc. Escape check first. Ignore everything outside except "{".
  • (d) (-score, seq) ascending. Loop steps - 1 times. Extend all by all.
