Part A14

Probabilistic machine learning: Bayesian inference, MCMC, Gaussian processes and uncertainty

A model that says 'the answer is 0.7' is less useful than one that says 'about 0.7, give or take 0.1, and I have seen little data like this'. This part builds the tools that quantify uncertainty: priors and posteriors, sampling, Gaussian processes, mixtures and calibration.

Advanced~6 hours

Frequentist, likelihood and Bayesian views

All three start from a model p(data | theta) with parameters theta.

ViewTreats parameters asAnswer
Maximum likelihood (MLE)Fixed unknown numbersThe theta that makes the data most probable
Maximum a posteriori (MAP)Random with a priorThe mode of the posterior (MLE plus a prior, i.e. regularisation)
BayesianRandom variablesThe whole posterior distribution p(theta | data)

Bayes' rule: posterior = likelihood x prior / evidence, that is p(theta | D) = p(D | theta) p(theta) / p(D). The prior encodes what you believed before seeing the data; the posterior is that belief updated by the evidence. With a lot of data the posterior concentrates and the prior matters less; with little data the prior matters a lot.

L2 regularisation equals a Gaussian prior on the weights and L1 a Laplace prior, so regularised models are MAP estimates in disguise.

How this gets asked

L2 regularisation corresponds to which prior on the weights?

  • Uniform No.
  • Gaussian Correct.
  • Laplace That is L1.
  • None No.

Ridge regression is MAP estimation with a Gaussian prior.

Self-check

MLE versus MAP versus full Bayes?

MLE maximises the likelihood, MAP maximises likelihood times prior, full Bayes keeps the whole posterior distribution.

Conjugate priors: exact Bayesian updating

For some prior-likelihood pairs the posterior has the same form as the prior (a conjugate prior), so updating is just arithmetic. The classic case: coin flips (Bernoulli) with a Beta prior. Beta(a, b) after observing h heads and t tails becomes Beta(a + h, b + t).

def beta_summary(a, b):
    mean = a / (a + b); var = a * b / ((a + b) ** 2 * (a + b + 1))
    return mean, var ** 0.5
prior = (1, 1)                                              # uniform: we know nothing
print("prior Beta(1,1): mean %.2f, std %.2f" % beta_summary(*prior))
heads, tails = 7, 3
post = (prior[0] + heads, prior[1] + tails)
print(f"after {heads} heads and {tails} tails -> Beta{post}: mean %.3f, std %.3f (MLE would say %.1f)" % (*beta_summary(*post), heads / (heads + tails)))
informative = (20, 20)                                      # a strong belief that the coin is fair
post2 = (informative[0] + heads, informative[1] + tails)
print(f"with a strong 'fair coin' prior Beta(20,20) -> Beta{post2}: mean %.3f" % beta_summary(*post2)[0])
big = (prior[0] + 700, prior[1] + 300)
print("with 1000 flips (700 heads) the prior hardly matters: mean %.3f, std %.3f" % beta_summary(*big))

Output

prior Beta(1,1): mean 0.50, std 0.29
after 7 heads and 3 tails -> Beta(8, 4): mean 0.667, std 0.131 (MLE would say 0.7)
with a strong 'fair coin' prior Beta(20,20) -> Beta(27, 23): mean 0.540
with 1000 flips (700 heads) the prior hardly matters: mean 0.700, std 0.014

Other conjugate pairs: Gaussian likelihood with Gaussian prior (for the mean), Poisson with Gamma, multinomial with Dirichlet. They power A/B testing posteriors (A11), Naive Bayes smoothing (a Dirichlet prior is Laplace smoothing) and bandits.

Credible versus confidence intervals

A 95% credible interval is a range that contains the parameter with 95% posterior probability (given the model and prior). A 95% confidence interval is a procedure that captures the true value in 95% of repeated experiments. The Bayesian statement is usually the one people want; the price is choosing a prior and being honest about it.

import math
def beta_pdf_grid(a, b, n=2001):
    xs = [i / (n - 1) for i in range(n)]
    ys = [(x ** (a - 1) * (1 - x) ** (b - 1)) if 0 < x < 1 else 0.0 for x in xs]
    total = sum(ys); return xs, [y / total for y in ys]
def credible_interval(a, b, mass=0.95):
    xs, ps = beta_pdf_grid(a, b)
    cum, lo, hi = 0.0, None, None
    for x, p in zip(xs, ps):
        cum += p
        if lo is None and cum >= (1 - mass) / 2: lo = x
        if hi is None and cum >= 1 - (1 - mass) / 2: hi = x
    return lo, hi
lo, hi = credible_interval(8, 4)
print(f"posterior Beta(8,4): 95% credible interval ({lo:.2f}, {hi:.2f}) | P(theta > 0.5) = {sum(p for x, p in zip(*beta_pdf_grid(8, 4)) if x > 0.5):.2f}")

Output

posterior Beta(8,4): 95% credible interval (0.39, 0.89) | P(theta > 0.5) = 0.89

How this gets asked

What does a 95% credible interval say?

  • The procedure covers the truth 95% of the time That is a confidence interval.
  • The parameter lies in the interval with 95% posterior probability Correct.
  • The data lies in the interval No.
  • The model is 95% right No.

It is conditional on the model and prior.

Sampling when there is no formula: MCMC

Most real posteriors are not conjugate. Markov chain Monte Carlo (MCMC) draws samples from a distribution known only up to a constant. Metropolis-Hastings: from the current point propose a nearby one; accept it with probability min(1, p(new) / p(old)); otherwise stay. After a burn-in, the chain's visited points are samples from the target. Histograms of samples give means, intervals and any other summary.

import math, random
random.seed(1)
data = [random.gauss(5.0, 2.0) for _ in range(30)]                 # unknown mean and std
def log_post(mu, sigma):
    if sigma <= 0: return -math.inf
    ll = sum(-math.log(sigma) - (x - mu) ** 2 / (2 * sigma ** 2) for x in data)
    log_prior = -mu ** 2 / (2 * 100 ** 2) - sigma / 10               # vague priors
    return ll + log_prior
mu, sigma, lp = 0.0, 1.0, log_post(0.0, 1.0)
samples, accepted = [], 0
for step in range(30000):
    mu2, sigma2 = mu + random.gauss(0, 0.4), sigma + random.gauss(0, 0.3)
    lp2 = log_post(mu2, sigma2)
    if math.log(random.random()) < lp2 - lp: mu, sigma, lp = mu2, sigma2, lp2; accepted += 1
    if step >= 5000: samples.append((mu, sigma))                    # discard burn-in
mus = sorted(s[0] for s in samples); sigmas = sorted(s[1] for s in samples)
q = lambda xs, p: xs[int(p * len(xs))]
print(f"acceptance rate {accepted / 30000:.2f} (about 0.2 to 0.5 is healthy)")
print(f"mean mu: posterior median {q(mus, 0.5):.2f}, 95% interval ({q(mus, 0.025):.2f}, {q(mus, 0.975):.2f}) | sample mean of data {sum(data) / len(data):.2f}")
print(f"std sigma: posterior median {q(sigmas, 0.5):.2f}, 95% interval ({q(sigmas, 0.025):.2f}, {q(sigmas, 0.975):.2f}) | true value 2.0")

Output

acceptance rate 0.49 (about 0.2 to 0.5 is healthy)
mean mu: posterior median 5.25, 95% interval (4.59, 5.91) | sample mean of data 5.24
std sigma: posterior median 1.85, 95% interval (1.45, 2.46) | true value 2.0

Diagnosing chains: run several chains from different starts and check they agree (the R-hat statistic near 1), inspect trace plots, compute the effective sample size (correlated samples carry less information) and tune the proposal width. Modern tools (Hamiltonian Monte Carlo, the NUTS sampler in Stan, PyMC, NumPyro) use gradients to explore high-dimensional posteriors efficiently. Variational inference instead fits a simple distribution to the posterior by optimisation: faster, approximate, and the basis of VAEs.

Bayesian decisions: Thompson sampling

To pick among options with unknown success rates, sample a plausible rate from each option's posterior and choose the best sample. Options with uncertain but promising rates get tried; clearly bad ones fade. It balances exploration and exploitation automatically (A9).

import random
random.seed(2)
true_rates = [0.04, 0.05, 0.065]
def run(strategy, rounds=6000):
    wins, losses, reward = [1, 1, 1], [1, 1, 1], 0
    pulls = [0, 0, 0]
    for t in range(rounds):
        if strategy == "thompson": arm = max(range(3), key=lambda i: random.betavariate(wins[i], losses[i]))
        elif strategy == "uniform": arm = t % 3
        else: arm = max(range(3), key=lambda i: wins[i] / (wins[i] + losses[i])) if t > 30 else t % 3         # greedy after a short trial
        win = random.random() < true_rates[arm]
        wins[arm] += win; losses[arm] += 1 - win; reward += win; pulls[arm] += 1
    return reward, pulls
for s in ("uniform", "greedy", "thompson"):
    r, p = run(s); print(f"{s:>8}: conversions {r:4d} | pulls per arm {p}")

Output

 uniform: conversions  322 | pulls per arm [2000, 2000, 2000]
  greedy: conversions  287 | pulls per arm [20, 5938, 42]
thompson: conversions  369 | pulls per arm [105, 1320, 4575]

How this gets asked

How does Thompson sampling choose an arm?

  • The arm with the highest mean That is greedy.
  • It samples a rate from each arm's posterior and picks the arm with the highest sample Correct.
  • Uniformly at random No.
  • The least tried arm No.

Uncertain arms get explored in proportion to their chance of being best.

Gaussian processes: distributions over functions

A Gaussian process (GP) is a prior over functions: any finite set of function values is jointly Gaussian with covariance given by a kernel k(x, x') measuring similarity (the RBF kernel says nearby inputs have similar outputs). Conditioning on observations gives a posterior over functions: a mean prediction and a variance that is small near data and grows away from it.

Posterior at test points x* given data (X, y) with noise s^2:

  • mean: K(x*, X) [K(X, X) + s^2 I]^-1 y
  • covariance: K(x*, x*) - K(x*, X) [K(X, X) + s^2 I]^-1 K(X, x*)
import math, random
random.seed(3)
def rbf(a, b, length=1.0, var=1.0): return var * math.exp(-0.5 * ((a - b) / length) ** 2)
def solve(A, B):                                              # solve A X = B by Gauss-Jordan (A is small and positive definite)
    n = len(A); M = [A[i][:] + B[i][:] for i in range(n)]; m = len(B[0])
    for i in range(n):
        p = max(range(i, n), key=lambda r: abs(M[r][i])); M[i], M[p] = M[p], M[i]
        piv = M[i][i]; M[i] = [v / piv for v in M[i]]
        for r in range(n):
            if r != i:
                f = M[r][i]; M[r] = [a - f * b for a, b in zip(M[r], M[i])]
    return [row[n:] for row in M]
X = [-4.0, -3.0, -1.0, 0.0, 2.0]
y = [math.sin(x) + random.gauss(0, 0.05) for x in X]
noise = 0.05 ** 2
K = [[rbf(a, b) + (noise if i == j else 0) for j, b in enumerate(X)] for i, a in enumerate(X)]
tests = [-4.0, -2.0, 0.0, 1.0, 3.0, 6.0]
Ks = [[rbf(t, x) for x in X] for t in tests]
alpha = solve(K, [[v] for v in y])
for t, ks in zip(tests, Ks):
    mean = sum(k * a[0] for k, a in zip(ks, alpha))
    v = solve(K, [[k] for k in ks]); var = rbf(t, t) - sum(k * vv[0] for k, vv in zip(ks, v))
    print(f"x = {t:>4}: prediction {mean:+.2f} +/- {2 * math.sqrt(max(var, 0)):.2f} (true sin(x) = {math.sin(t):+.2f})")

Output

x = -4.0: prediction +0.76 +/- 0.10 (true sin(x) = +0.76)
x = -2.0: prediction -0.88 +/- 0.98 (true sin(x) = -0.91)
x =  0.0: prediction +0.05 +/- 0.10 (true sin(x) = +0.00)
x =  1.0: prediction +0.75 +/- 1.08 (true sin(x) = +0.84)
x =  3.0: prediction +0.50 +/- 1.58 (true sin(x) = +0.14)
x =  6.0: prediction +0.00 +/- 2.00 (true sin(x) = -0.28)

Notice the error bars are tiny at observed points (x = -4, 0), larger between them (x = -2, 1), and large far outside the data (x = 6), where the prediction reverts to the prior mean of 0. That honest uncertainty is why GPs drive Bayesian optimisation (tuning hyperparameters or experiments with few evaluations: pick the next point by an acquisition function such as expected improvement). Costs: O(n^3) time for n points, so use sparse or approximate GPs beyond a few thousand points.

How this gets asked

How does a Gaussian process's predictive uncertainty behave away from the data?

  • It grows and the mean reverts to the prior Correct.
  • It stays zero No.
  • It is undefined No.

That is the GP's honest 'I do not know'.

Mixture models and the EM algorithm

Data from several hidden groups can be modelled as a mixture: p(x) = sum_k pi_k N(x | mu_k, sigma_k). The group label is a latent variable. Expectation-Maximisation (EM) alternates: E-step, compute each point's responsibility (probability of belonging to each component) given current parameters; M-step, re-estimate the parameters as responsibility-weighted statistics. Each iteration never decreases the likelihood; the result depends on initialisation (run several). k-means is the hard-assignment, equal-spherical special case.

import math, random
random.seed(4)
data = [random.gauss(0, 1) for _ in range(300)] + [random.gauss(5, 1.2) for _ in range(200)]
def normal_pdf(x, mu, s): return math.exp(-0.5 * ((x - mu) / s) ** 2) / (s * math.sqrt(2 * math.pi))
pi, mu, sd = [0.5, 0.5], [-1.0, 1.0], [1.0, 1.0]                 # rough initial guesses
for it in range(60):
    resp = []
    for x in data:                                               # E-step: responsibilities
        p = [pi[k] * normal_pdf(x, mu[k], sd[k]) for k in range(2)]; s = sum(p); resp.append([v / s for v in p])
    for k in range(2):                                           # M-step: weighted re-estimation
        nk = sum(r[k] for r in resp)
        pi[k] = nk / len(data); mu[k] = sum(r[k] * x for r, x in zip(resp, data)) / nk
        sd[k] = math.sqrt(sum(r[k] * (x - mu[k]) ** 2 for r, x in zip(resp, data)) / nk)
ll = sum(math.log(sum(pi[k] * normal_pdf(x, mu[k], sd[k]) for k in range(2))) for x in data)
print("estimated weights:", [round(v, 2) for v in pi], "(true 0.60, 0.40) | means:", [round(v, 2) for v in mu], "(true 0, 5) | stds:", [round(v, 2) for v in sd], "(true 1, 1.2)")
print("log-likelihood:", round(ll, 1))

Output

estimated weights: [0.59, 0.41] (true 0.60, 0.40) | means: [-0.01, 4.99] (true 0, 5) | stds: [0.93, 1.44] (true 1, 1.2)
log-likelihood: -1078.9

Choose the number of components by BIC/AIC or held-out likelihood. Uses: soft clustering, density estimation, anomaly detection (low likelihood), speaker models, and as the conceptual ancestor of variational autoencoders and diffusion models (latent-variable models trained by maximising a bound on likelihood).

Uncertainty in deep learning

Two kinds of uncertainty:

  • Aleatoric: noise inherent in the data (a blurry photo). More data does not remove it.
  • Epistemic: ignorance about the model (few similar examples). More data reduces it, and it is large out of distribution.

Practical estimators:

MethodIdeaCost
Deep ensemblesTrain several networks from different seeds; disagreement signals epistemic uncertaintySeveral trainings and inferences
MC dropoutKeep dropout on at test time, average many passesMany forward passes
Bayesian last layer / LaplaceBayesian treatment of only some parametersCheap, approximate
Heteroscedastic outputThe network predicts a mean and a varianceHandles aleatoric noise
Conformal predictionWrap any model to give intervals with guaranteed coverageNeeds a calibration set
Evidential / distance-awareSingle-pass uncertainty headsActive research
 
import random, math
random.seed(5)
def make_model(seed):                                          # a tiny "model": a random-sample polynomial fit (a stand-in for a network)
    rng = random.Random(seed); xs = [rng.uniform(-3, 3) for _ in range(25)]; ys = [math.sin(x) + rng.gauss(0, 0.2) for x in xs]
    def predict(x):                                            # kernel-weighted average of this model's own training sample
        w = [math.exp(-0.5 * ((x - xi) / 0.6) ** 2) + 1e-12 for xi in xs]; return sum(wi * yi for wi, yi in zip(w, ys)) / sum(w)
    return predict
ensemble = [make_model(s) for s in range(12)]
for x in (0.0, 2.0, 6.0, 10.0):
    preds = [m(x) for m in ensemble]; mean = sum(preds) / len(preds); sd = (sum((p - mean) ** 2 for p in preds) / len(preds)) ** 0.5
    print(f"x = {x:>4}: ensemble mean {mean:+.2f}, disagreement (std) {sd:.3f}" + ("   <- far outside the training range" if x > 4 else ""))

Conformal prediction in a few lines

Hold out a calibration set, compute the absolute residuals of your model on it, take the (1 - alpha) quantile q (with a finite-sample correction), and predict [y_hat - q, y_hat + q]. Under exchangeability the interval covers the truth with probability at least 1 - alpha, whatever the model.

import random, math
random.seed(6)
def truth(x): return 2 * x + 1
xs = [random.uniform(0, 10) for _ in range(3000)]
data = [(x, truth(x) + random.gauss(0, 1 + 0.2 * x)) for x in xs]
train, calib, test = data[:1000], data[1000:2000], data[2000:]
n = len(train); mx = sum(x for x, _ in train) / n; my = sum(y for _, y in train) / n
slope = sum((x - mx) * (y - my) for x, y in train) / sum((x - mx) ** 2 for x, _ in train); icpt = my - slope * mx
predict = lambda x: slope * x + icpt
scores = sorted(abs(y - predict(x)) for x, y in calib)
alpha = 0.1
q = scores[min(len(scores) - 1, math.ceil((len(scores) + 1) * (1 - alpha)) - 1)]
covered = sum(abs(y - predict(x)) <= q for x, y in test) / len(test)
print(f"fitted line: y = {slope:.2f} x + {icpt:.2f} | conformal half-width {q:.2f} | coverage on fresh data {covered:.1%} (target 90%)")

Output

fitted line: y = 1.97 x + 1.03 | conformal half-width 3.44 | coverage on fresh data 89.6% (target 90%)

Calibration

A classifier is calibrated if among predictions of "70% confident", about 70% are right. Modern neural networks are usually over-confident. Diagnose with a reliability diagram and the expected calibration error (ECE): bin predictions by confidence and compare average confidence with accuracy per bin. Fix with temperature scaling (divide logits by a learned T > 1), Platt scaling or isotonic regression fitted on a validation set. Calibration matters whenever probabilities drive decisions (medical triage, ad bidding, risk).

import math, random
random.seed(7)
def softmax(z):
    m = max(z); e = [math.exp(v - m) for v in z]; s = sum(e); return [v / s for v in e]
def sample(n, overconfidence):
    out = []
    for _ in range(n):
        label = random.randrange(3); logits = [random.gauss(0, 1) for _ in range(3)]; logits[label] += 1.0     # weak true signal
        out.append(([overconfidence * l for l in logits], label))
    return out
def ece(items, T=1.0, bins=10):
    buckets = [[] for _ in range(bins)]
    for logits, label in items:
        p = softmax([l / T for l in logits]); conf = max(p); buckets[min(bins - 1, int(conf * bins))].append((conf, p.index(conf) == label))
    return sum(len(b) / len(items) * abs(sum(c for c, _ in b) / len(b) - sum(ok for _, ok in b) / len(b)) for b in buckets if b)
items = sample(6000, overconfidence=3.0)                          # scaled-up logits mimic an over-confident network
best_T = min((t / 10 for t in range(5, 80)), key=lambda T: ece(items[:3000], T))
print(f"ECE before temperature scaling {ece(items[3000:]):.3f} | learned T = {best_T:.1f} | ECE after {ece(items[3000:], best_T):.3f}")

Output

ECE before temperature scaling 0.215 | learned T = 3.2 | ECE after 0.012
Key idea

Report distributions, not points. Update beliefs with Bayes' rule (exactly with conjugate priors, by MCMC or variational inference otherwise), act on uncertainty with Thompson sampling and Bayesian optimisation, use Gaussian processes when data is scarce and honest error bars matter, model hidden groups with mixtures and EM, and make deep models trustworthy with ensembles, conformal intervals and calibration.

Self-check

What does temperature scaling do?

Divides logits by a learned temperature to make predicted probabilities match observed accuracy without changing the predicted class.

Interview questions: Probabilistic ML

14 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic MLE versus MAP versus Bayesian inference?

MLE maximises the likelihood, MAP adds a prior and takes the posterior mode, and Bayesian inference keeps the entire posterior distribution.

Basic State Bayes' rule in words.

The posterior is proportional to the likelihood times the prior, normalised by the evidence.

Medium What is a conjugate prior? Give an example.

A prior for which the posterior has the same functional form, such as a Beta prior with a Bernoulli likelihood giving Beta(a + heads, b + tails).

Medium Credible versus confidence interval?

A credible interval contains the parameter with a stated posterior probability given the model and prior; a confidence interval is a procedure that covers the truth in a stated fraction of repeated experiments.

Medium What does L2 regularisation correspond to in Bayesian terms?

A zero-mean Gaussian prior on the weights; L1 corresponds to a Laplace prior.

Medium Explain Thompson sampling.

Sample a success rate from each option's posterior and play the option with the largest sample, balancing exploration and exploitation.

Medium How does Metropolis-Hastings work?

Propose a nearby point and accept it with probability min(1, p(new)/p(old)); after burn-in the visited points are samples from the target distribution.

Medium How do you diagnose MCMC convergence?

Run several chains from different starts, compare them with R-hat near 1, inspect trace plots and check the effective sample size.

Advanced What is a Gaussian process and what does it give you?

A prior over functions defined by a kernel; conditioning on data yields predictions with calibrated uncertainty that grows away from observations. Cost is O(n^3).

Advanced Explain the EM algorithm.

For latent-variable models: the E-step computes posterior responsibilities of the latent variables given current parameters; the M-step maximises the expected complete-data likelihood. Likelihood never decreases.

Advanced Aleatoric versus epistemic uncertainty?

Aleatoric is irreducible noise in the data; epistemic is lack of knowledge about the model and can shrink with more data.

Advanced How do deep ensembles and MC dropout estimate uncertainty?

Disagreement between independently trained networks, or between stochastic forward passes with dropout enabled, approximates epistemic uncertainty.

Advanced Explain conformal prediction.

Use a calibration set's residual quantile to build intervals around any model's predictions, guaranteeing coverage under exchangeability.

Advanced What is calibration and how do you fix miscalibration?

Predicted probabilities matching observed frequencies. Measure with reliability diagrams and ECE; fix with temperature scaling, Platt scaling or isotonic regression on validation data.
