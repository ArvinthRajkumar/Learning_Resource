Part A1

Classical machine learning algorithms from scratch

Before neural networks, a toolbox of simple algorithms solved most prediction problems, and still does for tabular data. Knowing how each works, and what it assumes, is a core interview skill. Every algorithm here is implemented in a few lines and run.

BasicMedium~6 hours

Linear regression

Intuition

Fit a straight line (or plane) through the data so the predictions are as close as possible to the answers. Prediction: y_hat = w x + b. The usual error to minimise is the mean squared error (MSE): the average of (y - y_hat)^2.

Two ways to solve it

  1. Closed form (normal equation): for one feature, w = Cov(x, y) / Var(x) and b = mean(y) - w mean(x). For many features w = (X^T X)^(-1) X^T y.
  2. Gradient descent: repeatedly move the parameters opposite to the gradient: w <- w - lr x dMSE/dw. Works for any model, scales to huge data.
import random
random.seed(0)
xs = [i / 10 for i in range(100)]
ys = [2.0 * x + 1.0 + random.gauss(0, 0.3) for x in xs]       # true line: y = 2x + 1 plus noise

n = len(xs)
mx, my = sum(xs) / n, sum(ys) / n
w = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / sum((x - mx) ** 2 for x in xs)
b = my - w * mx
print("closed form      w=%.3f b=%.3f" % (w, b))

w2, b2, lr = 0.0, 0.0, 0.01
for _ in range(5000):
    gw = sum(2 * (w2 * x + b2 - y) * x for x, y in zip(xs, ys)) / n
    gb = sum(2 * (w2 * x + b2 - y) for x, y in zip(xs, ys)) / n
    w2, b2 = w2 - lr * gw, b2 - lr * gb
print("gradient descent w=%.3f b=%.3f" % (w2, b2))

Output

closed form      w=1.996 b=0.996
gradient descent w=1.996 b=0.996

Assumptions (and how to check them)

Linearity, independent errors, constant error variance, roughly normal errors (for inference), and no extreme multicollinearity. Look at residual plots. Outliers pull the line strongly because errors are squared; use Huber or MAE loss for robustness.

Overfitting and regularisation

With many features or high-degree polynomials the model memorises noise. Regularisation adds a penalty on the weights:

MethodPenaltyEffect
Ridge (L2)lambda x sum(w^2)Shrinks all weights smoothly, handles correlated features
Lasso (L1)lambda x sum(abs(w))Drives some weights exactly to zero: feature selection
Elastic netBothCompromise

For ridge with one feature the solution becomes w = Cov(x, y) / (Var(x) + lambda): the penalty shrinks the slope.

import random
random.seed(1)
xs = [random.gauss(0, 1) for _ in range(20)]
ys = [3.0 * x + random.gauss(0, 2) for x in xs]
mx, my = sum(xs) / 20, sum(ys) / 20
cov = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / 20
var = sum((x - mx) ** 2 for x in xs) / 20
for lam in (0, 0.5, 2, 10):
    print("lambda %4.1f -> slope %.3f" % (lam, cov / (var + lam)))

Output

lambda  0.0 -> slope 2.783
lambda  0.5 -> slope 1.799
lambda  2.0 -> slope 0.873
lambda 10.0 -> slope 0.233

Choose lambda by cross-validation. Always standardise features before regularising, or the penalty depends on units.

How this gets asked

For points (1, 2), (2, 4), (3, 6), what is the least-squares slope?

The points lie exactly on y = 2x, so the slope is 2.

How does L1 (lasso) regularisation differ from L2 (ridge)?

  • L1 never shrinks weights It does.
  • L1 can set weights exactly to zero, giving feature selection; L2 shrinks them smoothly Correct.
  • L2 sets weights to zero No.
  • They are identical No.

The L1 penalty has a corner at zero that creates sparse solutions.

Self-check

Normal equation versus gradient descent?

The normal equation solves least squares directly (expensive for many features); gradient descent iterates and scales to any model and data size.

Logistic regression and classification

From a score to a probability

For two classes, compute a linear score z = w . x + b, squash it with the sigmoid p = 1 / (1 + e^(-z)), and predict class 1 if p > threshold. Train by minimising log loss (binary cross-entropy): -[y log p + (1 - y) log(1 - p)]. Its gradient is simply (p - y) x, as for linear regression.

import math, random
random.seed(2)
# two clusters
data = [((random.gauss(-1, 0.8), random.gauss(-1, 0.8)), 0) for _ in range(100)] + \
       [((random.gauss(1, 0.8), random.gauss(1, 0.8)), 1) for _ in range(100)]
random.shuffle(data)
w, b, lr = [0.0, 0.0], 0.0, 0.1
sig = lambda z: 1 / (1 + math.exp(-z))
for epoch in range(200):
    for (x1, x2), y in data:
        p = sig(w[0] * x1 + w[1] * x2 + b)
        g = p - y
        w[0] -= lr * g * x1; w[1] -= lr * g * x2; b -= lr * g
acc = sum((sig(w[0] * x1 + w[1] * x2 + b) > 0.5) == bool(y) for (x1, x2), y in data) / len(data)
print("weights", [round(v, 2) for v in w], "bias", round(b, 2), "accuracy", acc)

Output

weights [4.57, 3.59] bias 0.57 accuracy 0.975

Multi-class: softmax regression. The decision boundary of logistic regression is linear; add polynomial or interaction features for curved boundaries. The weights are interpretable as log-odds: e^(w_j) is the odds ratio for a one-unit increase of feature j.

Metrics beyond accuracy

Precision, recall, F1, ROC-AUC and PR-AUC (see F1). Choose the threshold from the business cost of false positives versus false negatives, and calibrate probabilities (Platt scaling, isotonic regression) if you need them to be trustworthy.

How this gets asked

What is the gradient of log loss with respect to the weights for one example?

  • (y - p) x Sign reversed.
  • (p - y) x Correct.
  • p x Missing the label.
  • (p - y)^2 No.

It has the same form as linear regression: error times the input.

Self-check

Why is logistic regression's boundary linear?

The predicted probability is monotonic in the linear score, so the 0.5 contour is where w.x + b = 0.

k-nearest neighbours and naive Bayes

k-NN

No training: store the data. To predict, find the k closest points and take a majority vote (or mean). Needs a distance (Euclidean, cosine), feature scaling, and a good k (small k overfits, large k underfits). Prediction cost is high (scan all points, or use a KD-tree or an approximate index), and it suffers from the curse of dimensionality: in high dimensions all points become nearly equidistant.

import math
train = [((1, 1), "a"), ((1, 2), "a"), ((2, 1), "a"), ((6, 6), "b"), ((7, 6), "b"), ((6, 7), "b")]
def knn(q, k):
    nearest = sorted(train, key=lambda p: math.dist(p[0], q))[:k]
    votes = {}
    for _, label in nearest:
        votes[label] = votes.get(label, 0) + 1
    return max(votes, key=votes.get)
print(knn((2, 2), 3), knn((5, 5), 3), knn((4, 4), 1))

Output

a b b

Naive Bayes

Apply Bayes' rule, assuming features are independent given the class (the "naive" part): P(class | features) is proportional to P(class) x product of P(feature | class). Despite the false assumption it works well for text. Use Laplace smoothing so an unseen word does not zero the product, and work in log space.

import math
spam = ["win money now", "free money offer", "win a free prize"]
ham = ["meeting at noon", "project status update", "lunch at noon tomorrow"]
def counts(docs):
    c = {}
    for d in docs:
        for w in d.split():
            c[w] = c.get(w, 0) + 1
    return c
cs, ch = counts(spam), counts(ham)
vocab = set(cs) | set(ch)
def score(msg, c, prior):
    total = sum(c.values())
    return math.log(prior) + sum(math.log((c.get(w, 0) + 1) / (total + len(vocab))) for w in msg.split() if w in vocab)
for msg in ("free money", "status at noon"):
    s_spam, s_ham = score(msg, cs, 0.5), score(msg, ch, 0.5)
    print(msg, "->", "spam" if s_spam > s_ham else "ham")

Output

free money -> spam
status at noon -> ham

How this gets asked

Why does k-NN struggle in very high dimensions?

  • It has too few parameters No.
  • Distances concentrate: all points look nearly equally far apart Correct.
  • It cannot use labels No.
  • It needs a GPU No.

This is the curse of dimensionality.

Decision trees and ensembles

Decision tree

Repeatedly split the data on the feature and threshold that make the groups most pure. Impurity measures: Gini 1 - sum(p_k^2) or entropy -sum(p_k log p_k). The information gain of a split is the impurity before minus the weighted impurity after.

def gini(labels):
    n = len(labels)
    return 1 - sum((labels.count(c) / n) ** 2 for c in set(labels)) if n else 0
data = [(2.0, 0), (3.0, 0), (4.0, 0), (6.0, 1), (7.0, 1), (8.0, 1), (5.0, 0), (5.5, 1)]
data.sort()
best = None
for i in range(1, len(data)):
    thr = (data[i - 1][0] + data[i][0]) / 2
    left = [y for x, y in data if x <= thr]
    right = [y for x, y in data if x > thr]
    g = (len(left) * gini(left) + len(right) * gini(right)) / len(data)
    if best is None or g < best[0]:
        best = (g, thr)
print("best threshold %.2f with weighted gini %.3f (parent gini %.3f)" % (best[1], best[0], gini([y for _, y in data])))

Output

best threshold 5.25 with weighted gini 0.000 (parent gini 0.500)

Trees handle mixed feature types, need no scaling, capture interactions and are readable, but a single deep tree overfits (high variance). Control with maximum depth, minimum samples per leaf, and pruning.

Bagging and random forests

Bagging trains many trees on bootstrap samples and averages them, which cuts variance. A random forest also picks a random subset of features at each split, decorrelating the trees. The average of n models with variance sigma^2 and pairwise correlation rho has variance rho sigma^2 + (1 - rho) sigma^2 / n.

import random
random.seed(3)
def one_model():           # a noisy estimator of the true value 10
    return 10 + random.gauss(0, 3)
single = [one_model() for _ in range(4000)]
bagged = [sum(one_model() for _ in range(25)) / 25 for _ in range(4000)]
var = lambda v: sum((x - sum(v) / len(v)) ** 2 for x in v) / len(v)
print("variance single %.2f, averaged over 25 independent models %.2f" % (var(single), var(bagged)))

Output

variance single 8.98, averaged over 25 independent models 0.36

Boosting

Build models sequentially, each fixing the previous ones' mistakes. Gradient boosting fits each new small tree to the negative gradient of the loss (the residuals for squared error) and adds it with a small learning rate. XGBoost, LightGBM and CatBoost add regularisation, histogram speedups and handling of categories. Boosting reduces bias; random forests reduce variance.

# Gradient boosting with stumps on a 1D regression problem.
xs = [i / 5 for i in range(50)]
ys = [x * x / 10 for x in xs]                    # a curve; a linear model cannot fit it
def best_stump(res):
    best = None
    for thr in [x + 0.1 for x in xs]:
        l = [r for x, r in zip(xs, res) if x <= thr]; rr = [r for x, r in zip(xs, res) if x > thr]
        if not l or not rr: continue
        lm, rm = sum(l) / len(l), sum(rr) / len(rr)
        err = sum((r - (lm if x <= thr else rm)) ** 2 for x, r in zip(xs, res))
        if best is None or err < best[0]: best = (err, thr, lm, rm)
    return best
pred, lr = [0.0] * len(xs), 0.3
for m in range(40):
    res = [y - p for y, p in zip(ys, pred)]
    _, thr, lm, rm = best_stump(res)
    pred = [p + lr * (lm if x <= thr else rm) for p, x in zip(pred, xs)]
    if m in (0, 9, 39):
        print("after %2d stumps: MSE %.3f" % (m + 1, sum((y - p) ** 2 for y, p in zip(ys, pred)) / len(ys)))

Output

after  1 stumps: MSE 10.295
after 10 stumps: MSE 0.220
after 40 stumps: MSE 0.049
Random forestGradient boosting
TreesIndependent, deepSequential, shallow
ReducesVarianceBias (and variance with regularisation)
TuningEasy, robust defaultsMore sensitive (learning rate, depth, rounds)
Parallel trainingYesSequential (but fast histograms)
Typical winner on tabular dataStrong baselineUsually the best

How this gets asked

Random forests reduce which source of error most?

  • Bias Boosting targets bias.
  • Variance, by averaging decorrelated trees Correct.
  • Noise in labels No.
  • Data size No.

Averaging many de-correlated high-variance trees lowers variance.

In gradient boosting with squared error, what does each new tree fit?

  • The original targets No.
  • The residuals (negative gradient) of the current ensemble Correct.
  • Random noise No.
  • The features No.

Each tree is a step of functional gradient descent.

Self-check

Bagging versus boosting?

Bagging trains independent models on bootstrap samples and averages them (variance); boosting trains sequentially on residuals (bias).

Support vector machines

An SVM finds the separating line with the largest margin: the widest gap between the classes. Only the support vectors (points on the margin) define it. The soft-margin form minimises (1/2)||w||^2 + C sum(hinge loss), with hinge loss max(0, 1 - y (w.x + b)) for labels y in {-1, +1}. Large C fits the training data tightly; small C allows margin violations for a wider margin.

The kernel trick replaces dot products by a kernel K(x, x') such as the RBF exp(-gamma ||x - x'||^2), implicitly working in a higher-dimensional space so a linear boundary there is curved in the original space.

import random
random.seed(4)
data = [((random.gauss(-1.5, 0.6), random.gauss(-1.5, 0.6)), -1) for _ in range(60)] + \
       [((random.gauss(1.5, 0.6), random.gauss(1.5, 0.6)), 1) for _ in range(60)]
w, b, lam, lr = [0.0, 0.0], 0.0, 0.01, 0.05
for epoch in range(100):
    for (x1, x2), y in data:
        margin = y * (w[0] * x1 + w[1] * x2 + b)
        if margin < 1:                                  # hinge loss active
            w[0] += lr * (y * x1 - lam * w[0]); w[1] += lr * (y * x2 - lam * w[1]); b += lr * y
        else:
            w[0] -= lr * lam * w[0]; w[1] -= lr * lam * w[1]
acc = sum(y * (w[0] * x1 + w[1] * x2 + b) > 0 for (x1, x2), y in data) / len(data)
print("linear SVM accuracy", acc)

Output

linear SVM accuracy 1.0

SVMs work well on small to medium, high-dimensional data (text) and have a convex objective, but kernel SVMs scale poorly with sample count (O(n^2) to O(n^3)) and need scaled features.

How this gets asked

What do support vectors determine?

  • Nothing No.
  • The separating hyperplane: only points on or inside the margin matter Correct.
  • The learning rate No.
  • The kernel No.

Points far from the margin do not affect the solution.

Clustering and dimensionality reduction

k-means

Alternate two steps until nothing changes: assign each point to the nearest centroid, then update each centroid to the mean of its points. It minimises within-cluster squared distance, finds only a local optimum (use several random starts, k-means++ initialisation), assumes round clusters of similar size, and needs k (use the elbow method or silhouette score).

import random, math
random.seed(5)
pts = [(random.gauss(0, 0.5), random.gauss(0, 0.5)) for _ in range(40)] + [(random.gauss(4, 0.5), random.gauss(4, 0.5)) for _ in range(40)]
cent = [pts[0], pts[1]]
for _ in range(10):
    groups = [[], []]
    for p in pts:
        groups[min((0, 1), key=lambda i: math.dist(p, cent[i]))].append(p)
    cent = [(sum(x for x, _ in g) / len(g), sum(y for _, y in g) / len(g)) for g in groups]
print("centroids:", [(round(x, 2), round(y, 2)) for x, y in cent], "sizes:", [len(g) for g in groups])

Output

centroids: [(0.09, 0.03), (3.95, 3.98)] sizes: [40, 40]

Other clustering: hierarchical (dendrograms), DBSCAN (density-based, finds arbitrary shapes and noise, no k), Gaussian mixture models (soft assignments with EM).

PCA

Find orthogonal directions of maximum variance and project the data onto the top few. The directions are the eigenvectors of the covariance matrix; the eigenvalues give the variance explained. Uses: compression, visualisation, denoising, decorrelating features. Standardise first. It is linear and unsupervised (it ignores labels).

import random, math
random.seed(6)
pts = []
for _ in range(500):
    t = random.gauss(0, 3)
    pts.append((t + random.gauss(0, 0.5), 0.5 * t + random.gauss(0, 0.5)))   # data stretched along a diagonal
mx = sum(x for x, _ in pts) / len(pts); my = sum(y for _, y in pts) / len(pts)
c = [[sum((p[i] - (mx, my)[i]) * (p[j] - (mx, my)[j]) for p in pts) / len(pts) for j in range(2)] for i in range(2)]
# power iteration finds the top eigenvector of the 2x2 covariance matrix
v = [1.0, 0.0]
for _ in range(100):
    v = [c[0][0] * v[0] + c[0][1] * v[1], c[1][0] * v[0] + c[1][1] * v[1]]
    n = math.hypot(*v); v = [v[0] / n, v[1] / n]
eig = v[0] * (c[0][0] * v[0] + c[0][1] * v[1]) + v[1] * (c[1][0] * v[0] + c[1][1] * v[1])
total = c[0][0] + c[1][1]
print("first component direction", [round(v[0], 2), round(v[1], 2)], "explains %.0f%% of variance" % (100 * eig / total))

Output

first component direction [0.89, 0.45] explains 98% of variance

Self-check

What does PCA compute?

Orthogonal directions of maximum variance (covariance eigenvectors), used to compress or visualise data.

Choosing and validating models

The bias-variance trade-off

Expected error = bias squared (model too simple) + variance (model too sensitive to the training sample) + irreducible noise. Complex models lower bias and raise variance. Regularisation, more data, bagging and early stopping reduce variance; richer features, boosting and larger models reduce bias.

Validation

  • Split into train / validation / test. Tune on validation; touch the test set once.
  • k-fold cross-validation for small data; stratified folds for imbalanced classes; time-series split (train on the past, test on the future) for temporal data; group k-fold when rows from one entity must not leak across folds.
  • Avoid data leakage: fit scalers, imputers and feature selection inside each fold or pipeline.
import random
random.seed(7)
n, k = 20, 5
idx = list(range(n)); random.shuffle(idx)
folds = [idx[i::k] for i in range(k)]
for i, test in enumerate(folds):
    train = [j for f in folds[:i] + folds[i + 1:] for j in f]
    print("fold", i, "train", len(train), "test", len(test), "disjoint:", not set(train) & set(test))

Key idea

For structured data, strong feature engineering with a well-tuned gradient boosting model usually beats a neural network. Always compare against a simple baseline (predict the mean or majority class; a logistic regression) so you know whether complexity pays.

Interview questions: Classical ML

14 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic Linear regression: what does it minimise and how is it solved?

The sum or mean of squared errors. Solve in closed form with the normal equation (X^T X)^(-1) X^T y, or by gradient descent for large data and other models.

Basic Why regularise a model, and what do L1 and L2 do?

To limit overfitting. L2 (ridge) shrinks weights smoothly; L1 (lasso) drives some weights to exactly zero, performing feature selection.

Basic How does logistic regression produce a probability?

A linear score is passed through the sigmoid; it is trained by minimising log loss, whose gradient is (p - y) x.

Basic Explain k-nearest neighbours and its main weaknesses.

Predict by a vote or mean of the k closest training points. It needs scaled features, is slow at prediction time and degrades in high dimensions.

Medium Bagging versus boosting?

Bagging trains models independently on bootstrap samples and averages them to reduce variance. Boosting trains models sequentially on the errors of the previous ones to reduce bias.

Medium What makes a random forest different from bagged trees?

It also samples a random subset of features at each split, decorrelating the trees so averaging reduces variance more.

Medium How does gradient boosting work?

Each new small tree fits the negative gradient (residuals for squared error) of the current ensemble, added with a learning rate. XGBoost, LightGBM and CatBoost add regularisation and speedups.

Medium How do decision trees choose splits?

By the largest impurity reduction (Gini or entropy information gain) over candidate features and thresholds.

Medium What is the kernel trick?

Replace dot products with a kernel function, such as RBF, so a linear model works in an implicit high-dimensional space without computing it.

Medium What assumptions does naive Bayes make, and why does it still work?

Features are conditionally independent given the class. The assumption is false, but the ranking of classes is often right, especially for text, and the model is fast and robust with little data.

Advanced Explain the bias-variance trade-off.

Expected error is bias squared plus variance plus irreducible noise. Simple models underfit (bias), flexible models overfit (variance). Choose complexity by validation, and use regularisation, ensembles and more data to manage it.

Advanced When does k-means fail and what are alternatives?

It assumes round, similar-size clusters, depends on initialisation and needs k. Use k-means++, Gaussian mixtures, DBSCAN for arbitrary shapes and noise, or hierarchical clustering.

Advanced How does PCA work and what are its limits?

It projects onto the orthogonal directions of maximum variance (covariance eigenvectors). It is linear, unsupervised, sensitive to scaling and may discard low-variance but predictive directions.

Advanced Why might a tuned gradient boosting model beat a neural network on tabular data?

Tabular features are heterogeneous with irregular interactions and modest sample sizes. Trees handle mixed types, missing values and non-smooth functions without heavy tuning.
