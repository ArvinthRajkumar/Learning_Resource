Part A8

Computer vision and multimodal models

Vision models turn pixels into labels, boxes and meaning, and multimodal models connect them to language. This part covers the building blocks and the classic computations (IoU, non-maximum suppression, contrastive loss), each run and checked.

MediumAdvanced~5 hours

Images as data

An image is a tensor H x W x C of numbers (0 to 255 per channel, or normalised to 0 to 1 or -1 to 1). Standard preprocessing: resize and crop to a fixed size, normalise with dataset mean and standard deviation, and apply augmentation to teach invariances (random crops, flips, colour jitter, rotation, cutout, mixup and CutMix). Never augment the validation set, and keep the same resize and normalisation at inference.

Convolutional networks

From pixels to features

Convolution layers (A3) detect local patterns; depth builds hierarchy: edges, textures, parts, objects. Key design elements:

  • Stride and pooling reduce resolution and increase the receptive field (the region of the input each unit sees).
  • Channels increase as resolution falls, keeping information.
  • Batch normalisation after convolutions.
  • Global average pooling replaces large fully connected layers.
# Receptive field growth: each layer with kernel k and stride s adds (k - 1) * product of earlier strides.
layers = [(3, 1), (3, 1), (3, 2), (3, 1), (3, 2)]       # (kernel, stride)
rf, jump = 1, 1
for i, (k, s) in enumerate(layers, 1):
    rf += (k - 1) * jump
    jump *= s
    print("after layer %d: receptive field %dx%d" % (i, rf, rf))

Output

after layer 2: receptive field 5x5
after layer 3: receptive field 7x7
after layer 4: receptive field 11x11
after layer 5: receptive field 15x15

ResNet and skip connections

Very deep plain networks became harder to train (not just overfit). Residual blocks compute y = x + F(x): the block only learns a correction, gradients flow along the identity path, and 50, 101 or 152 layers train well. Variants: bottleneck blocks (1x1 convolutions to shrink then expand channels), ResNeXt (grouped convolutions), DenseNet (concatenate earlier features), EfficientNet (balanced scaling of depth, width and resolution), ConvNeXt (modernised design).

Transfer learning

Reuse a network pretrained on a large dataset. Feature extraction: freeze the backbone, train a new head. Fine-tuning: unfreeze some or all layers with a small learning rate (often smaller for earlier layers). With little data, freeze more; with a similar domain and much data, fine-tune all. This is almost always better than training from scratch.

How this gets asked

What problem do residual connections solve?

  • Overfitting Not the main one.
  • Very deep plain networks being hard to optimise; the skip path lets gradients flow and the block learns a correction Correct.
  • Slow data loading No.
  • Class imbalance No.

y = x + F(x) preserves a direct gradient path.

Self-check

What is the receptive field?

The region of the input image that influences one unit; it grows with depth, kernel size and stride.

Vision transformers

A Vision Transformer (ViT) cuts the image into fixed patches (for example 16 x 16 pixels), flattens and linearly embeds each patch as a token, adds position embeddings and a learnable [CLS] token, and runs a standard transformer encoder (F2). For a 224 x 224 image with 16 x 16 patches there are (224 / 16)^2 = 196 tokens.

side, patch, d = 224, 16, 768
tokens = (side // patch) ** 2
print("patches per image:", tokens, "; with [CLS]:", tokens + 1)
print("attention score matrix entries per head:", (tokens + 1) ** 2)
print("patch embedding parameters:", patch * patch * 3 * d)

Object detection

Boxes, IoU and NMS

A detector outputs boxes (x1, y1, x2, y2) with class scores. Intersection over Union (IoU) measures overlap: area of overlap / area of union. A prediction is a true positive if its class is right and IoU with a ground-truth box exceeds a threshold (commonly 0.5). Detectors produce many overlapping boxes, so non-maximum suppression (NMS) keeps the highest-scoring box and removes others that overlap it above a threshold.

def iou(a, b):
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area = lambda r: (r[2] - r[0]) * (r[3] - r[1])
    return inter / (area(a) + area(b) - inter)
def nms(boxes, scores, thr=0.5):
    order = sorted(range(len(boxes)), key=lambda i: -scores[i])
    keep = []
    while order:
        i = order.pop(0)
        keep.append(i)
        order = [j for j in order if iou(boxes[i], boxes[j]) < thr]
    return keep
boxes = [(10, 10, 50, 50), (12, 12, 52, 52), (100, 100, 140, 140), (11, 9, 49, 51)]
scores = [0.9, 0.8, 0.95, 0.7]
print("IoU of first two:", round(iou(boxes[0], boxes[1]), 3))
print("kept after NMS:", nms(boxes, scores))

Output

IoU of first two: 0.822
kept after NMS: [2, 0]

The three overlapping boxes around the first object collapse to the best one (index 0), and the separate object (index 2) survives.

Metrics: AP and mAP

For each class, sort predictions by confidence, compute precision and recall as you go down the list, and take the area under the precision-recall curve: average precision (AP). mAP averages over classes (and COCO also averages over IoU thresholds 0.5 to 0.95). Report speed (frames per second) and size with accuracy.

How this gets asked

Two boxes overlap with intersection area 25 and union area 100. What is the IoU?

25 / 100 = 0.25.

What does NMS do?

  • Normalises images No.
  • Removes lower-scoring boxes that overlap a higher-scoring box above a threshold Correct.
  • Increases recall No.
  • Resizes boxes No.

It deduplicates multiple detections of the same object.

Self-check

Define IoU and AP.

IoU is overlap area over union area; AP is the area under the precision-recall curve for a class, averaged over classes as mAP.

Segmentation

  • Semantic segmentation labels every pixel with a class; models are encoder-decoder (U-Net with skip connections, DeepLab with dilated convolutions and pyramid pooling, SegFormer).
  • Instance segmentation separates individual objects (Mask R-CNN adds a mask head to Faster R-CNN).
  • Panoptic combines both.
  • Segment Anything (SAM) is a promptable model: given points, boxes or text, it outputs masks, trained on over a billion masks.

Loss functions: pixel-wise cross-entropy, Dice loss (1 - 2 |A and B| / (|A| + |B|)) for imbalanced foreground, and focal loss. Metrics: IoU (Jaccard) and Dice per class, mean IoU.

def dice(a, b):
    inter = sum(x and y for x, y in zip(a, b))
    return 2 * inter / (sum(a) + sum(b))
pred = [1, 1, 1, 0, 0, 0, 0, 1]
true = [1, 1, 0, 0, 0, 1, 0, 1]
inter = sum(p and t for p, t in zip(pred, true))
union = sum(p or t for p, t in zip(pred, true))
print("IoU %.3f, Dice %.3f" % (inter / union, dice(pred, true)))

Output

IoU 0.600, Dice 0.750

How this gets asked

Which loss helps when the foreground is a tiny fraction of pixels?

  • Plain accuracy Dominated by background.
  • Dice or focal loss Correct.
  • No loss No.
  • L2 on labels No.

They emphasise the rare class.

Self-check

Semantic versus instance segmentation?

Semantic labels each pixel by class; instance also separates individual objects of the same class.

Image-text models and VLMs

CLIP: contrastive image-text pretraining

Two encoders (an image encoder and a text encoder) map into a shared embedding space. Train on hundreds of millions of image-caption pairs so that each image is closest to its own caption: for a batch of N pairs, the N x N similarity matrix should have its diagonal large, with cross-entropy loss applied in both directions (image to text and text to image) and a learned temperature (A4).

import math
def clip_loss(sim, temp=0.07):
    n = len(sim)
    total = 0.0
    for i in range(n):                                           # image to text
        row = [s / temp for s in sim[i]]
        m = max(row); lse = m + math.log(sum(math.exp(v - m) for v in row))
        total += lse - row[i]
    for j in range(n):                                           # text to image
        col = [sim[i][j] / temp for i in range(n)]
        m = max(col); lse = m + math.log(sum(math.exp(v - m) for v in col))
        total += lse - col[j]
    return total / (2 * n)
good = [[0.9, 0.1, 0.0], [0.1, 0.8, 0.2], [0.0, 0.2, 0.7]]
bad = [[0.3, 0.3, 0.3], [0.3, 0.3, 0.3], [0.3, 0.3, 0.3]]
print("matched model loss %.3f | uninformative model loss %.3f (ln 3 = %.3f)" % (clip_loss(good), clip_loss(bad), math.log(3)))

Output

matched model loss 0.000 | uninformative model loss 1.099 (ln 3 = 1.099)

Zero-shot classification: embed the class names as text ("a photo of a dog") and pick the one closest to the image embedding, with no task-specific training. CLIP also powers retrieval, image search, filtering training data, and conditions diffusion models (D3). Limits: weak at counting, fine spatial relations and text in images; inherits web biases.

Vision-language models (VLMs)

Pattern: vision encoder (CLIP or SigLIP ViT) turns the image into patch features, a projector (a linear layer, MLP or a cross-attention resampler such as Q-Former or Perceiver) maps them into the LLM's embedding space as "image tokens", and the LLM reads image tokens plus text and generates text. Training stages: align the projector on caption data, then visual instruction tuning on question-answer data. Examples: LLaVA, Flamingo, BLIP-2, Qwen-VL, PaliGemma, and proprietary frontier models.

Evaluation and failure modes

Benchmarks: VQAv2, TextVQA, DocVQA, ChartQA, MMMU, MMBench. Common failures: hallucinating objects that are not there (POPE benchmark), poor counting and spatial reasoning, misreading small text, sensitivity to prompts, and bias. Mitigate with higher resolution, grounding supervision, preference tuning against hallucination, and OCR tools.

How this gets asked

How does CLIP perform zero-shot classification?

  • It retrains for each task No.
  • It embeds the class names as text prompts and picks the one closest to the image embedding Correct.
  • It uses a decision tree No.
  • It needs labelled examples No.

Shared embedding space lets text describe classes.

In a LLaVA-style VLM, what does the projector do?

  • Generates text That is the LLM.
  • Maps vision-encoder features into the LLM's token embedding space Correct.
  • Computes IoU No.
  • Trains the tokenizer No.

Image features become pseudo-tokens the LLM can read.

Self-check

How is CLIP trained?

Contrastively on image-caption pairs: the matching pair is the positive and other pairs in the batch are negatives, in both directions.

Key idea

The whole field follows one recipe: a large pretrained backbone (CNN or ViT), a task head, and fine-tuning on your data. Contrastive image-text pretraining is what connects vision to language, and IoU, NMS and mAP are the basic vocabulary of detection.

How this gets asked

For transfer learning with little data and a similar domain, you should usually:

  • Train from scratch Needs lots of data.
  • Freeze most of the pretrained backbone and train a new head, then optionally fine-tune with a small learning rate Correct.
  • Remove augmentation No.
  • Use a huge learning rate No.

Pretrained features are strong; protect them with freezing or small updates.

Interview questions: Vision and multimodal

12 questions. Try to answer aloud in under a minute, then reveal. Tags show the level.

Basic What are IoU and NMS?

IoU is the overlap area over union area of two boxes; non-maximum suppression keeps the best box and removes other boxes overlapping it above a threshold.

Basic Why use transfer learning in vision?

Pretrained backbones already encode general visual features, so fine-tuning needs less data and training time and usually performs better than training from scratch.

Basic What is data augmentation for images?

Random label-preserving transformations (crops, flips, colour jitter, mixup) that teach invariances and reduce overfitting.

Medium How does a vision transformer process an image?

It splits it into patches, embeds each as a token with position embeddings and a CLS token, and applies transformer encoder layers.

Medium CNN versus ViT trade-offs?

CNNs have locality and translation equivariance and work with less data; ViTs have little built-in bias, need more data or strong pretraining, and scale very well with global attention.

Medium What is mAP?

Mean average precision: the area under each class's precision-recall curve, averaged over classes (and over IoU thresholds in COCO).

Medium Semantic versus instance segmentation?

Semantic assigns a class to each pixel; instance also distinguishes separate objects of the same class.

Medium How does CLIP work?

Image and text encoders are trained contrastively on image-caption pairs so matching pairs are close in a shared space, enabling zero-shot classification and retrieval.

Advanced How is a vision-language model built?

A vision encoder produces patch features, a projector maps them into the LLM's embedding space as image tokens, and the LLM generates text, trained first on captions then on visual instructions.

Advanced Why do VLMs hallucinate objects and how do you reduce it?

Language priors override weak visual evidence. Use higher resolution, grounded training data, preference tuning against hallucination and tools such as OCR and detectors.

Advanced When use Dice loss?

For segmentation with a small foreground, where pixel accuracy is dominated by background; Dice (or focal loss) emphasises overlap of the rare class.

Advanced What is the receptive field and how do you increase it?

The input region affecting a unit. It grows with depth, kernel size, strides and dilated convolutions, or by attention.
