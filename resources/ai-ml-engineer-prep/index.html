AI/ML Engineer Assessment Prep

A teach-it-from-scratch guide for AI/ML engineer assessments and interviews. It starts with machine learning and transformer basics, goes deep on LLM inference, fine-tuning, RAG, evaluation statistics, agents and decoding, then covers system design, coding problems with tested solutions, and an interview question bank. The goal is to understand each mechanism well enough to answer any variation.

Highest yield first

Points are not spread evenly. The four coding problems are roughly 200 of the total points, so they come first. Within the theory, the numeric questions (memory math, statistics) reward real understanding because they cannot be guessed from keywords.

  1. Coding problems, part 07. Precise simulations. Points are lost on tie-breaking, tokenization and off-by-one errors, not on the big idea. Write each one from a blank file twice.
  2. KV cache and weight memory math, part 01. The factor of 2, KV heads under GQA, GiB vs GB.
  3. Paired significance testing, part 04. Only disagreements carry information. Exact sign test by hand.
  4. Why decode is memory-bandwidth bound, part 01. This one idea answers quantization, batching and speculative decoding questions.
  5. RAG diagnosis, BM25, RRF, nDCG, part 03. Formula details: 1-based rank, k = 60, log2(1 + position).
  6. Speculative and constrained decoding facts, part 01. Classic "which statement is correct" traps.
  7. LoRA and DPO, part 02. What is trained, what is frozen, what memory is saved.
  8. Idempotency for tool calls, part 05. One pattern in many disguises.
  9. If your basics feel shaky: F1 (metrics, losses, overfitting) and F2 (attention, parameter counting) before anything else. Interviews start there.
  10. For interview loops: part 12 (system design) and the part 13 bank. Practice answering aloud.

How to use this guide

  • Every topic section follows the same order: intuition, mechanism with a diagram, formulas, a worked numeric example, traps, sample questions, self-check. Skim the intuition, then do the worked example yourself on paper before reading the steps.
  • Click Mark as done at the end of each section. The bars above and the parts menu update.
  • Answers you check in sample questions and the practice quiz feed the weak-areas box.
  • Every topic page ends with leveled interview questions. All of them are collected in the interview bank.
  • Shortcuts: / search, t theme, j/k next/previous section, ? help.
  • All Python lives in solutions/. Run python3 solutions/run_all.py from this folder to execute every test and recompute every number.

Facts that depend on a library version, a provider, or a GPU SKU are flagged as such in the text. GPU numbers are approximate vendor figures.
